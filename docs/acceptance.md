# 验收标准

每个实验室上线前逐条检查。有一条不通过就不上线。

规范正文在 [`lab-standard.md`](lab-standard.md)，审核步骤在 [`review-checklist.md`](review-checklist.md)；这张表是上线前的总清单。

## 四条硬要求（2026-11-18 定）

1. **三维效果以 WeduLab 为基准**：材质、光影、水和玻璃的质感不能低于它的同类实验。
2. **操作统一、好上手、支持触摸屏**：所有实验用同一套操作条；能直接拖动场景里的物体；可点区域不小于 44 像素。
3. **原理文字默认隐藏**：界面上只有一句概念和任务，原理讲解点开才出现。
4. **突出关键参数**：这一课涉及的参数（如 ρ液、V排、g）要有专门的显示区，数值变化时能一眼看到。

## 1. 内容

- [ ] 对上教材的具体章节，规格卡里写明
- [ ] 每课有一句核心概念（不超过 20 个字）
- [ ] 每课有 3 到 5 条任务，写成要做的动作
- [ ] 每课有对应的读数，和公式一一对应
- [ ] 小测覆盖每一课，另有迁移题
- [ ] 界面上没有大段文字；原理讲解默认隐藏，点开才显示
- [ ] 这一课的关键参数有专门的显示区，和公式对应

## 2. 正确性

- [ ] 计算写成独立函数，用课本例题或标准数据核对过
- [ ] 画面、读数、图表、小测配图出自同一套计算
- [ ] 数据来源记录在规格卡里
- [ ] 示意性的内容在画面上标明"示意"
- [ ] 用词和教材一致

## 3. 画面

- [ ] 规格卡里"视觉映射"的每一行都做出来了
- [ ] 立体的内容用三维表现，材质和光影不低于 WeduLab 的同类实验（并排截图对比）
- [ ] 每课镜头正对这一课要看的东西
- [ ] 画面里的字不小于 16 像素，投屏后排看得清
- [ ] 没有和知识点无关的装饰

## 4. 交互

- [ ] 任务完成自动打勾，并给出一句结论
- [ ] 每课可以重做
- [ ] 操作不对时有提示，告诉学生下一步做什么
- [ ] 操作都在统一的底部操作条里，控件样式和位置各课一致
- [ ] 场景里的主要物体可以直接拖动；触摸屏上单指可完成全部操作
- [ ] 可点区域不小于 44 像素
- [ ] 键盘：↑↓ 对应主要的升降或增减，空格对应主按钮
- [ ] 进度记在本地，刷新后还在

## 5. 外壳统一

- [ ] 课程卡、面板、按钮、滑块用 `DESIGN.md` 规定的组件
- [ ] 配色、字号、圆角符合规范
- [ ] 和首页是同一种风格

## 6. 性能与适配

- [ ] 普通笔记本（集成显卡）上流畅
- [ ] 1366×768 投屏显示完整，不出现滚动条
- [ ] 手机竖屏至少能看、能切换课
- [ ] 首次打开 3 秒内可操作
- [ ] 系统开启"减少动态效果"时不出问题

## 7. 上架物料

- [ ] 封面线稿（按 `DESIGN.md` 第 8 节的画法）
- [ ] 一段说明文字、3 到 4 个知识点标签
- [ ] 首页卡片的课数、教材位置和实际一致
