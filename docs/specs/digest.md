# 消化和吸收实验室 · 规格卡 v1.0

状态：九个课次已做完，待验收。关联议题 #29。

## 总览

- 一句话：跟着一口馒头走一遍消化道，弄懂食物在消化道里经历了什么、营养在哪里被吸收。
- 教材位置：人教版生物学七年级下册，第四单元 生物圈中的人，第二章 人体的营养（第一节 食物中的营养物质；第二节 消化和吸收；第三节 合理营养与食品安全）。章节号按 2012 版教材写，2024 年新版的单元号见“待核实事项”。
- 主线：三类大分子营养物质（淀粉、蛋白质、脂肪）从进口腔到被吸收，每一段发生了什么。
- 场景：一座科学馆的“人体的营养”展厅（暗场，自己打光）。1 个单位 = 10 cm。

## 第 1 课 食物中的营养物质

在实验台上用三个小实验，认出食物里的淀粉、脂肪和蛋白质。

| 项目 | 内容 |
|---|---|
| 知识点 | 食物中有糖类、脂肪、蛋白质、水、无机盐、维生素六类营养物质；前三类能供能 |
| 一句概念 | 食物里含有六类营养物质 |
| 核心动作 | 往馒头上滴碘液；把花生在白纸上挤压；把纱布包着的面团放在清水里揉洗 |
| 看到的现象 | 馒头变蓝；白纸上留下透亮的油斑；清水变白、纱布里剩下黄白色有黏性的面筋 |
| 读数 | 检出的三种营养物质；面板上六类营养物质，哪三类能供能 |
| 真实锚点 | 馒头、花生、面粉，都是天天吃的东西 |
| 对应小测 | 第 1 题 |

任务清单

- [ ] 往馒头上滴碘液（淀粉遇碘变蓝）
- [ ] 把花生放在白纸上挤压（留下油斑：有脂肪）
- [ ] 把面团包在纱布里，在清水里揉洗（剩下面筋：主要是蛋白质）

视觉映射

| 知识点 | 必须看见的东西 | 由哪个量驱动 | 镜头与视图 |
|---|---|---|---|
| 淀粉遇碘变蓝 | 切开的馒头面上一块蓝黑色慢慢洇开 | 滴碘液的进度 | 实验台左半边，斜俯视 |
| 脂肪 | 花生被压扁，白纸上一圈半透明的油斑 | 挤压的进度 | 同上 |
| 蛋白质 | 烧杯里的水变成乳白，纱布里的面团缩小、变黄 | 揉洗的进度 | 同上 |

主操作区的按钮：滴碘液、挤压花生、揉洗面团。

数据：无数值读数，只有现象。

## 第 3 课 口腔里的消化

教材里的探究“馒头在口腔中的变化”。

| 项目 | 内容 |
|---|---|
| 知识点 | 唾液中的唾液淀粉酶能把淀粉分解成麦芽糖；牙齿的咀嚼、舌的搅拌帮助消化；温度太低时酶不起作用 |
| 一句概念 | 唾液淀粉酶把淀粉分解成麦芽糖 |
| 核心动作 | 三支试管放进 37 ℃ 温水保温；各滴 2 滴碘液；换成 0 ℃ 冰水重做 |
| 看到的现象 | 1 号（馒头碎屑 + 唾液，搅拌）不变蓝；2 号（馒头碎屑 + 清水，搅拌）变蓝；3 号（馒头块 + 唾液，不搅拌）部分变蓝。冰水里三支都变蓝 |
| 读数 | 水温、保温时间，三支试管的颜色 |
| 对应小测 | 第 3 题 |

任务清单

- [ ] 把三支试管放进 37 ℃ 的温水里保温 10 分钟
- [ ] 各滴 2 滴碘液，找出不变蓝的那支
- [ ] 换成 0 ℃ 的冰水，重做一遍

主操作区的按钮：放进水里保温、滴加碘液。分段选择：水温 37 ℃ / 0 ℃。

数据

| 条件 | 读数 | 来历 |
|---|---|---|
| 37 ℃，10 分钟 | 1 号不变蓝、2 号变蓝、3 号部分变蓝 | 教材 |
| 0 ℃，10 分钟 | 三支都变蓝 | 酶在低温下几乎不起作用（教材“温度对唾液淀粉酶的影响”） |

简化：`starchLeft` 是一级反应的示意模型，只用来决定颜色，不显示数值。保温 10 分钟在画面里用 6 秒走完，面板上的时钟按 10 分钟走。

## 第 4 课 胃里的消化

| 项目 | 内容 |
|---|---|
| 知识点 | 胃壁有发达的肌肉层，能蠕动；胃腺分泌胃液，胃液含盐酸和胃蛋白酶，能把蛋白质初步分解；胃里淀粉、脂肪基本不被消化 |
| 一句概念 | 胃液把蛋白质初步分解 |
| 核心动作 | 剖开胃；让胃蠕动（同时分泌胃液）；打开幽门 |
| 看到的现象 | 胃壁内的皱襞；一道道收缩波从胃体向幽门推，食物块变小、变成糊状的食糜；幽门开一下，食糜一小股进入十二指肠 |
| 读数 | 面板上三类物质的状态（示意条） |
| 对应小测 | 第 4 题 |

任务清单

- [ ] 剖开胃，看胃壁上的皱襞
- [ ] 让胃蠕动：食物和胃液混合，蛋白质被初步分解
- [ ] 打开幽门，食糜一小股一小股进入小肠

主操作区的按钮：剖开胃、胃蠕动、打开幽门。

## 第 5 课 小肠里的消化

| 项目 | 内容 |
|---|---|
| 知识点 | 肝分泌的胆汁（不含消化酶）把脂肪乳化成微粒；胰液、肠液含多种消化酶，把淀粉、蛋白质、脂肪彻底分解成葡萄糖、氨基酸、甘油和脂肪酸 |
| 一句概念 | 小肠是消化的主要场所 |
| 核心动作 | 加入胆汁；加入胰液和肠液；逐个看最终产物 |
| 看到的现象 | 大的脂肪滴碎成许多小微粒；长链的淀粉、折叠的蛋白质散成一个个小单位；脂肪微粒变成甘油和脂肪酸 |
| 读数 | 三类物质的最终产物 |
| 对应小测 | 第 5、6 题 |

任务清单

- [ ] 加入胆汁，看脂肪的变化
- [ ] 加入胰液和肠液
- [ ] 找到淀粉的最终产物：葡萄糖
- [ ] 找到蛋白质的最终产物：氨基酸
- [ ] 找到脂肪的最终产物：甘油和脂肪酸

主操作区的按钮：加入胆汁、加入胰液和肠液、看下一种产物。

简化：分子画成小球、小六边形、短棒，大小和个数都是示意，界面标“示意”。

## 第 6 课 吸收

| 项目 | 内容 |
|---|---|
| 知识点 | 小肠是吸收的主要器官：内表面有环形皱襞，皱襞上有小肠绒毛，绒毛壁和毛细血管壁都只有一层上皮细胞；葡萄糖、氨基酸进入毛细血管，大部分脂肪成分进入毛细淋巴管。胃吸收少量的水和酒精；大肠吸收少量的水、无机盐和部分维生素 |
| 一句概念 | 小肠是吸收的主要器官 |
| 核心动作 | 剖开小肠；放大一根绒毛；让营养被吸收；比一比胃和大肠 |
| 看到的现象 | 内壁上一圈圈的皱襞，铺满细小的绒毛；绒毛里的毛细血管网和中间的毛细淋巴管；小分子穿过绒毛壁进到管里被带走 |
| 读数 | 各部位吸收什么（面板） |
| 对应小测 | 第 7 题 |

任务清单

- [ ] 剖开小肠，看环形皱襞和小肠绒毛
- [ ] 放大一根绒毛，看里面的毛细血管和毛细淋巴管
- [ ] 让营养物质被吸收
- [ ] 看胃能吸收什么
- [ ] 看大肠能吸收什么

主操作区的按钮：剖开小肠、放大绒毛、吸收营养。分段选择：部位 小肠 / 胃 / 大肠。

## 第 7 课 合理营养与食品安全

|---|---|---|---|

| 6 | 蛋白质的最终产物 | 5 | 是氨基酸，不是多肽 |
| 7 | 只能吸收少量水和酒精的器官 | 6 | 胃也能吸收一点 |
| 8 | 平衡膳食宝塔最底层 | 7 | 谷薯类吃得最多 |

## 讲解

- 第 3 课：讲清三支试管各少了什么条件，1 号和 2 号对照的是“有没有唾液”。
- 第 5 课：胆汁乳化是把大滴变成小滴，没有变成别的物质。
- 第 6 课：葡萄糖、氨基酸进毛细血管，大部分脂肪成分进毛细淋巴管。

## 和规格卡原文的出入

- 骨架里的“示例课”换成七课 + 拓展 + 随堂检测。
