# 合成氨工厂实验室 · 规格卡 v1.0

状态：已做完九个课次，待审。议题 #25。

## 总览

- 一句话：在一座合成氨化肥厂里弄懂化学反应速率、化学平衡和勒夏特列原理，最后用它们解释合成氨工业为什么选这些条件。
- 教材位置：人教版高中化学 选择性必修 1《化学反应原理》第二章 化学反应速率与化学平衡（第一节 化学反应速率、第二节 化学平衡、第四节 化学反应的调控）。第三节 化学反应的方向不在本实验室。
- 主线：N₂ + 3H₂ ⇌ 2NH₃（正反应放热）。同一个反应贯穿速率、平衡、平衡常数和工业条件；勒夏特列原理的冷热、加压对比用课本上的 NO₂ / N₂O₄ 实验做。
- 场景：一座化肥厂。西头是中控化验楼（一层敞开的门脸，西半是化验室、东半是中控室，中间一道玻璃隔断）；往东是合成区（合成气压缩机厂房、合成塔、水冷器、氨冷器、氨分离器、循环压缩机，一条管廊把它们连起来）；再往东是氨罐区和尿素造粒塔；远处是冷却塔、火炬和别的厂房。
- 大场景的布局（x 向东，单位 m）：化验室 x −60…−38（第 1、2 课在 x = −54 的高压反应釜，第 5 课在 x = −44 的平衡球和注射器）；中控室 x −36…−22（第 4 课的大屏在后墙 x = −29）；合成塔在 (20, −6)，压缩机厂房在 x ≈ −2，氨分离器和循环压缩机在 x ≈ 34…40（第 3、6、7 课）；氨罐在 x ≈ 70，造粒塔在 x ≈ 92（拓展课）；随堂检测是全厂鸟瞰。
- 取值约定：浓度 mol/L，速率 mol/(L·min)，温度 °C，压强 MPa；R = 8.314 J/(mol·K)。第 1–4 课的合成氨反应在一个“示意温度”下进行，平衡常数取 K ≈ 0.59（由起始 1 mol/L N₂、3 mol/L H₂ 平衡时转化一半定出），界面上标“示意”。
- 分子模型：比例模型（原子是互相嵌进去的球），全实验室统一：N 蓝色、H 白色、O 红色。
- 和同类产品的区别：一座连续的厂区，器材都是这座厂里真有的东西；合成塔剖开看催化剂床层和换热，分子在催化剂表面正反两个方向同时反应；读数都从同一个计算核心来。

## 共用的计算核心

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `rates(c)` | 三种物质的浓度 | v正、v逆（按 N₂ 计，mol/(L·min)） | v正 = k正·c(N₂)·c³(H₂)，v逆 = k逆·c²(NH₃)，k正/k逆 = K（示意的速率式，只为让平衡常数的形式和课本一致） |
| `run(c0, t)` | 起始浓度、时间 | 各时刻浓度（四阶龙格-库塔积分） | 上式 |
| `Kc(c)` | 平衡浓度 | K = c²(NH₃)/[c(N₂)·c³(H₂)] | 课本定义 |
| `equilibrium(c0)` | 起始浓度 | 平衡浓度（二分法解 Q = K） | 同上 |
| `conversion(c0, c)` | 起始、平衡浓度 | N₂、H₂ 的转化率 | 消耗量 / 起始量 |
| `activeFraction(T, cat)` | 温度、有无催化剂 | 活化分子百分数（示意） | e^(−Ea/RT)，Ea 取示意值 |
| `no2(T, V)` | 温度、体积倍数 | NO₂、N₂O₄ 的浓度 | N₂O₄ ⇌ 2NO₂，25 °C 时 Kp ≈ 0.148，ΔH ≈ +57.2 kJ/mol（范特霍夫式换算到别的温度） |
| `nh3Eq(T, P)` | 温度、压强 | 平衡时氨的体积分数 | 课本的数据表（H₂ : N₂ = 3 : 1）插值：温度按 logit 线性插，压强按对数插 |
| `nh3Out(T, P)` | 温度、压强 | 出塔气中氨的体积分数（示意） | 平衡氨含量 × (1 − e^(−kτ))，k 按 Ea = 80 kJ/mol 的阿伦尼乌斯式，kτ(500 °C, 20 MPa) = 1.5，和压强成正比 |
| `passConv(y)` | 出塔氨含量 | 单程转化率 | 4 体积原料转化 ξ：y = 2ξ/(4 − 2ξ) |
| `loopUse(α, n)` | 单程转化率、循环次数 | 原料累计利用率 | 1 − (1 − α)ⁿ（不计放空） |
| `ureaFromNH3(m)` | 氨的质量 | 尿素的质量 | 2NH₃ + CO₂ = CO(NH₂)₂ + H₂O，60.06 / (2 × 17.03) |

## 第 1 课 化学反应速率

在化验室的小型高压反应釜里充入 N₂ 和 H₂，墙上的屏幕画浓度-时间曲线。

| 项目 | 内容 |
|---|---|
| 知识点 | 化学反应速率用单位时间内浓度的变化表示；同一反应用不同物质表示，速率之比等于化学计量数之比 |
| 一句概念 | 速率是单位时间里浓度的变化 |
| 核心动作 | 开始反应 → 2 min 时记下浓度 → 算三种速率 |
| 看到的现象 | 压力表指针慢慢回落；屏幕上 N₂、H₂ 两条线往下走、NH₃ 往上走 |
| 读数 | 2 min 时 c(N₂) 0.80、c(H₂) 2.40、c(NH₃) 0.40 mol/L；v(N₂) 0.10、v(H₂) 0.30、v(NH₃) 0.20 mol/(L·min) |
| 真实锚点 | 化肥厂化验室用小型高压釜评价催化剂 |
| 对应小测 | 第 1 题 |

任务：开始反应；2 min 时记下三种物质的浓度；算出三种速率并比较。

主操作区：开始反应、记录 2 min 的浓度、算速率。

数据：k正 由“2 min 时 c(N₂) 降到 0.80 mol/L”定出（示意）。

## 第 2 课 影响化学反应速率的因素

镜头推近反应釜，旁边一个放大窗里是釜里的分子：蓝色的 N₂、白色的 H₂，能量够高的活化分子带一圈橙色的光，发生有效碰撞时闪一下。

| 项目 | 内容 |
|---|---|
| 知识点 | 浓度增大：单位体积活化分子数增多；温度升高：活化分子百分数增大；催化剂：降低活化能，活化分子百分数增大 |
| 一句概念 | 活化分子越多，有效碰撞越多，反应越快 |
| 核心动作 | 分段选择换条件（原来、浓度加倍、升到 500 °C、加铁催化剂），各测 10 s |
| 读数 | 单位体积分子数、活化分子百分数、单位体积活化分子数、10 s 内有效碰撞次数 |
| 对应小测 | 第 2 题 |

数据（全部示意）：原来 400 °C、无催化剂时 Ea/RT = 2.3，活化分子百分数 e^(−2.3) ≈ 10%；升到 500 °C 约 13.5%；加铁催化剂 Ea 降到原来的 60%，约 25%。浓度加倍，分子数加倍、百分数不变。有效碰撞次数和单位体积活化分子数成正比，原来 10 s 6 次。

## 第 3 课 化学平衡状态

合成塔朝镜头剖开：厚壁的承压外筒、内件、两层催化剂床、床间和底部的换热器。旁边的放大窗是催化剂表面：N₂ 和 H₂ 吸附上去生成 NH₃（正反应），NH₃ 也会分解回去（逆反应）。面板上两条速率曲线，平衡时重合。

| 项目 | 内容 |
|---|---|
| 知识点 | 可逆反应；化学平衡状态：v正 = v逆 ≠ 0，各组分浓度保持不变；从正反应或逆反应开始都能达到同一平衡 |
| 一句概念 | 正逆反应速率相等，浓度就不再变 |
| 核心动作 | 通入原料气，看 v正 减小、v逆 增大到相等；换成“只有氨”再做一遍 |
| 读数 | v正、v逆、三种物质的浓度、正逆反应计数 |
| 对应小测 | 第 3 题 |

数据：起始 1、3、0 mol/L，平衡 0.50、1.50、1.00 mol/L；起始只有 2.00 mol/L NH₃，平衡相同。

## 第 4 课 化学平衡常数

中控室的大屏上同时画三组实验的浓度-时间曲线，各做到平衡，表里自动记下平衡浓度、K 和转化率。

| 项目 | 内容 |
|---|---|
| 知识点 | K = c²(NH₃)/[c(N₂)·c³(H₂)]；同一温度下 K 不随起始浓度变；转化率 |
| 一句概念 | 温度一定，K 就是一个定值 |
| 核心动作 | 分段选择第一、二、三组，各按一次“开始” |
| 读数 | 三组的平衡浓度、K、N₂ 和 H₂ 的转化率 |
| 对应小测 | 第 4 题 |

三组起始浓度（mol/L）：一 1、3、0；二 2、3、0（N₂ 加倍）；三 1、3、1（一开始就有氨）。三组 K 都约 0.59；转化率：第一组 N₂、H₂ 都是 50%；第二组 N₂ 30%、H₂ 60%；第三组都约 35%。

## 第 5 课 影响化学平衡的因素

化验台上做课本的两个实验：两只用弯玻璃管连通、塞着橡胶塞的圆底烧瓶（NO₂ 平衡球），一只放进热水、一只放进冰水；一支装着 NO₂ 的注射器，推、拉活塞。2NO₂（红棕色）⇌ N₂O₄（无色），正反应放热。

| 项目 | 内容 |
|---|---|
| 知识点 | 升温平衡向吸热方向移动；加压平衡向气体分子数减小的方向移动；勒夏特列原理 |
| 一句概念 | 平衡朝着减弱这种改变的方向移动 |
| 核心动作 | 放进热水和冰水；推活塞（体积减半）；拉活塞（体积加倍） |
| 看到的现象 | 热水里的泡颜色变深、冰水里的变浅；推活塞颜色先变深、又变浅一些，但比原来深；拉活塞先变浅、又变深一些 |
| 读数 | 各处 c(NO₂) 和原来的比值（颜色深浅和它成正比） |
| 对应小测 | 第 5、6 题 |

数据（约）：25 °C、总压约 100 kPa 时 N₂O₄ 的分解度约 0.19（由 Kp ≈ 0.148 算）；热水按 80 °C、冰水按 0 °C、容积不变算，NO₂ 浓度约是原来的 3.5 倍和 0.4 倍；注射器按 25 °C 等温算，体积减半时先变成 2 倍、新平衡约 1.46 倍，再拉回原体积时先变成约 0.73 倍、最后回到 1 倍。

## 第 6 课 合成氨的适宜条件

合成塔整座外观，剖面上标进出口温度；面板画两条曲线：平衡时的氨含量（随温度升高而降低）、出塔气的氨含量（先升后降）。

| 项目 | 内容 |
|---|---|
| 知识点 | 低温有利于平衡、却太慢；高温快、平衡氨含量低；400–500 °C 兼顾速率和平衡、催化剂活性；加压对速率和平衡都有利，但受设备和能耗限制，一般 10–30 MPa |
| 一句概念 | 选条件要兼顾速率和平衡 |
| 核心动作 | 分段选择 300、400、500、600 °C；加压到 30 MPa |
| 读数 | 平衡时氨的含量（课本数据表）、出塔氨含量（示意） |
| 对应小测 | 第 7 题 |

数据：20 MPa 时平衡氨含量 300 °C 64.2%、400 °C 38.2%、500 °C 19.1%、600 °C 9.1%；30 MPa、500 °C 26.4%。出塔氨含量按上面的示意式算：20 MPa 时约 1.2%、8.0%、14.8%、9.1%；30 MPa、500 °C 时约 23.6%。

## 第 7 课 分离氨和循环

镜头拉远看整个合成回路：合成气压缩机 → 合成塔 → 水冷器、氨冷器 → 氨分离器 → 循环压缩机 → 回到合成塔。管道里的气流用颜色区分（原料气、含氨的气、液氨）。

| 项目 | 内容 |
|---|---|
| 知识点 | 及时把氨冷凝分离出去，降低生成物浓度，平衡正向移动；未反应的 N₂、H₂ 循环使用，提高原料利用率 |
| 一句概念 | 分离出氨、气体循环，原料几乎都能用上 |
| 核心动作 | 开车；冷凝分离氨；循环 |
| 读数 | 出塔氨含量、单程转化率、循环次数、原料累计利用率 |
| 对应小测 | 第 8 题 |

数据（示意）：500 °C、20 MPa 出塔氨含量约 14.8%，单程转化率约 26%；循环 11 次累计利用率超过 95%（不计放空）。

## 讲解

- 第 3 课要讲清楚：平衡时正逆反应都还在进行，只是速度相等，所以“动态平衡”。
- 第 5 课推活塞要讲清楚“先变深是因为体积变小、浓度变大；再变浅是平衡移动；最后仍比原来深”。
- 数字按读法念：0.10 mol/(L·min) 念“0.1 摩尔每升每分钟”，NH₃ 念“氨”，N₂ 念“氮气”。

## 和规格卡原文的出入

- 第 5 课没有用分段选择，三个按钮（放进热水和冰水、推活塞、拉活塞）就够了；“拉活塞”是从压缩后的状态拉回原体积。
- 第 2 课的显示器不显示（放大窗挡在它前面），只在第 1 课用来画曲线。
- 第 7 课循环圈数：按单程约 26% 算，11 圈累计利用率才超过 95%（原写“10 次约 95%”）。
- 第 5 课机位分三段：先推近两只烧瓶，做完冷热对比推到注射器，全部做完拉远看全。
- 第 3 课机位后退、斜一点，整座剖开的塔和放大窗都在画面里。
- 拓展课的造粒塔画成圆筒形混凝土塔，塔前面画了一串下落的颗粒（示意塔内的情形）。
