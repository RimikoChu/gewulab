# 洋流和厄尔尼诺实验室 · 规格卡 v0.1

状态：待审。关联议题 #80。

## 总览

- 一句话：让学生弄懂洋流是怎么形成的、世界洋流怎样分布，以及洋流对气候、渔场、航行和污染的影响；最后弄懂厄尔尼诺和拉尼娜。
- 教材位置：人教版高中地理 选择性必修 1《自然地理基础》，“水的运动”一章中“洋流”一节和“海—气相互作用”一节（章节号待核实）。
- 主线：同一颗地球上的海水。先看海面上的洋流怎样流，再沿某条纬线把地球切开，看海面以下的海水（海峡两层水、上升流、温跃层）。
- 场景：太空里的一颗大地球（NASA 实拍影像 `earth_day.jpg`、水陆和夜灯 `earth_aux.jpg`，和大气环流、地球的运动用的是同两张），远处是太阳和星空。
  **大场景的布局**：整个实验室只有这颗地球，各课是地球上的不同海区，换课时镜头绕着地球飞过去：
  - 第 1 课：北太平洋（风海流）→ 直布罗陀海峡（沿 36°N 切开）→ 秘鲁沿岸（沿 12°S 切开）；
  - 第 2 课：北太平洋、南太平洋、北大西洋、南大西洋，镜头在每个环流中心的正上方；
  - 第 3 课：北太平洋北部、南极上空、北印度洋；
  - 第 4 课：大西洋两岸 → 西欧 → 秘鲁；
  - 第 5 课：北海道、纽芬兰、北海、秘鲁四个渔场，海面上有围网渔船；
  - 第 6 课：东海外的日本暖流，远洋科考船投放漂流浮标、顺流逆流航行、溢油；
  - 第 7 课：赤道太平洋，沿赤道把南半球整块切掉，从下方正对赤道上的剖面看，西边是印度尼西亚、东边是南美沿岸，和地图方向一致；
  - 拓展：北太平洋环流中心（垃圾带）、格陵兰到纽芬兰（冰山）；
  - 随堂检测：北海道外海，寒暖流交汇处的渔船和停在日本暖流上的科考船。
  切开时，切面从南极慢慢升到要切的纬度，切掉的那一块消失，剖面上最外一圈是海水，里面是岩石。
- 取值约定：经度东经为正；海水密度 ρ = 1027 × [1 − 1.7×10⁻⁴(T − 10) + 7.6×10⁻⁴(S − 35)] kg/m³（线性近似）；1 m/s = 3.6 km/h。
- 示意的简化（界面上标“示意”或“约”）：剖面上海水那一层的厚度放大了几千倍；表层水温是一个简化模型（同纬度平均 28 − 30 sin²φ °C，暖流、寒流附近 ±4 °C）；温跃层深度、海温距平、渔获指数、垃圾聚拢快慢、冰山融化纬度都是示意；船、浮标、冰山放大画了很多倍。
- 和同类产品的区别：所有课在同一颗真实影像的地球上；看水下一律把地球切开，剖面朝镜头，不从上方透过海面看。

## 第 1 课 洋流的成因

三处地方看三种成因。

| 项目 | 内容 |
|---|---|
| 知识点 | 风海流（最主要）、密度流、补偿流（水平的、垂直的上升流） |
| 一句概念 | 盛行风是洋流最主要的动力 |
| 核心动作 | 北太平洋：吹起盛行风；海峡：让海水流动；秘鲁：吹起离岸风 |
| 看到的现象 | 白色风箭头后面，红色洋流箭头跟着流；海峡剖面上表层向东、底层向西翻过海槛；秘鲁剖面上表层水被吹离海岸，冷水从下面升上来，温跃层在近岸抬高 |
| 读数 | 地中海一侧密度约 1029.1 kg/m³，大西洋一侧约 1026.9 kg/m³ |
| 真实锚点 | 直布罗陀海峡的两层水交换；秘鲁沿岸上升流 |
| 对应小测 | 第 1、2 题 |

任务清单

- [ ] 北太平洋：吹起盛行风，记下洋流方向
- [ ] 直布罗陀海峡：让两边的海水流动
- [ ] 秘鲁沿岸：吹起离岸风

主操作区：动作按钮（随地方换成“吹起盛行风 / 让海水流动 / 吹起离岸风”）、记录成因。分段选择：地方。

## 讲解

解说词在 `src/labs/ocean/narration.ts`。要讲清楚的：第 1、7 课切开地球时先说“沿哪条纬线切开、海水那一层放大了”；第 7 课说清“西边是印度尼西亚、东边是南美”，信风减弱时先说暖水往哪走，再说秘鲁沿岸的上升流、渔获和降水。

## 和规格卡原文的出入

- 骨架里的示例课已删除。
- 第 4 课的海面着色改成“比同纬度暖多少、冷多少”（距平），不画绝对水温：绝对水温赤道红、两极蓝，盖住了洋流的影响。赤道附近东西向的几条洋流不计入距平。
- 剖面一律切掉南边、从下方看，这样东在右、西在左，和地图方向一致。
