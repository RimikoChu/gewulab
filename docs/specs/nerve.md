# 神经调节实验室 · 规格卡 v0.1

状态：九个课次（1–7、拓展、随堂检测）按这张卡做完（2026-11-25），九课都能自动演示到结论条，待验收。关联议题 #32。

## 总览

- **一句话**：学生在一座“人体神经系统”展馆里，先认出神经系统的三部分和神经元，再让一只手去碰热水杯、给坐着的人叩膝盖、让他吃梅子看梅子，看冲动沿反射弧走一圈；然后推近到放大的眼球和耳里，跟着光线和声波走到视网膜、耳蜗，再沿神经到大脑；最后认大脑、小脑、脑干，用尺子测自己的反应时间。
- **教材位置**：生物，初中七年级下册，人教版“人体生命活动的调节”一章：人体对外界环境的感知（眼和视觉、耳和听觉）；神经系统的组成；神经调节的基本方式。准确的单元号、章号、节名，以及 2024 年新版教材是否调整了这一章，见“待核实事项”。
- **主线**：一个信号“从指尖到大脑”。第 1 课从脚尖传一个信号到脑；第 2 课放大到一个神经元；第 3、4 课是反射弧；第 5、6 课是眼和耳把光和声变成冲动；第 7 课是脑，加上一次真实的测量；拓展课把这些串成“接住一个球”。
- **场景**：议题建议“人体内部：从指尖到大脑”。这里放进一座科学馆的展馆：正中一个半透明的人坐在高凳上，身体里亮着脑、脊髓和全身的神经；四周悬着放大的脑、神经元、眼球、耳，两张展台上各有一只从展板圆孔里伸出来的手臂。**理由**：神经元、脊髓切面、眼球剖面、耳剖面都要放大几十倍才看得清，放不进“真的人体内部”；放进一座展馆，所有课仍在同一个连续的世界里，镜头可以从人的膝盖飞到他头顶的脑，再飞到旁边的眼球。
- **取值约定**：
  - 画面里 1 个单位是 10 cm；放大的模型另有放大倍数（神经元很多很多倍、脊髓约 20 倍、眼球 25 倍、耳约 15 倍、脑约 3.4 倍），都标“示意”。
  - g 取 9.8 N/kg（第 7 课尺子下落）。
  - 神经冲动的颜色：传入的冲动青色，传出的指令金黄色，往大脑上传的淡紫色。全实验室统一。冲动的速度都放慢了。
- **和同类产品的区别**：同类产品多是平面的反射弧示意图加连线题。这里学生自己让手碰热水杯、自己剪断传入或传出神经再碰一次，看“手缩不缩、觉不觉得烫”两件事分开发生；看得见冲动从指尖一路走到脊髓切面上的灰质，再回到上臂；眼和耳是剖开的立体模型，光线和声波在里面一步一步走；第 7 课测的是学生自己的真实反应时间。

## 画面上的约定

- **神经**：人体里的神经画成淡黄白色、微微发光的线，只画主要的几条，粗细加粗了；中枢、周围两部分分色时，脑和脊髓是青色，神经是金黄色。
- **冲动**：一个发光的光点拖着光尾，走过的那一截神经一直亮着；在手臂、腿里面的神经是透过皮肤“透视”画出来的。
- **放大模型**都罩在淡蓝的球壳里，一根细线连回人体上的那一处（脑连头顶，眼连左眼，耳连左耳）。
- **脊髓切面**：切面上蝴蝶形的是灰质（神经元的细胞体集中的地方，反射的神经中枢），外面一圈是白质；左右各伸出背根（带神经节，传入）和腹根（传出），汇成脊神经。界面和讲解里不出现“背根”“腹根”，只说“传入神经进入脊髓的那一段”“传出神经离开脊髓的那一段”。
- **眼球**：沿光轴剖开一半；虹膜的内圈就是瞳孔，随强光变小；近视眼时晶状体后面整体往后拉长。
- **耳**：一块剖开的颞骨，耳廓画小了；耳蜗是两圈多的螺旋管，半规管是三个互相垂直的环。
- **手臂**：从展板圆孔里伸出来，卷起的衬衫袖子，真实肤色的皮肤（指节、指尖红润一点，指甲有光泽）。缩手时前臂绕肘往上抬，整只手往回收。
- **坐着的人**：叩膝时只让右小腿绕膝盖往前弹，大腿前面的肌肉亮一下；接球时只让左臂绕肩抬起。

## 第 3 课 反射和反射弧

| 项目 | 内容 |
|---|---|
| 知识点 | 反射；反射弧由感受器、传入神经、神经中枢、传出神经、效应器组成；缩手反射的中枢在脊髓；任何一环断了反射不能完成；觉得烫是冲动上传到大脑 |
| 一句概念 | 反射要通过反射弧才能完成 |
| 核心动作 | 认一认反射弧；手指碰一下热水杯；剪断传入神经再碰；剪断传出神经再碰 |
| 看到的现象 | 五个部分依次亮起；碰杯时冲动从指尖沿手臂里的神经、背根进入脊髓灰质，再从腹根出来回到上臂的肌肉，手往回缩；另一路冲动沿白质往上（去大脑）；剪断处一道红圈，冲动走到那里就停 |
| 读数 | 缩手：缩了 / 没缩；觉得烫：是 / 否 |
| 真实锚点 | 手碰到烫的东西会先缩回来，然后才感到烫 |
| 对应小测 | 3 |

| 条件 | 缩手 | 觉得烫 | 来历 |
|---|---|---|---|
| 完好 | 缩 | 是（在缩手之后） | 教材 |
| 剪断传入神经 | 不缩 | 否 | 冲动到不了脊髓 |
| 剪断传出神经 | 不缩 | 是 | 冲动到了脊髓，又上传到大脑 |

主操作区的按钮：认一认反射弧、碰一下热水杯。分段选择：完好 / 剪断传入神经 / 剪断传出神经。

## 第 4 课 简单反射和复杂反射

| 项目 | 内容 |

## 第 5 课 眼和视觉

| 项目 | 内容 |
|---|---|
| 知识点 | 眼球的结构；物像落在视网膜上，冲动经视神经传到大脑皮层的视觉中枢形成视觉；近视的原因和凹透镜矫正；瞳孔遇强光缩小 |
| 一句概念 | 像落在视网膜上，视觉在大脑形成 |
| 核心动作 | 正常眼看远处的树；跟着冲动到大脑；换近视眼再看；戴凹透镜；强光照眼 |
| 看到的现象 | 光线从树梢、树根各三条，穿过瞳孔会聚，在视网膜上成一棵倒立的小树；冲动沿视神经出眼球，连回人体左眼、到大脑后部的视觉中枢；近视眼拉长，光线会聚在视网膜前方，视网膜上是模糊的一片；戴上凹透镜像落回；强光下瞳孔缩小 |
| 读数 | 像落在视网膜上 / 前；清楚 / 模糊；眼镜；瞳孔；近视眼的远点和矫正度数（示意） |

| 近视眼（眼轴 2.5 cm）看远处 | 像落在视网膜前约 1.0 mm；远点约 0.6 m | 透镜公式算出 |
| 戴凹透镜 | −1.67 D，约 175 度 | 1/0.025 − 1/0.024；度数 = 屈光度 × 100，取到 25 的整数倍 |

主操作区的按钮：看远处的树、戴上凹透镜、强光照眼睛。分段选择：正常眼 / 近视眼。

## 第 6 课 耳和听觉

| 项目 | 内容 |
|---|---|
| 知识点 | 耳的结构；声波 → 外耳道 → 鼓膜 → 听小骨 → 耳蜗 → 听觉神经 → 大脑皮层的听觉中枢；遇巨响张口，咽鼓管张开，鼓膜两侧气压平衡 |
| 一句概念 | 耳蜗产生冲动，听觉在大脑形成 |
| 核心动作 | 放出声音，跟着走一遍；闭着嘴来一声巨响；张开口再来一声 |
| 看到的现象 | 声波一圈圈从音箱走进外耳道；鼓膜、听小骨振动；耳蜗亮起；冲动沿听觉神经连回人体左耳、到听觉中枢；巨响时鼓膜被压进去，张口时咽鼓管里亮起一股气流，鼓膜几乎不动 |
| 读数 | 声音走到了哪一站；鼓膜被压进去多少（相对条，示意） |
| 对应小测 | 8 |

主操作区的按钮：放出声音、来一声巨响。分段选择：闭着嘴 / 张开口。

## 第 7 课 大脑、小脑、脑干

| 项目 | 内容 |
|---|---|
| 知识点 | 大脑皮层是最高级中枢，有运动、感觉、语言、视觉、听觉等功能区；小脑协调运动、维持平衡；脑干调节心跳、呼吸、血压；测反应时间 |
| 一句概念 | 大脑皮层是最高级的神经中枢 |
| 核心动作 | 逐个认大脑、小脑、脑干；按“准备”，尺子随机 1.5–3 s 后落下，看到就按“捏住”（或空格键），测三次 |
| 看到的现象 | 选中的部分亮起，大脑皮层上标出五个功能区；尺子从释放夹里掉下，捏住时手指合上，标出捏住处的刻度 |
| 读数 | 尺子落下的厘米数、反应时间（s）；三次和平均 |

数据：落下 19.6 cm ↔ 0.20 s（h = ½gt²，g = 9.8 N/kg）；落过 50 cm 算没接住。

主操作区的按钮：准备、捏住。分段选择：大脑 / 小脑 / 脑干。

## 讲解

解说词在 `src/labs/nerve/narration.ts`。要特别讲清楚的：第 3 课“先缩手、后觉得烫”和“剪断传出神经仍觉得烫”；第 4 课吃梅（简单）和看梅（复杂）的区别在冲动经没经过大脑皮层；第 5 课“视网膜上是物像，视觉在大脑”。第 3 课“碰一下热水杯”、第 5 课“看远处的树”在课里出现好几次，解说写成每次都说得通的话。

## 和规格卡原文的出入

- 教材里“眼和视觉”“耳和听觉”在“神经系统的组成”之前；这里放在反射之后（第 5、6 课），理由见上。
- 议题建议的拓展“酒驾对反应时间的影响”没有用具体的酒后反应时间（拿不准），改成比较两种假设的反应时间，并在原理里说明酒精使反应变慢。
- 第 4 课的膝跳反射做在展馆正中坐着的人身上（只有右小腿能转），没有另做一条腿的模型：这样冲动从膝盖到脊髓再回来的路线就在他自己的身体里。
