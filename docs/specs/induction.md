状态：已按此卡做完九个课次，待验收。关联议题 #67。

## 总览

- 一句话：从磁通量、感应电流的条件、楞次定律、法拉第电磁感应定律，一直走到发电机、变压器和远距离输电，弄懂“电是怎么从水电站送进家里的”。
- 教材位置：人教版（2019）高中物理选择性必修第二册 第二章“电磁感应”（第 1 节 楞次定律、第 2 节 法拉第电磁感应定律、第 3 节 涡流 电磁阻尼和电磁驱动）、第三章“交变电流”（第 1 节 交变电流、第 2 节 交变电流的描述、第 3 节 变压器、第 4 节 电能的输送）；磁通量和感应电流的条件在必修第三册第十三章（章节号见待核实事项）。
- 主线：一座小水电站发出的电，经升压站、高压输电线、变电站和配电变压器送到城里的住户。
- 场景：一条沿 x 轴展开的连续世界（1 单位 = 1 m）。
  - **大场景的布局**（从西往东）：
    1. 电站培训楼一层的电磁学实验室（x −44 ~ −10）：一排五张实验台，第 1–4 课和拓展课各占一张（x = −38、−32、−26、−20、−14）。
    2. 发电机厂房（x −6 ~ 40）：钢结构厂房，桥式起重机；地面上三台水轮发电机，西头 1 号机（x = 6）的定子机座剖开四分之一，看得见转子磁极和定子线圈（第 5 课）。厂房北面是混凝土重力坝和水库，压力钢管从坝里引到厂房。
    3. 升压站（x 46 ~ 72）：碎石场地、围栏，一台油浸式主变压器（剖开前面的油箱壁，看得见铁芯和绕组；第 6 课），高压套管、出线构架。
    4. 110 kV 输电线（x 80 ~ 280）：四基角钢桁架铁塔，每相一串绝缘子，三相导线和顶上的地线（第 7 课）。
    5. 城郊变电站（x ≈ 300）和城里（x 320 ~ 380）：降压变压器、10 kV 电杆上的配电变压器、几栋住宅楼（第 7 课最后一步镜头飞过去）。
- 取值约定：g = 9.8 N/kg；μ₀ = 4π×10⁻⁷ T·m/A；工频 f = 50 Hz；电压、电流的读数都是有效值（发电机的峰值另标 Em）。
- 和同类产品的区别：七课在同一个连续世界里，从实验台上的线圈一直走到城里的住户；看不见的磁感线、磁通量（穿过线圈的线数）、感应电流（沿导线流动的光点）、电压波形（示波器）全部画出来。

## 共用的计算核心（`src/labs/induction/physics.ts`）

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `helmholtzB()` | N = 200 匝、I = 2.0 A、R = 0.20 m | B ≈ 1.80×10⁻³ T | B = (4/5)^(3/2) μ₀NI/R |
| `flux(θ)` | 线圈转角 | Φ = BS cosθ（Wb） | S = 0.10 m × 0.10 m |
| `linesThrough(θ)` | 线圈转角 | 穿过线圈的磁感线根数（0°：64 根，60°：32 根） | 磁感线按 1.25 cm 一根画 |
| `magnetFlux(d)`、`galvo(d, v)` | 磁铁位置、速度 | 穿过线圈的磁通量（相对值）、电流计偏转 | 示意模型：偏转 ∝ −dΦ/dt |
| `lenz(pole, move)` | 哪一极、插入或拔出 | 感应电流的磁场方向、线圈上端的极性、俯视绕向、斥或吸 | 楞次定律 |
| `cutEmf(v)` | 导体棒速度 | E = BLv | B = 0.50 T，L = 0.10 m |
| `genEmf(φ)` | 转子转过的电角度 | e = Em sinφ | U = 10 kV（约），Em = √2 U |
| `transformer(U₁, n₁:n₂, P)` | 原线圈电压、匝数比、负载功率 | U₂、I₁、I₂ | U₁/U₂ = n₁/n₂，P₁ = P₂ |
| `lineLoss(U)` | 输电电压 | I = P/U、P损 = I²R、到达功率 | P = 11 MW，R = 5 Ω |
| `fallTime(pipe)` | 塑料管或铝管 | 下落时间 | 塑料管：自由落体 t = √(2h/g)；铝管：示意的收尾速度 |

## 第 1 课 磁通量

亥姆霍兹线圈在中间产生一片匀强磁场，转动里面的小线圈，看穿过它的磁感线有多少根。

| 项目 | 内容 |
|---|---|
| 知识点 | 磁通量 Φ = BS⊥ = BS cosθ；线圈平面与磁场垂直时最大，平行时为零；从另一面穿过时为负 |
| 一句概念 | 磁通量就是穿过这个面的磁感线有多少 |
| 核心动作 | 选角度 0°、60°、90°、180°，每个角度记一次 |
| 看到的现象 | 平行的蓝色磁感线，穿过线圈的那些变亮；转角变大，亮的线变少；180° 时从背面穿过 |
| 读数 | B = 1.80×10⁻³ T，S = 1.0×10⁻² m²，Φ（×10⁻⁵ Wb）= 1.80、0.90、0、−1.80；穿过的根数 64、32、0、64 |
| 真实锚点 | 中学实验室常用的亥姆霍兹线圈（半径 20 cm，每只 200 匝） |
| 对应小测 | 第 1 题 |

任务清单

- [ ] 线圈平面和磁场垂直（0°），记一次：Φ = BS
- [ ] 转到 60°，再记：Φ = BS cos60° = BS/2
- [ ] 转到 90°，再记：没有磁感线穿过，Φ = 0
- [ ] 转到 180°，再记：磁感线从背面穿过，Φ = −BS

视觉映射

| 知识点 | 必须看见的东西 | 由哪个量驱动 | 镜头与视图 |
|---|---|---|---|
| 磁通量 | 穿过线圈的磁感线高亮、其余暗 | θ | 从线圈斜前方稍俯视 |

主操作区的按钮：记录数据。分段选择：线圈的角度 0° / 60° / 90° / 180°（线圈匀速转过去）。

## 第 2 课 感应电流的条件

| 项目 | 内容 |
|---|---|
| 知识点 | 穿过闭合导体回路的磁通量发生变化，回路中就产生感应电流 |
| 一句概念 | 磁通量变化，闭合回路里才有感应电流 |
| 核心动作 | 插入磁铁、停在线圈里、拔出、快速插入 |
| 看到的现象 | 插入时指针偏一边，停住回到零，拔出偏另一边，快速插入偏得更大；导线上的光点只在有电流时流动 |
| 读数 | 穿过线圈的磁感线根数（磁铁在外 0 根，插到底 24 根）；电流计偏转（示意，满偏一格为 1） |
| 对应小测 | 第 2 题 |

任务：插入磁铁看指针；磁铁停在线圈里看指针；拔出磁铁；快速插入。按钮：插入磁铁 / 拔出磁铁。分段选择：慢（0.08 m/s）/ 快（0.24 m/s）。读数：慢插时指针最大偏 0.6 格，快插约 1.9 格（满偏 2 格，示意模型）。线圈的漆包线绕组朝前剖开一半，看得见里面的磁感线。

## 第 3 课 楞次定律

| 项目 | 内容 |
|---|---|
| 知识点 | 感应电流的磁场总要阻碍引起感应电流的磁通量的变化（增反减同、来拒去留） |
| 一句概念 | 感应电流的磁场总要阻碍磁通量的变化 |
| 核心动作 | 分段选择 N 极插入 / N 极拔出 / S 极插入 / S 极拔出，按“动磁铁”，表里自动记一行 |
| 看到的现象 | 蓝色是磁铁的磁感线，橙色是感应电流的磁场；线圈上端标出感应出的极性；插入时线圈和磁铁同名极相对（斥），拔出时异名极相对（吸） |
| 读数 | 每行：原磁场方向、磁通量增或减、感应磁场方向、俯视绕向、电流计偏向 |
| 对应小测 | 第 3、4 题 |

## 第 4 课 法拉第电磁感应定律

| 项目 | 内容 |
|---|---|
| 知识点 | E = nΔΦ/Δt；导体棒垂直切割磁感线 E = BLv |
| 一句概念 | 磁通量变化得越快，感应电动势越大 |
| 核心动作 | 以 0.10 m/s 推导体棒；拉回；换 0.20 m/s 再推；停在磁场里 |
| 看到的现象 | 回路围住的磁场面积（淡蓝色）随导体棒变大；毫伏表读数 |
| 读数 | B = 0.50 T，L = 0.10 m：0.10 m/s → 5.0 mV；0.20 m/s → 10.0 mV；停下 0；拉回 −5.0 mV |
| 对应小测 | 第 5 题 |

## 第 5 课 交流发电机

| 项目 | 内容 |
|---|---|
| 知识点 | 中性面（线圈平面与磁场垂直：Φ 最大、e = 0）；e = Em sinωt；有效值 U = Em/√2；T = 0.02 s，f = 50 Hz |
| 一句概念 | 转子转一圈，线圈里的电动势按正弦规律变 |
| 核心动作 | 盘车到中性面、转过四分之一周期、开机 |
| 看到的现象 | 1 号机剖开：转子 16 个磁极（红 N、蓝 S）、定子上高亮的一只线圈、穿过它的磁感线；示波器画出波形 |
| 读数 | U ≈ 10 kV（有效值，取整），Em = 14.1 kV；转速 375 r/min，8 对磁极，f = 8 × 375 / 60 = 50 Hz |
| 真实锚点 | 中小型水电站的发电机，额定转速 375 r/min（同步转速） |
| 对应小测 | 第 6 题 |

画面放慢：开机后约 4 秒一个周期，界面标“画面放慢”。

## 第 6 课 变压器

| 项目 | 内容 |
|---|---|
| 知识点 | U₁/U₂ = n₁/n₂；理想变压器 P₁ = P₂；输入功率由输出功率决定 |
| 一句概念 | 匝数比决定电压比，输入功率等于输出功率 |
| 核心动作 | 合闸（空载）；接上 11 MW 负载；负载减半；断开负载 |
| 看到的现象 | 剖开的油箱里三柱铁芯，中间一柱上内层低压绕组（粗线少匝）、外层高压绕组（细线多匝）；铁芯里交变的磁感线 |
| 读数 | U₁ = 10 kV，n₁:n₂ = 1:11，U₂ = 110 kV；11 MW：I₁ = 1100 A，I₂ = 100 A；5.5 MW：550 A、50 A；空载 I₁ ≈ 0 |
| 对应小测 | 第 7 题 |

## 第 7 课 远距离输电

| 项目 | 内容 |
|---|---|
| 知识点 | 输电功率一定，I = P/U；P损 = I²R；升压输电、到用户处降压 |
| 一句概念 | 电压升高到 n 倍，线路损耗降到 1/n² |
| 核心动作 | 选 10 kV、110 kV、220 kV 各送一次；最后降压送到住户 |
| 看到的现象 | 导线上流动的光点（越密电流越大）；损耗大时导线发红；城里窗户的灯亮度 |
| 读数 | P = 11 MW，R = 5 Ω：10 kV：1100 A、6.05 MW（55%）；110 kV：100 A、50 kW（0.45%）；220 kV：50 A、12.5 kW（0.11%）；降压：110 kV → 10 kV → 0.4 kV，住户 220 V |
| 对应小测 | 第 8、9 题 |

## 讲解

自动演示的解说词在 `src/labs/induction/narration.ts`。要特别讲清楚的：第 1 课“磁通量就是数穿过的线”；第 5 课中性面上磁通量最大、电动势却为零；第 7 课损耗是 1/n² 不是 1/n。

## 和规格卡原文的出入

- 第 4 课只做了导体棒切割（E = BLv），E = nΔΦ/Δt 的匝数 n 写在原理里，没有单独的任务。
- 第 3 课磁铁走得慢（0.05 m/s），电流计灵敏度按另一套多匝线圈取（示意），好让感应磁场看得清。
- 第 4 课的任务顺序改成：0.10 m/s 推 → 拉回 → 0.20 m/s 推 → 停下（推完要先拉回才能再推）。
- 拓展课的管长从 1 m 改成 0.6 m，镜头才能推近，管子、涡流和跳环占画面中间。
- 第 7 课最后一步“送到住户”按线路实际的 110 kV 送（选过 220 kV 也会换回 110 kV）。
- 第 6 课变压器铁芯里的磁感线画在绕组前面一层（沿铁芯轮廓），不然被绕组挡住。
- 第 5 课用剖开的水轮发电机（磁极转动、线圈不动），不是教材插图里线圈在磁场中转动的模型；中性面按“线圈平面与磁场垂直”讲，两种结构一致。
