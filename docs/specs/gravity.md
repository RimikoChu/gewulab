# 万有引力与航天实验室 · 规格卡 v1.0

状态：待审。关联议题 #62。

## 总览

- 一句话：从航天发射场出发，弄懂行星怎么绕太阳走、引力有多大、地球有多重、卫星要多快、为什么越高越慢、怎样从低轨道换到高轨道。
- 教材位置：人教版（2019）高中物理必修第二册，第七章“万有引力与宇宙航行”：7.1 行星的运动、7.2 万有引力定律、7.3 万有引力理论的成就、7.4 宇宙航行（章节号见“待核实事项”）。
- 主线：一颗要送上同步轨道的卫星。先看天上的规律（开普勒），再测出引力常量，称出地球，算出要多快、放多高，最后在发射场点火、两次变轨把它送上去。
- 场景：一座海边的航天发射场（参照海南文昌那样的滨海发射场：发射塔、火箭、远处的技术厂房和指挥楼），连着一间精密测量实验室；往上是太空：地球（NASA 实拍影像）、近地轨道、中圆轨道、同步轨道和月球；再远处是太阳系。
- **大场景的布局**（场景单位）：
  - 发射场在原点，1 单位 = 1 m：发射工位、脐带塔、火箭、导流槽、避雷塔、远处的厂房、海面。第 7 课从这里点火。
  - 测量实验室在发射场西侧（-260, 0, 120），1 单位 = 1 m：石台上的卡文迪什扭秤、光源、5 m 外的刻度尺。第 3 课。
  - 地球系在发射场正上方 2 万单位处，1 单位 = 637.1 km（地球半径 10 单位）：近地、中圆、同步轨道按真实半径之比画；月球轨道压缩到 120 单位（真实是 603 单位），标“示意”。第 4、5、6、7 课和拓展课。
  - 太阳系在地球系东边 4 万单位处：太阳和水金地火木的轨道，轨道半径之比真实（1 AU = 11 单位），行星和太阳画大了（示意）。第 1、2 课。
  - 换课时镜头从一处飞到另一处；第 7 课点火后镜头从发射场一路升到太空。
- 取值约定：G = 6.67×10⁻¹¹ N·m²/kg²，g = 9.8 m/s²，地球半径 R = 6371 km，地球质量 5.97×10²⁴ kg（算卫星用），一天 86400 s，1 AU = 1.496×10¹¹ m，一年 3.156×10⁷ s，太阳质量 1.989×10³⁰ kg，月球轨道半径 3.84×10⁸ m、周期 27.3 天。
- 简化（3.7）：卫星、空间站、行星、太阳画得比真实大（示意）；轨道都画成圆或正椭圆，不画倾角；第 1 课的行星轨道故意画扁（偏心率 0.5）；动画时间按比例加快，数字不加快；不计空气阻力。
- 和同类产品的区别：所有轨道、速度都是由同一套公式算出来的；牛顿的大炮用数值积分真算轨迹；变轨要等卫星真的飞到远地点才能点火。

## 第 1 课 行星的运动

| 项目 | 内容 |
|---|---|
| 知识点 | 开普勒第一定律（椭圆，太阳在一个焦点上）、第二定律（相等时间扫过相等面积） |
| 一句概念 | 行星走椭圆，离太阳近时走得快 |
| 核心动作 | 让示意行星走一圈；在近日点、远日点各扫一个月 |
| 看到的现象 | 行星在近日点附近飞快，远日点附近慢；两块扇形一块短粗、一块细长，面积一样 |
| 读数 | 到太阳的距离、速度；两块面积各占椭圆的 1/12（8.3%） |
| 真实锚点 | 地球轨道偏心率只有约 0.017，几乎是圆 |
| 对应小测 | 第 1 题 |

任务：让行星绕太阳走一圈 → 在近日点扫一个月 → 在远日点扫一个月。

按钮：走一圈 · 到近日点 / 到远日点（同一个按钮）· 扫一个月。

数据：示意行星 a = 1 AU、e = 0.5、T = 1 年；近日点 0.5 AU、51.6 km/s；远日点 1.5 AU、17.2 km/s（比为 (1+e)/(1−e) = 3）。

## 第 2 课 周期定律

| 项目 | 内容 |
|---|---|
| 知识点 | 开普勒第三定律 a³/T² = k，k 只和太阳有关 |
| 一句概念 | 离太阳越远，绕一圈越久，a³/T² 都一样 |
| 核心动作 | 选行星，按“记录数据” |
| 看到的现象 | 五颗行星按真实快慢绕太阳转；图上的点落在同一条过原点的直线上 |
| 读数 | a（AU）、T（年）、a³/T²（m³/s²） |
| 真实锚点 | 水星 0.387 AU、0.241 年；金星 0.723、0.615；地球 1、1；火星 1.524、1.881；木星 5.203、11.86 |

任务：记录地球 → 记录火星 → 记录木星。分段选择：水星、金星、地球、火星、木星。

数据：a³/T² 都约 3.36×10¹⁸ m³/s²，等于 GM太阳/4π²（相差不到 1%）。

## 第 3 课 称出引力常量

| 项目 | 内容 |
|---|---|
| 知识点 | 万有引力定律 F = Gm₁m₂/r²；卡文迪什扭秤：放大的思想（光杠杆） |
| 一句概念 | 用一面小镜子，把看不见的扭转放大成光点的移动 |
| 核心动作 | 把大球转到小球旁边；读光点；把大球换到另一边；算 G |
| 看到的现象 | T 形架慢慢扭过一个小角度，来回摆几下停住；墙上刻度尺的光点移了几厘米；换边后反向移 |
| 读数 | 光点位置（cm）、扭转角、引力 F、算出的 G |

任务：大球转到 A 侧，记下光点 → 转到 B 侧，再记 → 算出 G。按钮：转大球（A/B 侧，同一个）· 记录光点 · 算出 G。

这台扭秤的参数（示意，取接近卡文迪什原装置的量级）：大铅球 158 kg，小铅球 0.73 kg，球心距 0.225 m，T 形架两小球相距 1.8 m，石英丝扭转系数 6.0×10⁻⁵ N·m/rad，镜子到刻度尺 5 m。一个大球吸小球 1.52×10⁻⁷ N，扭转 0.0046 rad，光点移 4.56 cm；两侧来回共 9.12 cm，反算 G = 6.67×10⁻¹¹ N·m²/kg²。

## 第 4 课 称量地球

| 项目 | 内容 |
|---|---|
| 知识点 | 不考虑自转时 mg = GMm/R²；环绕法 M = 4π²r³/GT²；密度 ρ = M/V，近地卫星 ρ = 3π/GT² |
| 一句概念 | 知道 g 和 R，或者知道一颗卫星的 r 和 T，就能称出地球 |
| 核心动作 | 三个按钮，各用一种方法 |
| 读数 | 地球质量、密度 |

任务：用地面的 g 和 R 称 → 用月球的 r 和 T 称 → 用贴地飞的卫星算密度。

数据：M = 9.8×(6.371×10⁶)²/6.67×10⁻¹¹ = 5.96×10²⁴ kg；月球 r = 3.84×10⁸ m、T = 27.3 天 → 6.02×10²⁴ kg；贴地卫星 T = 84.4 分钟 → ρ = 5.51×10³ kg/m³。

## 第 5 课 宇宙速度

| 项目 | 内容 |
|---|---|
| 知识点 | 第一宇宙速度 7.9 km/s（最小发射速度、最大环绕速度）；第二 11.2 km/s；第三 16.7 km/s |
| 一句概念 | 抛得越快落得越远，快到 7.9 km/s 就绕着地球转 |
| 核心动作 | 选出口速度，按“开炮” |
| 看到的现象 | 2、4、6 km/s 一次比一次落得远；7.9 km/s 绕地球一圈回到山顶；11.2 km/s 飞走 |
| 读数 | 出口速度、射程、结局 |

设想的高山：山顶 400 km（在大气层以上，示意，牛顿的思想实验）。任务：2 km/s → 4 km/s → 6 km/s（射程变远）→ 7.9 km/s 绕地球 → 11.2 km/s 一去不回（共四条，见“出入”）。

数据（数值积分）：2 km/s 落在 629 km 外，4 km/s 1413 km，6 km/s 2883 km。v₁ = √(GM/R) = 7.9 km/s（也 = √(gR)）；v₂ = √2·v₁ = 11.2 km/s；第三宇宙速度由 v地 = √(GM太阳/1 AU) 算出 16.6 km/s，教材写 16.7 km/s，面板写 16.7。

## 第 6 课 人造卫星

| 项目 | 内容 |
|---|---|
| 知识点 | v = √(GM/r)、ω = √(GM/r³)、T = 2π√(r³/GM)：高轨低速长周期；同步卫星周期 24 h、在赤道上空约 3.6×10⁴ km |
| 一句概念 | 轨道越高，卫星越慢，转一圈越久 |
| 核心动作 | 选轨道，按“记录数据” |
| 看到的现象 | 三颗卫星按真实快慢转；同步卫星和地面上的一点一起转，始终在它上空 |

任务：记录近地轨道 → 中圆轨道 → 同步轨道。

数据：近地 r = 6700 km：7.71 km/s、1.52 h；中圆 r = 27900 km（北斗中圆轨道量级）：3.78 km/s、12.9 h；同步 r = 4.22×10⁴ km（由 T = 24 h 算出）：3.07 km/s、24 h，离地面 3.59×10⁴ km。

## 第 7 课 卫星变轨

| 项目 | 内容 |
|---|---|
| 知识点 | 近地圆轨道 → 椭圆转移轨道 → 高圆轨道；在近地点、远地点各加速一次；高轨道上速度反而小 |
| 一句概念 | 两次加速，卫星从低轨道换到高轨道 |
| 核心动作 | 点火发射；在近地点点火；等到远地点再点火 |
| 读数 | 当前速度、高度 |

任务：点火发射，进入近地轨道 → 近地点加速，进入转移轨道 → 远地点加速，进入同步轨道。

数据：近地圆轨道 7.71 km/s → 加速 2.42 km/s 到 10.13 km/s；到远地点减到 1.61 km/s → 加速 1.46 km/s 到 3.07 km/s；转移半圈 5.29 h。

## 讲解

解说词在 `src/labs/gravity/narration.ts`。要特别讲清：第 1 课两块扇形形状不同面积相等；第 3 课光点是放大了的扭转；第 5 课 7.9 km/s 是“贴着地面绕”的速度，山顶上稍慢一点也能绕；第 7 课加速后到了高轨道速度反而小。

## 和规格卡原文的出入

- 第 5 课任务是四条：2 km/s、6 km/s、7.9 km/s、11.2 km/s；4 km/s 留在分段选择里可以自己试。前两炮镜头贴近山顶，后两炮拉远看整个地球。
- 拓展课第二个实验只画月球（探测器绕月），火星的数只出现在面板表格里，没有画火星。表格里地球表面 g 由 G、M、R 算出是 9.81 m/s²，和全实验室取的 9.8 略有出入。
- 第 7 课远地点点火那一步自动演示不配讲解（要赶在远地点附近的时间窗里点火），讲解放在前一句“等它到远地点，再点火”里。
- 指挥大厅没有做：T²–a³ 图画在第 2 课的面板上。
- 第 2 课两个机位：选水星到火星时看内侧行星，选木星时镜头拉远；行星是示意大小，名字标在旁边。第 1、2 课轨道画成发光带，斜着看（约 30°）。
- 第 6 课镜头推近到中圆轨道，同步轨道一部分出画；左下方加了一个放大小窗，看选中轨道上那颗卫星（示意）。
- 测量实验室加了黑板和仪器柜；发射场的椰子树改成弯曲分节的树干加下垂的羽状叶，沙地加了大片深浅变化和海边湿沙。
