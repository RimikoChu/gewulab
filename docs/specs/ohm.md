## 总览

- **一句话**：学生在一间电子元件检测车间的防静电工作台上，用直流稳压电源、电流表、电压表、滑动变阻器和定值电阻连成电路，亲手测出电流跟电压成正比、跟电阻成反比，得到欧姆定律；再用伏安法测一只未知电阻和一只小灯泡的电阻，比较串联、并联后的总电阻；最后在车间的安全角算一算湿手为什么危险、短路电流有多大。拓展课在质检台上给一批色环电阻做阻值检验，再拆开看汽车油量表的原理。
- **教材位置**：物理，初中九年级全一册。人教版第十七章“欧姆定律”（电流与电压和电阻的关系；欧姆定律；电阻的测量；欧姆定律在串、并联电路中的应用）；第 7 课的安全用电对应第十九章“生活用电”里的安全用电。章节号和节名见“待核实事项”。
- **主线**：同一台直流稳压电源（输出 3.0 V）、同一只滑动变阻器（20 Ω 2 A）、同一对电流表和电压表，从第 1 课用到第 6 课。定值电阻是车间里常见的白色瓷壳水泥电阻，装在带两个接线柱的底板上。
- **场景**：一间电子元件检测车间。钢结构厂房，门式钢架和屋架，高处一排采光窗，屋顶吊着一行行条形灯；灰绿色环氧地坪上划着黄色的通道线和防静电区的黄黑边线。后墙一排防静电工作台（第 1–3 课），车间中间一排岛式工作台（第 4–6 课），东墙安全角挂着一块安全用电示教板（第 7 课），西头一张质检台，背后是元件料盘架（拓展课）。选它的理由：议题建议的就是电子元件检测车间；“测电阻、判断合格不合格”正是这里每天做的事，伏安法、欧姆定律在这里不是课本上的题，而是工作；工作台上本来就有电源、电表、元件、导线，器材放进去不突兀。
- **取值约定**：电源输出电压 3.0 V（第 3 课可调，0–3.0 V），内阻不计；导线电阻不计；电流表、电压表当作理想电表。电流表用 0–0.6 A 量程（分度值 0.02 A），电压表用 0–3 V 量程（分度值 0.1 V）。读数读到分度值：电流两位小数，电压一位小数；电阻算出来保留一位小数。滑动变阻器 20 Ω 2 A，一上一下接法。家庭电路电压 220 V。
- **和同类产品的区别**：电路是一根根导线连起来的，导线从接线柱上拧出来、弯着落到台面上，不穿过器材；电流沿导线流成一串亮点，电流越大跑得越快。电表是课堂上那种指针表：表盘两排刻度、三个接线柱，指针会摆过头再停稳；滑动变阻器是瓷管上密绕的电阻丝，滑片能直接拖。每记一组数据，面板上的坐标图里就多一个点，记够了再连成图像：定值电阻是一条过原点的直线，小灯泡是一条弯曲的线。

## 第 3 课 欧姆定律

| 项目 | 内容 |
|---|---|
| 知识点 | 欧姆定律 I = U/R；变形 U = IR、R = U/I；电阻是导体本身的性质，不随电压、电流改变 |
| 一句概念 | 电流等于电压除以电阻 |
| 核心动作 | 每道题先在分段选择里选出答案，再调电源、闭合开关，用电表验证 |
| 看到的现象 | 电流表的示数和算出来的一样 |
| 读数 | 电源显示屏、两只表、面板上的算式 |
| 对应小测 | 第 3 题 |

- [ ] 20 Ω 要通过 0.1 A：先算电压，再验证（2 V）

## 第 4 课 伏安法测电阻

| 项目 | 内容 |
|---|---|
| 知识点 | 伏安法：用电压表测电压、电流表测电流，R = U/I；多次测量求平均值，减小误差 |
| 一句概念 | 测出电压和电流，就能算出电阻 |
| 核心动作 | 在 1.3、2.0、2.6 V 下各记一组；求平均值 |
| 看到的现象 | 三次算出来的电阻不完全一样（8.1、8.3、8.1 Ω），平均 8.2 Ω |
| 读数 | U、I、R 和平均值 |
| 真实锚点 | 车间里给一只没标值的电阻测阻值 |
| 对应小测 | 第 4 题 |

任务清单

- [ ] 闭合开关，把电压调到 1.3 V，记一组
- [ ] 调到 2.0 V，再记一组
- [ ] 调到 2.6 V，再记一组
- [ ] 求三次的平均值

数据：Rₓ 的阻值取 8.2 Ω（界面上不出，只出测量结果）。三次的电流按分度值读：0.1585 → 0.16 A、0.2439 → 0.24 A、0.3171 → 0.32 A；R 分别为 8.125、8.333、8.125 Ω，平均 8.19 ≈ 8.2 Ω。每次不一样是因为电流只能读到分度值。

## 第 5 课 测小灯泡的电阻

| 项目 | 内容 |
|---|---|
| 知识点 | 灯丝的电阻随温度升高而增大；小灯泡的 I–U 图像是曲线；不同电压下的电阻不同，求平均没有意义 |
| 一句概念 | 灯越亮，灯丝越热，电阻越大 |
| 核心动作 | 在 1.0、1.5、2.0、2.5 V 下各记一组；判断能不能求平均 |
| 看到的现象 | 灯从暗红到正常发光；算出的电阻 6.3 → 6.8 → 7.7 → 8.3 Ω；图上的点连成一条往下弯的线，不在过原点的直线上 |
| 读数 | U、I、R |
| 真实锚点 | 小灯泡标着“2.5 V” |
| 对应小测 | 第 5 题 |

任务清单

- [ ] 闭合开关，把电压调到 1.0 V，记一组
- [ ] 调到 1.5 V、2.0 V，各记一组
- [ ] 调到 2.5 V（正常发光），再记一组
- [ ] 判断：能不能求平均值作为灯丝的电阻

数据：灯丝电阻用示意模型 R = 2 + 4√U（见待核实）；四个电压下的电流 0.1667、0.2174、0.2612、0.3003 A，读作 0.16、0.22、0.26、0.30 A。界面上标“示意”。

## 第 7 课 欧姆定律和安全用电

| 项目 | 内容 |
|---|---|
| 知识点 | 电压越高越危险；人体电阻越小，通过的电流越大；不能用湿手碰开关；短路时电阻极小，电流极大 |
| 一句概念 | 电压一定，电阻越小，电流越大 |
| 核心动作 | 分段选择干手 / 湿手，各算一次；闭合开关点亮灯；接上短路导线 |
| 看到的现象 | 示意表：干手约 22 mA，湿手约 220 mA，大十倍；短路时电流约 4400 A，空气开关跳闸、灯灭 |
| 读数 | 通过人体的电流（示意）、灯的电流、短路电流 |
| 对应小测 | 第 7 题 |

任务清单

- [ ] 干手：算一算通过人体的电流
- [ ] 湿手：再算一次
- [ ] 闭合开关，让灯正常发光
- [ ] 用一根导线把灯的两端直接连起来

数据：人体电阻干燥时按 10 kΩ、潮湿时按 1 kΩ 算（示意，见待核实）；灯 220 V 100 W，R = U²/P = 484 Ω，I ≈ 0.45 A；短路导线按 0.05 Ω 算（示意），I = 4400 A。界面上这些数都标“约”或“示意”。

## 画面上的约定

- 电表当作理想电表，电源内阻不计，所以电压表直接接在定值电阻两端时示数和算出来的一模一样。
- 电流表的读数取最接近指针的那一格（分度值 0.02 A），不估读到下一位。
- 小灯泡的电阻用示意模型，只保证“电压越高电阻越大、2.5 V 时约 0.3 A”，不是某一只真实灯泡的曲线。
- 第 7 课、拓展 2 的人体电阻、短路导线电阻、油量表参数是示意值，界面上标“示意”或“约”。
- 器材按真实尺寸画：电表约 13 cm 宽，滑动变阻器约 28 cm 长，电源约 24 cm 宽。只有第 5 课的小灯泡画大到 1.4 倍，好看清灯丝；第 3、6 课的电压表接在电阻（或两只电阻）两端，导线从后面接，和电流的回路不交叉。
- 第 7 课示教板上的手只表示“人手碰到带电体”这件事，通过人体的电流是按欧姆定律算出来的示意值，画面上没有真的触电过程。

## 和规格卡原文的出入

- 议题建议第 2 课用 5、10、15 Ω：改成 5、10、20 Ω，电压保持 2.0 V。15 Ω 在 2.0 V 下电流是 0.133 A，落不到电流表的刻度线上；20 Ω 时电阻加倍、电流减半，反比关系更好看出来。
- 议题建议拓展课“色环电阻质检，或电子秤 / 油量表”：做了色环质检和油量表两个。
