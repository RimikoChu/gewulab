## 总览

- **一句话**：学生亲手测出浮力、找到它的来源和大小规律，最后弄懂一块会沉的钢铁怎样变成能浮的船。
- **教材位置**：人教版物理八年级下册 第十章《浮力》，共三节：浮力、阿基米德原理、物体的浮沉条件及应用。
- **主线**：一块钢铁。前五课它在水槽里是一个金属块，一放手就沉；最后两课它变成船、潜水艇，浮了起来。
- **场景**：整个实验室放在一座造船厂里（2026-11-17 改定，不再用实验台）。器材都换成船厂里的真东西：吊车和吊秤代替弹簧测力计，试验水池代替溢水杯，计量槽和地磅代替小桶。第 4 课已按这个场景做完；其余各课下面写的“实验台”还是旧方案，做到那一课时再改成船厂里的对应场景（船坞、下水、打捞等）。
- **和同类产品的区别**：同类产品把这一章放进深海、港口等大场景里展示。我们按课本的实验顺序来，学生自己读数、记表、控制变量，做出来的数据和课本的探究实验对得上，老师可以直接照着上课。
- **取值约定**：g 取 9.8 N/kg，和教材正文一致；水的密度 1.0×10³ kg/m³。

## 共用的计算核心

画面、读数、数据表、小测配图都调用这几个函数。

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| 浮力 | 液体密度 ρ液、排开体积 V排 | F浮 = ρ液 g V排 | 阿基米德原理 |
| 测力计示数 | 物重 G、浮力 F浮 | F拉 = G − F浮（不小于 0） | 受力平衡 |
| 液体压强与压力 | 密度、深度 h、面积 S | p = ρgh，F = pS | 第九章液体压强 |
| 浮沉状态 | 物体质量 m、体积 V、液体密度 | 漂浮 / 悬浮 / 下沉 / 上浮 / 沉底；漂浮时的 V排 | 比较 G 和全部浸没时的 F浮 |
| 吃水深度 | 船的总质量、水线面积、液体密度 | 吃水 = m /(ρ液 × 水线面积) | 漂浮时 F浮 = G，船体按直壁简化 |
| 热气球升力 | 气球体积、外部和内部空气密度、自重 | 升力 = (ρ外 − ρ内) g V − G | 阿基米德原理用于气体 |

## 第 1 课 水里变轻了

学生第一次"测到"浮力：同一个金属块，在水里测力计的示数变小了，变小的部分就是浮力。

| 项目 | 内容 |
|---|---|
| 知识点 | 浸在液体中的物体受到向上的浮力；称重法：F浮 = G − F拉 |
| 一句概念 | 示数变小了多少，浮力就是多少 |
| 核心动作 | 上下拖动测力计，把金属块从空气中慢慢浸入水里 |
| 看到的现象 | 金属块入水，测力计指针回缩；水面上升；金属块旁出现向上的浮力箭头，随浸入加长 |
| 读数 | 空气中的示数 G、水中的示数 F拉、浮力 F浮 |
| 真实锚点 | 在水里搬石头比在岸上省力 |
| 对应小测 | 给出两次示数，求浮力 |

任务清单

- [ ] 在空气中读出金属块的重力（2.65 N）
- [ ] 把金属块完全浸入水中，再读一次（1.67 N）
- [ ] 算出浮力（0.98 N）
- [ ] 换成木块试一次，看示数变成多少（0，木块浮在水面）

数据：金属块为铝块，体积 100 cm³，重 2.65 N，完全浸没时浮力 0.98 N。

视觉映射

| 知识点 | 必须看见的东西 | 由哪个量驱动 | 镜头与视图 |
|---|---|---|---|
| 浮力存在 | 入水后测力计指针回缩 | F拉 = G − F浮 | 正对实验台，测力计和水槽同时入镜 |
| 浮力方向向上 | 金属块上的向上箭头 | F浮 | 同上 |
| 浮力随浸入变大 | 箭头变长、示数连续变化 | 浸入体积 | 同上 |
| 漂浮时拉力为零 | 木块浮起，挂绳松弛 | 浮沉状态 | 同上 |

## 第 2 课 浮力从哪来

学生看到浮力不是凭空来的：物体下表面受到的向上压力，比上表面受到的向下压力大。

| 项目 | 内容 |
|---|---|
| 知识点 | 液体压强随深度增大；浮力是上下表面的压力差；侧面的压力互相抵消 |
| 一句概念 | 下面托的力，比上面压的力大 |
| 核心动作 | 上下拖动水中的正方体；切换"贴紧水槽底" |
| 看到的现象 | 六个面上各有一组压力箭头，越深越长；左右、前后的箭头等长反向；上下两组的差保持不变 |
| 读数 | 上表面深度和压力、下表面深度和压力、压力差 |
| 真实锚点 | 桥墩插在河床里，下表面没有水，不受浮力 |
| 对应小测 | 桥墩受不受浮力？为什么？ |

任务清单

- [ ] 读出上、下表面受到的压力（上 4.9 N、下 14.7 N）
- [ ] 算出压力差（9.8 N）
- [ ] 把正方体往深处移，看压力差变不变
- [ ] 让正方体贴紧水槽底，看浮力还在不在

数据：正方体边长 10 cm，上表面在水下 5 cm 时，上表面压强 490 Pa、压力 4.9 N，下表面压强 1470 Pa、压力 14.7 N，压力差 9.8 N，等于 ρ水 g V。

视觉映射

| 知识点 | 必须看见的东西 | 由哪个量驱动 | 镜头与视图 |
|---|---|---|---|
| 压强随深度增大 | 箭头长度随深度变化，水槽侧壁有深度刻度 | p = ρgh | 水槽特写，略俯视 |
| 侧面压力抵消 | 左右、前后的箭头等长反向，可一键淡出 | 同上 | 同上 |
| 浮力是压力差 | 上下两组箭头并排比较，差值用高亮段标出 | F下 − F上 | 同上 |
| 压力差与深度无关 | 移动时差值段长度不变 | 同上 | 同上 |
| 下表面没水就没有浮力 | 贴底时下方箭头消失 | 是否贴底 | 水槽底部特写 |

## 第 3 课 浮力和什么有关

学生做一次完整的探究：每次只改一个条件，用数据说话。

| 项目 | 内容 |
|---|---|
| 知识点 | 浮力大小与浸入液体的体积、液体的密度有关；与浸没的深度、物体的密度、物体的形状无关；控制变量法 |
| 一句概念 | 只看两样：排开多少，排开的是什么 |
| 核心动作 | 选一个猜想 → 改这一个条件 → 读数 → 记录到数据表 |
| 看到的现象 | 改浸入体积或换液体时，示数变；改深度、换同体积的铜块、把橡皮泥捏成别的形状时，浮力不变 |
| 读数 | 当前条件下的 G、F拉、F浮；数据表逐行累积 |
| 真实锚点 | 同一个人在死海里比在游泳池里浮得更高 |
| 对应小测 | 给出一张数据表，问能得出哪条结论 |

任务清单

- [ ] 验证"浸入体积"：记录浸入一半和全部浸没两组数据
- [ ] 验证"液体密度"：在水、盐水、酒精里各测一次
- [ ] 验证"深度"：全部浸没后在两个深度各测一次
- [ ] 验证"物体密度"：同体积的铝块和铜块各测一次
- [ ] 说出哪两个因素有关

数据：100 cm³ 的物块全部浸没时，在酒精（0.8）、水（1.0）、盐水（1.1）里的浮力分别是 0.78 N、0.98 N、1.08 N（密度单位 ×10³ kg/m³）。

视觉映射

| 知识点 | 必须看见的东西 | 由哪个量驱动 | 镜头与视图 |
|---|---|---|---|
| 控制变量 | 面板上一次只有一个条件可调，其余锁定 | 当前猜想 | 实验台全景 |
| 与浸入体积有关 | 浸入越多，箭头越长、示数越小 | V排 | 同上 |
| 与液体密度有关 | 三个并排的水槽，液体颜色不同，示数不同 | ρ液 | 三个水槽同框 |
| 与深度无关 | 全部浸没后上下移动，示数不动 | 深度 | 同上 |
| 与物体密度、形状无关 | 换材料或形状后，F浮 一栏不变，只有 G 变 | 物体属性 | 同上 |
| 用数据下结论 | 数据表里变化的那一列高亮 | 记录 | 右侧数据表 |

## 第 4 课 阿基米德原理

学生把"浮力"和"排开的水"放在一起比：两个数总是相等。**样板课，已按造船厂场景做完。**

场景：造船厂码头。悬臂吊把物块吊进带观察窗的试验水池，水池注满到溢水口；溢出的水顺着溢水槽流进计量槽，计量槽放在地磅上。相当于课本里的弹簧测力计、溢水杯、小桶，放大到了真实尺度。

| 项目 | 内容 |
|---|---|
| 知识点 | 浮力等于物体排开的液体所受的重力；F浮 = G排 = ρ液 g V排 |
| 一句概念 | 排开多少水，就得到多大的浮力 |
| 核心动作 | 用吊车把物块放进水里（点一下 0.1 m，按住连续，也可以直接拖，或用“一半”“完全浸没”直接到位），在几个深度各按一次"记录数据" |
| 看到的现象 | 物块入水，水从溢水口流进计量槽；吊秤示数变小，地磅示数变大；两个结果并排显示，始终相等 |
| 读数 | G物、F拉（吊秤）、G槽、G总（地磅）；算出 F浮 = G物 − F拉，G排 = G总 − G槽；单位 kN |
| 可选条件 | 物块：钢锭 1 m³、钢锭 2 m³、混凝土块 1 m³；液体：淡水（1.00×10³ kg/m³）、海水（1.03×10³ kg/m³） |
| 过程规则 | 流进计量槽的水不会回去：物块提起后水池水位下降，要先"重新注水"才能再比一次 |
| 真实锚点 | 传说阿基米德在浴缸里看到水溢出来，想到了这个办法 |
| 对应小测 | 给出四个测量值，判断哪一步操作顺序不对会带来误差 |

任务清单

- [ ] 把物块放进水里一半，记录数据（钢锭 1 m³：都是 4.90 kN）
- [ ] 完全放进淡水，再记录一组（都是 9.80 kN）
- [ ] 换成海水，完全放进去再记录（都是 10.09 kN）

三条都完成后弹出结论卡：“每一组，F浮 都等于 G排”。

## 第 5 课 沉还是浮

学生找到浮沉的分界线：比的是物体和液体的密度。

| 项目 | 内容 |
|---|---|
| 知识点 | 浸没时 F浮 > G 上浮，F浮 = G 悬浮，F浮 < G 下沉；漂浮时 F浮 = G；用密度判断：ρ物 < ρ液 漂浮，= 悬浮，> 下沉 |
| 一句概念 | 比水密的沉，比水疏的浮 |
| 核心动作 | 把三个同体积、不同密度的球放进水里；往水里加盐；把橡皮泥球捏成碗 |
| 看到的现象 | 三个球分别漂浮、悬浮、沉底，每个球上画出重力和浮力两个箭头；加盐后鸡蛋从沉底到悬浮再到浮出水面；橡皮泥捏成碗后浮了起来 |
| 读数 | 物体密度、液体密度、G、F浮、状态；漂浮时露出水面的比例 |
| 真实锚点 | 冰山只有约十分之一露在水面上 |
| 对应小测 | 同一个鸡蛋在清水和盐水里，哪次受到的浮力大 |

任务清单

- [ ] 放入三个球，说出各自的状态
- [ ] 调球的密度，让它正好悬浮
- [ ] 往水里加盐，让鸡蛋浮起来
- [ ] 把橡皮泥球捏成碗，让它浮在水面
- [ ] 比较橡皮泥"球"和"碗"排开的水谁多

视觉映射

| 知识点 | 必须看见的东西 | 由哪个量驱动 | 镜头与视图 |
|---|---|---|---|
| 力的比较 | 每个物体上的重力、浮力两个箭头，长短可比 | G、F浮 | 水槽正面 |
| 密度的比较 | 密度条：物体和液体各一个刻度，谁高谁低一目了然 | ρ物、ρ液 | 右侧面板 |
| 漂浮时 F浮 = G | 浮出水面后两个箭头等长 | 浮沉状态 | 水槽正面 |
| 改变液体密度 | 盐溶解，水的颜色渐深，鸡蛋慢慢上浮 | ρ液 | 同上 |
| 空心能增大排开的水 | 橡皮泥从球变成碗，水面明显上升 | V排 | 水面特写 |

## 第 6 课 钢铁变成船

回到主线：钢铁的密度是水的近八倍，做成空心的船却能浮起来，还能改造成想沉就沉的潜水艇。

| 项目 | 内容 |
|---|---|
| 知识点 | 轮船靠空心增大排开的水；排水量是满载时排开水的质量；漂浮时 F浮 = G，装货越多吃水越深；潜水艇靠改变自身重力实现浮沉 |
| 一句概念 | 船靠空心浮起来，潜艇靠水舱沉下去 |
| 核心动作 | 轮船：增减货物；让船从河里驶入海里。潜水艇：给水舱注水、排水 |
| 看到的现象 | 轮船装货后吃水线上移，到载重线为止；入海后船身略微浮起。潜水艇水舱进水后下沉，排水后上浮，剖面里能看到水舱的水位 |
| 读数 | 轮船：总质量、浮力、吃水深度、离载重线还有多少。潜水艇：自重、浮力、深度、状态 |
| 真实锚点 | 船身上的载重线标志；我国的"奋斗者"号载人潜水器 |
| 对应小测 | 轮船从河里驶入海里，浮力和吃水各怎么变 |

任务清单

- [ ] 给轮船装货，直到水面到达载重线
- [ ] 让船从河里驶入海里，看船身上浮还是下沉
- [ ] 给潜水艇注水，让它悬停在水中
- [ ] 排水，让潜水艇浮出水面
- [ ] 说出潜水艇下潜过程中浮力变不变（完全浸没后不变）

视觉映射

| 知识点 | 必须看见的东西 | 由哪个量驱动 | 镜头与视图 |
|---|---|---|---|
| 空心增大 V排 | 同样多的钢，实心块沉底，船壳浮着，两者并排 | 浮沉状态 | 江面侧视，水上水下各一半 |
| 装货吃水加深 | 吃水线上移，船身刻度可读 | 总质量 | 船身特写 |
| 河到海 | 水色变化，船身浮起一小段 | ρ液 | 同上 |
| 潜艇改变自重 | 剖开的艇身里，水舱水位升降 | 水舱水量 | 水下侧视，艇身剖面 |
| 浸没后浮力不变 | 下潜时浮力箭头长度不变，重力箭头变化 | G、F浮 | 同上 |

## 第 7 课 飘在空中

浮力不只在水里：空气也是流体。最后用密度计把"漂浮"变成一件测量工具。

| 项目 | 内容 |
|---|---|
| 知识点 | 气体对物体也有浮力；热气球靠加热使内部空气密度变小；密度计漂浮时浮力等于重力，液体密度越大浸入越浅 |
| 一句概念 | 空气也能把东西托起来 |
| 核心动作 | 热气球：调节火焰加热。密度计：放进不同的液体 |
| 看到的现象 | 加热后气球里的空气变稀（粒子变疏），升力由负转正，气球离地。密度计在盐水里浮得高、在酒精里沉得深，刻度"上小下大" |
| 读数 | 热气球：内外空气密度、浮力、总重、升力。密度计：浸入深度、读出的密度 |
| 真实锚点 | 热气球节；实验室里测牛奶、酒精浓度的密度计 |
| 对应小测 | 密度计的刻度为什么上面的数小、下面的数大 |

任务清单

- [ ] 加热空气，让热气球升起来
- [ ] 找到刚好悬停时的温度
- [ ] 把密度计放进水、盐水、酒精，比较浸入的深度
- [ ] 用密度计读出一杯未知液体的密度

视觉映射

| 知识点 | 必须看见的东西 | 由哪个量驱动 | 镜头与视图 |
|---|---|---|---|
| 空气有浮力 | 气球上的浮力箭头，和水里的画法一致 | F浮 = ρ空气 g V | 气球全景 |
| 加热使密度变小 | 球内的空气粒子变疏，有粒子从底部流出 | 内部温度 | 气球剖面 |
| 升力 | 浮力与总重两个箭头的差 | 升力 | 同上 |
| 密度计原理 | 三支密度计并排，浸入深度不同 | ρ液 | 三个量筒同框 |
| 刻度上小下大 | 液面对准的刻度线高亮 | 浸入深度 | 刻度特写 |

## 拓展课

课本七课讲完之后的四节拓展课。它们不在教材正文里，但用的还是这一章的规律，场景更大、更有冲击力。
首页和课程栏里用"拓展"标出，老师可以选讲；小测不考拓展课的内容。

| 课 | 名称 | 看点 | 用到的规律 | 学生的核心动作 | 场景 |
|---|---|---|---|---|---|
| 拓展 1 | 太空里浮力消失了 | 天宫课堂里，乒乓球停在水中间不浮上来 | 浮力来自重力造成的压力差；失重时压力差没有了 | 拨动"重力"滑块，从地面调到空间站，看乒乓球和水里的压力箭头怎么变 | 空间站舱内，一杯水和一个乒乓球；窗外是地球 |
| 拓展 2 | 冰山的九成在水下 | 一座冰山露出水面的只有约十分之一；冰化了，水面不升不降 | 漂浮时 F浮 = G；ρ冰 和 ρ海水 的比值决定露出多少 | 调冰山大小和海水密度，读露出的比例；让浮冰融化，看水位线 | 极地海面，水上水下各一半的剖面 |
| 拓展 3 | 把沉船捞上来 | 用充气的浮筒把几百吨的沉船托出海面 | 增大 V排 就增大浮力；F浮 大于总重才能上浮 | 往沉船上绑浮筒、给浮筒充气，凑够浮力后起浮 | 海底沉船，上方是打捞船 |
| 拓展 4 | 王冠是不是纯金 | 阿基米德不毁坏王冠，就查出了掺假 | 用排开的水测体积，再算密度 | 分别把王冠和等重的金块浸入水中，比较溢出的水和测力计示数 | 古代的水盆和天平 |

每节拓展课同样有一句概念、三四条任务和读数，开工前按模板补全规格。

**这四节的选法**：一节来自中国空间站的真实授课，一节是常考的经典问题（冰融化后水面变不变），一节是工程应用，一节是科学史。场景分别在太空、极地、海底和古代，画面上和实验台拉开差距。

**待核实**：天宫课堂浮力实验的具体表述；冰和海水的密度取值；打捞案例的真实数据（如需引用具体沉船）；王冠故事按传说处理，画面上注明。
