# 基因的表达实验室 · 规格卡 v0.1

状态：已按此卡做完九个课次，待审。

## 总览

- 一句话：从细胞核里的 DNA 一直走到核糖体上的肽链，弄懂 DNA 的结构和复制、基因怎样经转录和翻译指导蛋白质的合成，以及碱基一变、蛋白质怎样跟着变。
- 教材位置：人教版（2019）高中生物学 必修 2《遗传与进化》第 3 章 基因的本质（DNA 的结构、DNA 的复制、基因通常是有遗传效应的 DNA 片段），第 4 章 基因的表达（基因指导蛋白质的合成），第 5 章第 1 节 基因突变（镰状细胞贫血）。章节号见“待核实事项”。
- 主线：一段 DNA 的信息怎样一步步变成蛋白质：DNA → mRNA → 肽链。
- 场景：一个放大的真核细胞内部。左边是细胞核（双层核膜、核孔复合体、染色质、核仁），核里暗紫色，飘着染色质丝；核膜外是细胞质：绕着细胞核的粗面内质网（层层的扁囊，表面密布核糖体）、线粒体（剖开能看见嵴）、游离的核糖体、囊泡和细胞骨架。暗处有柔和的光。

**大场景的布局**（场景单位示意，不按比例；细胞核半径 70）：

第 4 课结束时，mRNA 穿过核孔出去，镜头跟着它飞到核外，接上第 5、6 课。

- 取值约定：DNA 双螺旋直径约 2 nm、每转约 10 个碱基对、螺距约 3.4 nm（教材数）。模型里碱基对的间距拉大到看得清，标“示意”。遗传密码用标准遗传密码表（64 个密码子，61 个编码氨基酸，3 个终止密码子 UAA、UAG、UGA；起始密码子 AUG 同时编码甲硫氨酸）。
- 碱基颜色全实验室统一：A 红、T 黄、G 绿、C 蓝、U 紫。DNA 的旧链（母链）浅蓝，新链（子链）橙色，mRNA 粉色。嘌呤（A、G）画得长，嘧啶（T、C、U）画得短；A—T 之间两根氢键，G—C 之间三根。
- 和同类产品的区别：一个连续的细胞内部，各个过程在真实的地方发生（复制、转录在核里，翻译在内质网的核糖体上）；碱基一个个配上去、mRNA 一点点长出来、核糖体一格一格往前走，密码表就立在核糖体旁边，查到哪格亮哪格。

## 共用的计算核心

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `complement(s)` | DNA 碱基序列 | 逐个配对的互补碱基（A—T，G—C） | 碱基互补配对原则 |
| `antiparallel(s)` | 5′→3′ 的一条链 | 互补链按 5′→3′ 写出（反向互补） | 两条链反向平行 |
| `counts(s)` | 双链的一条链 | 双链中 A、T、G、C 各多少个 | |
| `purineRatio(s)` | 同上 | (A+G)/(T+C)，双链里恒为 1 | 嘌呤数 = 嘧啶数 |
| `replicate(n, bp)` | 复制代数、碱基对数 | DNA 分子数 2ⁿ、含母链的 2、母链占全部链 1/2ⁿ、需要的游离脱氧核苷酸 (2ⁿ−1)×2×bp | 半保留复制 |
| `variety(n)` | 碱基对数 | 4ⁿ | DNA 的多样性 |
| `transcribe(t)` | 模板链（3′→5′ 写） | mRNA（5′→3′）：A→U，T→A，G→C，C→G | 转录的碱基配对 |
| `codonOf / CODE` | 密码子 | 氨基酸或终止 | 标准遗传密码表 |
| `translate(m)` | mRNA | 从第一个 AUG 读起、到终止密码子为止的氨基酸序列 | |
| `anticodon(c)` | 密码子 | tRNA 上的反密码子 | 反密码子与密码子互补 |
| `synonyms(aa)` | 氨基酸 | 编码它的全部密码子 | 密码的简并 |
| `mutate(s, kind)` | 基因、突变类型 | 突变后的序列、翻译结果、和正常的差别 | |

## 第 1 课 DNA 的双螺旋结构

| 项目 | 内容 |
|---|---|
| 知识点 | 两条链反向平行盘旋成双螺旋；脱氧核糖和磷酸交替连接在外侧构成基本骨架，碱基在内侧；A 与 T、G 与 C 配对，以氢键相连 |
| 一句概念 | 碱基互补配对，两条链反向平行 |
| 核心动作 | 给左边一条链的 12 个碱基逐个配上互补的脱氧核苷酸；标出两条链的方向；盘成双螺旋 |
| 看到的现象 | 游离的脱氧核苷酸一个个飘过来，对上了才贴住；A—T 两根氢键、G—C 三根；梯子拧成螺旋 |
| 读数 | 双链中 A、T、G、C 的个数，(A+G)/(T+C) |
| 真实锚点 | 双螺旋直径约 2 nm，每转约 10 对碱基 |
| 对应小测 | 第 1 题 |

上链：5′-ATGCGTACCGAG-3′；配出的链（下，按 3′→5′ 从左往右）：TACGCATGGCTC；按 5′→3′ 写为 CTCGGTACGCAT。

任务：
- [ ] 给第一个碱基 A 配对（配上 T）
- [ ] 把剩下的 11 个都配上
- [ ] 标出两条链的方向
- [ ] 把梯子盘成双螺旋

按钮：配一个碱基（第二次起变成“配完剩下的”）、标出方向、盘成双螺旋。

数据：双链里 A = T = 5，G = C = 7，(A+G)/(T+C) = 1（`counts`、`purineRatio`）。

## 第 2 课 DNA 的复制

| 项目 | 内容 |
|---|---|
| 知识点 | 解旋酶解开双链；以每条链为模板，DNA 聚合酶按碱基互补配对连上游离的脱氧核苷酸；边解旋边复制；子代 DNA 各含一条母链（半保留复制） |
| 一句概念 | 复制是半保留的：每个子代 DNA 留一条母链 |
| 核心动作 | 让复制叉从左走到右；再复制两代 |
| 看到的现象 | 环形的解旋酶往前推，双链在它身后分开；两个 DNA 聚合酶在两条模板上把橙色的子链一个个接上（一条连续，另一条一段一段）；最后变成两个 DNA，都是一蓝一橙 |
| 读数 | 第 n 代 DNA 分子数、含母链的 DNA 数、母链占全部链的比例、用掉的游离脱氧核苷酸数 |
| 真实锚点 | 1 个 DNA 复制 3 代得 8 个，其中 2 个含母链 |
| 对应小测 | 第 2、9 题 |

任务：
- [ ] 让复制叉从头走到尾（两个 DNA，各一条母链）
- [ ] 再复制一代（4 个，含母链的 2 个）
- [ ] 再复制一代，数含母链的（8 个里 2 个，占 1/4）

按钮：开始复制、再复制一代。

数据（16 对碱基的一段）：n=1：2 个 DNA，2 个含母链，母链占 1/2，用掉 32 个脱氧核苷酸；n=2：4，2，1/4，96；n=3：8，2，1/8，224。

## 第 3 课 基因是有遗传效应的 DNA 片段

| 项目 | 内容 |
|---|---|
| 知识点 | 染色体（染色质）主要由 DNA 和蛋白质组成；基因通常是有遗传效应的 DNA 片段；碱基对的排列顺序千变万化（多样性），每个 DNA 有特定的排列顺序（特异性） |
| 一句概念 | 基因通常是有遗传效应的 DNA 片段 |
| 核心动作 | 从染色质一级级放大到 DNA，找到两个基因；选碱基对数，算排列方式 |
| 读数 | n 对碱基的排列方式 4ⁿ |
| 对应小测 | 第 3 题 |

任务：
- [ ] 放大染色质：看 DNA 缠在组蛋白上
- [ ] 再放大：在 DNA 上找到基因
- [ ] 算一算：3 对碱基有几种排列（64）
- [ ] 10 对碱基呢（1 048 576）

按钮：放大一级。分段选择：碱基对数 1 / 3 / 10。

## 第 4 课 转录

| 项目 | 内容 |
|---|---|
| 知识点 | 在细胞核中，以 DNA 的一条链为模板，RNA 聚合酶按碱基互补配对合成 mRNA；RNA 中 U 代替 T；mRNA 通过核孔进入细胞质 |
| 一句概念 | 以 DNA 的一条链为模板合成 RNA |
| 核心动作 | 让 RNA 聚合酶沿基因走一遍；把 mRNA 和非模板链比一比；把 mRNA 送出核孔 |
| 看到的现象 | RNA 聚合酶里 DNA 解开一小段，核糖核苷酸配上去，粉色的 mRNA 从酶里一点点伸出来，走过的 DNA 又合上 |
| 读数 | mRNA 序列、碱基数（21） |
| 对应小测 | 第 4 题 |

基因：非模板链（编码链）5′-ATGGCTCACGAGTGGAAATGA-3′；模板链 3′-TACCGAGTGCTCACCTTTACT-5′；mRNA 5′-AUGGCUCACGAGUGGAAAUGA-3′。这一段是为了教学设计的示意序列（不是某个真实基因）。

任务：
- [ ] 让 RNA 聚合酶从头走到尾
- [ ] 把 mRNA 和另一条链比一比，找出不同
- [ ] 把 mRNA 送出细胞核

按钮：开始转录、和非模板链比一比、送出细胞核。

## 第 5 课 遗传密码

| 项目 | 内容 |
|---|---|
| 知识点 | mRNA 上决定一个氨基酸的 3 个相邻碱基叫密码子；从起始密码子开始读；终止密码子不编码氨基酸；多种密码子可以对应同一种氨基酸（简并） |
| 一句概念 | mRNA 上三个碱基决定一个氨基酸 |
| 核心动作 | 找到起始密码子，在密码表上一个个查下去，直到终止 |
| 看到的现象 | mRNA 上三个一组框起来，密码表上对应的行、列、格子亮起来 |
| 读数 | 当前密码子、氨基酸 |
| 对应小测 | 第 5 题 |

任务：
- [ ] 找到起始密码子 AUG（甲硫氨酸）
- [ ] 一个个查到终止密码子
- [ ] 看一看：丙氨酸有几种密码子（4 种：GCU、GCC、GCA、GCG）

按钮：找起始密码子、查下一个、看丙氨酸的密码子。

## 第 6 课 翻译

| 项目 | 内容 |
|---|---|
| 知识点 | 游离在细胞质中的氨基酸，以 mRNA 为模板合成有一定氨基酸顺序的蛋白质；核糖体沿 mRNA 移动；tRNA 一端携带氨基酸、另一端的反密码子与密码子配对；读到终止密码子，合成停止 |
| 一句概念 | 核糖体沿 mRNA 移动，tRNA 运来氨基酸 |
| 核心动作 | 让核糖体一格格往前走，直到终止 |
| 看到的现象 | 三叶草形的 tRNA 带着氨基酸进来，反密码子和密码子对上，肽链接上一个，核糖体往前挪三个碱基，空的 tRNA 离开；读到 UGA，肽链脱下 |
| 读数 | mRNA 碱基数 21、密码子 7 个、氨基酸 6 个 |
| 对应小测 | 第 6 题 |

任务：
- [ ] 第一个 tRNA 带着甲硫氨酸到位（反密码子 UAC）
- [ ] 接上第二个氨基酸
- [ ] 一直翻译到终止密码子（21 个碱基、6 个氨基酸）

按钮：前进一个密码子、翻译到底。

## 第 7 课 基因突变

| 项目 | 内容 |
|---|---|
| 知识点 | DNA 中碱基的替换、增添或缺失，引起基因碱基序列的改变，叫基因突变；镰状细胞贫血：血红蛋白基因一个碱基替换，谷氨酸换成缬氨酸 |
| 一句概念 | 碱基一变，蛋白质可能跟着变 |
| 核心动作 | 选一种突变，翻译，和正常的肽链比 |
| 看到的现象 | 替换：只有一个氨基酸变了，红细胞变成镰刀形；增添、缺失：从那里往后的氨基酸全变了 |
| 读数 | 各种情况下的氨基酸序列、和正常的相比变了几个 |
| 对应小测 | 第 7 题 |

序列：人血红蛋白 β 链基因开头的一段（编码链）ATG GTG CAC CTG ACT CCT GAG GAG AAG，镰状细胞贫血是第 7 个密码子（不算起始的甲硫氨酸是第 6 个氨基酸）GAG → GTG，谷氨酸 → 缬氨酸。增添、缺失在同一位置示意。

任务：
- [ ] 翻译正常的基因
- [ ] 换成碱基替换（A→T），翻译
- [ ] 换成增添一个碱基，翻译
- [ ] 换成缺失一个碱基，翻译

按钮：翻译这段。分段选择：正常 / 替换 / 增添 / 缺失。

## 讲解

解说词在 `src/labs/expression/narration.ts`。要讲清楚：第 1 课“为什么下面的链是从 3′ 读到 5′”；第 2 课另一条子链为什么是一段一段的（只说“方向相反”，不展开冈崎片段的名字）；第 4 课 T 和 U 的对照；第 6 课反密码子和密码子配对。

## 和规格卡原文的出入

- 第 2、5、6 课的任务合并成 3 条（原来 4 条）：读数放进任务说明，免得出现只看不做的任务。
- 第 1 课的序列改成 ATGCGTACCGAG，让 A、G 数目不同。
- 细胞核没有剖开一角，镜头直接在核内、核外取景。
- 第 6 课核糖体在内质网上方，大亚基没有朝向内质网（为了让 tRNA 和密码子朝镜头）。
