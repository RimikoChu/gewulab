# 静电场实验室 · 规格卡 v1.0

状态：已按此卡做完九个课次，待审。关联议题 #65。

## 总览

- 一句话：弄懂电荷之间的力怎样用“电场”来描述（电场强度、电场线、电势、等势面），再用它算出一个带电粒子在电场里怎样加速、怎样偏转，最后看懂喷码机怎样靠电场把一滴墨打到该去的位置。
- 教材位置：人教版高中物理必修第三册，第九章“静电场及其应用”（库仑定律；电场 电场强度）和第十章“静电场中的能量”（电势能和电势；电势差；电势差与电场强度的关系；电容器的电容；带电粒子在电场中的运动）。章节号见“待核实事项”。
- 主线：一滴带电的墨。前五课在实验台上把“力—场—电势—电容”逐个量出来，第 6 课让电子加速，第 7 课让墨滴在偏转板里做类平抛运动，拓展课用它打出一个点阵字。
- 场景：一座喷码机工厂的装配测试车间。**大场景的布局**：钢结构厂房，环氧地坪。北墙（z = −4.6）前是一条包装输送线，纸箱在辊道上排队，线上架着一台连续喷墨喷码机（白色机柜、软管、打印头）。车间中间（z = 0）沿东西方向一排七张防静电实验台，从西到东依次是第 1 到第 7 课的器材，相邻两张台相距 4.5 m；第 7 课的台子上是一台放大 10 倍的打印头教学模型。拓展课的喷码用 7 号台的打印头模型（换一个机位），静电屏蔽在最东头的 8 号台。随堂检测的镜头退到车间东南角看全景。
- 取值约定：静电力常量 k = 9.0×10⁹ N·m²/C²；真空介电常数 ε₀ = 8.85×10⁻¹² F/m；元电荷 e = 1.6×10⁻¹⁹ C；电子质量 9.11×10⁻³¹ kg；g = 9.8 N/kg。电场强度在点电荷处用 N/C，在平行板间用 V/m。力、功、电荷量用科学记数法，保留两位有效数字（库仑力保留三位）。
- 和同类产品的区别：电场线、等势面不是贴图，是按 `physics.ts` 里的场逐条算出来的；每课都有一个要读的数；最后落在一台真实机器（喷码机）上。
- 简化（规范 3.7）：带电球都按点电荷算；第 2 课的小球悬点由支架跟着移动，保证小球停在标出的距离上；第 3 课的头发屑画成几百根短丝，再叠上算出来的电场线；第 7 课和拓展课的打印头模型放大 10 倍、墨滴放慢，读数按真实尺寸；墨滴的重力远小于电场力，忽略。

## 共用的计算核心

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `coulomb(q1, q2, r)` | 两个电荷量、距离 | 力（N） | F = kq₁q₂/r² |
| `torsionForce(near, half)`、`twist(F)` | 距离是否减半、电荷量是否减半 | 力；旋钮转角（°） | 悬丝的扭转角和力成正比，取每度 4.0×10⁻⁵ N |
| `pointField(Q, r)`、`probeForce(q, r)`、`hangAngle(F)` | 电荷量、距离 | 场强、力、悬线偏角 | E = kQ/r²；tan θ = F/(mg) |
| `fieldAt(charges, p)`、`traceLine`、`fieldLines(layout)`、`hairDir(layout, p)`、`midField(layout)` | 电极摆法 | 合场强、电场线上的点、中点场强 | 场强叠加；沿场强方向逐步走（中点法） |
| `potential(x)`、`potDiff(a, b)`、`fieldWork(a, b)`、`uniField()` | 到正极板的距离、两点 | 电势、电势差、做功、场强 | φ = U(1 − x/d)；W = qU；E = U/d |
| `capacitance(S, d, ε)`、`capVoltage(mode)`、`meterAngle(U)` | 面积、板距、介质 | 电容、电压、静电计张角 | C = ε_rε₀S/d；Q 不变时 U = Q/C |
| `gunSpeed(U)` | 加速电压 | 速度 | qU = ½mv² |
| `deflect(q, U)`、`jetPath(q, U, x)` | 墨滴电荷量、偏转电压 | 加速度、时间、侧移、偏角、落点 | 类平抛：y₁ = ½at²，tan θ = at/v₀，y = y₁ + D tan θ |
| `rowCharge(k)`、`rowOffset(k)` | 点阵的行号 | 电荷量、落点 | 同上 |

## 第 1 课 库仑定律

在库仑扭秤上量两个带电小球之间的力。

| 项目 | 内容 |
|---|---|
| 知识点 | 库仑定律：真空中两个静止点电荷之间的力，与电荷量的乘积成正比，与距离的二次方成反比 |
| 一句概念 | 力与电荷量乘积成正比，与距离平方成反比 |
| 核心动作 | 把 C 球推近到一半距离；用不带电的同样小球碰一下 C 球，让它的电荷量减半 |
| 看到的现象 | A 球被推开，转动顶上的旋钮把它拉回原位，旋钮转过的角度和力成正比 |
| 读数 | 旋钮转角（°）、力（N） |
| 真实锚点 | 库仑扭秤：悬丝的扭转角度比较力的大小 |
| 对应小测 | 第 1 题 |

任务清单

- [ ] 给两个小球带上电，读出力（0.10 m，1.44×10⁻³ N，36°）
- [ ] 把 C 球推近到 0.05 m（5.76×10⁻³ N，144°：4 倍）
- [ ] 让 C 球的电荷量减半（2.88×10⁻³ N，72°：减半）

视觉映射

| 知识点 | 必须看见的东西 | 由哪个量驱动 | 镜头与视图 |
|---|---|---|---|
| 力的大小 | 顶上刻度盘的指针、两球之间一对斥力箭头 | `twist(F)`、F | 斜俯视，玻璃筒居中 |
| 距离 | C 球的位置、两球间的距离标注 | r | 同上 |

主操作区的按钮：带上电；推近到 0.05 m；电荷量减半。

直接操作：无（三步都是按钮）。

数据

| 条件 | 读数 | 来历 |
|---|---|---|
| 4.0×10⁻⁸ C、4.0×10⁻⁸ C、0.10 m | 1.44×10⁻³ N，36° | F = kq₁q₂/r² |
| 距离 0.05 m | 5.76×10⁻³ N，144° | 同上 |
| C 球 2.0×10⁻⁸ C、0.05 m | 2.88×10⁻³ N，72° | 同上 |

## 第 2 课 电场强度

用一个试探小球去“探”带电金属球周围的电场。

| 项目 | 内容 |
|---|---|
| 知识点 | 电场强度 E = F/q；点电荷的电场 E = kQ/r²；场强由场源决定，与试探电荷无关 |
| 一句概念 | E = F/q，由电场本身决定 |
| 核心动作 | 把试探小球挂到 0.10、0.20、0.30 m；换成电荷量一半的小球 |
| 看到的现象 | 离得越远悬线偏得越小；换小球后力减半，F/q 不变 |
| 读数 | F、F/q |
| 真实锚点 | 带电金属球（绝缘柱上的空心球） |
| 对应小测 | 第 2、3 题 |

任务清单

- [ ] 把小球挂到 0.10 m 处，记录（1.8×10⁻⁴ N，9.0×10⁴ N/C）
- [ ] 挂到 0.20 m，记录（2.25×10⁴ N/C，四分之一）
- [ ] 挂到 0.30 m，记录（1.0×10⁴ N/C，九分之一）
- [ ] 回到 0.10 m，换成电荷量一半的小球，记录（力减半，F/q 还是 9.0×10⁴ N/C）

主操作区的按钮：记录数据。分段选择：位置（0.10 / 0.20 / 0.30 m）。另一个按钮：换小球（q / q/2）。

数据：Q = 1.0×10⁻⁷ C；试探电荷 2.0×10⁻⁹ C 和 1.0×10⁻⁹ C；小球质量 0.05 g；偏角 tan θ = F/(mg)，0.10 m 处约 20°。

## 第 3 课 电场线

油盘里放电极，接通高压，浮在油面上的头发屑沿电场线排开。

| 项目 | 内容 |
|---|---|
| 知识点 | 电场线从正电荷（或无限远）出发，到负电荷（或无限远）终止；疏密表示强弱，切线方向是场强方向；不相交 |
| 一句概念 | 电场线的疏密表示强弱，切线表示方向 |
| 核心动作 | 依次换四种电极，接通高压，读中点场强 |
| 读数 | 两电极连线中点的场强 |
| 真实锚点 | 模拟电场线的演示：蓖麻油里的头发屑 |
| 对应小测 | 第 4 题 |

任务清单

- [ ] 一个正电荷：接通高压（电场线向四周散开；距它 0.06 m 处 5.0×10⁴ N/C）
- [ ] 等量异种：接通（从正到负；中点 1.0×10⁵ N/C）
- [ ] 等量同种：接通（互相排开；中点 0）
- [ ] 平行板：接通（平行等距，匀强电场 5.0×10⁴ V/m）

主操作区的按钮：接通高压。分段选择：电极（四种）。

数据：每个电极 2.0×10⁻⁸ C，两电极相距 0.12 m；平行板相距 0.10 m、电压 5000 V。电场线由 `fieldLines` 逐条算出。

## 第 4 课 电势和等势面

两块大平行板之间的匀强电场，半透明的面是等势面。

| 项目 | 内容 |
|---|---|
| 知识点 | 电势、等势面、电势差；W = qU 与路径无关；匀强电场 U = Ed；沿电场线电势降低；电场线与等势面垂直 |
| 一句概念 | 电场力做功只看两点的电势差 |
| 核心动作 | 用探针量 A、B 的电势；把试探电荷沿 A→B、B→C、A→C 三条路移动 |
| 读数 | φ_A、φ_B、U_AB、W |
| 对应小测 | 第 5、6 题 |

任务清单

- [ ] 用探针量 A、B 两点的电势（500 V、100 V，U_AB = 400 V，E = 400 V ÷ 0.20 m = 2000 V/m）
- [ ] 把电荷沿电场线从 A 移到 B（W = 8.0×10⁻⁶ J）
- [ ] 沿等势面从 B 移到 C（W = 0）
- [ ] 从 A 斜着直接到 C（W 还是 8.0×10⁻⁶ J）

主操作区的按钮：量电势；移动电荷。分段选择：路径（A→B / B→C / A→C）。

数据：U = 600 V，d = 0.30 m，负极板接地取 0；等势面每 100 V 一个，相距 0.05 m；q = +2.0×10⁻⁸ C；A 距正极板 0.05 m，B、C 距正极板 0.25 m，C 比 B 高 0.10 m。

## 第 5 课 电容器

平行板电容器接静电计：充电后断开电源，电荷量不变，改电容看电压。

| 项目 | 内容 |
|---|---|
| 知识点 | 电容 C = Q/U；平行板电容器 C = ε_rε₀S/d；充电和放电 |
| 一句概念 | 板距小、正对面积大、有介质，电容就大 |
| 核心动作 | 充电后断开；板距加倍；正对面积减半；插入介质板；放电 |
| 读数 | 静电计张角、U、C、Q |
| 对应小测 | 第 7 题 |

任务清单

- [ ] 给电容器充电到 1000 V，然后断开电源（Q ≈ 1.3×10⁻⁸ C）
- [ ] 板距加倍（C 减半，U 升到 2000 V）
- [ ] 正对面积减半（C 减半，U 升到 2000 V）
- [ ] 插入介质板（C 变 3 倍，U 降到约 333 V）
- [ ] 放电（U 回到 0）

主操作区的按钮：充电并断开；放电。分段选择：电容器（原样 / 板距加倍 / 正对面积减半 / 插入介质板）。

数据：S = 0.030 m²，d = 0.020 m，C = 13.3 pF；ε_r = 3；静电计张角与电压成正比（2000 V 对应 56°，示意）。

## 第 6 课 粒子的加速

示波管里的电子枪：电子从阴极出发，被加速电压拉向阳极。

| 项目 | 内容 |
|---|---|
| 知识点 | 电场力做功等于动能的增加：qU = ½mv² |
| 一句概念 | 加速电压越高，粒子越快：qU = ½mv² |
| 核心动作 | 500 V 发射；2000 V 发射；反接电源 |
| 读数 | 电子穿出阳极时的速度、动能（eV） |
| 对应小测 | 第 8 题 |

任务清单

- [ ] 用 500 V 发射电子（1.33×10⁷ m/s）
- [ ] 换成 2000 V 再发射（2.65×10⁷ m/s：电压 4 倍，速度 2 倍）
- [ ] 把电源反接，再发射（电子被推回阴极，出不来）

主操作区的按钮：发射电子；电源反接。分段选择：加速电压（500 / 1000 / 2000 V）。

## 第 7 课 粒子的偏转

喷码机打印头的教学模型：墨滴先带上电，再飞过一对偏转板。

| 项目 | 内容 |
|---|---|
| 知识点 | 带电粒子垂直进入匀强电场做类平抛运动：沿初速度方向匀速，沿电场方向匀加速 |
| 一句概念 | 垂直进入匀强电场，粒子做类平抛运动 |
| 核心动作 | 不带电喷一滴；带 2.0×10⁻¹³ C；带 4.0×10⁻¹³ C；偏转电压减半 |
| 读数 | 出板时的侧移、落在纸上的侧移 |
| 真实锚点 | 连续喷墨喷码机：不带电的墨滴直飞进回收槽，带电的被偏转板打到纸上 |
| 对应小测 | 第 9 题 |

任务清单

- [ ] 不充电，喷一滴（直飞进回收槽）
- [ ] 充 2.0×10⁻¹³ C，喷一滴（落点 2.4 mm）
- [ ] 充 4.0×10⁻¹³ C，喷一滴（落点 4.8 mm：电荷量加倍，落点加倍）
- [ ] 把偏转电压减半，再喷一滴（落点回到 2.4 mm）

主操作区的按钮：喷一滴；电压减半。分段选择：墨滴的电荷量（三档）。

数据：m = 1.0×10⁻¹⁰ kg，v₀ = 20 m/s，板长 20 mm，板距 10 mm，电压 6000 V（E = 6.0×10⁵ V/m），出板到纸 30 mm。q = 4.0×10⁻¹³ C 时 a = 2400 m/s²，t = 1.0 ms，y₁ = 1.2 mm，tan θ = 0.12，y = 4.8 mm。

## 讲解

解说词在 `src/labs/efield/narration.ts`。自动演示时各课应放出的句数（开场 + 各步 + 结论）：第 1 课 8，第 2 课 10，第 3 课 13，第 4 课 12，第 5 课 12，第 6 课 10，第 7 课 13，拓展课 10，随堂检测 2。同一句提示语重复出现的（“记录数据”“接通高压”“喷一滴”等）解说写成通用说法，每一步看到了什么放在下一步开头说。要特别讲清的：第 1 课旋钮转角和力成正比；第 4 课“斜着走做功一样多”；第 5 课“断开电源以后电荷量不变”；第 7 课读数是按真实尺寸算的，模型放大了 10 倍。科学记数法按“几乘十的负几次方”读。

## 和规格卡原文的出入

- 议题里写的是“电场线和等势面；加速和偏转；电容器”三项。按教材顺序补了库仑定律和电场强度两课，电容器放在加速、偏转之前（教材顺序）。
- 第 1 课的扭秤为了看得清，悬丝管做短了，小球半径画成 1.6 cm（规格卡 3.7 的简化，力按点电荷算）。
- 第 3 课油面上画了约五百根头发屑：没通电时方向杂乱，通电后转到当地电场的方向（`hairDir`），电场线叠在上面。
- 拓展课的喷码加了一块检视屏，把纸带上打出的点阵放大显示；纸带上的字是真实大小的 10 倍，只有几厘米高。
