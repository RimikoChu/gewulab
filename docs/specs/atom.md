# 分子和原子实验室 · 规格卡 v1.0

状态：待审。关联议题 #16。

## 总览

- 一句话：从一滴水一路放大到原子核，弄懂物质由分子、原子构成；分子在运动、有间隔；化学变化里分子分成原子；原子由原子核（质子、中子）和电子构成；质子数相同的一类原子叫一种元素。
- 教材位置：人教版化学九年级上册 第三单元“物质构成的奥秘”（课题 1 分子和原子、课题 2 原子的结构、课题 3 元素）。新版教材的单元和课题编号见“待核实事项”。
- 主线：同一滴水。第 1 课放大到水分子，第 5 课把水分子拆开，第 6 课放大到氧原子和原子核，第 7 课看原子核里的质子数。
- 场景：一间中学化学实验室。北墙一条长实验台（黑色理化板台面、白瓷砖墙裙、墙上试剂架），西头一台通风橱，东墙挂一张元素周期表挂图，窗外是校园。各课在台上各占一格，自西向东：
  - 通风橱（第 2 课）→ 表面皿上的一滴水（第 1 课）→ 冷热水两只烧杯（第 3 课）→ 量筒（第 4 课）→ 水电解器和分子模型盘（第 5 课）→ 铁架台上的滴管（第 6 课）→ 周期表挂图和原子核模型（第 7 课）→ 注射器和热水杯（拓展）。随堂检测看整间实验室。
  - 第 1、6 课的“放大”是真的镜头推进：整间实验室绕着那滴水等比放大（等价于镜头一路推近），推到水滴里面以后，依次接上水分子、原子、原子核三层模型，每层在上一层的同一点上接着放大，中间不跳。
- 取值约定：温度 20 °C（冷水）、80 °C（热水）；相对原子质量 H 1、C 12、N 14、O 16；20 滴水约 1 mL；阿伏加德罗常数 6.02×10²³ mol⁻¹（只在 physics.ts 里用来算一滴水里的分子数，界面上不出现这个名字）；R = 8.314 J/(mol·K)。
- 和同类产品的区别：放大不是切换图片，而是同一个三维世界里连续推进 13 个数量级；分子用比例模型，原子大小比例按范德华半径；每课学生亲手做实验、读一个数。

## 共用的计算核心

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `dropVolume()` | — | 一滴水的体积 0.05 mL | 20 滴水约 1 mL（教材的取法） |
| `moleculesInDrop()` | — | 1.67×10²¹ | 0.05 g ÷ 18 g/mol × 6.02×10²³ |
| `waterMoleculeMass()` | — | 2.99×10⁻²⁶ kg | 18 g/mol ÷ 6.02×10²³ |
| `viewWidth(z)` | 放大级 z | 视野宽度（m） | 第 0 级视野 30 cm，每级 10 倍；第 1 课从 20 cm、第 6 课从 5 cm 开始 |
| `meanSpeed(Mr, T)` | 相对分子质量、温度 | 分子热运动的平均速率（m/s） | √(8RT / πM)，气体和液体里的分子都适用 |
| `diffuseRate(T)` | 温度 | 品红扩散快慢（相对 20 °C） | 斯托克斯—爱因斯坦关系 D ∝ T/η；水的黏度 20 °C 1.002 mPa·s、80 °C 0.355 mPa·s。只驱动动画，界面不显示 |
| `mixVolume(a, w)` | 酒精、水的体积（mL） | 混合后的体积 | 20 °C 密度：乙醇 0.7893、水 0.9982 g/mL；混合液按质量分数插值（40% 0.9352、50% 0.9139 g/mL）。50 + 50 → 约 96 mL |
| `electrolysis(t)` | 通电时间 | 两极气体体积 | 2H₂O = 2H₂↑ + O₂↑，体积比 2 : 1 |
| `ATOMS` | 原子名 | 质子、中子、电子数 | H-1、C-12、C-14、N-14、O-16 |
| `nucleusCharge`、`netCharge` | 原子 | 核电荷数、整个原子的电荷 | 质子 +1、电子 −1、中子不带电 |
| `relMass` | 原子 | 质子数 + 中子数 | 质子、中子的相对质量约为 1，电子可忽略 |
| `syringe(p)`、`ballGrow(T)` | 压力倍数、温度 | 空气体积、球内空气体积倍数 | 玻意耳定律；等压时 V ∝ T |

## 第 1 课 一滴水

把一滴水一级级放大，看见水分子。

| 项目 | 内容 |
|---|---|
| 知识点 | 物质由分子、原子等微观粒子构成；分子的质量和体积都很小 |
| 一句概念 | 水由水分子构成，分子很小很小 |
| 核心动作 | 用滴管滴一滴水；按“放大”两次：先看水滴，再推进到水分子 |
| 看到的现象 | 镜头从实验台推进到水滴，穿进水里，水分子出现，并且一直在动 |
| 读数 | 视野宽度（20 cm → 1.2 cm → 4 nm）、放大倍数；一滴水里约 1.67×10²¹ 个水分子 |
| 真实锚点 | 一个水分子的质量约 3×10⁻²⁶ kg |
| 对应小测 | 第 1 题 |

任务清单
- [ ] 用滴管往表面皿上滴一滴水
- [ ] 放大，看清这滴水
- [ ] 继续放大，看见水分子
- [ ] 缩回实验台

视觉映射

| 知识点 | 必须看见的东西 | 由哪个量驱动 | 镜头与视图 |
|---|---|---|---|
| 分子很小 | 视野宽度连续变小 13 个数量级里的前 8 个 | 放大级 z | 镜头连续推进，主体始终在画面中心 |
| 分子在运动 | 水分子抖动、转动 | 时间 | 推进到水分子那一层 |

主操作区：滴一滴水、放大、缩小。数据：视野宽度由 `viewWidth` 算；分子数由 `moleculesInDrop` 算。

## 第 2 课 分子在运动

| 项目 | 内容 |
|---|---|
| 知识点 | 分子总是在不断运动着 |
| 一句概念 | 看不见的氨分子跑进了烧杯 A |
| 核心动作 | ① 往酚酞溶液里滴浓氨水（变红）；② 大烧杯罩住 A（酚酞溶液）和 B（浓氨水）；③ 等几分钟 |
| 看到的现象 | A 从外到里慢慢变红；放大示意圈里，氨分子从 B 跑出来进到 A |
| 读数 | 氨分子平均速率约 600 m/s（20 °C）；A 的颜色 |
| 对应小测 | 第 2 题 |

任务：滴浓氨水看颜色；罩上大烧杯；等几分钟看 A 变红；（B 一直无色）。主操作区：滴浓氨水、罩上大烧杯、等几分钟。

数据：`meanSpeed(17, 293.15)` ≈ 604 m/s。时间是快进的，界面写“几分钟后”，不写具体分钟数。

## 第 3 课 冷水和热水

| 项目 | 内容 |
|---|---|
| 知识点 | 温度越高，分子运动越快 |
| 一句概念 | 热水里，品红散得更快 |
| 核心动作 | 往两只烧杯里各放一小粒品红；看哪杯先变均匀；切换“冷水 / 热水”看分子 |
| 读数 | 两杯水的温度；水分子平均速率 20 °C 约 587 m/s、80 °C 约 644 m/s |
| 对应小测 | 第 3 题 |

任务：放入品红；等一会儿比较；看冷水里的分子；看热水里的分子。主操作区：放入品红、等一会儿。分段选择：冷水 / 热水（放大示意圈里看哪一杯）。

## 第 4 课 分子间有间隔

| 项目 | 内容 |
|---|---|
| 知识点 | 分子之间有间隔 |
| 一句概念 | 50 mL 加 50 mL，不到 100 mL |
| 核心动作 | 往量筒里倒 50 mL 水（染成红色便于看）；再沿壁倒 50 mL 酒精；塞紧，上下颠倒几次混匀 |
| 读数 | 量筒读数：50 → 100 → 约 96 mL |
| 真实锚点 | 混合前后总质量不变，体积变小 |
| 对应小测 | 第 4 题 |

主操作区：倒入水、倒入酒精、颠倒混匀。数据由 `mixVolume(50, 50)` 算。

## 第 5 课 分子分成原子

| 项目 | 内容 |
|---|---|
| 知识点 | 化学变化中，分子分成原子，原子重新组合成新分子；原子是化学变化中的最小粒子 |
| 一句概念 | 分子可以再分，原子重新组合 |
| 核心动作 | 接通电源电解水；把 2 个水分子模型拆成原子；组合成 2 个氢分子和 1 个氧分子 |
| 读数 | 负极、正极气体体积（2 : 1）；分子数 2 → 3；氢原子 4 → 4、氧原子 2 → 2 |
| 对应小测 | 第 5 题 |

主操作区：接通电源、拆成原子、组合成新分子。

## 第 6 课 原子的结构

| 项目 | 内容 |
|---|---|
| 知识点 | 原子由原子核和核外电子构成，原子核由质子和中子构成；核电荷数 = 质子数 = 核外电子数；原子不显电性；相对原子质量 ≈ 质子数 + 中子数 |
| 一句概念 | 原子核很小，电子在核外运动 |
| 核心动作 | 放大：水分子 → 氧原子 → 原子核；数一数质子、中子；换成氢原子再看 |
| 读数 | 氧：质子 8、中子 8、电子 8，相对原子质量 16；氢：1、0、1，相对原子质量 1 |
| 对应小测 | 第 6、7 题 |

主操作区：放大、缩小、数一数。分段选择：氧原子 / 氢原子。原子核在原子那一级画大了，标“示意，原子核实际小得多”。
