# 酸、碱和中和实验室 · 规格卡 v1.0

状态：待审。关联议题 #23。

## 总览

- 一句话：在一座化工园区的污水处理厂里，用指示剂、pH 试纸和 pH 计认识酸和碱的性质，亲手做一次酸碱中和，再到中和池里给一池酸性废水算好、投好熟石灰。
- 教材位置：人教版化学九年级下册，第十单元“酸和碱”（课题 1 常见的酸和碱；课题 2 酸和碱的中和反应）。章节号和新版教材的单元名见“待核实事项”。
- 主线：化工园区排来的酸性废水。先在化验室认识酸、碱和指示剂，再测它的 pH，最后在中和池里把它中和到可以排放。
- 场景：化工园区污水处理厂。**大场景的布局**（自西向东，画面单位 1 m = 6）：
  - 最西边是化验楼一层的化验室（x −176 到 −52）：门脸敞开，靠后墙一条长化验台。台子最西头是一台通风橱（第 2 课），往东依次是第 1、3、4 课的格子，第 5 课的滴定台，最东一格是拓展课。
  - 化验室往东隔一条厂内道路是污水处理区（x 0 到 170）：调节池、中和池（朝镜头剖开，带搅拌机和在线 pH 计，第 7 课）、贴着中和池的加药间（钢结构小厂房，前墙拿掉：熟石灰乳罐、液碱罐、加药泵）、沉淀池、排放口和在线监测房，排放口边上一张不锈钢取样台（第 6 课）。
  - 围墙外是化工园区：精馏塔、球罐、管廊和烟囱。
  - 随堂检测的机位从高处看整座厂。
- 取值约定：常温 25 °C，水的离子积取 1×10⁻¹⁴；相对原子质量 H 1、O 16、S 32、Na 23、Cl 35.5、Ca 40；稀溶液密度按 1 g/mL；pH 计读数保留一位小数，pH 试纸读整数。
- 指示剂变色（教材的简化说法）：紫色石蕊溶液遇酸变红、遇碱变蓝、中性仍为紫色；无色酚酞溶液遇酸和中性不变色、遇碱变红。酚酞的变色点按 pH 8.2 算（第 5 课用）。
- 和同类产品的区别：滴定管、点滴板、pH 试纸和比色卡做成实物的样子，读数都由 `physics.ts` 按浓度和体积算出；中和反应同时看颜色、pH 计读数和 pH 曲线三样；最后落到一池真实尺度的废水上做一次投药计算。

## 共用的计算核心

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `litmus(pH)` | pH | 红 / 紫 / 蓝 | 教材：遇酸红、遇碱蓝；按 pH < 5 红、> 8 蓝（显色范围约 5–8） |
| `phenol(pH)` | pH | 无色 / 红 | pH ≥ 8.2 显红 |
| `phOf(cH)` / `phOfOH(cOH)` | 氢离子 / 氢氧根浓度 | pH | pH = −lg c(H⁺)，c(H⁺)·c(OH⁻) = 1×10⁻¹⁴ |
| `titrationPH(V)` | 加入的盐酸体积 mL | pH | 20.00 mL 0.100 mol/L NaOH 加 0.100 mol/L HCl，强酸强碱，体积相加 |
| `paperRead(pH)` | pH | 试纸读数（整数）和比色卡颜色 | 广泛 pH 试纸 1–14 的标准色 |
| `limeNeed(V, c)` | 废水体积 m³、硫酸浓度 mol/L | 熟石灰 kg | Ca(OH)₂ + H₂SO₄ = CaSO₄ + 2H₂O，M(Ca(OH)₂) = 74 g/mol |
| `pondPH(kg)` | 投加的熟石灰 kg | 池水 pH | 按剩余的硫酸或多出的氢氧化钙算 |
| `heatRise()` | — | 中和后升高的温度 | ΔT = n·57.3 kJ/mol ÷ (m·4.18 J/(g·°C)) |

## 第 1 课 酸碱指示剂

化验台上一块白瓷点滴板，两排六个凹穴；左边三只细口瓶（稀盐酸、食盐水、石灰水），右边两只滴瓶（紫色石蕊溶液、无色酚酞溶液）。

| 项目 | 内容 |
|---|---|
| 知识点 | 酸碱指示剂（石蕊、酚酞）遇酸碱溶液的颜色变化 |
| 一句概念 | 指示剂遇酸、遇碱显示不同的颜色 |
| 核心动作 | 选一种溶液，往它上排的凹穴滴石蕊、下排的凹穴滴酚酞 |
| 看到的现象 | 稀盐酸：石蕊变红、酚酞不变色；食盐水：石蕊仍紫、酚酞不变色；石灰水：石蕊变蓝、酚酞变红 |
| 读数 | 表格里六格颜色 |
| 真实锚点 | 污水厂化验室每天用指示剂快速判断水样的酸碱性 |
| 对应小测 | 第 1 题 |

任务清单

- [ ] 给稀盐酸滴石蕊和酚酞
- [ ] 给石灰水滴石蕊和酚酞
- [ ] 给食盐水滴石蕊和酚酞（反例：中性溶液两种都不变）

主操作区的按钮：滴石蕊、滴酚酞。分段选择：溶液（稀盐酸 / 食盐水 / 石灰水）。

数据：颜色由 `litmus`、`phenol` 按三种溶液的 pH 定出（计算里设定稀盐酸 1、食盐水 7、石灰水 12）；三种溶液的 pH 不显示在界面上（第 6 课才讲 pH）。

## 第 2 课 常见的酸

通风橱里：一瓶浓盐酸（带磨口塞）、一瓶浓硫酸、一张白纸、一根玻璃棒、一只盛水的烧杯。

| 项目 | 内容 |
|---|---|
| 知识点 | 浓盐酸的挥发性；浓硫酸的腐蚀性（使纸张炭化）；浓硫酸的稀释方法 |
| 一句概念 | 浓盐酸易挥发，浓硫酸有强腐蚀性 |
| 核心动作 | 打开浓盐酸瓶塞；玻璃棒蘸浓硫酸在纸上写字；把浓硫酸沿烧杯壁慢慢注入水中并搅拌 |
| 看到的现象 | 瓶口出现白雾；纸上的字迹慢慢变黑；烧杯外壁发烫 |
| 读数 | 无数字，物理性质表 |
| 真实锚点 | 污水厂和化工厂里，浓酸都在通风橱或通风良好的地方取用 |
| 对应小测 | 第 2 题 |

任务清单

- [ ] 打开浓盐酸的瓶塞，看瓶口
- [ ] 用玻璃棒蘸浓硫酸，在纸上写个字
- [ ] 稀释浓硫酸：把浓硫酸沿烧杯壁慢慢注入水中

按钮：打开瓶塞、在纸上写字、稀释浓硫酸。稀释的顺序在原理里讲（切不可把水倒进浓硫酸）。

## 第 3 课 酸的化学性质

试管架上两支试管；一枚生锈的铁钉、一小瓶锌粒、一瓶稀盐酸。

| 项目 | 内容 |
|---|---|
| 知识点 | 酸与金属氧化物反应（除铁锈）；酸与活泼金属反应生成氢气 |
| 一句概念 | 酸能和铁锈、和活泼金属反应 |
| 核心动作 | 把生锈铁钉放进试管，加稀盐酸，等一会儿；换锌粒再做 |
| 看到的现象 | 铁锈溶解，溶液变黄；铁锈除尽后铁钉表面冒气泡；锌粒表面冒出大量气泡 |
| 读数 | 现象表 |
| 真实锚点 | 污水厂检修时用稀盐酸给管件除锈（酸洗） |
| 对应小测 | 第 3 题 |

任务清单

- [ ] 生锈的铁钉放进稀盐酸
- [ ] 铁锈除尽后再等一会儿
- [ ] 锌粒放进稀盐酸

方程式：Fe₂O₃ + 6HCl = 2FeCl₃ + 3H₂O；Fe + 2HCl = FeCl₂ + H₂↑；Zn + 2HCl = ZnCl₂ + H₂↑。

按钮：加稀盐酸、等一会儿。分段选择：铁钉 / 锌粒。

## 第 4 课 常见的碱

表面皿上几粒氢氧化钠，一只盛水的烧杯，一只盛石灰水的烧杯和一根吸管。

| 项目 | 内容 |
|---|---|
| 知识点 | 氢氧化钠易潮解、溶于水放热、有强腐蚀性；氢氧化钙微溶于水；碱与二氧化碳反应 |
| 一句概念 | 氢氧化钠易潮解，碱能和二氧化碳反应 |
| 核心动作 | 氢氧化钠在空气中放一会儿；放进水里摸烧杯；往石灰水里吹气 |
| 看到的现象 | 表面变潮湿；烧杯外壁发热；石灰水变浑浊 |
| 读数 | 现象表、俗名 |
| 真实锚点 | 加药间里的液碱和熟石灰乳就是这两种碱 |
| 对应小测 | 第 4 题 |

任务清单

- [ ] 氢氧化钠放在表面皿上，放一会儿
- [ ] 把氢氧化钠放进水里，摸一摸烧杯
- [ ] 用吸管向石灰水里吹气

方程式：CO₂ + Ca(OH)₂ = CaCO₃↓ + H₂O；2NaOH + CO₂ = Na₂CO₃ + H₂O（原理里讲，氢氧化钠要密封保存）。

## 第 5 课 中和反应（样板课）

滴定台：铁架台上的蝴蝶夹夹着一支 25 mL 酸式滴定管，装着 0.100 mol/L 稀盐酸；下面是放在铁架台底座上的磁力搅拌器和一只 250 mL 烧杯，盛 20.00 mL 0.100 mol/L 氢氧化钠溶液，插着 pH 电极，电极线接到台式 pH 计。

| 项目 | 内容 |
|---|---|
| 知识点 | 酸和碱作用生成盐和水；中和时 pH 的变化；指示剂判断“恰好完全反应” |
| 一句概念 | 酸和碱作用生成盐和水 |
| 核心动作 | 滴酚酞；先快放到 19.50 mL；再一滴一滴加到红色恰好褪去；多滴一滴看 pH |
| 看到的现象 | 溶液变红；滴下的地方一闪而过的无色，搅匀后又红；最后一滴红色褪去；pH 从 13.0 落到 7.0，多一滴落到 3.9 |
| 读数 | 滴定管读数（mL，两位小数，25 mL 酸式滴定管）、pH 计读数、pH 曲线 |
| 真实锚点 | 化验室测废水酸度、碱度的基本方法就是这样的滴定 |
| 对应小测 | 第 5 题 |

任务清单

- [ ] 往氢氧化钠溶液里滴两滴酚酞
- [ ] 打开活塞，先放到 19.50 mL
- [ ] 一滴一滴加，到红色恰好褪去
- [ ] 再多滴一滴，看 pH（反例：盐酸过量）

数据（一滴按 0.05 mL）：

| 加入盐酸 | pH | 来历 |
|---|---|---|
| 0.00 mL | 13.0 | c(OH⁻) = 0.100 mol/L |
| 19.50 mL | 11.1 | c(OH⁻) = 0.100 × 0.50 ÷ 39.50 |
| 19.95 mL | 10.1 | 仍为红色 |
| 20.00 mL | 7.0 | 恰好中和 |
| 20.05 mL | 3.9 | c(H⁺) = 0.100 × 0.05 ÷ 40.05 |

按钮：滴酚酞、放到 19.50 mL、滴一滴（按住连续滴）。

## 第 6 课 溶液的酸碱度

排放口旁的不锈钢取样台：三只取样瓶（调节池进水、中和池出水、加药间碱液），一块白瓷板上三条 pH 试纸，一张标准比色卡，一根玻璃棒。

| 项目 | 内容 |
|---|---|
| 知识点 | pH 的范围 0–14，< 7 酸性、= 7 中性、> 7 碱性；pH 越小酸性越强；pH 试纸的正确用法 |
| 一句概念 | pH 小于 7 显酸性，大于 7 显碱性 |
| 核心动作 | 选一瓶，用玻璃棒蘸取滴到试纸上，再和比色卡对照 |
| 看到的现象 | 试纸变色；比色卡上对应的色块亮出来 |
| 读数 | 进水 pH 2，出水 pH 7，碱液 pH 12 |
| 真实锚点 | 城镇污水处理厂出水 pH 要在 6–9 之间（GB 18918-2002 表 1 基本控制项目） |
| 对应小测 | 第 6、7 题 |

任务清单

- [ ] 测调节池进水的 pH
- [ ] 测中和池出水的 pH
- [ ] 测加药间碱液的 pH

数据：

| 水样 | 读数 | 来历 |
|---|---|---|
| 调节池进水 | 2 | 按含硫酸 0.005 mol/L（c(H⁺) = 0.01 mol/L）设定，和第 7 课同一池水 |
| 中和池出水 | 7 | 恰好中和 |
| 加药间碱液 | 12 | 按 0.01 mol/L 氢氧化钠设定 |

水样的浓度是为了教学设定的，界面上只出现读数。

## 第 7 课 中和反应的应用

中和池朝镜头剖开：池里一台立式搅拌机，池边一支在线 pH 计和显示屏；后面的加药间里有熟石灰乳罐和加药泵，一根加药管接到池里。

| 项目 | 内容 |
|---|---|
| 知识点 | 用熟石灰中和酸性废水；根据化学方程式计算 |
| 一句概念 | 用熟石灰中和酸性废水 |
| 核心动作 | 算一池废水要多少熟石灰；分别投 20、37、50 kg，看在线 pH 计 |
| 看到的现象 | 石灰乳顺加药管流进池里，搅拌后 pH 上升；20 kg 不够，37 kg 到 7.0，50 kg 超过 9 |
| 读数 | 在线 pH 计读数；熟石灰用量 |
| 真实锚点 | 排放要求 pH 6–9（同第 6 课） |
| 对应小测 | 第 8 题 |

计算：一池废水 100 m³，含硫酸 0.005 mol/L，硫酸 500 mol；需要 Ca(OH)₂ 500 mol × 74 g/mol = 37.0 kg。

| 投加熟石灰 | 池水 pH | 来历 |
|---|---|---|
| 0 kg | 2.0 | c(H⁺) = 0.010 mol/L |
| 20 kg | 2.3 | 剩余硫酸 229.7 mol |
| 37 kg | 7.0 | 恰好中和 |
| 50 kg | 11.5 | 多出的氢氧化钙 175.7 mol，c(OH⁻) = 3.5×10⁻³ mol/L |

任务清单

- [ ] 算一算这一池要投多少熟石灰
- [ ] 投 20 kg，看 pH
- [ ] 投 37 kg，看 pH
- [ ] 投 50 kg，看 pH（反例：投多了）

按钮：算投加量、投加熟石灰。分段选择：投加量 20 / 37 / 50 kg。每次投加前自动换一池新的废水。

## 拓展课

| 课 | 名称 | 一句话 | 学生的核心动作 | 在场景里的位置 |
|---|---|---|---|---|
| 拓展一 | 紫甘蓝指示剂 | 紫甘蓝汁遇酸变红、遇碱变绿 | 把紫甘蓝汁分别滴进稀盐酸、清水、石灰水 | 化验台最东一格 |
| 拓展二 | 中和放热 | 中和反应放出热量 | 50 mL 0.50 mol/L 盐酸和 50 mL 0.50 mol/L 氢氧化钠溶液混合，读温度计 | 同上 |

中和放热的数：n = 0.025 mol，ΔT = 0.025 × 57.3 kJ ÷ (100 g × 4.18 J/(g·°C)) ≈ 3.4 °C，从 20.0 °C 升到 23.4 °C。不计散热，界面上标“约”。57.3 kJ/mol 是高中教材的中和热，界面只出现温度。

## 随堂检测

| 题 | 题目要点 | 对应课 | 考查的易错点 |
|---|---|---|---|
| 1 | 能使无色酚酞变红的溶液 | 1 | 酚酞遇酸不变色 |
| 2 | 稀释浓硫酸的正确操作 | 2 | 酸入水，不是水入酸 |
| 3 | 稀盐酸除铁锈后溶液的颜色 | 3 | 铁锈生成的是氯化铁，黄色 |

| 7 | pH 大小和酸碱性强弱 | 6 | pH 越小酸性越强 |
| 8 | 中和酸性废水的计算 | 7 | 按化学方程式的计量数 |
| 9 | 生活中的中和反应（胃酸过多服用含氢氧化铝的药） | 综合 | 改良酸性土壤用熟石灰，不用氢氧化钠 |

## 讲解

- 第 5 课最容易看漏的是“滴下去的地方先褪色，搅匀又红”，讲解里要提一句；“恰好褪色”那一滴要停顿。
- pH 读法：pH 7.0 读作“pH 七”，3.9 读作“三点九”。
- 化学式读中文名：HCl 读“盐酸”，NaOH 读“氢氧化钠”，Ca(OH)₂ 读“氢氧化钙”或“熟石灰”。

## 和规格卡原文的出入

- 第 5 课改用 25 mL 酸式滴定管（原写 50 mL）：管子短一些，整套滴定台在画面里能放大；烧杯改成 250 mL，液面高度是示意的（20 mL 太浅，电极插不到），不按体积比例画。
- 第 7 课每次投加的过程（换一池废水、投加、搅匀）压缩到 9 秒，原理里写了“过程加快了”。
- 第 3、4 课的反应和潮解过程加快了，原理里已注明。
