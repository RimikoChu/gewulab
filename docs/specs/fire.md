# 燃烧和灭火实验室 · 规格卡 v0.1

状态：九个课次（1–7、拓展、随堂检测）做完（2026-11-23），做了三轮截图打磨，待验收。关联议题 #20。

## 总览

- **一句话**：学生在一处消防训练基地里，先在科普实验厅的实验台上一个一个找出燃烧的三个条件（可燃物、氧气、温度达到着火点），再到室外训练场把三个条件合成“火三角”，用三种办法各灭一处火，给三种火选灭火器，最后回到实验厅做粉尘爆炸、认安全标志。
- **教材位置**：化学，初中。人教版九年级上册“燃料及其利用”单元的“燃烧和灭火”（燃烧的条件、灭火的原理和方法、易燃物和易爆物的安全知识）。准确的单元号、课题名见“待核实事项”。
- **主线**：火三角。前三课各找出一个条件，第 4 课合起来，第 5、6 课反过来拆掉一个条件灭火，第 7 课讲条件凑齐得太快会怎样（爆炸）。
- **场景**：消防训练基地（议题建议的场景，保留）。理由：基地里本来就有给中小学生上课的科普实验厅，室外训练场上有燃烧箱、厨房火灾模拟台、油盘火、灭火器架和训练塔，三条件和灭火的每一课都能用这里真有的东西来做；室内实验和室外实训在同一个院子里，镜头飞过去是连着的。
- **取值约定**：温度用 °C，整数；空气里氧气的体积分数取 21%；着火点取教材上的数（白磷 40 °C，红磷 240 °C，木材 250–330 °C）。场景里 1 m 画成 6 个单位（`M = 6`），实验台台面高 85 cm。
- **和同类产品的区别**：火焰不是贴图，是会摇曳的着色器火焰，靠舞台的泛光发光；烧杯罩住蜡烛以后，火焰是随着罩里氧气减少一点点变小再熄灭的，熄灭的时间按烧杯的容积算；铜片实验里铜片的温度跟着热水走，白磷、红磷谁先着、水下的白磷通氧以后才着，全由“温度是否达到着火点、有没有氧气”这一条判断推出来；灭火时选错了办法不报错，而是给出为什么不行（油锅泼水会溅、燃气火浇水浇不灭）。

课次理由：教材先做燃烧条件的探究（铜片实验），再归纳三个条件，然后讲灭火的原理和灭火器，最后讲易燃物和易爆物的安全，顺序一致。教材里铜片实验一次就同时说明了“需要氧气”和“温度要达到着火点”；这里把“需要氧气”先用烧杯罩蜡烛单独做一课（学生最熟悉），铜片实验专讲着火点，但第 3 课的最后一步（水下白磷通氧气）仍然回扣氧气。“需要可燃物”一课用的是教材上“用棉花分别蘸酒精和水加热”和“小木条、小石块加热”两个对比。

## 第 1 课 燃烧需要可燃物

| 项目 | 内容 |
|---|---|
| 一句概念 | 能燃烧的物质才会燃烧：可燃物 |
| 核心动作 | 选一样东西，按“放到火焰上加热” |
| 看到的现象 | 木条、酒精棉球着火；石块、水棉球烧不着（水棉球冒白汽） |
| 对应小测 | 第 1 题 |

任务：用坩埚钳夹起小木条加热；换成小石块；换成蘸酒精的棉球；换成蘸水的棉球。

## 第 2 课 燃烧需要氧气

| 项目 | 内容 |
|---|---|
| 一句概念 | 隔绝氧气，燃烧就停止 |
| 核心动作 | 罩上烧杯，看罩里氧气变少、火焰变小熄灭；换大烧杯再罩一次 |

| 对应小测 | 第 2 题 |

## 第 3 课 温度要达到着火点（样板课）

| 项目 | 内容 |
|---|---|
| 一句概念 | 温度要达到着火点，可燃物才会燃烧 |
| 核心动作 | 倒入冷水看一次，换热水看一次，再给水下白磷通氧气 |
| 读数 | 铜片温度；白磷 40 °C、红磷 240 °C |

## 第 6 课 灭火器的选择

| 项目 | 内容 |
|---|---|
| 一句概念 | 不同的火，用不同的灭火器 |
| 核心动作 | 每处火选一只灭火器；手套拔掉保险销，对准火焰根部压下压把 |
| 适用范围 | 水基型：木材、棉布等；干粉：一般失火，还有油、气等；二氧化碳：图书、档案、贵重设备、精密仪器 |
| 对应小测 | 第 7 题 |

## 画面上的约定

- 火焰是自己写的着色器：一张始终朝着镜头的面片，按噪声往上翻滚，焰心亮黄、外焰橙红，蜡烛和燃气火根部带一点蓝；颜色超过 1，配合舞台的泛光发出光晕。每处火配一盏闪动的点光源，照亮周围。
- 烟是一团团朝着镜头的软边贴片，往上飘、变大、变淡：木柴和油火是灰黑的烟，白磷燃烧是白烟，水浇在火上是白色的水汽。
- 蜡烛熄灭的时间是简化模型算的：蜡烛每秒耗氧约 4.4 mL（按每小时烧掉约 6 g 石蜡估算），氧气降到约 16% 熄灭，不考虑罩里气体的流动。界面上写“约”。
- 铜片的温度取热水的温度，忽略铜片散热；倒水以后铜片要过一会儿才热起来，画面上是升温的过程。
- 消防训练基地是示意：各处的距离比真实的近，方便镜头飞过去。
- 人手出现时是带袖子的手套：实验厅里是蓝色丁腈手套和白大褂的袖子，训练场上是消防手套和带反光条的战斗服袖子；只在动作进行时出现。
- 粉尘爆炸的铁皮罐朝镜头的一半剖开（规范 4.5），看得见罐里的蜡烛、漏斗和面粉；罐盖是透明塑料的，爆炸时被掀飞。
- 第 3 课的铜片实验放在通风橱里；倒水用一只盛水的大烧杯，铜片从旁边的白瓷板上盖到杯口。
- 第 5、6 课换“哪处火”时，镜头飞到那处火前面。
- 灭火器：筒体、底圈、黄铜瓶头阀、压把和提把、保险销和黄色拉环、压力表（二氧化碳灭火器没有）、喷管、喷嘴（二氧化碳是喇叭筒）、白色标签；标签上的型号（MSWZ/6、MFZ/ABC4、MT/5）是常见规格的写法，示意。

## 和规格卡原文的出入

- 议题建议的课次里，第 2 课“燃烧需要氧气”用烧杯罩蜡烛，第 3 课用铜片实验讲着火点，都照做。拓展课改成三个小专题（隔离带、低姿逃生、水枪灭火）；隔离带放在训练塔东边的一片枯草地上，背景是开阔的草地和训练塔；低姿逃生放在一只剖开的烟热训练室里，不在训练塔里（塔里的房间从外面看不清）。
- 第 7 课的安全标志做成四选一（禁止烟火、禁止吸烟、当心爆炸、禁止燃放鞭炮），问“面粉厂车间门口最该贴哪一个”，答案是禁止烟火；教材插图里还有别的图标，没有全做。

## 待核实事项

- [ ] 教材版本和章节：2012 版人教九年级上册是第七单元“燃料及其利用”、课题 1“燃烧和灭火”；2024 年新版教材的单元名和课题名没有对着书核对。
- [ ] 蜡烛每秒耗氧 4.4 mL、熄灭时氧气约 16% 是估算，不是实测；熄灭用时只作示意。
- [ ] 木材的着火点范围 250–330 °C 凭记忆，没有对着教材的表核对。
- [ ] 新版教材里灭火器写的是“水基型”还是“泡沫”；水基型灭火器（泡沫类）按国家标准也能扑灭部分油类火，这里只按教材讲“最合适”的一种。
- [ ] 面粉颗粒取 50 μm 是示意，没有查实测粒径。
- [ ] 安全标志的图形是自己画的示意图，形状和配色照国家标准的大类（禁止标志红圈斜杠、警告标志黄色三角），细节没有对照标准原图。
- [ ] 低姿逃生里烟层的高度是示意，没有给数。
- [ ] 没有用外部素材。
