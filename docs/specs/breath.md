# 呼吸实验室 · 规格卡 v0.1

状态：九个课次（1–7、拓展、随堂检测）按这张卡做完（2026-11-23），九课都能自动演示到结论条，待验收。关联议题 #30。

## 总览

- **一句话**：学生先剖开一个头颈部模型，看一口气怎样经过鼻、咽、喉、气管、支气管，被拦下灰尘、变得温暖湿润；再推近到肺泡，看支气管一级级分到肺泡、肺泡壁外缠着毛细血管；然后亲手让肋间肌和膈肌收缩，看胸廓怎样前后左右变大、上下变长，用钟罩模型对照，读出肺内气压比外界低多少；最后推近到肺泡壁，看氧和二氧化碳怎样穿过两层细胞，并用澄清石灰水比较吸入和呼出的气体。
- **教材位置**：生物，初中七年级下册，人教版“人体的呼吸”一章：呼吸道对空气的处理；发生在肺内的气体交换（含呼吸运动、肺泡与血液的气体交换）。准确的单元号、章号、节名以及 2024 年新版教材是否调整了这一章，见“待核实事项”。
- **主线**：一口气。第 1 课这口气从鼻孔进来，第 2 课它沿支气管走到肺泡，第 3、4 课看是什么把它“吸”进来的，第 5 课读出它为什么会流进来、流出去，第 6 课它在肺泡里把氧交给血液，第 7 课比较它进来时和出去时有什么不同。
- **场景**：议题建议“人体内部的胸腔和肺”。这里放在**同一座科学馆里的“呼吸展厅”**（血液循环实验室是这座馆的人体展厅），正中是一尊半身的胸腔模型（头到骨盆，立在展柱上）：皮肤是半透明的壳，里面有脊柱、十二对肋骨、胸骨、肋间肌、膈、两肺、气管和支气管树，模型会呼吸。它的正前方有一排展台，都转过身来朝着它：头颈部的正中剖面模型和气管内壁的放大镜球、肺泡和肺泡壁两个放大镜球、一张放钟罩模型和澄清石灰水的实验台。**理由**：第 1 课要剖开头颈部看呼吸道，第 4、7 课是课本上的实验装置，第 2、6 课是放大的示意模型，都放不进“真的人体内部”。放进一座展厅，所有课仍在一个连续的世界里，钟罩模型可以和对面的胸腔模型对照着看。
- **取值约定**：
  - 外界气压取 101.3 kPa（标准大气压）。
  - 颜色和血液循环实验室一致：**鲜红表示动脉血（含氧多），暗蓝表示静脉血（含氧少）**；毛细血管从流进来的一头到流出去的一头由蓝渐变到红。
  - 氧画成橙色小球，二氧化碳画成灰紫色小球，和血液循环实验室一致。
  - 画面里 1 个单位是 10 cm。头颈部剖面模型放大 1.5 倍；肺泡、气管内壁、肺泡壁三个放大模型另有放大倍数，都标“示意”。
  - 呼吸动作（肋骨上提的角度、膈下降的距离）为了看得清**放大了**，界面上标“示意，动作放大”。
- **和同类产品的区别**：同类产品多是一张胸廓剖面图加箭头，或一段钟罩模型的视频。这里胸廓是一根根肋骨绕着各自和脊柱的关节转动、肋间肌跟着收缩变色、膈的穹顶真的往下压；钟罩模型和旁边的胸腔模型同步动，学生自己拉橡皮膜；肺内气压按气体的体积和压强关系一步步算出来，吸气、呼气时的读数和气流方向对得上。

## 共用的计算核心

`src/labs/breath/physics.ts`

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `AIRWAY` | — | 呼吸道五段的名称和作用 | 教材 |
| `catchAt(size)` | 灰尘颗粒大小（µm，示意的三档） | 在哪里被拦下：鼻毛 / 黏液 / 到了肺里 | 教材“呼吸道对空气的处理能力是有限的”；颗粒大小只分三档，示意 |
| `dustTally(list)` | 一口气里的灰尘 | 鼻毛拦下几颗、黏液粘住几颗、进到肺里几颗 | 由上一条数出来 |
| `ribTurn(k)` | 肋间肌收缩的程度 k（0–1） | 肋骨上提的角度（度） | 示意，动作放大 |
| `chestDepth(k)`、`chestWidth(k)` | k | 胸廓前后径、左右径（cm） | 由肋骨转角按几何算出；静止时前后径 18 cm、左右径 28 cm 是成年人的大致尺寸，示意 |
| `diaDrop(k)` | 膈肌收缩的程度 k | 膈顶下降的距离（cm） | 示意，动作放大 |

| `jarPressure(dV)` | 多出来的空间 | 钟罩里（气球外）的气压（kPa） | 玻意耳定律 pV = 常数，钟罩里空气 1.5 L |
| `balloonR(V)` | 气球里的气体体积 | 气球半径 | 球的体积 |
| `breathStep(s, V, dt)` | 肺里的气体量、肺的容积、时间步长 | 新的气体量、肺内气压、气流 | pV = nRT 等温；气流 = 压强差 ÷ 气道阻力 |
| `lungVolume(k)` | 胸廓扩大的程度 | 肺的容积（L） | 平静呼气末 2.5 L，一次平静吸气多 0.5 L，示意 |
| `diffuse(a, b, rate, dt)` | 两边的含量 | 新的两边含量 | 从高处向低处扩散，量守恒 |
| `layersToCross()` | — | 2（肺泡壁、毛细血管壁各一层细胞） | 教材 |
| `AIR` | — | 吸入、呼出气体的成分（%） | 教材的表 |
| `co2In(kind, mL)` | 吹进的是呼出气体还是空气、多少 mL | 通入的二氧化碳（mL） | 成分表 × 体积 |
| `cloud(co2)` | 通入的二氧化碳 | 浑浊程度（0–1） | 示意：越多越浑 |

## 第 1 课 呼吸道

一口气从鼻孔进来，走过鼻、咽、喉、气管、支气管。

| 项目 | 内容 |
|---|---|
| 知识点 | 呼吸道的组成；鼻毛、鼻黏膜、气管的黏液和纤毛的作用；呼吸道对空气的处理能力有限 |
| 一句概念 | 呼吸道让空气变得清洁、温暖、湿润 |
| 核心动作 | “吸一口气”，看空气沿通道走，经过一段亮一段；看灰尘在哪里被拦下。“推近气管内壁”，看纤毛把黏液和灰尘往咽喉推 |
| 看到的现象 | 大颗灰尘挂在鼻毛上；小颗粘在气管的黏液上；最细的少数几颗一直走到肺里。纤毛一排排像麦浪一样摆，黏液层往上走 |
| 读数 | 一口气里的灰尘：鼻毛拦下几颗、黏液粘住几颗、进到肺里几颗（示意）；空气走过的段数 |
| 真实锚点 | 雾霾天戴口罩；感冒时鼻塞要用口呼吸，口呼吸的空气没被鼻处理 |
| 对应小测 | 第 1 题 |

任务清单

- [ ] 看灰尘在哪里被拦下
- [ ] 推近气管内壁，看纤毛把黏液往哪里送
- [ ] 认一认：咽是空气和食物共同的通道

## 第 2 课 肺和肺泡

| 项目 | 内容 |
|---|---|
| 知识点 | 肺位于胸腔，左右各一；支气管入肺后反复分支，末端形成肺泡；肺泡外缠绕着毛细血管；肺泡壁和毛细血管壁都只由一层上皮细胞构成 |
| 一句概念 | 肺泡多、壁薄，外面缠着毛细血管 |
| 核心动作 | “看支气管树”：肺变透明，支气管从气管开始一级级亮起来；“推近到肺泡”；“剖开肺泡” |
| 看到的现象 | 支气管越分越细，最后通到一串串肺泡；剖开后肺泡是空的，壁只有薄薄一层，外面贴着毛细血管 |
| 读数 | 模型里支气管分了几级；氧从肺泡到血液要穿过几层细胞（2） |
| 对应小测 | 第 2 题 |

任务清单

- [ ] 让肺变透明，看支气管一级级分下去
- [ ] 推近到肺泡
- [ ] 剖开肺泡，看壁有多薄
- [ ] 数一数：肺泡里的气到血液要穿过几层细胞

主操作区的按钮：看支气管树、推近到肺泡、剖开肺泡。

## 第 3 课 呼吸运动：胸廓

| 项目 | 内容 |
|---|---|
| 知识点 | 胸廓由脊柱、肋骨、胸骨和肋间肌等组成；肋间肌收缩时肋骨向上向外运动，胸骨向上向前，胸廓的前后径和左右径都增大 |
| 一句概念 | 肋间肌收缩，胸廓前后左右变大 |

| 对应小测 | 第 3 题 |

## 第 4 课 呼吸运动：膈

| 项目 | 内容 |
|---|---|
| 知识点 | 膈肌收缩，膈顶部下降，胸廓上下径增大；钟罩模型：玻璃钟罩代表胸廓，Y 形管代表气管和支气管，气球代表肺，橡皮膜代表膈 |
| 一句概念 | 膈肌收缩，膈顶下降，胸廓上下变长 |

| 对应小测 | 第 4 题 |

## 第 5 课 吸气和呼气时的气压

| 项目 | 内容 |
|---|---|
| 知识点 | 吸气：肋间肌和膈肌收缩 → 胸廓扩大 → 肺扩张 → 肺内气压低于外界 → 气体入肺；呼气相反 |
| 一句概念 | 肺内气压低于外界就吸气，高于外界就呼气 |
| 核心动作 | “吸气”“呼气”“记录数据” |
| 看到的现象 | 胸腔模型从侧面看，胸廓和膈一起动，肺胀大；鼻孔处的气流箭头朝里或朝外；肺旁的读数标签一直在变 |
| 读数 | 肺内气压（kPa，两位小数）、和外界相差多少（Pa）、肺的容积（L） |
| 真实锚点 | 平静吸气时肺内气压只比外界低一百帕左右 |
| 对应小测 | 第 5 题 |

## 第 6 课 肺泡里的气体交换

| 项目 | 内容 |
|---|---|
| 知识点 | 肺泡里氧的含量比血液里高，氧扩散进血液；血液里二氧化碳的含量比肺泡里高，二氧化碳扩散进肺泡；血液由静脉血变成动脉血 |
| 一句概念 | 气体从含量高的地方扩散到含量低的地方 |
| 核心动作 | “让血流过”；分段选择看“氧”或“二氧化碳”；“屏住呼吸”（肺泡里不换新鲜空气，交换变慢） |
| 看到的现象 | 橙色小球从肺泡穿过两层细胞进到红细胞里，红细胞由蓝变红；灰紫色小球反过来走 |
| 读数 | 流进来、流出去的血里氧和二氧化碳的多少（相对含量条，示意）；要穿过的细胞层数 |
| 对应小测 | 第 6 题、第 8 题 |

## 第 7 课 吸入和呼出的气体

| 项目 | 内容 |
|---|---|
| 知识点 | 呼出的气体与吸入的空气相比，二氧化碳和水分增多，氧减少；二氧化碳使澄清的石灰水变浑浊 |
| 一句概念 | 呼出的气体里二氧化碳多 |
| 核心动作 | “向甲瓶吹气”“向乙瓶推空气”“看成分表” |
| 看到的现象 | 两瓶里都冒气泡；甲瓶越来越浑，乙瓶基本不变 |
| 读数 | 各通入 300 mL 气体后，通入的二氧化碳：甲约 12 mL，乙约 0.09 mL；成分表 |
| 对应小测 | 第 7 题 |

## 和规格卡原文的出入

- 骨架里的示例课（称箱子）已删掉。
- 第 4 课：原来打算显示“拉下瞬间钟罩里的气压”（87.1 kPa，`jarPressure` 仍在计算核心里、有测试），做的时候发现这个数是“气球不鼓”的假想情况，学生容易当成真实读数，界面上改成只说“气压比外界低 → 空气进气球 → 相等”，不显示这个数。
- 第 3 课：加了“从上面看”时的一圈虚线（静止时胸廓的轮廓），方便比大小。
- 第 7 课：没有画人。吹气时，淡蓝的一串小团顺着吹气管流进甲瓶；推注射器时顺着胶皮管流进乙瓶。
- 场景：胸腔模型里加了一颗心脏（心尖朝左下，主动脉红、肺动脉和上腔静脉蓝，半透明，不讲它，不加标签）。
- 场景（第二轮）：原来头颈部模型在左、实验台在右、放大镜球挂在肺旁，几课的画面里会露出别的展台；改成前排一排、转过来朝着胸腔模型（见“大场景的布局”）。
- 加载（第二轮）：各个大模型改成分段生成，每段十来毫秒，当前这一课要用的先生成；进页面时不再有超过 0.5 秒的卡顿。
- 肺泡模型剖开时只剖左边一半（x < 0.85 的部分），右边的肺泡和毛细血管留着对照，“毛细血管壁”的标签指在右边。
