# 质量与密度实验室 · 规格卡 v0.1

状态：九个课次（1–7、拓展、随堂检测）全部做完（2026-11-21），待验收。关联议题 #6。

## 总览

- **一句话**：学生在一座金属冶炼厂的化验室里，用托盘天平称质量、用量筒测体积，自己称出“同种物质的质量和体积成正比”，得到密度这个概念，再用它测石块和盐水、认出一块金属、算出一块称不了的大铝锭有多重。
- **教材位置**：物理，初中。人教版八年级上册“质量与密度”一章（质量、密度、测量物质的密度、密度与社会生活）。准确的章号、节名见“待核实事项”。
- **主线**：一台托盘天平、一只量筒。前三课学会用它们，后四课用它们得到密度、使用密度。
- **场景**：金属冶炼厂的化验室和窗外的料场。化验室里靠墙一长排实验台，各课在台上各占一处；墙上一排窗，窗外是成垛的铝锭、铜板、钢坯，一台龙门吊，远处是熔炼车间和烟囱。料场上有一张检验台和一块轧制用的大铝锭。
- **取值约定**：密度用课本常见值，铝 2.7、铜 8.9、铁 7.9、水 1.0、冰 0.9、酒精 0.8（×10³ kg/m³）。质量用 g，体积用 cm³（1 mL = 1 cm³），密度同时给 g/cm³ 和 kg/m³。天平：称量 200 g，砝码 100、50、20、20、10、5 g 各一只，标尺 0–5 g、分度值 0.2 g。量筒：量程 100 mL，分度值 1 mL。
- **和同类产品的区别**：同类产品多是直接给出质量和体积让学生代公式。这里质量是在天平上从大到小试砝码、移游码称出来的，体积是在量筒上读出来的；横梁真的会倾斜、摆动、慢慢停住；规律（m–V 图线）是学生自己一个点一个点记出来的；步骤顺序对误差的影响，是把两种做法都做一遍比出来的。

## 共用的计算核心

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| 质量 | 物质、体积 | m = ρV | 密度公式 |
| 体积 | 物质、质量 | V = m ÷ ρ | 密度公式 |
| 密度 | 质量、体积 | ρ = m ÷ V；×1000 换成 kg/m³ | 密度的定义；1 g/cm³ = 1×10³ kg/m³ |
| 称量的过程 | 质量 | 砝码从大到小逐个试，放上去超过了就取下；剩下的由游码补 | 天平的使用方法 |
| 天平的读数 | 盘里的砝码、游码示数 | 两者相加 | 教材 |
| 横梁歪多少 | 左右两边各多少克 | 相差 2 g 以上歪到头；左边重则指针偏左 | 画面用的简化，见“画面上的约定” |
| 量筒里液柱的高度 | 体积、内半径 | 体积 ÷ 截面积 | 几何 |
| 斜着看的读数 | 体积、视线倾角 | 视线对准凹液面最低处，延长到近处筒壁所对的刻度 | 几何；只用来表现“俯视偏大、仰视偏小” |
| 排水法 | 两次读数 | 相减 | 教材 |

## 每课的操作

| 课 | 主操作区的按钮 | 一组开关 |
|---|---|---|
| 1 | 压成饼 / 等冰熔化 / 拿到料场（随开关换）、记录 | 改变什么：形状 / 状态 / 位置 |
| 2 | 游码归零 → 调平衡螺母；铜块放左盘 → 加某只砝码 / 取下某只砝码；移动游码 | 无 |
| 3 | 倒入水、放入石块、记录 | 视线：俯视 / 平视 / 仰视 |
| 4 | 称下一块、记录 | 物质：铝块 / 铜块 |
| 5 | 放上天平、记录 | 物质：铝块 / 铁块 / 铜块 |
| 6 | 一个按钮，文字是当前这一步（称石块的质量、往量筒里倒水……算密度） | 测什么：石块 / 盐水全倒 / 盐水倒一部分 |
| 7 | 一个按钮，文字是当前这一步（称质量、浸没在量筒里、算密度查表……） | 解决什么问题：这是什么金属 / 大铝锭有多重 / 铁球是空心的吗 |
| 拓展 | 每个专题一个按钮 | 选专题 |

每一课都能自动演示到结论卡。做错时有提示的地方：第 2 课没调平就放物体、砝码没试完就移游码；第 3 课没有平视就记录、没记 V₁ 就放石块。

每课的一句概念：1 质量不随形状、状态、位置改变；2 左物右码，砝码加游码就是质量；3 视线与凹液面的最低处相平；4 同种物质，质量与体积成正比；5 密度 ρ = m/V，是物质的一种特性；6 测出质量和体积，用 ρ = m/V 算密度；7 知道密度，能认物质、算质量、算体积。

## 拓展课

| 专题 | 一句话 | 学生的核心动作 |
|---|---|---|
| 水结成冰 | 质量不变，体积变大，密度变小：冰浮在水面上，水管会冻裂 | 按“让水结冰”，看烧杯里的体积从 90 cm³ 变成 100 cm³ |
| 冬天的湖 | 水在 4 ℃ 时密度最大，沉在湖底，所以湖不会冻到底 | 按“入冬降温”，看冰层和各层水温 |
| 热空气上升 | 气体受热膨胀，密度变小而上升，形成气流 | 按“点燃酒精灯”，看上方的纸风车转起来 |

## 随堂检测

九道题：冰熔化后质量和体积怎么变（第 1 课）、指针偏左怎样调平衡螺母（2）、由砝码和游码读质量（2）、俯视量筒读数偏大还是偏小（3）、排水法求体积（3）、同种物质质量与体积成正比的计算（4）、切掉一半密度变不变（5）、盐水全倒进量筒结果偏大还是偏小（6）、判断铁球空心并求空心体积（7）。拓展课不考。

## 画面上的约定

- 画面里 1 cm 画成 0.06 个单位，整间化验室和料场都按这个比例，器材之间的大小关系是真实的（天平底座长约 33 cm，托盘直径约 10 cm，量筒高约 18 cm，金属块截面 2 cm × 2 cm）。
- 托盘天平照学校里的架盘天平来建：漆面铸铁底座、立柱和刀口、横梁、指针和分度盘、横梁正面的标尺和游码、两端的平衡螺母、托盘架和托盘、导杆。指针朝上，分度盘在立柱顶上：左盘沉时指针偏左。
- 横梁的倾斜是按时间算的阻尼摆动；两边相差 2 g 以上就歪到限位。这是为了看得清做的简化，真实天平的灵敏度比这高得多。
- 东西要等落到盘里天平才动：物体和砝码都是“提起、平移、放下”，砝码由镊子夹着。没有画人的手。
- 读数在三维画面里小，所以右边面板里有放大的小图：第 1、2 课是分度盘和标尺的特写（读游码左边缘），第 3 课是量筒液面的侧面剖视（带视线）。
- 玻璃器皿用半透明材质（不做折射），里面的液体单独画；量筒里的液面是凹的。水画成蓝色、盐水画成黄绿色，只为了分得清，真的盐水是无色的。
- 第 3 课俯视、仰视的读数是按视线倾斜 15° 算的，界面上写“约”。
- 第 6 课“全倒”时杯壁沾住 2 mL 是为了看出偏差设的数，“看原理”里写明了。
- 第 7 课料场的大铝锭、拓展课的湖（一只长玻璃缸当剖面）是示意，不按比例。
- 金属块和铁球放进量筒时没有画细线。
- 金属块没有用公共的 `Metal` 材质，在 `parts.tsx` 里自己写了一个（金属度 0.62、带拉丝纹）：平直的小面在摄影棚式的环境光里只映出一片黑，铝、铁、铜分不出颜色。砝码、托盘、横梁等其余金属件用的都是 `Metal`。
- 液体用不受光照的半透明材质，玻璃的底色调得偏暗：这样浸在水里的石块、金属块才看得见。
