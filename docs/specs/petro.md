# 从石油到塑料实验室 · 规格卡 v1.0

状态：已做完九个课次，待审。关联议题 #73。

## 总览

- 一句话：跟着一滴原油走完一座炼油厂和石化厂，弄懂石油怎样分开、长链怎样断成短链、甲烷乙烯苯各会发生什么反应、官能团怎样一步步转化、乙烯怎样连成聚乙烯。
- 教材位置：人教版高中化学必修第二册第七章“有机化合物”（认识有机化合物、乙烯与有机高分子材料、乙醇与乙酸）、第八章“化学与可持续发展”里“煤、石油和天然气的综合利用”；选择性必修 3“有机化学基础”里烃、烃的衍生物、合成高分子的相关内容。章节号见“待核实事项”。
- 主线：碳链。原油里长短不一的碳链先按沸点分开，再断成短链得到乙烯，乙烯一路变成乙醇、乙醛、乙酸、乙酸乙酯，或者自己连成聚乙烯。
- 场景：一座炼油厂和石化厂，傍晚的斜阳。**大场景的布局**（x 向东，单位 m，镜头从南往北看）：
  - 最西头（x −72 到 −44）是中心化验室，南面敞开，后墙一条化验台，自西向东三格：甲烷和氯气的光照取代（第 3 课）、乙烯通入两种溶液（第 4 课）、苯和两种溶液（第 5 课）。
  - x −9 是原油加热炉（立式圆筒炉），x 5 是常压分馏塔（高约 35 m），两者都能朝镜头剖开（第 1 课）。塔后是塔顶空冷器和回流罐，西北角是原油罐区。
  - x 40 是管式裂解炉（辐射室可剖开，看炉管和火嘴），炉顶是急冷换热器和汽包（第 2 课）。
  - x 66 到 96 是一排四台反应装置：乙烯水合反应器、乙醇氧化反应器、乙醛氧化塔、酯化釜带精馏柱（第 6 课）。
  - x 112 是聚乙烯流化床反应器，x 120 到 138 是挤出造粒线（敞棚下的挤出机、水下切粒、离心干燥、料仓）（第 7 课）。
  - x 156 到 172 是回收车间：分拣皮带和六只料箱、加热试验台（拓展课）。
  - 北面 z −17 一条管廊把各装置连起来；南面 z 16 是厂区主路；远处是球罐、火炬、冷却塔。
- 取值约定：相对原子质量 H 1、C 12、O 16、Cl 35.5、Br 80。沸点是常压下的值。键长单位 pm（1 pm = 10⁻¹² m）。
- 分子一律用球棍模型，画在设备旁边的放大窗里：碳黑、氢白、氧红、氯绿、溴红棕。模型的大小是示意，不按设备比例。
- 和同类产品的区别：分子模型不是单独的一页，而是挂在真实装置旁边；每一步反应都能数原子、对质量。

## 共用的计算核心

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `ALKANE_BP` | 碳原子数 | 正构烷烃的沸点（°C） | 手册值，见待核实 |
| `fractionOf(bp)` | 沸点 | 落在哪一种馏分 | 馏分的沸点范围（约） |
| `mass(f)` | 分子式 | 相对分子质量 | 相对原子质量 |
| `CRACK`、`balanced(step)` | 第几步 | 反应物和两种产物的分子式；碳、氢是否守恒 | CₙH₂ₙ₊₂ → 烷烃 + 烯烃 |
| `substituted(n)` | 取代了几个氢 | 产物、消耗的 Cl₂ 和生成的 HCl 的个数 | 每取代 1 个 H 消耗 1 个 Cl₂、生成 1 个 HCl |
| `fades(gas, solution)` | 气体或苯、溶液 | 褪不褪色、为什么 | 教材实验 |
| `BOND` | 键的种类 | 键长（pm） | 手册值，见待核实 |
| `ROUTE`、`esterFromEthene(t)` | 乙烯的质量 | 理论上最多得到多少乙酸乙酯 | 2 C₂H₄ → 1 CH₃COOC₂H₅ |
| `polymerMass(n)` | 聚合度 | 聚乙烯的相对分子质量 28n | 链节的式量 × n |
| `RESINS` | 回收标志 | 是哪一种塑料 | 通用的塑料回收标志 |

## 第 1 课 石油的分馏

原油加热后送进分馏塔，沸点低的升得高，各种馏分从不同高度流出来。

| 项目 | 内容 |
|---|---|
| 知识点 | 石油是多种烃的混合物；分馏利用沸点不同把它分开，是物理变化；每种馏分仍是混合物 |
| 一句概念 | 沸点越低，在塔里升得越高 |
| 核心动作 | 点燃加热炉；选一种烷烃送进塔 |
| 看到的现象 | 炉膛起火，油气进塔；被追踪的分子升到某一层塔盘后冷凝，从侧线流出；沸点比进塔温度高的留在塔底 |
| 读数 | 碳原子数、沸点、去向；沸点随碳原子数变化的图 |
| 真实锚点 | 常压分馏塔的塔顶、侧线、塔底出料 |
| 对应小测 | 第 1、2 题 |

任务清单

- [ ] 点燃加热炉，把原油送进分馏塔
- [ ] 送进辛烷 C₈H₁₈，看它从哪一层出来（汽油）
- [ ] 送进十六烷 C₁₆H₃₄（柴油）
- [ ] 送进丙烷 C₃H₈（塔顶，石油气）
- [ ] 送进二十五烷 C₂₅H₅₂（不汽化，留在塔底，重油）

视觉映射

| 知识点 | 必须看见的东西 | 由哪个量驱动 | 镜头与视图 |
|---|---|---|---|
| 按沸点分层 | 塔朝镜头剖开：塔盘、降液管、泡罩，盘上液体从上到下由浅到深 | 馏分 | 斜俯视，塔在中间，炉在左 |
| 沸点和碳链 | 放大窗里的球棍模型，链越长沸点越高 | 选的烷烃 | 放大窗在塔的右侧 |

主操作区的按钮：点燃加热炉；送进分馏塔。分段选择：追踪哪种烷烃。

数据

| 条件 | 读数 | 来历 |
|---|---|---|
| 丙烷、辛烷、十六烷、二十五烷 | 沸点 −42.1、125.7、286.8、401.9 °C | 手册值 |
| 石油气、汽油、煤油、柴油、重油 | 沸点约 40 以下、40–200、200–280、280–350、350 °C 以上；碳原子数 C₁–C₄、C₅–C₁₁、C₁₁–C₁₆、C₁₅–C₁₈、C₂₀ 以上 | 教材的石油分馏产品图，范围是约数 |
| 进塔温度 | 约 360 °C | 常压炉出口的常见值，约数 |

简化：真实的塔里是很多种烃一起在各层塔盘上反复汽化、冷凝，这里只追踪一个分子；塔盘只画了十几层。

## 第 2 课 裂化和裂解

把重油里的长链在高温下断开，得到汽油和乙烯这样的短链。

| 项目 | 内容 |
|---|---|
| 知识点 | 裂化：长链烃断成短链烃，提高汽油的产量；裂解：更高的温度，得到乙烯、丙烯等；都是化学变化 |
| 一句概念 | 长链断开，得到一个烷烃一个烯烃 |
| 核心动作 | 把烃送进炉管；把炉温升到裂解的温度 |
| 看到的现象 | 炉管发红，放大窗里碳链断开，一头补上氢成为烷烃，另一头出现碳碳双键 |
| 读数 | 反应物和两种产物的分子式、碳氢原子数、相对分子质量 |
| 对应小测 | 第 3 题 |

任务清单

- [ ] 约 500 °C：把十六烷送进炉管（C₁₆H₃₄ → C₈H₁₈ + C₈H₁₆）
- [ ] 再送一次：辛烷继续断（C₈H₁₈ → C₄H₁₀ + C₄H₈）
- [ ] 把炉温升到约 800 °C，送丁烷（C₄H₁₀ → C₂H₆ + C₂H₄）
- [ ] 再送一次丁烷，换一处断开（C₄H₁₀ → CH₄ + C₃H₆）

主操作区的按钮：送进炉管。分段选择：炉温（约 500 °C 裂化、约 800 °C 裂解）。

数据：相对分子质量 226 = 114 + 112；114 = 58 + 56；58 = 30 + 28；58 = 16 + 42。每一步碳、氢原子数守恒。

简化：真实的催化裂化在提升管反应器里用催化剂进行，产物是很多种烃的混合物；这里放在同一台管式炉里，每次只画一种断法。

## 第 3 课 甲烷和取代反应

| 项目 | 内容 |
|---|---|
| 知识点 | 甲烷是正四面体结构；光照下甲烷和氯气发生取代反应，逐步生成四种氯代物和氯化氢 |
| 一句概念 | 一个氢换成一个氯，同时生成氯化氢 |
| 核心动作 | 开灯、关灯；让下一个氯分子过来 |
| 看到的现象 | 量筒里黄绿色变浅、液面上升、筒壁出现油状液滴；放大窗里 Cl 换下 H |
| 读数 | 取代了几个氢、消耗几个 Cl₂、生成几个 HCl、产物 |
| 对应小测 | 第 4 题 |

任务清单

- [ ] 不开灯，让一个氯分子过来（不反应）
- [ ] 开灯，再让氯分子过来（CH₄ + Cl₂ → CH₃Cl + HCl）
- [ ] 继续，取代到二氯甲烷
- [ ] 一直取代到四氯化碳

主操作区的按钮：开灯（关灯）；来一个氯分子。

数据：键角 109°28′；一氯甲烷是气体，二氯甲烷、三氯甲烷、四氯化碳是油状液体（教材）。液面上升的高度是示意。

简化：真实的反应里四种氯代物同时生成，这里一步一步画。

## 第 4 课 乙烯和加成反应

| 项目 | 内容 |
|---|---|
| 知识点 | 乙烯是平面结构，含碳碳双键；能和溴发生加成反应，能被酸性高锰酸钾溶液氧化；甲烷都不能 |
| 一句概念 | 双键打开一根，两头各接上一个原子 |
| 核心动作 | 换气体；把气体通入两种溶液中的一种 |
| 看到的现象 | 乙烯使两种溶液都褪色，甲烷都不褪色；放大窗里双键变单键，两个溴接上去 |
| 读数 | 键长 C=C 134 pm、C–C 154 pm；相对分子质量 28 + 160 = 188 |
| 对应小测 | 第 5 题 |

任务清单

- [ ] 把甲烷通入溴的四氯化碳溶液（不褪色）
- [ ] 把甲烷通入酸性高锰酸钾溶液（不褪色）
- [ ] 换成乙烯，通入溴的四氯化碳溶液（褪色，加成）
- [ ] 把乙烯通入酸性高锰酸钾溶液（褪色，氧化）

每次通气之前，瓶里都是新换的溶液。

主操作区的按钮：通入溴的四氯化碳溶液；通入酸性高锰酸钾溶液。分段选择：气体（甲烷、乙烯）。

## 第 5 课 苯

| 项目 | 内容 |
|---|---|
| 知识点 | 苯不能使溴水（因反应）和酸性高锰酸钾溶液褪色；六个碳碳键完全相同，介于单键和双键之间；在催化剂作用下能和液溴发生取代 |
| 一句概念 | 苯的六个碳碳键一样长 |
| 核心动作 | 换试剂；滴入苯并振荡；量键长；做溴代 |
| 看到的现象 | 溴水里的溴被萃取到上层的苯里，没有褪色反应；高锰酸钾溶液不褪色；六个键长都是 140 pm；溴代后生成溴苯和溴化氢 |
| 读数 | 键长 140 pm，和 154、134 pm 比 |
| 对应小测 | 第 6 题 |

任务清单

- [ ] 把苯滴进溴水，振荡（分层，上层橙红色，是萃取）
- [ ] 把苯滴进酸性高锰酸钾溶液，振荡（不褪色）
- [ ] 量一量六个碳碳键的键长（都是 140 pm）
- [ ] 加液溴和溴化铁（取代，生成溴苯和 HBr）

主操作区的按钮：滴入苯并振荡；量键长；加液溴和催化剂。分段选择：试管里的溶液（溴水、酸性高锰酸钾溶液）。

## 第 6 课 官能团的转化

| 项目 | 内容 |
|---|---|
| 知识点 | 乙烯水化得乙醇；乙醇催化氧化得乙醛；乙醛氧化得乙酸；乙酸和乙醇酯化得乙酸乙酯（可逆）。官能团：碳碳双键、羟基、醛基、羧基、酯基 |
| 一句概念 | 换一个官能团，就换一类物质 |
| 核心动作 | 每一步选加什么（水、氧气、乙醇），开反应器 |
| 看到的现象 | 镜头飞到下一台反应装置；放大窗里官能团变了 |
| 读数 | 相对分子质量 28、46、44、60、88；56 t 乙烯理论上最多得 88 t 乙酸乙酯 |
| 对应小测 | 第 7 题 |

任务清单

- [ ] 乙烯加水，得到乙醇
- [ ] 乙醇通氧气，得到乙醛
- [ ] 乙醛通氧气，得到乙酸
- [ ] 乙酸加乙醇，得到乙酸乙酯

主操作区的按钮：开始反应。分段选择：加什么（水、氧气、乙醇）。选错时给一句提示，不反应。

简化：各步的催化剂和条件只写教材上的；装置的外形是示意。计算按完全转化，不计酯化的可逆。

## 第 7 课 加聚反应

| 项目 | 内容 |
|---|---|
| 知识点 | 乙烯的双键打开，一个个连成长链，生成聚乙烯；单体 CH₂=CH₂、链节 –CH₂–CH₂–、聚合度 n；聚乙烯的相对分子质量 28n |
| 一句概念 | 双键打开，小分子连成长链 |
| 核心动作 | 开始聚合；标出链节；换聚合度；开造粒机 |
| 看到的现象 | 放大窗里一排乙烯的双键依次打开，连成一条链；造粒线切出白色颗粒，落进料仓 |
| 读数 | 聚合度 n、相对分子质量 28n |
| 对应小测 | 第 8 题 |

任务清单

- [ ] 开始聚合（双键打开，连成长链）
- [ ] 标出链节
- [ ] 把聚合度换成 5000，读相对分子质量（140 000）
- [ ] 开造粒机

主操作区的按钮：开始聚合；标出链节；开造粒机。分段选择：聚合度（1000、5000、10000）。

简化：放大窗里只画了 6 个单体；真实的聚乙烯每条链的聚合度不一样，n 是平均值。
