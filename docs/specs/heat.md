# 内能和热机实验室 · 规格卡 v0.1

状态：九个课次（1–7、拓展、随堂检测）的代码写完（2026-11-25），待验收。关联议题 #10。

## 总览

- **一句话**：学生在一座汽车发动机厂里，先在质检实验室的台子上把分子热运动、分子间的作用力、内能、比热容一件件做出来，再走进发动机测试间算冷却液吸了多少热、燃料放了多少热、发动机效率多高，最后在培训区把一台剖开的汽油机一个冲程一个冲程地转过去，看内能怎样变成机械能。
- **教材位置**：物理，初中，人教版九年级全一册“内能”“内能的利用”两章（分子热运动、内能、比热容；热机、热机的效率、能量的转化和守恒）。准确的章号、节名见“待核实事项”。
- **主线**：发动机里的“热”。第 1–3 课弄清热是分子的运动、内能能用做功和热传递改变；第 4–5 课说明发动机为什么用水做冷却液、冷却液吸了多少热；第 6–7 课看发动机怎样把燃料的内能变成机械能、为什么只有一小部分变成了有用功。
- **场景**：一座汽车发动机厂的厂房。一端是玻璃隔出来的质检实验室，靠墙一长排实验台；中间是两间发动机测试间（台架、测功机、散热器、燃料秤）；再往里是培训区，一台剖开的单缸汽油机立在展示台上；另一端是总装线，传送线上排着发动机，线头一台剖开的四缸机。
- **取值约定**：温度用 ℃，热量用 J。水的比热容 4.2×10³ J/(kg·℃)，铝 0.88×10³ J/(kg·℃)；汽油的热值 4.6×10⁷ J/kg，柴油 4.3×10⁷ J/kg；室温 20 ℃。加热实验每分钟记一次。
- **和同类产品的区别**：同类产品的四冲程多是一张平面动画。这里是一台剖开的发动机：缸体、缸盖、活塞、连杆、曲轴、进排气门、凸轮轴、火花塞按真实结构联动，气门由凸轮顶开，凸轮轴转速是曲轴的一半；剖面上看得见混合气被压缩变热、火花一点火焰从火花塞往外烧开。比热容和热量的数都是从实验读数里算出来的，不是现成给的。

## 共用的计算核心

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `diffuse` | 秒、水温 | 红墨水散开的程度 0–1：热水 9 秒、冷水 40 秒基本均匀 | 示意，快慢之比自定 |
| `gasMix` | 秒 | 上瓶里二氧化氮占的比例，从 0 慢慢升到 0.5 | 示意 |
| `molSpeed` | 温度 | 分子放大图里的平均速度，和热力学温度的平方根成正比 | 分子动理论；放大图是示意 |
| `syringe` | 装的是什么、推力 | 活塞前进的比例：空气 0.5，水 0.02 | 示意：只表现“气体容易压缩、液体很难” |
| `heatQ` | c、m、Δt | Q = c m Δt | 教材公式 |
| `mixT` | 两物体的 c、m、初温 | 热平衡时的共同温度 | 能量守恒（热传递时 Q吸 = Q放，忽略散热） |
| `heater` | 物质、分钟 | 两个加热器每分钟各给 2.1×10³ J，水和油的温度 | 加热器的功率自定；比热容见取值约定 |
| `specific` | Q、m、Δt | c = Q / (m Δt) | 教材公式 |
| `coolant` | 质量、秒 | 冷却液升到 90 ℃ 的过程、熄火后降到 40 ℃ 的过程 | 温度变化过程是示意，只用两头的数算 |
| `fuelQ` | m、q | Q = m q | 教材公式 |
| `piston` | 曲轴转角 | 活塞位置、连杆角度、进排气门开度、当前冲程 | 曲柄连杆机构的几何关系；气门开度曲线示意 |
| `firing` | 曲轴转角 | 四缸机各缸处在哪个冲程（点火顺序 1-3-4-2） | 直列四缸常见的点火顺序 |

## 第 4 课 比热容

| 项目 | 内容 |
|---|---|
| 知识点 | 比热容；水的比热容大；用水做冷却剂 |
| 一句概念 | 质量相同时，水升温慢，吸热本领强 |
| 核心动作 | 同时给等质量的水和食用油通电加热 4 分钟；再只给水加热到和油一样的温度；算出食用油的比热容 |
| 看到的现象 | 4 分钟后水升了 10 ℃、油升了 20 ℃；水要加热 8 分钟才升 20 ℃ |
| 读数 | 两支温度计、加热时间 |
| 对应小测 | 第 5 题（升温快慢和比热容） |

任务清单

- [ ] 同时给水和食用油加热 4 分钟，比一比谁升温多
- [ ] 只给水接着加热，直到它也升高 20 ℃
- [ ] 算出食用油的比热容

主操作区：“通电加热”“只给水加热”“算比热容”。

数据：水和食用油各 0.2 kg，初温 20 ℃；两个相同的电加热器每分钟各给 2.1×10³ J；4 分钟水 20 → 30 ℃，油 20 → 40 ℃；8 分钟水升到 40 ℃。由水的数算出加热器 4 分钟给的热 Q = 4.2×10³ × 0.2 × 10 = 8.4×10³ J，油的比热容 c = 8.4×10³ ÷ (0.2 × 20) = 2.1×10³ J/(kg·℃)。食用油的体积按密度 0.9×10³ kg/m³ 画（油面比水面高一点）。

## 第 7 课 热值和热机效率

| 项目 | 内容 |
|---|---|
| 知识点 | 热值 Q = mq；热机效率 η = W有 / Q放；能量的去向 |
| 一句概念 | 燃料放出的热只有一部分变成有用功 |
| 核心动作 | 启动发动机，烧完燃料秤上的 0.1 kg 汽油；读测功机算效率；看能量去了哪里 |
| 读数 | Q放 = 0.1 × 4.6×10⁷ = 4.6×10⁶ J；测功机 W有 = 1.15×10⁶ J；η = 25% |
| 能量去向（示意） | 废气带走 35%、冷却液带走 30%、摩擦和其他 10%、有用功 25%；界面标“示意” |
| 对应小测 | 第 9 题（热值和燃料质量无关；效率不可能达到 100%） |

## 讲解

- 拓展课第 3 个小实验原定“能量守恒（把第 7 课的四份能量加起来）”，改成“柴油机压燃”：柴油机的两个要点（吸进空气、压燃）各做一步更清楚；能量守恒放进“看原理”。
