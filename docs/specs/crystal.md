# 分子的形状和晶体实验室 · 规格卡 v1.0

状态：待审。关联议题 #72。

## 总览

- 一句话：先弄懂一个分子为什么是这个形状（价层电子对互相排斥、杂化轨道、分子的极性），再弄懂大量粒子怎样堆成晶体（晶胞里怎样数粒子、四类晶体的结构和性质）。
- 教材位置：人教版高中化学选择性必修 2《物质结构与性质》第二章“分子结构与性质”（第二节 分子的空间结构、第三节 分子结构与物质的性质）、第三章“晶体结构与性质”（第一节 物质的聚集状态与晶体的常识、第二节 分子晶体与共价晶体、第三节 金属晶体与离子晶体）。节的编号见“待核实事项”。
- 主线：同一批球棍模型。前四课是五个分子（CO₂、BF₃、CH₄、NH₃、H₂O），后三课是五个晶胞（NaCl、CsCl、金刚石、干冰、铜）。干冰里的 CO₂、金刚石里的碳，前后两半各出现一次。
- 场景：一间晶体结构实验室（大学里做 X 射线衍射的那种屋子）。深色地坪，北墙一排带灯的矿物标本柜，东墙一台 X 射线衍射仪和样品柜，西墙一排高窗，南墙一块画着晶胞的黑板。屋里八个圆形展台，每个展台上一只铝制转台，转台上立着这一课的大模型（约 0.4 m 宽）。**大场景的布局**：
  - 北墙前一排四个展台，自西向东：第 1 课（电子对互相排斥）→ 第 2 课（孤电子对）→ 第 3 课（杂化轨道）→ 第 4 课（分子的极性）。
  - 屋子中间两个展台：第 5 课（氯化钠晶胞）在西，第 6 课（四种晶胞）在东。这两课的镜头在展台北边往南看（第 5 课俯得高，背景是地坪；第 6 课平一些，背景是南墙的黑板），和北墙前四课的背景分开。
  - 东墙衍射仪旁边：第 7 课（四类晶体）。西窗下：拓展课（石墨和金刚石）。
  - 换课时镜头从一个展台飞到另一个展台；不是当前这一课的展台上摆着静止的模型。随堂检测看整间屋子。
- 取值约定：键角按教材写法 CH₄ 109°28′、NH₃ 107°、H₂O 105°、BF₃ 120°、CO₂ 180°；阿伏加德罗常数 N_A = 6.02×10²³ mol⁻¹；相对原子质量 C 12、Na 23、Cl 35.5、Cu 63.5；长度用 pm，密度用 g/cm³，温度用 °C。
- 画法的约定：分子和晶胞都用球棍模型；球的大小不按真实比例（为了看清内部，球画小了），键长的相对长短也只是示意。孤电子对画成半透明的瓣，杂化轨道画成一大一小的瓣，都是示意。
- 和同类产品的区别：形状不是直接给出的，学生先数电子对、再看电子对被推开；晶胞可以真的切开，每个粒子留在晶胞里的那一块（1/8、1/4、1/2）是一个有切面的实体，可以逐类点亮来数。

## 共用的计算核心

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `lonePairs(m)` | 分子 | 中心原子上的孤电子对数 | ½(a − x·b)：a 中心原子价电子数，x 配位原子数，b 每个配位原子最多能接受的电子数（H 为 1，其余为 8 − 价电子数） |
| `pairs(m)` | 分子 | 价层电子对数 | σ 键电子对数 + 孤电子对数 |
| `idealAngle(n)` | 电子对数 2、3、4 | 180°、120°、109.47° | 电子对之间离得最远时的夹角；4 对时 arccos(−1/3) |
| `dirs(m)` | 分子 | 各根键、各对孤电子对的方向 | 按教材键角摆出来；画面只用它 |
| `bondAngle(m)` | 分子 | 键角（度） | 由 `dirs` 的两根键算出，和教材键角一致 |
| `angleText(deg)` | 度 | “109°28′” | 度分写法，整度不写分 |
| `hybrid(m)` | 分子 | sp、sp²、sp³，没参加杂化的 p 轨道数 | 杂化轨道数 = 价层电子对数 |
| `dipoleSum(m)` | 分子 | 键的极性的向量和（一根键记 1） | 各根键方向的向量和；由电负性小的一端指向大的一端 |
| `sites(c)` | 晶胞 | 每个粒子的分数坐标、元素、位置类别 | 坐标有几个是 0 或 1：3 个在顶点，2 个在棱，1 个在面，0 个在体内 |
| `count(c, el)` | 晶胞、粒子 | 属于这个晶胞的个数 | 顶点 1/8、棱 1/4、面 1/2、体内 1 |
| `density(c)` | 晶胞 | 密度（g/cm³） | N·M / (N_A·a³) |
| `CRYSTALS` | 四类晶体 | 构成粒子、作用力、熔点、能否导电 | 见第 7 课数据表 |

## 第 1 课 电子对互相排斥

中心原子周围的价层电子对互相排斥，尽量离得远，分子的形状就定了。

| 项目 | 内容 |
|---|---|
| 知识点 | 价层电子对互斥模型；σ 键电子对数；孤电子对数 ½(a − xb) |
| 一句概念 | 电子对互相排斥，离得越远越稳定 |
| 核心动作 | 选分子 → 数电子对 → 松开 → 量键角 |
| 看到的现象 | 配位原子一开始挤在一侧；松开后被推开，停在彼此最远的位置 |
| 读数 | 价层电子对数、键角 |
| 真实锚点 | CO₂ 180°、BF₃ 120°、CH₄ 109°28′ |
| 对应小测 | 第 1 题 |

任务清单

- [ ] 数出 CO₂ 的价层电子对，松开，量键角（2 对，180°，直线形）
- [ ] 换成 BF₃ 再做一遍（3 对，120°，平面三角形）
- [ ] 换成 CH₄ 再做一遍（4 对，109°28′，正四面体形）

视觉映射

| 知识点 | 必须看见的东西 | 由哪个量驱动 | 镜头与视图 |
|---|---|---|---|
| 电子对数 | 每根键上亮起一个电子对的标记，面板上列出算式 | `pairs` | 斜俯视，模型在转台上 |
| 互相排斥 | 配位原子从挤在一起的位置滑到最远的位置 | 松开的进度 | 同上 |
| 键角 | 两根键之间的弧线和读数 | `bondAngle` | 同上 |

主操作区的按钮：数电子对、松开、量键角。分段选择：分子（CO₂ / BF₃ / CH₄）。

直接操作：拖动画面可以转着看模型。

数据

| 条件 | 读数 | 来历 |
|---|---|---|
| CO₂ | σ 键电子对 2，孤电子对 ½(4 − 2×2) = 0，共 2 对，180° | 教材 |
| BF₃ | 3 + ½(3 − 3×1) = 3 对，120° | 教材 |
| CH₄ | 4 + ½(4 − 4×1) = 4 对，109°28′ | 教材 |

## 第 2 课 孤电子对

CH₄、NH₃、H₂O 都是 4 对价层电子对，VSEPR 模型都是四面体形；孤电子对占着位置，但看分子的形状时不算它。

| 项目 | 内容 |
|---|---|
| 知识点 | VSEPR 模型和分子的空间结构的区别；孤电子对的排斥作用更强 |
| 一句概念 | 孤电子对也占地方，还把键角挤小 |
| 核心动作 | 选分子 → 显示孤电子对 → 量键角 |
| 看到的现象 | NH₃ 顶上一只半透明的瓣，H₂O 上两只；键角一个比一个小 |
| 读数 | 孤电子对数、键角、分子的空间结构 |
| 真实锚点 | 109°28′ → 107° → 105° |
| 对应小测 | 第 2、3 题 |

任务清单

- [ ] 量出 CH₄ 的键角（没有孤电子对，109°28′）
- [ ] NH₃：显示孤电子对，再量键角（1 对，107°，三角锥形）
- [ ] H₂O：显示孤电子对，再量键角（2 对，105°，V 形）

主操作区的按钮：显示孤电子对、量键角。分段选择：分子（CH₄ / NH₃ / H₂O）。

数据

| 条件 | 读数 | 来历 |
|---|---|---|
| NH₃ | 孤电子对 ½(5 − 3×1) = 1，键角 107° | 教材 |
| H₂O | 孤电子对 ½(6 − 2×1) = 2，键角 105° | 教材 |

## 第 3 课 杂化轨道

中心原子的 s 轨道和 p 轨道混合成几个一样的杂化轨道，再去和别的原子成键。

| 项目 | 内容 |
|---|---|
| 知识点 | sp³、sp²、sp 杂化；杂化轨道用来形成 σ 键或容纳孤电子对；没参加杂化的 p 轨道形成 π 键 |
| 一句概念 | 几对价层电子对，就要几个杂化轨道 |
| 核心动作 | 选分子 → 杂化 → 成键 |
| 看到的现象 | 一个球形的 s 轨道和三个哑铃形的 p 轨道，变成 2、3、4 个一大一小的瓣，指向和上两课的形状一样 |
| 读数 | 杂化类型、杂化轨道数、夹角、剩下的 p 轨道数 |
| 真实锚点 | CH₄ sp³ 109°28′；BF₃ sp² 120°；CO₂ sp 180° |
| 对应小测 | 第 4 题 |

任务清单

- [ ] CH₄：让碳原子杂化，再和 4 个氢成键（sp³）
- [ ] BF₃：让硼原子杂化，再和 3 个氟成键（sp²，剩 1 个 p 轨道）
- [ ] CO₂：让碳原子杂化，再和 2 个氧成键（sp，剩 2 个 p 轨道，形成 π 键）

主操作区的按钮：杂化、成键。分段选择：分子（CH₄ / BF₃ / CO₂）。

## 第 4 课 分子的极性

键有极性，分子不一定有极性：要看各根键的极性的向量和。

| 项目 | 内容 |
|---|---|
| 知识点 | 极性键、非极性分子、极性分子；正电中心和负电中心是否重合 |
| 一句概念 | 键的极性的向量和为零，分子就没有极性 |
| 核心动作 | 选分子 → 画出键的极性 → 合成 |
| 看到的现象 | 每根键上一支箭头，指向电负性大的原子；合成后箭头抵消成零，或者合成一支大箭头 |
| 读数 | 向量和（一根键记 1）、极性分子还是非极性分子 |
| 真实锚点 | CO₂ 0、BF₃ 0、CH₄ 0；NH₃、H₂O 不为零 |
| 对应小测 | 第 5 题 |

任务清单

- [ ] CO₂：画出两根键的极性，合成（抵消，非极性分子）
- [ ] H₂O：同样做一遍（不抵消，极性分子）
- [ ] 把 BF₃、CH₄、NH₃ 也都做一遍（只有 NH₃ 是极性分子）

主操作区的按钮：画出键的极性、合成。分段选择：分子（五个）。

数据

| 条件 | 读数 | 来历 |
|---|---|---|
| H₂O | 向量和 2cos(105°/2) = 1.22 | 由键角算 |
| NH₃ | 向量和 1.12 | 由键角 107° 算 |
| 电负性 | H 2.1、B 2.0、C 2.5、N 3.0、O 3.5、F 4.0 | 教材的电负性图（鲍林标度）；界面只用来说明箭头方向 |

## 第 5 课 晶胞里数粒子

晶胞是晶体里重复的小方块，顶点、棱、面上的粒子是和旁边的晶胞合用的。

| 项目 | 内容 |
|---|---|
| 知识点 | 均摊法：顶点 1/8、棱 1/4、面 1/2、体内 1；由晶胞的边长算密度 |
| 一句概念 | 粒子被几个晶胞合用，就只算几分之一 |
| 核心动作 | 切开晶胞 → 逐类点亮、记录 → 合计 → 算密度 |
| 看到的现象 | 切开后，顶点上的球只剩 1/8 留在晶胞里，棱上的剩 1/4，面上的剩半个，体内的是整个 |
| 读数 | 每一类的个数 × 份额，Na⁺、Cl⁻ 的总数，密度 |
| 真实锚点 | 一个 NaCl 晶胞里 4 个 Na⁺、4 个 Cl⁻；a = 564 pm，密度 2.17 g/cm³（实测约 2.17） |
| 对应小测 | 第 6 题 |

任务清单

- [ ] 切开晶胞
- [ ] 顶点、棱上、面上、体内四类位置各记一次
- [ ] 合计出 Na⁺ 和 Cl⁻ 各有几个
- [ ] 用晶胞算出氯化钠的密度

主操作区的按钮：切开晶胞、记下这一类、合计（合计之后变成“算密度”）。分段选择：位置（顶点 / 棱上 / 面上 / 体内）。

数据

| 条件 | 读数 | 来历 |
|---|---|---|
| 顶点 | 8 个 Cl⁻ × 1/8 = 1 | 均摊 |
| 棱上 | 12 个 Na⁺ × 1/4 = 3 | 均摊 |
| 面上 | 6 个 Cl⁻ × 1/2 = 3 | 均摊 |
| 体内 | 1 个 Na⁺ × 1 = 1 | 均摊 |
| 密度 | 4 × 58.5 ÷ (6.02×10²³ × (564×10⁻¹⁰ cm)³) = 2.17 g/cm³ | a = 564 pm |

## 第 6 课 换个晶胞再数

同样的数法，用在四种晶胞上。

| 项目 | 内容 |
|---|---|
| 知识点 | CsCl、金刚石、干冰、铜的晶胞；分子晶体按分子数 |
| 一句概念 | 数法不变：看粒子在顶点、棱、面还是体内 |
| 核心动作 | 选晶胞 → 切开数一数 → 记录 |
| 看到的现象 | 晶胞被切开，各类位置依次点亮，旁边的标签写着份额 |
| 读数 | 各类位置的个数、总数、化学式 |
| 真实锚点 | CsCl 1 : 1；金刚石 8 个碳原子；干冰 4 个 CO₂ 分子；铜 4 个原子 |
| 对应小测 | 第 7 题 |

任务清单

- [ ] 氯化铯：切开数一数，记录（Cs⁺ 1 个、Cl⁻ 1 个）
- [ ] 金刚石（8 个碳原子）
- [ ] 干冰（4 个 CO₂ 分子）
- [ ] 铜（4 个铜原子）

主操作区的按钮：切开数一数、记录。分段选择：晶胞（氯化铯 / 金刚石 / 干冰 / 铜）。

干冰晶胞里 CO₂ 分子的朝向是示意（都沿体对角线方向）；数的时候按分子的中心。

## 第 7 课 四类晶体

构成粒子不同、粒子间的作用力不同，性质就不同。

| 项目 | 内容 |
|---|---|
| 知识点 | 离子晶体、分子晶体、共价晶体、金属晶体的构成粒子、作用力、熔点、导电性 |
| 一句概念 | 粒子间的作用力决定晶体的性质 |
| 核心动作 | 选晶体 → 加电压 → 加热 |
| 看到的现象 | 铜里有自由电子在流动；氯化钠固态不导电，熔化后离子能动了才导电；干冰很快变成一个个 CO₂ 分子飞走，分子本身没坏；金刚石到 3500 °C 还没熔化 |
| 读数 | 温度、熔点、能否导电 |
| 真实锚点 | 见数据表 |
| 对应小测 | 第 8、9 题 |

任务清单

- [ ] 铜：加电压，再加热到熔化
- [ ] 氯化钠：固态加一次电压，加热到熔化后再加一次
- [ ] 干冰：加电压、加热
- [ ] 金刚石：加电压、加热

主操作区的按钮：加电压、加热。分段选择：晶体（铜 / 氯化钠 / 干冰 / 金刚石）。

数据

| 晶体 | 类型 | 构成粒子 | 作用力 | 熔点 | 导电 | 来历 |
|---|---|---|---|---|---|---|
| 铜 | 金属晶体 | 金属阳离子和自由电子 | 金属键 | 1083 °C | 固态导电 | 公认数据 |
| 氯化钠 | 离子晶体 | Na⁺、Cl⁻ | 离子键 | 801 °C | 固态不导电，熔融导电 | 教材 |
| 干冰 | 分子晶体 | CO₂ 分子 | 范德华力 | −78.5 °C 升华 | 不导电 | 公认数据 |
| 金刚石 | 共价晶体 | 碳原子 | 共价键 | 高于 3500 °C | 不导电 | 教材 |

加热的起点：干冰 −100 °C，其余 25 °C。加热的快慢是示意，不代表真实的时间。

## 和规格卡原文的出入

- 场景按议题的建议用“晶体实验室”，没有改。
- 议题说高中实验室要“看曲线”：这一间的内容是空间结构，没有适合画曲线的量，定量放在数电子对、键角、均摊计数和算密度上。
- 第 5、6 课的镜头改成从北往南看：原来往北看时，后排展台正好挤在主体后面。为此加了南墙和黑板（黑板上只有粉笔画，没有字）。随堂检测的镜头在南墙外面，看全景时不画南墙。
- 第 1、2、4 课的分子模型比展台上静止摆着的放大了约 1.2 倍，为了主体够大。
- 第 6 课没有做配位数。第 7 课转台上加了一只白瓷浅槽：铜和氯化钠熔化后流进槽里，粒子在液面下游动（为了不挤，熔化后粒子画小了约一半，是示意），电极板下沿伸进槽里；电极板顶上有接线柱，导线从接线柱接到小灯。
- 顶栏的课次标签缩短了（电子对、孤电子对、杂化、极性、数粒子、再数、四类晶体、石墨金刚石、检测），课程块里的课名不变。
- 南墙的黑板缩小并挪到西段，第 6 课的画面里不再出现；随堂检测的镜头改成压低拉近，看三个展台。
- 拓展课推杆的立柱挪到转台右后侧的石台面上，用横臂托住套筒。
- 晶胞里“点亮某一类位置”用统一的暖色光，不用粒子自己的颜色（深色的碳原子自己发光看不出来）。
- 没有人手出现：推一推用的是装在立柱上的推杆。
