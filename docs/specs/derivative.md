## 总览

- **一句话**：学生跟着一辆小轿车走一条起伏的山路，从“这几秒平均开多快”问到“这一瞬间开多快”，从割线问到切线，弄懂导数是什么、怎么求、怎么用它看出路在哪里上坡下坡、哪里是坡顶谷底，最后用它找用料最省的易拉罐。
- **教材位置**：数学，高中。人教 A 版选择性必修第二册第五章“一元函数的导数及其应用”：导数的概念及其意义、导数的运算、导数在研究函数中的应用。准确的节号见“待核实事项”，界面不写节号。
- **主线**：“路的坡度就是导数”。山路的纵断面画在路旁的电子屏上：横轴 x 是里程（单位百米），纵轴 y 是比谷底高多少米。这样导数 f′(x) 就是“每走 100 m 升高几米”，正好是路牌上的坡度百分数。
- **山路的纵断面**：f(x) = 0.5x³ − 4.5x² + 7.5x + 12.5，0 ≤ x ≤ 6（全长 600 m）。f′(x) = 1.5x² − 9x + 7.5 = 1.5(x − 1)(x − 5)。x = 1 是坡顶（16 m），x = 5 是谷底（0 m，溪上的小桥）。坡度最陡 7.5%（起点和终点上坡），下坡最陡 6%（x = 3），都在山区公路常见的范围里。
- **场景**：一条山区二级公路。从西往东：平地上的区间测速起点 → 服务区（停车场、便利店、电子屏）→ 起步点和测速屏 → 上坡到坡顶 → 一路下坡到谷底的小桥 → 再上坡出山。路面是沥青，中间双黄线、两边白线，两侧波形护栏，路边有坡度警告牌；北侧是山坡和远山，南侧是缓坡；树是阔叶树。
- **电子屏**：深色不透明的户外 LED 屏，钢框、两根立柱、混凝土基础。全实验室的线色统一：函数图像琥珀色，割线天蓝色，切线珊瑚红，导函数紫色；递增段绿色，递减段橙色。
- **取值约定**：第 1、2 课路程 m、时间 s、速度 m/s（换成 km/h 时乘 3.6，保留一位小数）；山路 x 单位百米、y 单位 m，坡度 = f′(x) %；易拉罐 r、h 单位 cm，S 单位 cm²，V = 330 cm³，π 取计算器值，S 保留一位小数；拓展课路程 km、时间 min、速度 km/h、油量 L。
- **和同类产品的区别**：同类产品多是一块坐标纸上拖一个点。这里每一条曲线都对着一件真事：车开出去，屏上才描出 s–t 曲线；割线转成切线的同时，车就停在那一点，路牌上写着那一点的坡度。

## 第 1 课 这几秒开了多快

| 项目 | 内容 |
|---|---|
| 知识点 | 平均变化率：函数 y = f(x) 从 x₁ 到 x₂ 的平均变化率 Δy/Δx = (f(x₂) − f(x₁))/(x₂ − x₁)；它是割线的斜率 |
| 一句概念 | 平均变化率就是割线的斜率 |
| 核心动作 | 按“出发”，车从停车线起步开 8 s，屏上同步描出 s = t²；分段选择时间段 0–2 s、2–6 s、6–8 s，屏上画出割线 |
| 读数 | 0–2 s 平均速度 2 m/s；2–6 s 8 m/s；6–8 s 14 m/s |
| 真实锚点 | 车从停车线起步加速，加速度 2 m/s²（示意） |
| 对应小测 | 第 1 题 |

任务：按“出发”；选 0–2 s；选 2–6 s；选 6–8 s。
结论：平均速度 = Δs/Δt，是 s–t 图像上割线的斜率；越往后割线越陡，车在加速。

## 第 2 课 这一瞬间开多快（样板课）

| 项目 | 内容 |
|---|---|
| 知识点 | 瞬时速度；导数的定义 f′(x₀) = lim(Δx→0) (f(x₀ + Δx) − f(x₀))/Δx |
| 一句概念 | Δt 趋于 0，平均速度趋于瞬时速度 |
| 核心动作 | 按“从右边逼近”：Δt 从 1 连续缩小到 0.001，割线连续转动；按“从左边逼近”：Δt 从 −1 到 −0.001；按“开过测速屏”：车在 t = 2 s 开过路边的雷达测速屏 |
| 读数 | t₀ = 2 s：Δt = 1、0.1、0.01、0.001 时平均速度 5、4.1、4.01、4.001 m/s；Δt = −1、−0.1、−0.01、−0.001 时 3、3.9、3.99、3.999 m/s；极限 4 m/s = 14.4 km/h；切线 s = 4t − 4 |
| 真实锚点 | 路边的雷达测速屏显示的是车经过那一刻的速度 |

## 第 3 课 坡有多陡

| 项目 | 内容 |
|---|---|
| 知识点 | 导数的几何意义：f′(x₀) 是曲线在点 (x₀, f(x₀)) 处切线的斜率；切线方程 y − f(x₀) = f′(x₀)(x − x₀) |
| 一句概念 | 切线的斜率就是导数 |
| 核心动作 | 车停在 P（x = 3）。按“连割线 PQ”（Q 在 x = 5）；按“Q 逼近 P”，Q 沿曲线连续滑向 P；按“画切线” |
| 读数 | f(3) = 8；割线 PQ 斜率 −4；Δx = 2、1、0.5、0.1 时 −4、−5.5、−5.875、−5.995；切线斜率 f′(3) = −6，切线 y = −6x + 26；路边警告牌“下坡 6%” |

## 第 4 课 导数怎么求

| 项目 | 内容 |
|---|---|
| 知识点 | (xⁿ)′ = nxⁿ⁻¹；(sin x)′ = cos x；(eˣ)′ = eˣ；(ln x)′ = 1/x；简单复合函数 (sin 2x)′ = 2cos 2x |
| 一句概念 | 切线斜率连起来，就是导函数 |
| 核心动作 | 分段选择函数；按“描导函数”：切点从左扫到右，下面一格同步描出切线斜率 |
| 读数 | x³ → 3x²（x = 2 时 12）；sin x → cos x（x = 0 时 1）；eˣ → eˣ（x = 1 时 e ≈ 2.718）；ln x → 1/x（x = 2 时 0.5）；sin 2x → 2cos 2x（x = 0 时 2） |

和、差、积、商的求导法则写在“看原理”里，随堂检测考到。

## 第 5 课 上坡还是下坡

| 项目 | 内容 |
|---|---|
| 知识点 | 在某个区间上 f′(x) > 0，f(x) 单调递增；f′(x) < 0，单调递减 |
| 一句概念 | f′ > 0 递增，f′ < 0 递减 |
| 核心动作 | 按“开过整段山路”：车从 x = 0 开到 x = 6（快进），屏上半格的切线跟着车走，下半格描出 f′；按“标出递增区间”“标出递减区间” |
| 读数 | f′(x) = 1.5(x − 1)(x − 5)；递增区间 (0, 1)、(5, 6)；递减区间 (1, 5)；车所在处的坡度实时显示 |

## 第 6 课 坡顶和谷底

| 项目 | 内容 |
|---|---|
| 知识点 | 极值：f′(x₀) = 0，左正右负是极大值，左负右正是极小值；闭区间上的最值要比较极值和端点值 |
| 一句概念 | f′ 变号处是极值，最值还要比端点 |
| 核心动作 | 按“停在坡顶”“停在谷底”：车开过去停下，屏上在左右各画一条切线；按“求 [2, 6] 上的最值” |
| 读数 | 坡顶 x = 1：f′(0.5) = 3.375 > 0、f′(1.5) = −2.625 < 0，极大值 f(1) = 16；谷底 x = 5：f′(4.5) = −2.625、f′(5.5) = 3.375，极小值 f(5) = 0；[2, 6] 上 f(2) = 13.5、f(5) = 0、f(6) = 3.5：最大值 13.5（端点 x = 2），最小值 0 |

## 第 7 课 最省料的易拉罐

| 项目 | 内容 |
|---|---|
| 知识点 | 用导数求实际问题的最值：列函数、求导、令导数为 0、检验 |
| 一句概念 | 令导数为 0，找出最省的那一个 |
| 核心动作 | 分段选择罐子的底面半径 3 cm、5 cm（罐子连续变形，容积不变）；按“求导找最省” |

## 随堂检测

九道题：平均变化率（第 1 课）、由路程函数求瞬时速度（第 2 课）、切线方程（第 3 课）、基本初等函数的导数（第 4 课）、复合函数求导（第 4 课）、单调递减区间（第 5 课）、易错：f′(x₀) = 0 不一定是极值点（第 6 课）、综合：闭区间上的最大值在端点（第 6 课）、易拉罐 h = 2r（第 7 课）。

## 讲解

- 第 2 课要讲清：Δt 不能等于 0，只能无限接近 0；左右两边都逼近同一个数，这个数才是导数。
- 第 3 课要讲清：x 的单位是百米、y 的单位是米，所以导数就是坡度的百分数。
- 第 6 课要讲清：极大值不一定是最大值，最值还要比端点。
- 读法：f′(x) 念成“f 撇 x”；Δt 念成“德尔塔 t”。
