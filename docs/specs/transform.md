# 图形的变换实验室 · 规格卡 v1.0

状态：待审。议题 #46。

## 总览

- 一句话：在一间做瓷砖、窗花、花布的工坊里，亲手把图形平移、翻折、旋转，看清每种变换由什么决定、对应点之间有什么关系，以及三种变换都不改变图形的形状和大小。
- 教材位置：人教版初中数学。平移在七年级下册“相交线与平行线”一章的“平移”一节；轴对称在八年级上册“轴对称”一章的“轴对称”“画轴对称图形”两节；旋转在九年级上册“旋转”一章的“图形的旋转”“中心对称”“课题学习 图案设计”三节（章节号见“待核实事项”）。
- 主线：一面不对称的“小旗”（旗杆加三角旗面）在第 1、5 课里反复出现；每课都标出三个对应点 A、B、C 和它们的像 A′、B′、C′。
- 场景：一间传统工坊（木梁瓦顶的大开间，地面铺 30 cm 见方的青砖，北墙是砖墙和木雕花窗，东边晾着蓝印花布）。**大场景的布局**（x 朝东，z 朝南，单位 m）：

| 位置 | 课 | 器材 |
|---|---|---|
| 西南的青砖地面 (−10, 3) | 第 1 课 | 地上的花砖：蓝色小旗和橙色的像，30 cm 一格 |
| 西北的剪纸桌 (−6, −5) | 第 2 课 | 红纸、剪刀、折痕 |
| 北边正中的木工台 (−0.5, −5) | 第 3 课 | 平放的半扇木花窗、对称轴、铅笔格 |
| 北墙上的风车板 (5, −8.7) | 第 4 课 | 竖着的木板、黄铜轴钉、风车叶片 |
| 东北的彩绘瓷砖台 (10.5, −4.5) | 第 5 课 | 白釉方砖台面、旋转中心 O |
| 南边的拷贝台 (−3, 3.5) | 第 6 课 | 灯箱、描图纸、三角形 |
| 东南的印花长桌 (4.5, 3.5) | 第 7 课 | 白布、花瓣木模、蓝靛 |
| 西北角的剪纸桌 (−12, −5)、东南的地面 (11, 4.5) | 拓展 | 团花；正多边形地砖 |

从西往东、从北往南走一圈，就是“平移 → 轴对称 → 旋转 → 中心对称 → 全等 → 图案”的顺序。

- 取值约定：长度一律用 cm，保留一位小数；角度用度，取整数。原图一律蓝色（#3b7cf6），像一律橙色（#f7962f），辅助线（对应点连线、垂线）是白色细虚线，对称轴是紫色虚线，旋转中心是一颗黄铜钉。
- 和同类产品的区别：每种变换都有连续的过程（滑过去、翻过去、转过去），而且放在真实的手工活里：剪纸是真的对折再剪，花窗是照着一半补另一半，印花布是拿木模转着印、平移着印。

| 课 | 名称 | 知识点 | 学生的核心动作 | 场景 |
|---|---|---|---|---|
| 1 | 地砖上的平移 | 平移的方向和距离；对应点连线平行且相等 | 选方向和格数，把花砖推过去，连对应点 | 青砖地面 |
| 2 | 对折剪窗花 | 轴对称；对称轴垂直平分对应点连线 | 对折红纸、剪、展开，连对应点量距离 | 剪纸桌 |
| 3 | 补全木花窗 | 画轴对称图形 | 逐个作对称点，连成另一半，对折检验 | 木工台 |
| 4 | 风车叶片 | 旋转中心、旋转角；对应点到中心距离相等 | 绕轴钉转叶片，量 OA、OA′ 和旋转角，拼成风车 | 北墙风车板 |
| 5 | 转半圈 | 中心对称、中心对称图形 | 绕 O 转 180°，连对应点；判断两块花砖 | 彩绘瓷砖台 |
| 6 | 形状大小不变 | 平移、轴对称、旋转都是全等变换；轴对称改变绕向 | 三种变换各做一次，量边和角 | 拷贝台 |
| 7 | 印一块花布 | 用旋转、平移设计图案 | 木模转着印出团花，再平移印满一块布 | 印花长桌 |

## 共用的计算核心

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `translate(p, v)` | 点、平移向量 | 像点 | 平移定义 |
| `reflectU(p, u0)` | 点、竖直对称轴 u = u0 | 像点 | 轴对称定义 |
| `rotate(p, o, deg)` | 点、中心、角度（逆时针为正） | 像点 | 旋转定义 |
| `dist`、`angleAt`、`sides`、`angles`、`turnDir` | 点 | 距离、角、三边、三角、绕向 | 平面几何 |
| `shift1(key)` | 第 1 课的平移 | 三对对应点、连线长（cm）、是否平行 | |
| `cut2(key)` | 第 2 课的花样 | 整个窗花轮廓、三对对应点到折痕的距离 | |
| `win3()` | — | 花窗另一半的四个对称点 | |
| `blades4(deg)` | 旋转角 | 叶片数、每片的位置、OA、OB、量到的角 | |
| `half5()`、`selfTurn5(key)` | 花砖 | 对应点、是否经过 O、转 180° 后是否和自己重合 | |
| `move6(key)` | 变换 | 像的三边、三角、绕向 | |
| `print7()` | — | 团花四片的角度、六朵团花的位置 | |
| `tuan(wedges)`、`tess(n)` | 折成几层、正几边形 | 对称轴条数；围一点的角度和、缝隙 | |

## 第 1 课 地砖上的平移

工坊地上铺着 30 cm 见方的青砖。一块蓝色釉面的小旗花砖嵌在砖缝上，把它沿砖缝推过去，看它怎么动。

| 项目 | 内容 |
|---|---|
| 知识点 | 平移由方向和距离决定；对应点连线平行（或在同一直线上）且相等 |
| 一句概念 | 对应点连线平行且相等 |
| 核心动作 | 选方向和格数，按“平移”，花砖匀速滑过去；按“连对应点” |
| 看到的现象 | 原图留下蓝色轮廓，像是橙色的；AA′、BB′、CC′ 三条白色虚线一样长、方向一样 |
| 读数 | AA′、BB′、CC′ 的长（cm） |
| 真实锚点 | 一块地砖 30 cm |
| 对应小测 | 第 1 题 |

任务清单

- [ ] 向右平移 5 格，连对应点（AA′ = BB′ = CC′ = 150.0 cm）
- [ ] 向上平移 3 格，再连一次（90.0 cm）
- [ ] 斜着平移：右 4 格、上 3 格（150.0 cm，三条连线平行）

视觉映射

| 知识点 | 必须看见的东西 | 由哪个量驱动 | 镜头与视图 |
|---|---|---|---|
| 平移是整体滑动 | 橙色花砖从原处匀速滑到新位置，方向不转 | 平移向量 | 接近俯视（仰角约 64°），花砖和终点都在画面中间 |
| 对应点连线 | 三条白虚线、三个箭头方向一致 | 对应点 | 同上 |

主操作区的按钮：平移、连对应点、记录数据。分段选择：平移方式（右 5 格 / 上 3 格 / 右 4 上 3）。

数据

| 条件 | 读数 | 来历 |
|---|---|---|
| 右 5 格 | 150.0 cm | 5 × 30 cm |
| 上 3 格 | 90.0 cm | 3 × 30 cm |
| 右 4 上 3 | 150.0 cm | 量出来的；（4×30）² + （3×30）² = 150²（界面只给量出的数，不讲勾股定理） |

## 第 2 课 对折剪窗花

一张 24 cm 见方的红纸。对折，沿画好的半边花样剪下，再展开。

| 项目 | 内容 |
|---|---|
| 知识点 | 轴对称图形；对称轴垂直平分对应点连线 |
| 一句概念 | 对称轴垂直平分对应点连线 |
| 核心动作 | 对折（右半边翻到左半边上），剪（剪刀沿花样走一圈），展开，连对应点 |
| 看到的现象 | 纸是两层一起剪的，展开后两边完全一样；AA′ 被折痕从中间穿过，成直角 |
| 读数 | A、B、C 到折痕的距离和 A′、B′、C′ 到折痕的距离；连线和折痕的夹角 |
| 真实锚点 | 民间剪纸“对折剪” |
| 对应小测 | 第 2、3 题 |

任务清单

- [ ] 对折红纸，剪出蝴蝶，展开
- [ ] 连对应点：量一量到折痕的距离
- [ ] 换成花瓶，再剪一个

数据（单位 cm，1 格 = 1 cm）

| 花样 | A 到折痕 | B 到折痕 | C 到折痕 |
|---|---|---|---|
| 蝴蝶 | 10.0 | 7.0 | 5.6 |
| 花瓶 | 3.0 | 6.0 | 5.0 |

按钮：对折 / 展开（同一个按钮）、沿线剪、连对应点。分段选择：花样。

## 第 3 课 补全木花窗

木工台上平放着一扇正在做的花窗（内框 80 cm × 90 cm），左半边的木条已经钉好，中间一条对称轴。照着左半边，把右半边补出来。

| 项目 | 内容 |
|---|---|
| 知识点 | 画轴对称图形：过点作对称轴的垂线，在另一侧截取相等的长度，得到对称点，再连起来 |
| 一句概念 | 先找对称点，再连成图形 |
| 核心动作 | 按“找对称点”四次（A、B、C、D 各一次），按“连成图形”，按“对折检验” |
| 看到的现象 | 每次从点出发一条白虚线垂直穿过对称轴，量出同样的长度，落下一个橙点；连起来以后橙色木条出现；左半边翻过来正好盖住右半边 |
| 读数 | 各点到对称轴的距离 |
| 对应小测 | 第 3 题 |

任务清单

- [ ] 作出 A 的对称点 A′
- [ ] 作出 B′、C′、D′
- [ ] 连成另一半花窗
- [ ] 沿对称轴对折，检验是否重合

数据（1 格 = 10 cm）：A、B、C、D 到对称轴分别是 20.0、30.0、10.0、30.0 cm。

## 第 4 课 风车叶片

北墙上挂着一块木板，正中一颗黄铜轴钉 O，钉着一片三角形的风车叶片 OAB（OA = 30.0 cm，OB = 25.0 cm）。

| 项目 | 内容 |
|---|---|
| 知识点 | 旋转三要素：旋转中心、旋转方向、旋转角；对应点到旋转中心的距离相等；对应点与中心连线的夹角等于旋转角 |
| 一句概念 | 对应点到旋转中心距离相等 |
| 核心动作 | 选旋转角，按“旋转”，叶片绕 O 逆时针转过去；按“量一量”；一片一片转，拼成风车 |
| 看到的现象 | 叶片绕钉转，形状不变；OA 和 OA′ 一样长，∠AOA′ = ∠BOB′ = 旋转角 |
| 读数 | OA、OA′、OB、OB′（cm），∠AOA′、∠BOB′（°） |
| 对应小测 | 第 4 题 |

任务清单

- [ ] 绕 O 旋转 90°，量 OA、OA′ 和旋转角
- [ ] 再转两次，拼成四叶风车
- [ ] 换 120°，拼一个三叶风车

按钮：旋转、量一量。分段选择：旋转角 90° / 120°。四叶或三叶拼成后，整架风车转一圈，看出它转 90°（或 120°）就和自己重合。

## 第 5 课 转半圈

彩绘瓷砖台上铺着白釉方砖（每块 10 cm，铅笔格 5 cm 一格）。

| 项目 | 内容 |
|---|---|
| 知识点 | 中心对称：一个图形绕某点旋转 180° 和另一个图形重合；对称点连线经过对称中心并被它平分。中心对称图形 |
| 一句概念 | 对称点连线都经过对称中心 |
| 核心动作 | 把小旗绕 O 转 180°，连对应点；再把平行四边形、正三角形花砖各绕自己的中心转 180° |
| 看到的现象 | AA′、BB′、CC′ 都穿过 O，O 两边一样长；平行四边形转半圈和原来重合，正三角形不重合 |
| 读数 | OA 和 OA′ 等（cm），转 180° 后是否重合 |
| 对应小测 | 第 5、6 题 |

任务清单

- [ ] 把小旗绕 O 旋转 180°
- [ ] 连对应点：都经过 O，被 O 平分
- [ ] 平行四边形花砖转半圈：和自己重合
- [ ] 正三角形花砖转半圈：不重合

数据（1 格 = 5 cm，O 在 (3, 1)）：OA = OA′ = 21.2 cm，OB = OB′ = 10.0 cm，OC = OC′ = 11.2 cm。

按钮：转 180°、连对应点。分段选择：小旗 / 平行四边形 / 正三角形。

## 第 6 课 形状大小不变

拷贝台的灯箱上铺着描图纸，纸上一个三角形 ABC（1 格 = 4 cm：AB = 16.0 cm，BC = 17.0 cm，CA = 12.6 cm；∠A = 72°，∠B = 45°，∠C = 63°）。

| 项目 | 内容 |
|---|---|
| 知识点 | 平移、轴对称、旋转都只改变位置，不改变形状和大小（全等变换）；轴对称把 A→B→C 的绕向反过来 |
| 一句概念 | 三种变换都不改变形状大小 |
| 核心动作 | 选一种变换，按“变换”，看三角形怎么动；按“量一量” |
| 看到的现象 | 像的三边、三角都和原图一样；平移、旋转后 A→B→C 仍是逆时针，轴对称后变成顺时针 |
| 读数 | 像的三边（cm）、三角（°）、绕向 |
| 对应小测 | 第 7 题 |

任务清单

- [ ] 平移：量像的边和角
- [ ] 轴对称：量一量，看绕向
- [ ] 旋转：量一量

变换：平移（右 6 格、上 1 格）；轴对称（对称轴 u = 5.5）；旋转（绕 (5, 0) 逆时针 90°）。

## 第 7 课 印一块花布

印花长桌上铺一块白布（100 cm × 60 cm），旁边一块刻着一片花瓣的木模和一盆蓝靛。

| 项目 | 内容 |
|---|---|
| 知识点 | 图案设计：用旋转、平移（和轴对称）把一个基本图形组合成图案 |
| 一句概念 | 一片花瓣，转着印、移着印 |
| 核心动作 | 按“旋转 90° 再印”三次印出一朵团花；按“平移再印”；按“印满整块布” |
| 看到的现象 | 木模绕团花中心转 90° 落下，留下一片新花瓣；整朵团花向右平移 28 cm 印第二朵；最后印成两行三列 |
| 读数 | 已印的花瓣数、用到的变换 |
| 对应小测 | 第 8 题 |

任务清单

- [ ] 旋转：花瓣绕中心转 90°，印成一朵四瓣团花
- [ ] 平移：把团花向右平移 28 cm，再印一朵
- [ ] 印满整块布：两行三列

## 讲解

解说词在 `src/labs/transform/narration.ts`。要特别讲清楚的：第 2 课“两层一起剪”是两边一样的原因；第 3 课每作一个点都说“过点作垂线、另一边截取一样长”；第 4 课强调转的是整片叶片，钉子不动。

## 和规格卡原文的出入

- 第 2 课蝴蝶花样重画（加了触角、身子收窄），A、B、C 到折痕改为 10.0、7.0、5.6 cm。
- 第 7 课花瓣放大到原来的 1.35 倍，团花之间的平移从 24 cm 改为 28 cm，布上更满。
- 拓展 2 的正五边形留缝处画了一块红色的扇形，标出 36°。
- 随堂检测第 9 题（综合题）“回到对应那一课”指向第 6 课。
