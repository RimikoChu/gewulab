# 大气环流实验室 · 规格卡 v1.0

状态：待审。议题 #79。

## 总览

- 一句话：把整个地球的大气画出来——从地球不自转时的单圈环流，到加上地转偏向力的三圈环流；七个气压带、六个风带在哪、怎么来；它们怎样随太阳直射点南北移动、怎样影响气候；海陆热力性质差异怎样把气压带切成高低压中心，又怎样形成季风。
- 教材位置：人教版（2019）高中地理选择性必修 1《自然地理基础》，第三章“大气的运动”中“气压带和风带”“气压带和风带对气候的影响”两节（章节号见待核实事项）。
- 主线：同一颗地球。课与课之间只换视角、季节和“地球的条件”（自转不自转、地表均匀还是有海陆）。
- 场景：太空里的一颗大地球（NASA Blue Marble 实拍影像，昼夜明暗随太阳方向变化，背后是星空，远处有太阳）。外面一层大气，厚度放大很多倍（界面标“示意”）。
- **大场景的布局**：地球球心在原点，半径 10 个场景单位；大气层外表面半径 15（真实对流层只有地球半径的约 0.2%，这里放大两百多倍，示意）。各课的机位都看着这颗地球，只是方位和远近不同：第 1、2 课把地球连同大气沿两条经线切掉四分之一，镜头从切口斜着看进去，右边那片经线剖面几乎正对镜头，上面画环流圈（第 2 课跟那团空气时，镜头转到没切开的一面看它的路线）；第 3 课正对大西洋看整颗地球的气压带和风带；第 4 课从侧面看，太阳在左前方，晨昏线和直射点可见；第 5 课推近到雅典、新加坡、达尔文三处；第 6 课到北极上空斜着往下看整个北半球；第 7 课推近到东亚和南亚；拓展课到北太平洋上空（航线）和赤道太平洋（信风）。换课时镜头绕着地球飞过去。
- 取值约定：黄赤交角 23.4°；地球半径 6371 km，自转角速度 7.292×10⁻⁵ rad/s；高压蓝、低压红（全间统一）；暖红、冷蓝；风的流动箭头一律白色，被选中跟踪的一团空气用淡黄。
- 和同类产品的区别：环流圈、气压带、风带、高低压中心都画在同一颗实拍地球上，风是从气压场按“从高压吹向低压、再按纬度偏转”算出来的流动箭头，季节一变，气压场和风一起连续变化；每课亲手做一件事、读到一个数或一个风向。

| 课 | 名称 | 知识点 | 学生的核心动作 | 场景 |
|---|---|---|---|---|

## 共用的计算核心（`physics.ts`）

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `subsolarLat(day)` | 日序 | 直射点纬度 | 23.4° × sin(2π(day − 80)/365)，示意 |
| `beltShift(sunLat)` / `beltLat` | 直射点纬度 | 气压带移动的度数、中心纬度 | 示意：直射点到回归线时移动 5°，按比例；两极高压不动 |
| `pressure(lon, lat, air)` | 位置、状态 | 近地面气压的相对值（正高负低） | 示意：单圈 −cos 2φ；三圈为七条高斯带（宽 10°）；加上高低压中心（离中心越近原来的带剩得越少） |
| `surfaceWind` / `windAtName` | 位置、状态 | 风的方向分量、八方位风向 | 先取水平气压梯度力，再按纬度向右（北）/向左（南）偏，最大 55°，赤道为 0 |
| `upperHeading(lat)` / `upperDrift(lat)` | 纬度 | 赤道高空向北气流的偏向角、往东偏过的经度 | 角动量守恒 u = Ωa sin²φ / cosφ，南北向速度取 20 m/s（示意） |
| `controlAt(lat, day)` / `yearOf(place)` | 纬度、日序 | 受哪个气压带或风带控制、多雨少雨 | 赤道低压半宽 9°、其余气压带半宽 5°（示意） |
| `airOf(month)` | 1 月或 7 月 | 那个月的大气 | 三圈 + 季节移动 + 高低压中心 |
| `monsoonAt(city, month)` | 城市、月份 | 风向 | 同上 |
| `trace(lon, lat, air)` | 起点、状态 | 一团空气的近地面路线 | 沿风向每步 0.6° |
| `routeKm` / `flightHours` | — | 大圆航线长度、往东往西的飞行时间 | 空速 900 km/h，沿线平均西风 100 km/h（示意） |
| `warmSpan(trade)` | 信风强弱 | 暖水从 120°E 往东伸的经度跨度 | 示意 |

## 第 1 课 单圈环流

| 项目 | 内容 |
|---|---|
| 知识点 | 假设地球不自转、地表均匀：赤道受热多，空气膨胀上升，近地面成低压；极地冷却下沉，近地面成高压；高空由赤道流向极地，近地面由极地流回赤道 |
| 一句概念 | 不自转时，赤道和两极之间只有一个环流 |
| 核心动作 | 让太阳照射（地球受热不均），看剖面上的环流转起来，量近地面气压和风向 |
| 看到的现象 | 剖面赤道一端变红、两极变蓝；赤道上升、极地下沉的一圈流线；地表的白色箭头从两极流向赤道；近地面赤道红色低压、两极蓝色高压 |
| 读数 | 北半球、南半球近地面的风向：北风、南风 |
| 对应小测 | 第 1 题 |

任务：让太阳照射赤道 → 看大气转起来（自动打勾）→ 量近地面的气压和风向。按钮：让太阳照射、量气压和风向。

## 第 2 课 三圈环流

| 项目 | 内容 |
|---|---|
| 知识点 | 地球自转产生地转偏向力：赤道上空流向极地的气流在北半球向右偏，到 30°N 附近几乎成了西风，空气堆积下沉，近地面形成副热带高气压带；单圈环流变成低纬、中纬、高纬三个环流圈 |
| 一句概念 | 地球一自转，一个大圈就分成了三个 |
| 核心动作 | 让地球自转；跟着一团高空空气从赤道往北走，看它偏转；记下近地面四个纬度的气压 |
| 读数 | 偏向角（示意）：10°N 约 35°、20°N 约 71°、30°N 约 82°；往东偏过约 72 个经度 |
| 对应小测 | 第 2 题 |

任务：让地球自转 → 跟一团高空的空气 → 记下近地面 0°、30°、60°、90° 的气压（低、高、低、高）。按钮：让地球自转、跟一团空气、记录气压。

## 第 3 课 气压带和风带

| 项目 | 内容 |
|---|---|
| 知识点 | 七个气压带：赤道低气压带（热力）、南北副热带高气压带（动力）、南北副极地低气压带（动力）、南北极地高气压带（热力）；六个风带：东北/东南信风带、西风带、极地东风带；风从高压吹向低压，北半球向右偏、南半球向左偏 |
| 一句概念 | 七个气压带、六个风带相间分布 |
| 核心动作 | 画出气压带；画出风带；换到南半球看风向 |
| 读数 | 北半球：信风带东北风、西风带西南风、极地东风带东北风；南半球：东南风、西北风、东南风 |
| 对应小测 | 第 3 题 |

任务：画出七个气压带 → 画出六个风带 → 北半球记下三个风带的风向 → 换南半球再记。按钮：画出气压带、画出风带、记录风向；分段：北半球／南半球。

## 第 4 课 季节移动

| 项目 | 内容 |
|---|---|
| 知识点 | 气压带和风带随太阳直射点的季节移动而移动：就北半球来说，夏季北移、冬季南移 |
| 一句概念 | 直射点往北，气压带风带跟着往北 |
| 核心动作 | 按“下一个节气”，太阳直射点连续移动，晨昏线跟着变；到节气时记录 |
| 读数 | 直射点纬度；赤道低压带、北半球副热带高压带的中心纬度（约）：春分 0°、30°N；夏至 5°N、35°N；冬至 5°S、25°N |
| 对应小测 | 第 4 题 |

任务：春分时记录 → 走到夏至记录 → 走到冬至记录。按钮：下一个节气、记录。

## 第 5 课 气压带、风带对气候的影响

| 项目 | 内容 |
|---|---|
| 知识点 | 热带雨林气候：终年受赤道低气压带控制，全年高温多雨；地中海气候：夏季受副热带高气压带控制炎热干燥，冬季受西风带控制温和多雨；热带草原气候：赤道低气压带和信风带交替控制，干湿季分明 |
| 一句概念 | 谁控制这里，就决定这里下不下雨 |
| 核心动作 | 选一个地方，按“走一年”或“到七月”“到一月”，看这个月是哪个气压带或风带盖在它头上 |
| 读数 | 十二个月各受谁控制、多雨少雨（示意） |
| 对应小测 | 第 5 题 |

任务：雅典到七月 → 雅典到一月 → 新加坡走一年 → 达尔文走一年。

## 第 6 课 海陆分布与高低压中心

| 项目 | 内容 |
|---|---|
| 知识点 | 海陆热力性质差异：冬季陆地比海洋冷，夏季陆地比海洋热；北半球 1 月副极地低气压带被亚欧大陆上的亚洲高压（蒙古—西伯利亚高压）切断，只剩海洋上的阿留申低压、冰岛低压；7 月副热带高气压带被亚洲低压（印度低压）切断，只剩海洋上的夏威夷高压、亚速尔高压 |
| 一句概念 | 海陆冷热不同，气压带被切成一块块 |
| 核心动作 | 选 1 月／7 月，按“显示海陆冷暖”，再按“画出气压中心” |
| 读数 | 各中心的名称和高低；被切断的是哪一个气压带 |
| 对应小测 | 第 6 题 |

## 第 7 课 季风

| 项目 | 内容 |
|---|---|
| 知识点 | 东亚季风：冬季西北风，夏季东南风，主要由海陆热力性质差异形成；南亚季风：冬季东北风，夏季西南风，夏季的西南季风由南半球东南信风越过赤道向右偏转而成（气压带风带季节移动），也有海陆热力差异 |
| 一句概念 | 冬夏风向相反，就是季风 |
| 核心动作 | 冬季记录上海、孟买的风向，放一团空气看它从亚洲高压吹出来；夏季再记录，放一团空气看东南信风越过赤道变成西南风 |
| 读数 | 风向：冬季上海西北风、孟买东北风；夏季上海东南风、孟买西南风 |
| 对应小测 | 第 7、8 题 |

## 讲解

单圈和三圈环流要讲清“剖面上的圈”和“地面上的箭头”是同一件事的两个面；第 7 课放一团空气时，讲清越过赤道以后偏转方向反过来。

## 和规格卡原文的出入

- 第一版之后按审看意见改过一轮：第 1、2 课从“一圈光环”改成切掉四分之一地球的经线剖面，大气层厚度放大到地球半径的一半（示意）；第 5、7 课和拓展课的风箭头只画在相关的一带、数量减到约三分之一；第 7 课冷暖只着在陆地上，不再叠气压着色。

## 待核实事项

- [ ] 教材的节号和节名（“气压带和风带”“气压带和风带对气候的影响”在第三章的第几节）。
- [ ] 气压带季节移动的幅度：这里取直射点到回归线时移动 5°（示意），教材只说“夏季北移、冬季南移”。
- [ ] 高低压中心的位置（亚洲高压约 46°N 98°E、阿留申低压约 52°N 178°E、冰岛低压约 62°N 28°W、亚洲低压约 31°N 75°E、夏威夷高压约 34°N 150°W、亚速尔高压约 35°N 35°W）是示意的大致位置；7 月北美大陆上的低压没有标名称。
- [ ] 风场是示意模型（气压梯度方向再按纬度偏 0°–55°），只保证八方位风向和教材一致，不代表真实风速。
- [ ] 偏向角用角动量守恒和 20 m/s 的南北向速度算，数值只是示意。
- [ ] 航线平均西风 100 km/h、空速 900 km/h 是示意值。
- [ ] 控制雅典、新加坡、达尔文的气压带风带按示意半宽判定，月份边界不代表真实干湿季。
