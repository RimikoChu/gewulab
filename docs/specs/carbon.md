状态：九个课次（1–7、拓展、随堂检测）做完，每课自动演示带讲解能走到结论条，待验收。关联议题 #19。

## 总览

- **一句话**：学生在一座汽水厂里，先在厂里的质检化验室认识金刚石、石墨和 C₆₀，用大理石和稀盐酸制一瓶二氧化碳，做它的性质实验；再到灌装车间看碳化罐怎样把二氧化碳压进水里、开瓶为什么冒泡；回到化验台做一氧化碳还原氧化铜；最后走进厂旁边的玻璃温室，看作物怎样“吃”二氧化碳，弄清自然界里碳的循环。
- **教材位置**：化学，初中。人教版九年级上册“碳和碳的氧化物”单元（碳单质的多样性；二氧化碳制取的研究；二氧化碳和一氧化碳）。准确的单元号、课题名见“待核实事项”，界面上不写课题号。
- **主线**：二氧化碳。第 1 课从碳元素说起，第 2 课把二氧化碳制出来，第 3、4 课看它的性质，第 5 课看工厂怎么用它，第 6 课看碳的另一种氧化物一氧化碳，第 7 课看二氧化碳在自然界里怎样循环。
- **场景**：汽水厂和厂旁边的玻璃温室（议题建议的场景，保留）。理由：汽水厂本来就离不开二氧化碳：厂区里立着液态二氧化碳储罐，灌装车间里有碳化罐，汽水开瓶冒泡正是第 5 课要讲的事；厂里的质检化验室台上本来就有烧杯、锥形瓶、试管，第 1–4、6 课和拓展课的实验放在这里是真有其事。现代的玻璃温室会往棚里补二氧化碳促进作物生长，第 7 课放在这里，学生能读到棚里的二氧化碳浓度怎样随光照和补气变化。
- **取值约定**：场景里 1 m 画成 6 个单位（`M = 6`），化验台台面高 85 cm。气体密度按标准状况：二氧化碳 1.977 g/L，空气 1.293 g/L。相对原子质量：C 12，O 16，Ca 40，Cu 64，H 1，Cl 35.5。二氧化碳浓度用 ppm（体积分数的百万分之一），保留整数。质量用 g，保留两位小数（不足 1 g 时保留三位）。
- **和同类产品的区别**：碳单质的三个球棍模型由程序按真实的晶体结构算出原子位置（C₆₀ 是 60 个原子、90 根键）；制取二氧化碳时气泡的多少按反应速率走，换成稀硫酸后气泡很快变少停下；阶梯蜡烛按烧杯里二氧化碳的高度一支一支熄灭；碳化罐里的溶解量按亨利定律随压强算；温室里的二氧化碳浓度按光合作用、呼吸作用和补气三项一秒一秒算出来。

课次理由：教材先讲碳的单质，再讲二氧化碳的实验室制取，然后讲二氧化碳和一氧化碳的性质和用途，顺序一致。二氧化碳的性质分成两课：第 3 课是物理性质和“不支持燃烧”，第 4 课是两个化学性质。汽水是二氧化碳“能溶于水”的真实用途，放在性质之后。碳循环和温室效应是“二氧化碳对生活和环境的影响”，放在最后。

## 共用的计算核心

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `diamondAtoms`、`graphiteAtoms`、`c60Atoms`、`bonds` | 无 | 原子坐标、成键 | 金刚石立方晶胞（每个碳原子连 4 个）；石墨层状六边形（层内每个连 3 个，层间距约 0.335 nm）；C₆₀ 截角二十面体（60 个顶点、90 条棱） |
| `ALLOTROPES` | 哪种单质 | 硬度、导电性、结构、用途 | 教材 |
| `co2FromCaCO3` | 碳酸钙质量（g） | 生成二氧化碳的质量（g） | CaCO₃ + 2HCl = CaCl₂ + H₂O + CO₂↑，100 : 44 |
| `genRate`、`collected` | 哪种酸、反应了几秒 | 产气速率（相对）、集气瓶里收集了几成 | 简化模型，示意：稀硫酸的速率很快衰减 |
| `beakerCO2`、`candleOut` | 倒了几秒 | 烧杯里二氧化碳的高度、哪支蜡烛熄灭 | 简化模型，示意 |
| `squeeze` | 瓶的容积、加水的体积 | 瓶里的气体剩多少、瓶子缩到多大 | 通常状况下 1 体积水约能溶解 1 体积二氧化碳 |
| `caco3FromCO2` | 二氧化碳质量 | 碳酸钙沉淀的质量 | CO₂ + Ca(OH)₂ = CaCO₃↓ + H₂O，44 : 100 |
| `SOLUBILITY`、`dissolved` | 温度、压强 | 每升水溶解二氧化碳的质量（g/L） | 亨利定律：溶解量与压强成正比；1 个大气压下的溶解度取表值 |
| `cuFromCuO` | 氧化铜质量 | 生成铜的质量 | CO + CuO =△= Cu + CO₂，80 : 64 |
| `greenhouseStep`、`photoRel` | 棚里的二氧化碳浓度、有没有光、补不补气、过了几秒 | 下一刻的浓度；光合作用的相对快慢 | 简化模型，示意 |
| `sublime` | 放了几秒 | 干冰还剩多少克 | 简化模型，示意；干冰在一个大气压下的升华温度 −78.5 °C |

## 第 1 课 碳的单质

| 项目 | 内容 |
|---|---|
| 知识点 | 金刚石、石墨、C₆₀ 都是由碳元素组成的单质；碳原子的排列方式不同，物理性质差异很大 |
| 一句概念 | 同是碳原子，排法不同，性质大不同 |
| 核心动作 | 选一种碳单质；用玻璃刀（刀头是金刚石）和石墨棒各在玻璃上划一下；把石墨棒接进电路；数一数 C₆₀ 模型的原子 |
| 看到的现象 | 金刚石在玻璃上划出一道白痕；石墨划不动，只留下一道黑印；石墨接进电路，小灯泡亮；C₆₀ 模型上的原子一个个点亮，数到 60 |
| 读数 | 莫氏硬度：金刚石 10，石墨 1–2；C₆₀ 的原子数 60 |
| 真实锚点 | 玻璃刀的刀头镶着金刚石；铅笔芯、干电池的电极用石墨 |
| 对应小测 | 第 1 题 |

任务：用金刚石在玻璃上划一下 → 用石墨在玻璃上划一下 → 把石墨接进电路 → 数一数 C₆₀ 的原子。

主操作区：在玻璃上划一下、接进电路、数原子（按当前选的单质能用的那几个亮着）。分段选择：金刚石 / 石墨 / C₆₀。

## 第 2 课 二氧化碳的制取（样板课）

| 项目 | 内容 |
|---|---|
| 知识点 | 实验室用大理石（或石灰石）和稀盐酸制取二氧化碳；固体和液体常温反应，用锥形瓶加长颈漏斗，长颈漏斗下端伸到液面以下；二氧化碳密度比空气大、能溶于水，用向上排空气法收集，导管伸到集气瓶底部；验满：燃着的木条放在瓶口，熄灭则已集满；不用稀硫酸：生成的硫酸钙微溶，覆盖在大理石表面，反应很快停止 |
| 一句概念 | 大理石加稀盐酸，向上排空气法收集 |
| 核心动作 | 装大理石、从长颈漏斗加稀盐酸；燃着的木条放到瓶口验满；盖上玻璃片正放；换稀硫酸再做一遍 |
| 看到的现象 | 大理石表面冒出大量气泡；集气瓶里的二氧化碳从瓶底往上积（画成淡淡的一层，示意）；没集满时木条照常燃烧，集满时木条熄灭；稀硫酸的气泡很快变少、停下 |
| 读数 | 集气瓶里收集了几成（示意）；10 g 碳酸钙完全反应生成 4.4 g 二氧化碳 |
| 对应小测 | 第 2、3 题 |

任务：装大理石、加稀盐酸 → 用燃着的木条验满 → 盖好玻璃片，正放在桌上 → 换成稀硫酸再做一次。

主操作区：装入大理石 / 加入稀酸（同一个按钮，按顺序换字）、验满、盖玻璃片。分段选择：稀盐酸 / 稀硫酸。没集满就验满：木条照常燃烧，提示还没集满。

## 第 3 课 二氧化碳的性质

| 项目 | 内容 |
|---|---|
| 知识点 | 二氧化碳的密度比空气大；不能燃烧，也不支持燃烧；能溶于水 |
| 一句概念 | 比空气重、不助燃、能溶于水 |
| 核心动作 | 把一瓶二氧化碳沿烧杯壁慢慢倒进放着阶梯蜡烛的烧杯；往装满二氧化碳的软塑料瓶里倒约三分之一瓶水，拧紧瓶盖，振荡 |
| 看到的现象 | 下层的蜡烛先熄灭，上层的后熄灭；软塑料瓶变瘪 |
| 读数 | 二氧化碳 1.977 g/L，空气 1.293 g/L；500 mL 的瓶加 170 mL 水，振荡后瓶里的气体从 330 mL 减到约 160 mL（示意） |
| 对应小测 | 第 4 题 |

任务：把二氧化碳倒进烧杯 → 往软塑料瓶里加水、拧紧 → 振荡。

## 第 4 课 二氧化碳与水、石灰水

| 项目 | 内容 |
|---|---|
| 知识点 | CO₂ + H₂O = H₂CO₃，碳酸使紫色石蕊溶液变红；H₂CO₃ = H₂O + CO₂↑，加热后溶液又变紫；CO₂ + Ca(OH)₂ = CaCO₃↓ + H₂O，澄清石灰水变浑浊，常用来检验二氧化碳 |
| 一句概念 | 遇水成碳酸，遇石灰水变浑浊 |
| 核心动作 | 把导管伸进紫色石蕊溶液通气；用试管夹夹住试管在酒精灯上加热；把导管伸进澄清石灰水通气 |
| 看到的现象 | 紫色变红；加热时冒出小气泡，红色退回紫色；石灰水里出现白色浑浊 |
| 读数 | 通入的二氧化碳体积（示意）；44 g 二氧化碳生成 100 g 碳酸钙 |
| 对应小测 | 第 5 题 |

任务：向紫色石蕊溶液中通入二氧化碳 → 加热变红的溶液 → 向澄清石灰水中通入二氧化碳。分段选择：石蕊溶液 / 澄清石灰水。

## 第 5 课 汽水厂

| 项目 | 内容 |
|---|---|
| 知识点 | 气体的溶解度随压强增大而增大、随温度升高而减小；汽水是在加压下溶入二氧化碳制成的；打开瓶盖，压强减小，二氧化碳的溶解度变小，从水里逸出 |
| 一句概念 | 压强越大，溶进去的二氧化碳越多 |
| 核心动作 | 选碳化罐的压强（100 / 200 / 300 kPa）充二氧化碳，读溶解量；灌装封盖；打开瓶盖 |
| 看到的现象 | 碳化罐朝镜头剖开，二氧化碳从罐顶进来，罐里的水被冲成细小的水流；压强越大溶进去越多；开瓶时瓶里涌出大量气泡 |
| 读数 | 5 °C 时：100 kPa 约 2.7 g/L，200 kPa 约 5.5 g/L，300 kPa 约 8.2 g/L（亨利定律算：一个大气压 101.325 kPa 下 2.77 g/L，按压强成正比） |
| 真实锚点 | 汽水厂的碳化罐，在冷却后的水里加压溶入二氧化碳 |
| 对应小测 | 第 6 题 |

任务：用 100 kPa 充二氧化碳 → 加到 300 kPa 再充 → 灌装、封盖 → 打开瓶盖。主操作区：充入二氧化碳、灌装封盖、打开瓶盖。分段选择：100 / 200 / 300 kPa。

## 第 6 课 一氧化碳

| 项目 | 内容 |
|---|---|
| 知识点 | 一氧化碳有毒（与血红蛋白结合）；能燃烧，产生蓝色火焰；有还原性：CO + CuO =△= Cu + CO₂；实验先通一氧化碳排尽空气再加热（防止爆炸），结束时先停止加热，继续通一氧化碳到玻璃管冷却（防止铜重新被氧化）；尾气点燃处理 |
| 一句概念 | 一氧化碳有毒、能燃烧、能还原氧化铜 |
| 核心动作 | 点燃导管末端的酒精灯；通入一氧化碳；加热氧化铜；停止加热，冷却后停止通气 |
| 看到的现象 | 尾气处燃起蓝色火焰；黑色粉末逐渐变成红色；澄清石灰水变浑浊 |
| 读数 | 玻璃管里 2.00 g 氧化铜完全反应后剩 1.60 g 铜 |
| 对应小测 | 第 7 题 |

任务：点燃尾气处的酒精灯 → 通入一氧化碳，排尽管里的空气 → 加热氧化铜 → 停止加热，冷却后停止通气。没通一氧化碳就加热：不让加热，提示为什么。

## 第 7 课 碳循环

| 项目 | 内容 |
|---|---|
| 知识点 | 二氧化碳是光合作用的原料，温室里补二氧化碳能促进作物生长；自然界中二氧化碳通过光合作用被消耗，通过动植物的呼吸、化石燃料的燃烧等产生；大气中二氧化碳增多会加剧温室效应；低碳生活 |
| 一句概念 | 光合作用吸收，呼吸和燃烧放出 |
| 核心动作 | 关上天窗，看棚里的二氧化碳浓度下降；打开钢瓶补气到 1000 ppm；天黑，看浓度回升；看碳循环 |
| 读数 | 二氧化碳浓度（ppm）；光合作用的相对快慢（示意，以 400 ppm 时为 100%） |
| 真实锚点 | 大气中二氧化碳约 420 ppm；温室补气常补到 800–1000 ppm |
| 对应小测 | 第 8、9 题 |

任务：关上天窗，看浓度下降 → 打开钢瓶补二氧化碳 → 天黑，看浓度变化 → 看自然界的碳循环。主操作区：关上天窗、补充二氧化碳 / 停止补气、天黑 / 天亮。分段选择：温室里 / 自然界（选“自然界”时镜头拉远到整个厂区，标出光合作用、呼吸作用、燃料燃烧三条箭头）。

## 拓展课 干冰

## 画面上的约定

- 二氧化碳是无色的。为了看清它往哪里流、积到多高，制取、倾倒、充气时画成很淡的一层灰白（界面在标签上写“示意”）。
- 制取、充气、通气、光合作用的过程都加快了；第 7 课的钟加快，面板上写明“过程加快”。
- 碳化罐朝镜头剖开（规范 4.5），罐壁的切口画出壁厚。
- 球棍模型里原子和键的粗细是为了看清，不按比例。

## 和规格卡原文的出入

- 第 7 课：开头不是“日出”，而是白天开着天窗（棚里和室外一样约 420 ppm），第一步改为“关上天窗”；“看碳循环”从按钮改为分段选择“温室里 / 自然界”，主操作区仍是三个按钮。天黑时补气自动关掉（温室夜里不补气）。
- 第 1 课：只把石墨接进电路（玻璃刀头上的金刚石不便接进电路），金刚石“不导电”按教材写在面板表格里。
- 第 4 课：试管架上多一支空试管，导管不用时插在里面。
- 第 5 课：开瓶的那一瓶放在输送线末端的抽检台上，镜头在灌装后从碳化罐移到抽检台。
- 第 6 课：主操作区三个按钮是“点燃尾气处的灯”“通入一氧化碳 / 停止通气”“加热 / 停止加热”，操作顺序不对时不执行，提示语说明原因。
- 拓展课：两件事按顺序做（放上干冰 → 测温度 → 放进温水），没有分段选择。
