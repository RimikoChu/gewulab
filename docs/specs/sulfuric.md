# 接触法制硫酸实验室 · 规格卡 v1.0

状态：九个课次已做完，待验收。关联议题 #71。

## 总览

- 一句话：跟着硫一路走过一座硫酸厂，弄懂硫铁矿怎样一步步变成硫酸，以及工业上怎样在速率和平衡之间取舍。
- 教材位置：人教版高中化学必修第二册“化工生产中的重要非金属元素”（硫及其化合物：硫酸的工业制法、浓硫酸的性质）；选择性必修 1“化学反应速率与化学平衡”（化学反应的调控）。具体章节号见“待核实事项”。
- 主线：硫元素的去向。FeS₂ → SO₂ → SO₃ → H₂SO₄，三个设备（沸腾炉、接触室、吸收塔）对应三个反应。
- 场景：一座以硫铁矿为原料的硫酸厂。**大场景的布局**（单位 m，x 轴自西向东就是工艺流程的方向，镜头在南侧）：
  - 最西头 x = −92 到 −66：中控化验楼，一层敞着门脸，里面一条化验台（第 7 课）。
  - x = −44 到 −24：原料棚、矿堆和上料皮带。
  - x = −16：沸腾炉（第 1 课，可朝镜头剖开）。
  - x = −6 到 21：净化工段，依次是旋风除尘器、电除尘器、洗涤塔、干燥塔（第 2 课）。
  - x = 29：二氧化硫鼓风机；x = 36：热交换器（拓展，可剖开）；x = 47：接触室（第 3、4、5 课，可剖开，里面四层催化剂）。
  - x = 62：吸收塔（第 6 课，可剖开）；x = 71：尾气吸收塔；x = 79：烟囱。
  - x = 94：成品酸储罐和装车台（拓展）。
  - 北侧 z = −13 一条管廊贯穿东西；更远是冷却塔、厂房。各设备之间用工艺管道按上面的顺序接起来。
- 取值约定：相对原子质量 H 1、C 12、O 16、S 32、Fe 56、Cu 64；气体摩尔体积（标准状况）22.4 L/mol；原料气体积分数 SO₂ 7%、O₂ 11%、N₂ 82%；转化率保留一位小数，单位 %；温度单位 °C，压强单位 MPa。
- 颜色约定（全实验室一致）：SO₂ 黄、SO₃ 青绿、空气和 O₂ 浅蓝、水蒸气白、矿尘灰褐。
- 和同类产品的区别：不是一张流程图配动画，而是能飞到每台设备跟前、把设备剖开看里面；条件的取舍用教材数据表里的数来比较。

| 课 | 名称 | 知识点 | 学生的核心动作 | 场景 |
|---|---|---|---|---|
| 1 | 沸腾炉造气 | 4FeS₂ + 11O₂ =高温= 2Fe₂O₃ + 8SO₂；粉碎矿石、鼓入空气加快反应 | 换块矿和矿粉，鼓风，比较烧掉多少；算产气量 | 沸腾炉（剖开） |
| 2 | 炉气的净化 | 除尘、洗涤、干燥；杂质使催化剂中毒 | 在四个取样点各化验一次 | 净化工段 |
| 3 | 接触室里的催化氧化 | 2SO₂ + O₂ ⇌ 2SO₃，可逆、放热，V₂O₅ 作催化剂 | 不装和装催化剂各通一次气，记平衡时的转化率 | 接触室（剖开） |
| 4 | 温度的选择 | 速率和平衡的取舍：400–500 °C | 换三个温度，比较平衡转化率和出口转化率 | 接触室外观 |
| 5 | 压强和空气用量 | 常压已经够高；过量空气提高 SO₂ 转化率 | 换压强、换空气用量，各记一次 | 转化工段（鼓风机、热交换器、接触室） |
| 6 | 吸收和尾气 | 用 98.3% 浓硫酸吸收 SO₃；逆流；尾气用氨水吸收 | 先用水、再用浓硫酸吸收，开尾气吸收 | 吸收塔（剖开）、尾气塔、烟囱 |
| 7 | 浓硫酸的性质 | 吸水性、脱水性、强氧化性 | 做三个小实验 | 化验室 |
| 拓展 | 热和料的两笔账 | 热交换器利用反应热；关系式 FeS₂ ~ 2H₂SO₄ | 开热交换器；装一车酸 | 热交换器（剖开）、成品酸罐 |
| 测 | 随堂检测 | 九道选择题 | 逐题作答 | 全厂鸟瞰 |

## 共用的计算核心

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `so2FromFeS2(m)`、`slagFromFeS2(m)` | FeS₂ 的质量 | SO₂、Fe₂O₃ 的质量 | 方程式 4FeS₂ + 11O₂ = 2Fe₂O₃ + 8SO₂ |
| `areaTimes(d0, d1)` | 粉碎前后的粒径 | 表面积的倍数 | 同质量球形颗粒的总表面积和粒径成反比 |
| `burned(ore, t)` | 矿料、鼓风时间 | 烧掉的比例 | 示意：一级过程，矿粉的速率常数是块矿的 10 倍 |
| `dirtAt(tap)`、`poisons(tap)` | 取样点 | 三类杂质的相对含量、是否使催化剂中毒 | 示意：出炉时记作 100 |
| `xTable(t, p)` | 温度、压强 | SO₂ 平衡转化率 | 教材数据表（见下） |
| `kp(t)`、`xEq(t, p, o2)` | 温度、压强、O₂ 体积分数 | 平衡转化率 | 由数据表常压一列反推平衡常数，再解平衡 |
| `conv3(cat, t)`、`rates3(cat, t)` | 有无催化剂、时间 | 转化率、正逆反应速率的相对值 | 示意：一级趋近平衡 |
| `xOut(t)` | 温度 | 流过催化剂层后的实际转化率 | 示意：速率每升高约 40 °C 翻一倍 |
| `tailSO2(x)`、`tailAfter(x)` | 转化率 | 尾气中 SO₂ 的体积分数 | 物料衡算；氨水去除 95% 为示意 |
| `waterFromBluestone`、`carbonFromSucrose`、`so2FromCu` | 质量 | 质量、体积 | 化学式和方程式 |
| `exchange(hot, cold, eff)` | 两股气体的温度、换热效率 | 两个出口温度 | 示意：两股气体流量和比热相同 |
| `acidFromOre(m, w, c)` | 矿石质量、FeS₂ 质量分数、酸的质量分数 | 硫酸的质量 | 关系式 FeS₂ ~ 2H₂SO₄ |

## 第 1 课 沸腾炉造气

硫铁矿在沸腾炉里焙烧，得到二氧化硫。

| 项目 | 内容 |
|---|---|
| 知识点 | 4FeS₂ + 11O₂ =高温= 2Fe₂O₃ + 8SO₂；粉碎矿石增大接触面积，从炉底鼓入空气使矿粒“沸腾” |
| 一句概念 | 矿石粉碎、鼓入空气，烧得又快又透 |
| 核心动作 | 选矿料，鼓入空气，看 10 s 烧掉多少；算 1 t FeS₂ 的产气量 |
| 看到的现象 | 块矿堆在分布板上，只有表面发红；矿粉被气流托起来翻滚，整层通红，黄色的 SO₂ 从炉顶出去 |
| 读数 | 烧掉的比例（示意）；1 t FeS₂ 得 SO₂ 1.07 t、Fe₂O₃ 0.67 t |
| 真实锚点 | 沸腾炉因矿粒像沸腾的液体而得名 |
| 对应小测 | 第 1 题 |

任务清单

- [ ] 用块矿鼓风 10 s，看烧掉多少（约 39%，示意）
- [ ] 换成矿粉再鼓风 10 s（约 99%，示意）
- [ ] 算出 1 t FeS₂ 能得到多少 SO₂（1.07 t）

主操作区的按钮：鼓入空气；算产气量。分段选择：块矿 / 矿粉。

## 第 2 课 炉气的净化

出炉的气体要除尘、洗涤、干燥后才能进接触室。

| 项目 | 内容 |
|---|---|
| 知识点 | 炉气里的矿尘、砷和硒的化合物使催化剂中毒，水蒸气对设备和生产有不良影响 |
| 一句概念 | 炉气先净化，催化剂才不中毒 |
| 核心动作 | 换取样点，取样化验 |
| 看到的现象 | 管道里的气流从灰褐色一段段变干净；面板上三类杂质逐个归零 |
| 读数 | 矿尘、砷硒化合物、水蒸气的相对含量（出炉时为 100，示意） |
| 对应小测 | 第 2 题 |

任务清单：在出炉、除尘后、洗涤后、干燥后四处各化验一次。

主操作区的按钮：取样化验。分段选择：四个取样点。

## 第 3 课 接触室里的催化氧化

| 项目 | 内容 |
|---|---|
| 知识点 | 2SO₂ + O₂ ⇌ 2SO₃（催化剂 V₂O₅，加热），放热的可逆反应；催化剂加快反应但不改变平衡 |
| 一句概念 | 催化剂让反应变快，但转化不到 100% |
| 核心动作 | 不装催化剂通气一次，装上再通一次，记下平衡时的转化率 |
| 看到的现象 | 剖开的接触室里四层催化剂；气流从黄色（SO₂）变成青绿色（SO₃）；面板上转化率曲线和正逆速率 |
| 读数 | 450 °C、常压：平衡转化率 97.5%，还剩 2.5% 的 SO₂；不装催化剂时同样时间只有约 6.8%（示意） |
| 对应小测 | 第 3、4 题 |

主操作区的按钮：通入原料气；记录平衡转化率。分段选择：不装催化剂 / 装 V₂O₅。

## 第 4 课 温度的选择

| 项目 | 内容 |
|---|---|
| 知识点 | 正反应放热，温度低平衡转化率高，但速率慢、催化剂活性低；工业上用 400–500 °C |
| 一句概念 | 温度要兼顾速率和平衡 |
| 核心动作 | 依次选 550、400、450 °C，看平衡转化率和出口转化率 |
| 读数 | 常压平衡转化率 550 °C 85.6%、400 °C 99.2%、450 °C 97.5%；出口转化率（示意）85.6%、91.1%、97.3% |
| 对应小测 | 第 5 题 |

主操作区的按钮：记录这一组。分段选择：400 / 450 / 500 / 550 °C。

## 第 5 课 压强和空气用量

| 项目 | 内容 |
|---|---|
| 知识点 | 正反应气体分子数减小，加压有利；但常压下转化率已经很高，加压要耐压设备和更多动力，所以用常压。通入过量空气提高 SO₂ 的转化率 |
| 一句概念 | 常压就够，多给空气更划算 |
| 核心动作 | 常压记一次，10 MPa 记一次；回到常压，把氧气减到恰好够再记一次 |
| 读数 | 450 °C：0.1 MPa 97.5%，10 MPa 99.7%（只多 2.2 个百分点）；O₂ 恰好够（3.5%）时约 89.5%（按平衡常数推算） |
| 对应小测 | 第 6、7 题 |

主操作区的按钮：记录这一组；空气减到恰好够 / 恢复过量空气。分段选择：0.1 / 0.5 / 1 / 10 MPa。

## 第 6 课 吸收和尾气

| 项目 | 内容 |
|---|---|
| 知识点 | SO₃ + H₂O = H₂SO₄；用水吸收会形成酸雾、吸收慢，工业上用 98.3% 的浓硫酸；气体从塔底进、酸从塔顶淋下（逆流），填料增大接触面积；尾气里的 SO₂ 用氨水吸收：SO₂ + 2NH₃·H₂O = (NH₄)₂SO₃ + H₂O |
| 一句概念 | 用浓硫酸吸收 SO₃，尾气要处理 |
| 核心动作 | 用水吸收一次，换浓硫酸再吸收一次，开尾气吸收 |
| 看到的现象 | 剖开的吸收塔：填料层、塔顶淋下的酸、塔底上升的气；用水时塔里一片白雾；烟囱口的黄色尾气在开了尾气吸收后消失 |
| 读数 | 尾气中 SO₂ 约 0.19%（转化率 97.5% 时，按物料衡算），氨水吸收后约 0.01%（示意） |
| 对应小测 | 第 8 题 |

主操作区的按钮：通入 SO₃；开尾气吸收。分段选择：水 / 98.3% 浓硫酸。

## 第 7 课 浓硫酸的性质

化验室里的三个小实验。

| 实验 | 做什么 | 现象 | 数 |
|---|---|---|---|
| 吸水性 | 往胆矾上滴浓硫酸 | 蓝色晶体变白 | 25 g 胆矾失去 9 g 结晶水 |
| 脱水性 | 往蔗糖里加浓硫酸 | 变黑、膨胀成疏松的炭柱，冒白雾 | 34.2 g 蔗糖留下 14.4 g 碳 |
| 强氧化性 | 铜片和浓硫酸共热 | 铜片溶解，品红溶液褪色，试管里稀释后溶液变蓝 | 6.4 g 铜生成 2.24 L SO₂（标准状况） |

一句概念：浓硫酸能吸水、脱水、强氧化。主操作区的按钮：加浓硫酸（铜片那一个是“加热”）。分段选择：三个实验。Cu + 2H₂SO₄(浓) =△= CuSO₄ + SO₂↑ + 2H₂O。对应小测第 9 题。

## 讲解

- 第 1 课要讲清“沸腾”指的是矿粒被气流托起来翻滚，不是液体烧开。
- 第 3 课强调两条曲线最后停在同一个高度以下：催化剂只改变快慢。
- 第 4、5 课读数按“百分之九十七点五”读；压强读“兆帕”。
- 化学式按读法写：SO₂ 读“二氧化硫”，V₂O₅ 读“五氧化二钒”，98.3% 读“百分之九十八点三”。

## 做了哪些简化

- 设备的大小和间距为了镜头好看做了压缩，不是某一座厂的实测尺寸。
- 接触室画成四层催化剂、层间在塔内换热；实际装置的层间换热多在塔外的热交换器里完成。
- 净化工段只画了旋风除尘、电除尘、洗涤塔、干燥塔四台设备。
- 管道里的彩色小球是示意气流方向和成分，不代表分子的真实大小和数量。
- 第 7 课的器材自己动作（滴管提起来滴加、小烧杯抬起来倾倒、酒精灯点着），没有画人手。

## 和规格卡原文的出入

- 骨架里的“示例课”整课换掉。
