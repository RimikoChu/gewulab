# 血液循环实验室 · 规格卡 v0.1

状态：九个课次（1–7、拓展、随堂检测）按这张卡做完（2026-11-23），九课都能自动演示到结论卡，待验收。关联议题 #31。

## 总览

- **一句话**：学生先把一管血静置分层、认出血液的成分，再剖开三种血管和一颗心脏，亲手让心房、心室按顺序收缩，看瓣膜怎样让血只朝一个方向流；然后跟着一团血走完体循环和肺循环，最后推近到肺泡和组织细胞旁边，看氧和二氧化碳在哪里交换、血的颜色在哪里变。
- **教材位置**：生物，初中七年级下册，人教版“人体内物质的运输”一章：流动的组织——血液；血流的管道——血管；输送血液的泵——心脏（含血液循环）。准确的单元号、章号、节名以及 2024 年新版教材是否调整了这一章，见“待核实事项”。
- **主线**：一个人身体里的血。第 1 课从他手臂上采的一管血开始，第 2 课看他手臂里的三种血管，第 3、4 课看他胸腔里的心脏，第 5、6 课看血在他全身和两肺之间走，第 7 课推近到他的肺泡和肌肉，拓展课给他量血压、数脉搏。
- **场景**：议题建议“人体内部的心脏和血管”。这里的做法是：一座科学馆里的人体展厅，正中站着一个半透明的人体（示意），身体里画出心脏、两肺、主要的动脉和静脉、各处的毛细血管网；人体两侧是两张展台（放试管和放大的血管）；肺和肌肉旁边各悬着一个放大的模型（肺泡、组织细胞）。**理由**：第 1 课的试管、第 2 课和第 7 课的放大模型都不是人体真实尺度的东西，放不进“真的人体内部”；放进一座展厅，所有的课仍在同一个连续的世界里，地面、灯光、远近都成立，镜头可以从试管飞到心脏再飞到肺泡。
- **取值约定**：
  - 心率：第 4、5、6 课用 75 次/分（教材讲心动周期用的就是这个心率），一次心跳 0.8 s。拓展课换一位同学，安静时心率 72 次/分。
  - 颜色：**鲜红表示动脉血（含氧多），暗蓝表示静脉血（含氧少）**，全实验室统一，血管按里面流的血上色，不按“动脉、静脉”上色——所以肺动脉是蓝的、肺静脉是红的。
  - 画面里 1 个单位是 10 cm；心脏、血管、细胞的放大模型另有放大倍数，都标“示意”。
- **和同类产品的区别**：同类产品多是一张平面的血液循环图加连线题。这里每一样结构都是学生自己剖开、推近看的；心脏的跳动由学生一步一步按出来，瓣膜开合、血往哪里走都看得见，还能“让血倒流”看它被瓣膜挡住；红细胞是沿着血管走的一颗颗粒子，颜色在毛细血管里慢慢变，学生看得见“在哪里变的”。

课次理由：教材“血液”一节拆成第 1 课；“血管”一节是第 2 课；“心脏”一节内容最多，拆成“结构”和“泵血”两课（一课是认，一课是动），再把节末的“血液循环”拆成体循环、肺循环两课，最后单独做一课“在哪里换了气”（议题点名要的，也是教材这一节最难的地方）。“输血与血型”一节不在这间实验室（以后单做或放进拓展）。脉搏和血压在教材“血管”一节，这里放进拓展课，是因为它们是体检里真实的测量，动作和第 2 课完全不同；随堂检测不考。观察小鱼尾鳍的实验没有做，见“和规格卡原文的出入”。

## 共用的计算核心

| 函数 / 表 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `LAYERS`、`layers(k)` | 静置的进度 k（0–1） | 试管里各层的高度比例：血浆 55%、白细胞和血小板一薄层、红细胞 | 教材：血浆约占 55%；薄层的厚度是示意 |
| `CELLS` | 红细胞 / 白细胞 / 血小板 | 形态、有无细胞核、数量多少、功能 | 教材 |
| `VESSELS`、`speedOf` | 动脉 / 静脉 / 毛细血管 | 管壁、管腔、血流速度、有无瓣膜；画面里粒子的相对速度 | 教材；相对速度是示意 |
| `singleFile` | 毛细血管内径、红细胞直径 | 能并排通过几个红细胞 | 内径 8–10 µm（教材），红细胞直径约 7–8 µm |
| `CHAMBERS` | 四个腔 | 连着的血管、里面的血、壁的厚薄排序 | 教材 |
| `HR`、`period`、`PHASES`、`phaseAt` | 心率、时刻 | 一次心跳的时长；此刻是心房收缩、心室收缩还是全心舒张 | 75 次/分时 0.8 s：心房收缩 0.1 s、心室收缩 0.3 s、全心舒张 0.4 s（教材的心动周期图） |
| `valves` | 时期 | 房室瓣、动脉瓣开还是关 | 教材 |
| `canFlow` | 从哪里到哪里 | 血能不能这样流（只能 静脉→心房→心室→动脉） | 教材 |
| `SYSTEMIC`、`PULMONARY` | — | 两条循环途径的各站名称、起点终点、血在哪里变 | 教材 |
| `bloodAfter` | 流过的地方、原来的血 | 流过肺部毛细血管成动脉血，流过组织处毛细血管成静脉血 | 教材 |
| `bloodMass` | 体重 | 血量的范围（体重的 7%–8%） | 教材“成年人的血量大致相当于本人体重的 7%–8%” |
| `AIR`、`diffuses` | 吸入 / 呼出；两处的氧多少 | 氧和二氧化碳的体积分数；气体从多的一侧扩散到少的一侧 | 教材上一章“人体的呼吸”里的表：吸入氧 21%、二氧化碳 0.03%；呼出氧 16%、二氧化碳 4% |
| `kPa`、`BP_NORMAL`、`bpOk` | mmHg | kPa；在不在正常范围 | 1 mmHg = 133.3 Pa；正常范围：收缩压 12–18.7 kPa，舒张压 8–12 kPa（教材） |
| `beats` | 心率、秒数 | 这段时间里脉搏跳几次 | 脉搏次数和心率相同 |

## 画面上的约定

- **放大**：血细胞、三种血管、肺泡、组织细胞都是放大的模型，毛细血管比动脉、静脉放大得更多；心脏、肺、血管在人体里大致按比例，但红细胞画成一颗颗看得见的粒子，比真的大得多。各课结论卡下面写明。
- **颜色**：动脉血鲜红、静脉血暗蓝（见取值约定）。红细胞粒子流过毛细血管时颜色慢慢变。真实的静脉血是暗红色的，不是蓝色；在第 1 课的原理和第 5 课结论卡下面说明。
- **心脏的剖面**：按教材的四腔示意图摆：右心房在左上、左心房在右上、右心室在左下、左心室在右下（从正面看，左右和身体相反），一个剖面同时切开四个腔。真实心脏的左心房在后面，一个正面的剖面切不全四个腔；这是为了看清楚的简化。
- **心动周期放慢**：第 4 课按一步，一个时期放慢成两三秒走完；“连续跳动”时按真实节拍（0.8 s 一次）。
- **血管的数量**：只画主要的几根动脉和静脉，每处的毛细血管网只画一小片。
- **气体**：氧画成橙色小球，二氧化碳画成灰紫色小球，只表示“往哪里走”，个数不代表多少。
- **人体**是半透明的示意轮廓，不画骨骼和其他器官。第 3、4 课看心脏时，人体和肺淡到几乎看不见，身体里的血管也收起来，只留心脏和连着的几段大血管（剪断的样子）。
- **心脏的模型**：心肌是一整块曲面（四个腔、中间的隔、心室里的肉柱和乳头肌），表面有冠状血管和沟里的脂肪；剖开时前半边往前拿开、淡出。左心室的壁画得最厚，右心室和心房的壁薄。各部分的厚薄和大小是示意，不按真实的毫米数。

## 第 1 课 血液的组成

| 项目 | 内容 |
|---|---|
| 知识点 | 血液由血浆和血细胞组成；血细胞包括红细胞、白细胞、血小板 |
| 一句概念 | 血液由血浆和血细胞组成 |
| 核心动作 | 往血里加抗凝剂静置；逐个认出三种血细胞 |
| 看到的现象 | 一管均匀的红色血液慢慢分成三层：上面淡黄透明的血浆，中间一薄层白色，下面暗红；显微镜视野里，一种细胞突出显示，其余变淡 |

| 真实锚点 | 教材“观察血液的分层现象”、用显微镜观察人血的永久涂片 |

## 第 2 课 三种血管

| 项目 | 内容 |
|---|---|
| 知识点 | 动脉：管壁厚、弹性大、血流快，把血从心脏送到全身；静脉：管壁薄、管腔大、血流慢，四肢静脉里有静脉瓣，把血送回心脏；毛细血管：管壁只有一层上皮细胞、内径很小只允许红细胞单行通过、血流最慢，是物质交换的地方 |
| 一句概念 | 毛细血管最细最薄，血流最慢 |
| 核心动作 | 剖开三段血管；逐段看；让静脉里的血倒流一下 |
| 看到的现象 | 三段血管纵向剖开一半，看得见管壁的厚薄和管腔的大小；红细胞在动脉里随心跳一冲一冲地快走，在静脉里慢慢走，在毛细血管里一个接一个地挤过去；倒流时静脉瓣合上，血走不回去 |
| 读数 | 管壁、管腔、血流速度、血流方向；毛细血管内径和并排几个红细胞 |
| 真实锚点 | 手背上鼓起的“青筋”是静脉；捆扎上臂后，手臂上鼓起的一个个小“结”就是静脉瓣的位置 |
| 对应小测 | 2 |

任务清单

- [ ] 剖开三段血管
- [ ] 看动脉：管壁厚，血流快
- [ ] 看静脉：管壁薄，管腔大，里面有瓣膜
- [ ] 让静脉里的血倒流一下，看静脉瓣
- [ ] 看毛细血管：红细胞单行通过

主操作区的按钮：剖开血管、让血倒流（只在看静脉时可按）。分段选择：动脉 / 静脉 / 毛细血管。

## 第 3 课 心脏的结构

| 项目 | 内容 |
|---|---|
| 知识点 | 心脏主要由心肌构成，有四个腔：左心房、左心室、右心房、右心室；左右不相通，同侧上下相通；心房连静脉、心室连动脉；左心室壁最厚；心房与心室之间有房室瓣，心室与动脉之间有动脉瓣 |
| 一句概念 | 心脏有四个腔，心房连静脉，心室连动脉 |
| 核心动作 | 剖开心脏；逐个认四个腔和连着的血管；找两种瓣膜 |
| 看到的现象 | 一颗有冠状血管、表面湿润的心脏；剖开时前半边移开淡出，露出四个腔和中间的隔；认到哪一个腔，哪一个腔和连着的血管亮起来；左心室的壁明显最厚 |
| 读数 | 正在看的腔、连着的血管、里面流的血 |
| 真实锚点 | 心脏在胸腔中部偏左，大小和本人的拳头差不多 |
| 对应小测 | 3 |

任务清单

- [ ] 剖开心脏，数一数有几个腔
- [ ] 逐个认出四个腔和连着的血管
- [ ] 找出壁最厚的那个腔
- [ ] 找出房室瓣和动脉瓣

主操作区的按钮：剖开心脏、看下一个腔、看瓣膜。没有分段选择。认腔的顺序：右心房 → 右心室 → 左心房 → 左心室（最后一个就是壁最厚的）。

| 右心室 | 肺动脉 | 静脉血 | 教材 |
| 左心房 | 肺静脉 | 动脉血 | 教材 |
| 左心室 | 主动脉 | 动脉血 | 教材；壁最厚，因为要把血送到全身 |

## 第 4 课 心脏怎样泵血

| 项目 | 内容 |
|---|---|
| 知识点 | 心房收缩，血被压进心室；心室收缩，房室瓣关闭、动脉瓣打开，血射进动脉；全心舒张，静脉里的血流回心房、心室；瓣膜只能朝一个方向开，血只能 心房→心室→动脉 |
| 一句概念 | 瓣膜让血只能朝一个方向流 |
| 核心动作 | 按“下一步”依次做三个时期；按“让血倒流”；按“连续跳动” |
| 看到的现象 | 剖开的心脏在动：哪一部分收缩，哪一部分就缩小；红细胞从静脉进心房、穿过房室瓣进心室、穿过动脉瓣进动脉；倒流时红细胞堆在关着的瓣膜前面过不去 |
| 读数 | 现在是哪个时期；房室瓣、动脉瓣开还是关；一次心跳的时长和各时期的时长 |
| 真实锚点 | 心率 75 次/分时，一次心跳 0.8 s |
| 对应小测 | 4 |

任务清单

- [ ] 让心房收缩：血从心房进心室
- [ ] 让心室收缩：房室瓣关，动脉瓣开，血射进动脉
- [ ] 全心舒张：血从静脉流回心房
- [ ] 让血倒流一下：瓣膜关着，流不回去
- [ ] 让心脏连续跳动，读出一次心跳用多长时间

主操作区的按钮：下一步（按钮上写着下一个时期的名字）、让血倒流、连续跳动。没有分段选择。

数据

| 条件 | 读数 | 来历 |
|---|---|---|
| 心率 75 次/分 | 一次心跳 0.8 s：心房收缩 0.1 s，心室收缩 0.3 s，全心舒张 0.4 s | 教材；0.8 = 60 ÷ 75 |
| 心房收缩 | 房室瓣开、动脉瓣关 | 教材 |
| 心室收缩 | 房室瓣关、动脉瓣开 | 教材 |
| 全心舒张 | 房室瓣开、动脉瓣关 | 教材 |

## 第 5 课 体循环

| 项目 | 内容 |
|---|---|
| 知识点 | 体循环的途径；在组织处毛细血管，动脉血变成静脉血 |
| 一句概念 | 体循环把动脉血送到全身，换回静脉血 |
| 核心动作 | 从左心室送出一团血跟着走；换去头部再送一次；让全身的血流起来 |
| 看到的现象 | 镜头看着整个人；一团亮红的红细胞从左心室出发，沿主动脉走到下肢，在下肢的毛细血管网里慢慢变成暗蓝，沿静脉回到右心房；走过的路线留下一条淡淡的轨迹；最后全身的血一起流 |
| 读数 | 这团血此刻在哪一站、是动脉血还是静脉血；全身的血量 |
| 真实锚点 | 体重 60 kg 的人，血量约 4.2–4.8 kg |
| 对应小测 | 5 |

任务清单

- [ ] 从左心室送出一团血，看它走到哪里
- [ ] 看它在哪里由动脉血变成静脉血
- [ ] 看它从哪里回到心脏
- [ ] 换成去头部，再送一次
- [ ] 让全身的血流起来

主操作区的按钮：送出一团血、全身流动。分段选择：去下肢 / 去头部 / 去上肢 / 去腹部（任务里要用到的是下肢和头部）。

数据

| 条件 | 读数 | 来历 |
|---|---|---|
| 体循环途径 | 左心室 → 主动脉 → 各级动脉 → 全身各处毛细血管 → 各级静脉 → 上、下腔静脉 → 右心房 | 教材 |
| 去下肢、腹部 | 经下腔静脉回右心房；去头部、上肢：经上腔静脉回右心房 | 教材 |
| 体重 60 kg | 血量 4.2–4.8 kg | 60 × 7% = 4.2，60 × 8% = 4.8；体重 60 kg 是示意 |

## 第 6 课 肺循环

| 项目 | 内容 |
|---|---|
| 知识点 | 肺循环的途径；在肺部毛细血管，静脉血变成动脉血；肺动脉里流的是静脉血，肺静脉里流的是动脉血；体循环和肺循环同时进行，在心脏处连在一起 |
| 一句概念 | 肺循环把静脉血送到肺，换成动脉血 |
| 核心动作 | 从右心室送出一团血跟着走；点选肺动脉和肺静脉看里面的血；两条循环一起看 |
| 看到的现象 | 镜头看着胸腔，两叶肺半透明；一团暗蓝的血从右心室出发进肺动脉，分到两肺，在肺泡外的毛细血管里变成鲜红，经肺静脉回左心房 |
| 读数 | 这团血此刻在哪一站、是什么血；选中的血管叫什么、里面是什么血 |
| 真实锚点 | 肺动脉是全身唯一流着静脉血的动脉 |
| 对应小测 | 6、8 |

任务清单

- [ ] 从右心室送出一团血，看它走到哪里
- [ ] 看它在哪里由静脉血变成动脉血
- [ ] 看它回到心脏的哪个腔
- [ ] 看肺动脉和肺静脉里各流着什么血
- [ ] 让两条循环一起流

主操作区的按钮：送出一团血、两条循环一起。分段选择：看肺动脉 / 看肺静脉。

## 第 7 课 在哪里换了气

| 项目 | 内容 |
|---|---|
| 知识点 | 肺泡与血液的气体交换：肺泡里的氧扩散进血液，血液里的二氧化碳扩散进肺泡，静脉血变动脉血；组织里的气体交换：血液里的氧扩散进组织细胞，细胞产生的二氧化碳扩散进血液，动脉血变静脉血；气体从浓度高的地方扩散到浓度低的地方 |
| 一句概念 | 气体总是从多的地方扩散到少的地方 |
| 核心动作 | 让血流过肺泡；换到组织处再让血流过；对比吸入和呼出的气体 |
| 看到的现象 | 放大的肺泡外缠着毛细血管，血从一头流进来是蓝的、从另一头流出去是红的；橙色的氧球从肺泡穿过两层薄壁进血管，灰紫色的二氧化碳球反过来走；组织处正好相反 |
| 读数 | 此处的氧、二氧化碳各从哪里到哪里；血由什么血变成什么血；吸入和呼出气体里氧、二氧化碳的体积分数 |
| 真实锚点 | 呼出的气体里氧变少（21% → 16%）、二氧化碳变多（0.03% → 4%） |
| 对应小测 | 7 |

任务清单

- [ ] 在肺泡处让血流过，看氧和二氧化碳往哪里走
- [ ] 换到组织处，再让血流过
- [ ] 对比吸入和呼出的气体

主操作区的按钮：让血流过、对比吸入和呼出的气体。分段选择：肺泡处 / 组织处（换了镜头飞到那个模型）。

数据

| 条件 | 读数 | 来历 |
|---|---|---|
| 吸入的气体 | 氧 21%，二氧化碳 0.03% | 教材“人体的呼吸”一章的表 |
| 呼出的气体 | 氧 16%，二氧化碳 4% | 同上 |
| 肺泡处 | 肺泡里氧多 → 血液；血液里二氧化碳多 → 肺泡；静脉血 → 动脉血 | 教材 |
| 组织处 | 血液里氧多 → 细胞；细胞里二氧化碳多 → 血液；动脉血 → 静脉血 | 教材 |

## 拓展课

| 课 | 名称 | 一句话 | 学生的核心动作 | 在场景里的位置 |

| 拓展 1 | 量血压 | 血压计读出收缩压和舒张压，换成 kPa 和正常范围比一比 | 绑好袖带测一次；换成 kPa | 人体左臂和血压计 |
| 拓展 2 | 数脉搏 | 按住手腕上的桡动脉数 15 秒，乘以 4 就是每分钟的脉搏，和心率一样 | 开始数 | 人体左手腕 |

## 和规格卡原文的出入

- 议题建议的场景“人体内部”改成“科学馆里的人体展厅”，理由见总览。
- “观察小鱼尾鳍内血液的流动”没有做成拓展课，拓展课做的是血压和脉搏；小鱼尾鳍里“从主干流向分支的是动脉、单行通过的是毛细血管”这个判断方法，放进了第 2 课的原理里。以后可以加一个拓展小实验。
- 第 7 课的组织模型原定放在左腿旁边，做的时候和右边的血管展台、血压计小桌挤在一起，改放到右腿旁边（画面左下）。
- 第 5 课“去哪里”的分段选择有四项（下肢、头部、上肢、腹部），任务只要求下肢和头部，另两项可以自己试。
- 一团血走一趟的时间：体循环 6–9 s，肺循环 7 s（按路程长短放慢，示意）。
- 拓展课主操作区的按钮随分段选择换：量血压时是“测血压”“换成 kPa”，数脉搏时是“开始数”。
