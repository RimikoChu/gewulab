# 压强实验室 · 规格卡 v0.1

状态：九个课次（1–7、拓展、随堂检测）全部做完，都在同一座水电站大场景里（2026-11-18），待验收。

## 总览

- **一句话**：学生亲手比出“压力的效果看什么”，把探头伸进水里量出液体压强的规律，再弄懂大坝为什么上窄下宽、船怎样翻过大坝、空气为什么也会压人。
- **教材位置**：人教版物理八年级下册 第九章《压强》，四节：压强、液体的压强、大气压强、流体压强与流速的关系。
- **主线**：一座水电站。大坝挡住的水越深，压强越大；船靠连通器翻过大坝；坝顶的观测站量大气压。
- **场景**：整个实验室是**一座连续的水电站**，所有的课都在这一个大场景里，各占一处。换课时画布不重建，镜头在场景里飞到另一处（2026-11-18 定，参考同类产品“一个大场景里放多个实验站”的做法）。浮力实验室是每课各搭一套环境、换课等于换页，压强不再这样做。
- **大场景的布局**（从左到右，整个世界朝镜头剖开）：下游河道和发电厂房 → 大坝（高 110 m，坝顶有第 6 课的观测桌）→ 水库（坝前深 100 m，往岸边变浅到 6 m）→ 挡墙和泥浆井（第 3 课）→ 岸上的工地：软土路（第 2 课）、沙地（第 1 课）→ 风洞试验棚（第 7 课）→ 引水渠上的小船闸（第 5 课）。第 4 课站远了看整座大坝。远处一座雪山，山顶有一块平台（第 6 课“带到山顶”）。
- **和浮力实验室的衔接**：浮力第 2 课“上下表面的压力差”直接用到这一章的液体压强。两个实验室连着用，覆盖八年级下册第九、十两章。
- **取值约定**：g 取 9.8 N/kg；水的密度 1.0×10³ kg/m³；标准大气压 1.013×10⁵ Pa（760 mm 水银柱）；水银密度 13.6×10³ kg/m³。

## 操作和质感的要求（浮力验收后新增）

浮力实验室验收时，课程编排 85 分，3D 和交互 75 分，扣在质感和按钮太多。压强实验室按下面的要求做。

**操作**

- 主操作区最多三个按钮，而且都是一步到位的（例如“放到 5 m”“记录数据”）。不放“一步一步升降”这类微调按钮。
- 微调靠直接拖：拖探头、拖水位、拖玻璃管、点阀门。能拖的东西第一次出现时有“可以拖”的提示。
- 换条件的开关（换液体、换车）每课最多一组。
- 提示语和主按钮闪动保留，和浮力一样。

**质感**

- 主要器材的模型要有倒角、接缝、螺栓这类细节，不能只是方块和圆柱。
- 混凝土、钢、沙、土用实拍的材质贴图（Poly Haven，CC0）。
- 水要有折射感，物体入水有水花，水位变化有流动的过程。
- 这些先在第 3 课样板上做出来，确认达标后再铺到其余课。

## 共用的计算核心

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| 固体压强 | 压力 F、受力面积 S | p = F/S | 压强的定义 |
| 液体压强 | 液体密度 ρ、深度 h | p = ρgh | 液体压强公式 |
| 连通器水位 | 各段的水量、底面积、阀门开关 | 各段水位随时间的变化；阀门打开的两段最终相平 | 连通器原理 |
| 水银柱高度 | 大气压 p₀ | h = p₀ /(ρ水银 g) | 托里拆利实验 |
| 气压随高度 | 海拔 | 大气压（查表插值） | 待核实数据来源 |

## 第 1 课 压出来的坑

同一块混凝土，换个放法，沙地上的坑深浅不一样。

| 项目 | 内容 |
|---|---|
| 知识点 | 压力的作用效果和压力大小有关，和受力面积有关 |
| 一句概念 | 压得多重、压在多大一块地方，都算数 |
| 核心动作 | 拖着混凝土块转到平放、侧放、立放，放到沙地上；再叠一块上去 |
| 看到的现象 | 沙地陷下去，坑的深浅不同；坑边有一把标尺 |
| 读数 | 压力 F、受力面积 S、坑深 |
| 器材 | 混凝土预制块 2 m × 1 m × 0.5 m，重 23.52 kN |
| 真实锚点 | 书包带做宽了不勒肩；刀磨薄了才好切 |
| 对应小测 | 两种放法，哪个效果更明显，为什么 |

任务清单

- [ ] 把混凝土块平放在沙地上，记下坑深
- [ ] 换成立放：压力没变，面积小了，坑更深
- [ ] 平放再叠一块：面积没变，压力大了，坑也更深

数据：平放 S = 2 m²；侧放 1 m²；立放 0.5 m²。

## 第 2 课 压强

把“压力的效果”变成一个能算的数。

| 项目 | 内容 |
|---|---|
| 知识点 | 压强 p = F/S，单位 Pa；增大、减小压强的办法 |
| 一句概念 | 每一平方米上压着多大的力 |
| 核心动作 | 先猜：20 吨的挖掘机和 20 吨的卡车，谁会陷进软土；再让它们开上去 |
| 看到的现象 | 卡车的轮子陷进去，挖掘机的履带几乎不陷 |
| 读数 | F、S、p |
| 真实锚点 | 坦克用履带；图钉尖很尖、钉帽很宽 |
| 对应小测 | 给出质量和接触面积，算压强 |

数据

| 对象 | 压力 | 接触面积 | 压强 |
|---|---|---|---|
| 履带挖掘机 20 吨 | 196 kN | 4.2 m² | 46.7 kPa |
| 轮式卡车 20 吨 | 196 kN | 0.3 m² | 653 kPa |
| 第 1 课的混凝土块（平放 / 立放） | 23.52 kN | 2 m² / 0.5 m² | 11.76 kPa / 47.04 kPa |

任务清单

- [ ] 猜一猜谁会陷进去，再让两辆车开上软土
- [ ] 算出两辆车的压强，差了多少倍
- [ ] 给卡车垫上钢板再开一次：面积大了，不陷了

## 第 3 课 水里的压强（样板课）

学生抓着一只压力探头伸进水库，自己找出液体压强的四条规律。

| 项目 | 内容 |
|---|---|
| 知识点 | 液体内部向各个方向都有压强；同一深度各方向相等；深度越大压强越大；深度相同时液体密度越大压强越大 |
| 一句概念 | 越深，压得越厉害 |
| 核心动作 | 抓住探头上下拖改深度；点一下探头换朝向（朝上、朝侧面、朝下）；把探头换到旁边的泥浆井 |
| 看到的现象 | 探头的壳是透明的，能看到橙色橡皮膜凹进去，越深凹得越多；岸上读数箱的数跟着变；探头入水溅起水珠，移动时冒气泡 |
| 读数 | 深度 h、压强 p、探头朝向 |
| 地点 | 水库岸边，水和岸都朝镜头剖开；水深 6 m，水里立着一根水尺；挡墙另一侧是一口泥浆井（1.2×10³ kg/m³），岸上的小吊臂能转过去 |
| 真实锚点 | 潜水越深耳朵越疼；深海鱼捞上来会胀破 |
| 对应小测 | 同一深度换方向，读数变不变 |

任务清单（控制变量，和浮力第 3 课同一种做法）

- [ ] 探头放到 2.5 m，三个朝向各记一次：读数都是 24.5 kPa
- [ ] 放到更深（至少深 1 m）再记一次：5 m 处 49.0 kPa
- [ ] 换到泥浆井，放到和水库里一样的深度：5 m 处 58.8 kPa（2.5 m 处 29.4 kPa）

主操作区三个按钮：放到 2.5 m、放到 5 m、记录数据；另有一组开关选水库或泥浆井。其余全靠拖和点探头。键盘 ↑↓ 升降、←→ 换朝向、空格记录。

实现说明：代码在 `src/labs/pressure/`（`physics.ts`、`lesson3.tsx`、`scene3.tsx`），入口 `/labs/pressure/index.html`。舞台、吊机控制暂时直接用浮力实验室的 `float/dock.tsx` 和 `float/use-crane.ts`。深度比原计划的 5 m、10 m 减半，是为了让探头在画面里足够大。材质里只有混凝土是实拍贴图，土层、水尺、水底光斑是程序画的。

## 第 4 课 大坝为什么上窄下宽

把上一课的规律用到大坝上。

| 项目 | 内容 |
|---|---|
| 知识点 | p = ρgh；液体压强只和密度、深度有关，和水有多少无关 |
| 一句概念 | 水越深的地方，坝要越厚 |
| 核心动作 | 上下拖水库的水位；在坝面上点一个位置看那里的压强 |
| 看到的现象 | 坝面上一排箭头，越往下越长；水位升高，所有箭头一起变长 |
| 读数 | 水深 h、坝底压强 p |
| 真实锚点 | 三峡大坝的蓄水位和坝高（数据待核实） |
| 对应小测 | 水库变宽一倍，坝底压强变不变 |

任务清单

- [ ] 把水位拖到 50 m：坝底 490 kPa
- [ ] 拖到 100 m：坝底 980 kPa，翻了一倍
- [ ] 把水库换成窄的：同样 100 m 深，坝底还是 980 kPa

## 第 5 课 船怎样翻过大坝

学生自己当船闸的操作员。

| 项目 | 内容 |
|---|---|
| 知识点 | 连通器：上端开口、底部连通，液体不流动时各部分液面相平；船闸 |
| 一句概念 | 底下连通了，水面就会一样高 |
| 核心动作 | 直接点阀门和闸门：开下游阀门 → 开下游闸门 → 船进闸室 → 关门 → 开上游阀门 → 开上游闸门 |
| 看到的现象 | 阀门一开，闸室和那一侧的水面慢慢相平；闸门只有两边水面相平时才开得动 |
| 读数 | 上游、闸室、下游三处的水位 |
| 真实锚点 | 三峡船闸（级数待核实）；茶壶、锅炉水位计 |
| 对应小测 | 下面哪个不是连通器 |

任务清单

- [ ] 让闸室的水面和下游相平，把船放进闸室
- [ ] 让闸室的水面和上游相平，把船送到上游
- [ ] 两边水面不平时去开闸门：开不动，看提示说为什么

顺序点错时不报错，只是闸门打不开并给一句提示。

## 第 6 课 空气也在压

| 项目 | 内容 |
|---|---|
| 知识点 | 大气压强的存在；托里拆利实验；标准大气压；大气压随高度降低 |
| 一句概念 | 我们头顶上压着一整片空气 |
| 核心动作 | 把装满水银的玻璃管倒插进水银槽；拖着管子倾斜；换粗管；把整套器材带到山顶 |
| 看到的现象 | 水银柱停在 760 mm；管子倾斜、变粗，竖直高度都不变；到了山顶，水银柱变矮 |
| 读数 | 水银柱的竖直高度、对应的大气压 |
| 地点 | 坝顶观测站的桌面特写；“山顶”是另一个机位 |
| 真实锚点 | 覆杯实验；吸盘；用吸管喝饮料 |
| 对应小测 | 管子倾斜后，水银柱的长度和高度各怎么变 |

任务清单

- [ ] 做一次托里拆利实验，读出 760 mm
- [ ] 把管子倾斜：长度变长，竖直高度还是 760 mm
- [ ] 带到山顶再做一次：水银柱变矮

换算：760 mm 水银柱 = 1.013×10⁵ Pa；换成水要 10.3 m 高。

## 第 7 课 流得快，压得轻

| 项目 | 内容 |
|---|---|
| 知识点 | 在气体和液体中，流速越大的位置压强越小；飞机的升力 |
| 一句概念 | 流得快的那一边，压强小 |
| 核心动作 | 拖风速；拖机翼的角度；先做“往两张纸中间吹气” |
| 看到的现象 | 两张纸向中间靠拢；机翼上方的气流线更密更快，上下表面各一只压力表，读数不一样 |
| 读数 | 上表面、下表面的压强，压强差 |
| 真实锚点 | 站台上的安全线；两艘船不能并排靠得太近 |
| 对应小测 | 火车进站时，人为什么要站在安全线外 |

任务清单

- [ ] 往两张纸中间吹气：纸向中间靠
- [ ] 打开风洞：机翼上表面的压强比下表面小
- [ ] 把风速调大：压强差变大，机翼被托起来

说明：课本只要求定性结论。压力表的读数用简化模型算，界面上不出现课本以外的公式。

| 课 | 名称 | 一句话 | 学生的核心动作 | 地点 |

| 拓展 1 | 马德堡半球 | 两个抽空的铜半球，几匹马都拉不开 | 抽气，再加马，看要多大的力 | 广场 |

## 随堂检测

九道选择题，每课一道易错题，加两道综合题。答错可以一键回到对应那一课。

| 题 | 题目要点 | 对应课 | 考查的易错点 |
|---|---|---|---|
| 1 | 同一块砖三种放法，对地面压强最大的是哪种 | 1 | 压力不变时看面积 |
| 2 | 给出质量和接触面积，算压强 | 2 | 压力等于重力、面积要用总接触面积 |
| 3 | 同一深度换方向，压强计读数 | 3 | 各方向相等 |
| 4 | 三个形状不同、水深相同的容器，底部压强谁大 | 4 | 只看深度，不看水的多少 |
| 5 | 下面哪个不是连通器 | 5 | 上端开口、底部连通 |
| 6 | 托里拆利实验中把管子倾斜 | 6 | 高度不变、长度变长 |
| 7 | 火车站台的安全线 | 7 | 流速大压强小 |
| 8 | 综合：潜水员在 20 m 深处受到水的压强 | 3、4 | p = ρgh 的计算 |
| 9 | 综合：增大或减小压强的实例分类 | 1、2 | 改压力还是改面积 |

和规格卡原文的出入：

- 第 2 课没有“先猜”的单独一步，只在提示语里问一句。
- 第 4 课“在坝面上点一个位置看压强”没做，改成坝面上每 10 m 一个箭头，并标出半深处的压强。
- 第 5 课的船闸不在大坝上，是岸上一段引水渠上的小船闸（落差 4 m）；真实的大坝船闸落差大得多，要分好几级。
- 第 7 课没有“拖机翼的角度”，只调风速；两张纸改成头顶一根吹风管往下吹。压强读数用简化模型算，只用来比大小。
- 拓展 2 原计划“下潜七千米”，改成在大坝脚下潜到 100 m（留在同一个场景里），七千米的数据写在“看原理”里。
- 拓展 1 的半球半径取 0.2 m，是我们自己定的器材，不是历史上那一对的尺寸；“两边各八匹马”写在“看原理”里。
- 拓展 3 的沸点是约数：约 70 kPa 时 90 ℃，约 200 kPa 时 120 ℃。
