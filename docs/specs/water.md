# 水的净化和组成实验室 · 规格卡 v0.1

状态：九个课次（1–7、拓展、随堂检测）做完（2026-11-23），每课自动演示带讲解能走到结论条，待验收。关联议题 #17。

## 总览

- **一句话**：学生在一座自来水厂里，从河边取一杯河水开始，在厂里的化验室用烧杯、漏斗、活性炭一步步把浑水变清，再沿着厂区走一遍真正的净水流程；最后用肥皂水分出硬水和软水、蒸馏得到纯水，用霍夫曼水电解器把水分解，弄清水由氢、氧两种元素组成。
- **教材位置**：化学，初中。人教版九年级上册“自然界的水”单元（水的净化、硬水和软水、水的组成）。准确的单元号、课题名见“待核实事项”。
- **主线**：一杯河水。第 1 课取来，第 2–4 课在化验室里沉淀、过滤、吸附，第 5 课看水厂怎么把同样的事做大，第 6 课再往下净化到纯水，第 7 课把纯水分解。
- **场景**：自来水厂（议题建议的场景，保留）。理由：水厂本身就有取水口（第 1 课取河水的地方）、絮凝沉淀池、滤池、活性炭池、加氯间、清水池、送水泵房，第 5 课能沿着真实的流程走一遍；水厂都有化验室，台上本来就是烧杯、漏斗、浊度仪、蒸馏装置，第 2–4、6、7 课的实验放在这里是真有其事。
- **取值约定**：场景里 1 m 画成 6 个单位（`M = 6`），化验台台面高 85 cm。浊度单位 NTU，保留整数（小于 10 时保留一位小数）。气体体积用 mL，保留一位小数。电解时的气体摩尔体积取 24.5 L/mol（约 25 °C、一个大气压），法拉第常数 96485 C/mol。
- **和同类产品的区别**：浑水的颜色、透明度、杯底泥沙的厚度全由一个浊度值推出来，沉淀、过滤、吸附每一步都能在浊度仪上读到它下降；明矾的矾花是一颗颗聚起来再沉下去的；过滤时“一贴二低三靠”就标在正在倒的那一套器材上；霍夫曼电解器两边的气柱按电流和时间算，液面一格一格下降，中间的储液球里液面跟着升高。

课次理由：教材先讲水的净化（沉淀、过滤、吸附、蒸馏，以及自来水厂的净水过程、硬水和软水），再讲水的组成（电解水），顺序一致。“纯净物和混合物”是前一单元的内容，放在第 1 课当引子，用河水和蒸馏水各判断一次。教材里自来水厂的流程是一张图，这里把它做成第 5 课，放在化验室的三步之后，学生先自己做过，再看水厂怎么做大。

## 共用的计算核心

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `murk` | 浊度（NTU） | 浑浊程度 0–1（画面的颜色和透明度由它推） | 按浊度的对数映射，示意 |
| `settle` | 加不加明矾、静置了几秒 | 上层水的浊度、杯底泥沙的厚度 | 指数衰减的简化模型，示意（见“画面上的约定”） |
| `filtered` | 进来的浊度、滤纸完好还是破了 | 滤液的浊度 | 简化模型，示意 |
| `colorLeft` | 加不加活性炭 | 滤液颜色还剩原来的几成 | 简化模型，示意 |
| `PLANT`、`stationTurb` | 水厂的第几站 | 那一站出水的浊度 | 示意；出厂水的限值取国家标准 1 NTU |
| `foam` | 水的硬度 | 泡沫多少、浮渣多少 | 示意：硬度越高泡沫越少、浮渣越多 |
| `gas` | 电流、通电时间 | 负极氢气、正极氧气的体积（mL） | 法拉第定律：n(H₂) = I·t / (2F)，V = n·Vm；氧气是氢气的一半 |
| `drip` | 每秒滴几滴、一滴多少 | 一天、一年漏掉多少水 | 计算；一滴按 0.05 mL 估 |
| `isPure` | 哪种水 | 纯净物还是混合物 | 定义 |

## 第 1 课 天然水里有什么

| 项目 | 内容 |
|---|---|
| 知识点 | 天然水是混合物：泥沙等不溶性杂质、可溶性杂质、细菌等微生物；蒸馏水是纯净物 |
| 一句概念 | 河水里溶着、混着很多东西，是混合物 |
| 核心动作 | 用取样桶从河里打水，倒进烧杯；静置；判断 |
| 看到的现象 | 烧杯里的河水黄浊；静置后杯底沉下一层泥沙，上面的水仍不透明 |
| 读数 | 浊度 约 60 NTU（示意） |
| 真实锚点 | 水厂每天要从取水口取样化验原水 |
| 对应小测 | 第 1 题 |

任务：取一杯河水 → 静置，看杯底 → 判断河水是什么 → 判断蒸馏水是什么。

主操作区：取一杯河水、静置、拿一瓶蒸馏水。分段选择：这杯水是“纯净物 / 混合物”。选错时提示为什么。

## 第 2 课 沉淀

| 项目 | 内容 |
|---|---|
| 知识点 | 静置沉淀能让较大的颗粒沉下去；明矾溶于水生成的胶状物吸附悬浮杂质，使其沉降 |
| 一句概念 | 加明矾，细小的杂质聚成矾花沉下去 |
| 核心动作 | 往右边那杯加明矾、搅拌；两杯一起静置；测浊度 |
| 看到的现象 | 左杯只沉下一点泥，上面仍然浑；右杯里一团团矾花聚起来往下沉，上层变清 |
| 读数 | 左杯约 25 NTU，右杯约 6 NTU（示意） |
| 对应小测 | 第 2 题 |

任务：往右杯加明矾，搅拌 → 两杯静置 → 测两杯的浊度。

## 第 3 课 过滤（样板课）

| 项目 | 内容 |
|---|---|
| 知识点 | 过滤把不溶于水的固体和液体分开；一贴二低三靠；滤纸破损、液面高于滤纸边缘，滤液会浑浊 |
| 一句概念 | 过滤除去不溶性杂质 |
| 核心动作 | 折滤纸放进漏斗；沿玻璃棒倒入静置后的河水；测滤液浊度；换一张破了的滤纸再滤 |
| 看到的现象 | 滤纸对折两次、打开成锥形贴在漏斗里；滤液沿着烧杯内壁流下，清了；滤纸破了，浑水直接漏下去 |
| 读数 | 进来的水约 25 NTU；滤液约 2 NTU（完好）/ 约 21 NTU（破了）（示意） |
| 对应小测 | 第 3 题 |

“一贴二低三靠”以标签标在器材上：滤纸紧贴漏斗内壁；滤纸边缘低于漏斗口、液面低于滤纸边缘；烧杯口靠玻璃棒、玻璃棒靠三层滤纸一边、漏斗下端靠烧杯内壁。

## 第 4 课 吸附

| 项目 | 内容 |
|---|---|
| 知识点 | 活性炭疏松多孔，能吸附色素和异味；过滤只能除去不溶性杂质 |
| 一句概念 | 活性炭能吸附水里的色素和异味 |
| 核心动作 | 把滴了红墨水的水直接过滤；再往水里加活性炭搅拌后过滤 |
| 读数 | 颜色还剩原来的 100%（直接过滤）/ 约 5%（加活性炭）（示意） |
| 对应小测 | 第 4 题 |

## 第 5 课 自来水厂

| 项目 | 内容 |
|---|---|
| 知识点 | 自来水厂的净水过程：取水、加絮凝剂、沉淀、过滤、活性炭吸附、投药消毒、配水；消毒是化学变化，其余是物理变化 |
| 一句概念 | 水厂一步步把河水变成自来水 |
| 核心动作 | 按“去下一站”沿着厂区走；在加氯间投加消毒剂 |
| 读数 | 各站出水的浊度（示意）；出厂水的浊度限值 1 NTU |
| 对应小测 | 第 5 题 |

各站：取水泵房 → 絮凝沉淀池（剖开，能看到矾花和池底的泥）→ 滤池（剖开，砂层和承托层）→ 活性炭池 → 加氯间 → 清水池（剖开）→ 送水泵房。

## 第 6 课 硬水和软水

| 项目 | 内容 |
|---|---|
| 知识点 | 含有较多可溶性钙、镁化合物的水叫硬水；用肥皂水区分（泡沫少、浮渣多的是硬水）；生活中煮沸降低硬度，实验室用蒸馏；蒸馏得到的水是纯净物 |
| 一句概念 | 肥皂水分硬软，煮沸、蒸馏能软化 |
| 核心动作 | 两支试管（井水、蒸馏水）加肥皂水振荡；把井水煮沸再试；蒸馏井水再试 |
| 看到的现象 | 井水泡沫少、浮渣多；蒸馏水泡沫多；煮过的井水杯底有水垢，泡沫变多；蒸馏时温度计读 100 °C，冷凝管下端一滴滴流出水 |
| 读数 | 温度计 100 °C（一个大气压下水的沸点）；泡沫高度（示意） |
| 对应小测 | 第 6、7 题 |

## 第 7 课 水的组成

| 项目 | 内容 |
|---|---|
| 知识点 | 电解水：正极得到氧气、负极得到氢气，体积比约 1∶2；氧气使带火星的木条复燃，氢气燃烧产生淡蓝色火焰；水由氢元素和氧元素组成 |
| 一句概念 | 水由氢、氧两种元素组成 |
| 核心动作 | 接通电源，收集气体；检验正极、负极的气体 |
| 读数 | 电流 1.0 A；正极 10.0 mL、负极 20.0 mL；实际要通电约 2.6 min |
| 真实锚点 | 霍夫曼水电解器是化验室和学校实验室常用的仪器 |
| 对应小测 | 第 8 题 |

气体体积：n(H₂) = I·t / (2F)，V(H₂) = n·Vm；1.0 A 通电 157.5 s 得 20.0 mL 氢气。画面加快 15 倍（界面写“过程加快”）。

- 第 5 课：加氯间放在活性炭池和清水池之间（原来画在清水池后面，镜头飞过去会被清水池挡住），清水池和送水泵房往东挪了。

- 第 4 课：没有分段选择，两个按钮（过滤；换一杯、加活性炭搅拌），顺序做下来。

- 第 1 课：折叠桌放到取样平台上（原来在岸上），镜头站在平台上，河面在桌子周围和前方。
