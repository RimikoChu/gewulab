# 水溶液里的离子平衡实验室 · 规格卡 v1.0

状态：待审。关联议题 #70。

## 总览

- 一句话：在城市水质检测中心的实验大厅里，用导电性装置、pH 计、电位滴定仪和离心机，看清水溶液里的离子：谁完全电离、谁部分电离，水自己也电离，盐会水解，沉淀也有溶解平衡。
- 教材位置：人教版高中化学选择性必修 1《化学反应原理》第三章“水溶液中的离子反应与平衡”（第一节 电离平衡；第二节 水的电离和溶液的 pH；第三节 盐类的水解；第四节 沉淀溶解平衡）。节名和实验编号见“待核实事项”。
- 主线：河里取来的水样要做检测。先用两杯酸弄清强弱电解质和电离平衡，再测水和溶液的 pH，用标准溶液做一次中和滴定，最后看盐的水解和沉淀的转化。
- 场景：城市水质检测中心的实验大厅。**大场景的布局**（自西向东，画面单位 1 m = 6）：
  - 大厅（x −170 到 4）靠后墙一条长实验台，后墙台面以上是一排大玻璃窗；窗外是河道和对岸的自来水厂（沉淀池、清水池、厂房），远处是城市楼群。
  - 实验台从西往东依次是：导电性实验装置（第 1 课）、醋酸电离平衡的 pH 计和恒温水浴（第 2 课）、纯水的 pH 测定和电热板（第 3 课）、容量瓶和 pH 计稀释台（第 4 课）、电位滴定仪（第 5 课，带一块实时画曲线的屏幕）、盐溶液的 pH 测定（第 6 课）、离心机（第 7 课），最东头一台通风橱（拓展课在通风橱前）。
  - 随堂检测的机位在河岸取样栈桥一带，低角度斜看：左边是检测中心大楼（北面竖向遮阳板、玻璃幕墙、楼名牌，东山墙玻璃幕墙和门厅雨棚、台阶，楼顶冷却塔），沿河两排行道树，中间是河道，右边对岸是自来水厂。
- 取值约定：常温 25 °C；Kw = 1.0×10⁻¹⁴（50 °C 取 5.3×10⁻¹⁴）；Ka(CH₃COOH) = 1.75×10⁻⁵；Kb(NH₃·H₂O) = 1.8×10⁻⁵；H₂CO₃ 的 Ka2 = 4.7×10⁻¹¹；Ksp(AgCl) = 1.8×10⁻¹⁰，Ksp(AgI) = 8.5×10⁻¹⁷。稀溶液混合时体积相加。pH 计读数保留两位小数，滴定管读到 0.01 mL。
- 微观放大窗：每课在器材旁边浮一扇圆形放大窗，里面画离子和分子（示意，不按比例、不按数目）。颜色全间统一：H⁺（H₃O⁺）红、OH⁻ 蓝、Cl⁻ 绿、Na⁺ 紫、CH₃COO⁻ 橙、CH₃COOH 分子是橙球连红球、NH₄⁺ 青、NH₃·H₂O 分子青球连蓝球、Ag⁺ 银白、I⁻ 深紫；AgCl 沉淀是白色颗粒团、AgI 是黄色颗粒团；水分子淡灰小球。
- 和同类产品的区别：所有读数（pH、Ka、Kw、滴定曲线、Q 和 Ksp）都由 `physics.ts` 按浓度算出；宏观（灯泡、pH 计、指示剂颜色、沉淀）和微观（放大窗）一起看；曲线画在仪器自己的屏幕上。

## 共用的计算核心

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `weakAcidH(c, Ka)` | 浓度、电离常数 | c(H⁺) | 解 x²/(c − x) = Ka，不做近似 |
| `kaFromPH(c, pH)` | 浓度、pH 计读数 | Ka | Ka = c(H⁺)²/(c − c(H⁺)) |
| `ions(k, t)` | 溶液、温度 | c(H⁺)、c(OH⁻) | c(H⁺)·c(OH⁻) = Kw |
| `dilPH(k, n)` | 盐酸 / 醋酸、稀释次数 | pH | 盐酸计入水的电离；醋酸按电离平衡 |
| `titrationPH(V)` | 加入 NaOH 溶液 mL | pH | 20.00 mL 0.1000 mol/L HCl 用 0.1000 mol/L NaOH 滴定，体积相加 |
| `saltPH(k)` | 盐 | pH | Kh = Kw/Ka 或 Kw/Kb，再按 x²/(c − x) = Kh 解 |
| `qAgCl()`、`qAgI()` | — | 离子积 Q | 一滴按 0.05 mL，体积相加 |
| `convK()` | — | 沉淀转化的 K | Ksp(AgCl)/Ksp(AgI) |
| `sodaPH()` | — | 0.10 mol/L Na₂CO₃ 的 pH | 只算第一步水解，Kh1 = Kw/Ka2 |

## 第 1 课 电解质的强弱（强电解质和弱电解质）

实验台上一块电工板，并排两只 250 mL 烧杯，分别盛 0.10 mol/L 盐酸和 0.10 mol/L 醋酸，每杯插一对石墨电极，各串一只小灯泡，接到同一台学生电源上。

| 项目 | 内容 |
|---|---|
| 知识点 | 强电解质在水溶液中完全电离，弱电解质部分电离 |
| 一句概念 | 浓度相同，盐酸里的离子多得多 |
| 核心动作 | 闭合开关；放大窗分别看两杯 |
| 看到的现象 | 盐酸那只灯亮，醋酸那只灯很暗；放大窗里盐酸全是 H⁺ 和 Cl⁻，醋酸里大多是分子 |
| 读数 | c(H⁺)：盐酸 0.10 mol/L，醋酸 1.3×10⁻³ mol/L；电离度 100% 和 1.3% |
| 真实锚点 | 导电性是水质检测里电导率仪的原理 |
| 对应小测 | 第 1 题 |

任务：闭合开关比较两只灯泡 → 放大看盐酸 → 放大看醋酸。

按钮：闭合开关。分段选择：放大窗看哪一杯（盐酸 / 醋酸）。灯泡亮度按两杯离子浓度之比画（示意）。

## 第 2 课 弱电解质的电离平衡

pH 计、复合电极、一只 100 mL 烧杯盛 0.10 mol/L 醋酸，旁边一台恒温水浴（50 °C）和一只 100 mL 容量瓶。

| 项目 | 内容 |
|---|---|
| 一句概念 | 电离平衡会随条件移动，Ka 只随温度变 |
| 核心动作 | 测 pH；稀释十倍再测；把烧杯放进热水浴 |
| 读数 | 0.10 mol/L：pH 2.88，α 1.3%，Ka 1.75×10⁻⁵；0.010 mol/L：pH 3.39，α 4.1%，Ka 1.75×10⁻⁵ |
| 加热 | 只讲方向：电离吸热，升温平衡向电离方向移动，c(H⁺) 增大。不显示加热后的 pH 数值（见待核实） |
| 对应小测 | 第 2 题 |

按钮：测 pH、稀释十倍、放进热水浴。

## 第 3 课 水的电离

pH 计、电热板，三只烧杯：纯水、0.010 mol/L 盐酸、0.010 mol/L NaOH 溶液。

| 项目 | 内容 |
|---|---|
| 一句概念 | 稀溶液里 c(H⁺)·c(OH⁻) = Kw |
| 读数 | 25 °C 纯水 pH 7.00，c(H⁺) = c(OH⁻) = 1.0×10⁻⁷；50 °C 纯水 pH 6.64，c(H⁺) = c(OH⁻) = 2.3×10⁻⁷，仍是中性；盐酸 pH 2.00，c(OH⁻) = 1.0×10⁻¹²；NaOH 溶液 pH 12.00 |
| 对应小测 | 第 3 题 |

按钮：测 pH、加热到 50 °C。分段选择：哪一杯。

## 第 4 课 溶液 pH 的计算

稀释台：pH 计（屏幕上画 pH—稀释次数的折线）、100 mL 容量瓶、移液管；两瓶 0.10 mol/L 的酸。

| 项目 | 内容 |
|---|---|
| 一句概念 | 强酸稀释十倍 pH 加 1，弱酸加不到 1 |
| 读数 | 盐酸：1.00 → 2.00 → 3.00 → 4.00；醋酸：2.88 → 3.39 → 3.91 → 4.47 |
| 对应小测 | 第 4 题 |

按钮：稀释十倍。分段选择：盐酸 / 醋酸。

## 第 5 课 酸碱中和滴定

电位滴定仪：主机屏幕实时画 pH—V 曲线；铁架台上一支 25 mL 滴定管（聚四氟乙烯活塞，0 刻度在上）装 0.1000 mol/L NaOH 溶液；磁力搅拌器上一只 250 mL 烧杯盛 20.00 mL 0.1000 mol/L 盐酸，插着复合电极（电位滴定要插电极，用烧杯）。

| 项目 | 内容 |
|---|---|
| 一句概念 | 终点附近一滴碱，pH 突跃好几个单位 |
| 读数 | 0 mL pH 1.00；19.90 mL 3.60；19.98 mL 4.30；20.00 mL 7.00；20.02 mL 9.70；25.00 mL 12.05 |
| 指示剂 | 酚酞（8.2–10.0）和甲基橙（3.1–4.4）的变色范围都落在突跃里；石蕊变色不敏锐，不用作滴定指示剂 |
| 对应小测 | 第 5 题 |

按钮：放到 19.90 mL、滴半滴（0.02 mL）、放到 25.00 mL。分段选择：指示剂（酚酞 / 甲基橙 / 石蕊）。

## 第 6 课 盐类的水解

三只烧杯：0.10 mol/L NaCl、CH₃COONa、NH₄Cl 溶液；pH 计电极移到哪杯测哪杯。

| 项目 | 内容 |
|---|---|
| 一句概念 | 谁弱谁水解，谁强显谁性 |
| 读数 | NaCl 7.00；CH₃COONa 8.88；NH₄Cl 5.13 |
| 放大窗 | CH₃COO⁻ + H₂O ⇌ CH₃COOH + OH⁻；NH₄⁺ + H₂O ⇌ NH₃·H₂O + H⁺ |
| 对应小测 | 第 6 题 |

按钮：测 pH。分段选择：哪一杯。

## 第 7 课 沉淀溶解平衡

离心机旁的试管架：一支离心管盛 2 mL 0.1 mol/L NaCl 溶液，两只滴瓶（0.1 mol/L AgNO₃、0.1 mol/L KI）。

| 项目 | 内容 |
|---|---|
| 一句概念 | 沉淀会向更难溶的方向转化 |
| 读数 | 滴 2 滴 AgNO₃：Q(AgCl) = 4.5×10⁻⁴ > Ksp = 1.8×10⁻¹⁰，析出白色沉淀；滴 4 滴 KI：Q(AgI) = 1.6×10⁻¹¹ > Ksp = 8.5×10⁻¹⁷，沉淀变黄；K = 2.1×10⁶ |
| 对应小测 | 第 7、8 题 |

按钮：滴 AgNO₃、滴 KI、离心。

## 和规格卡原文的出入

- 第 1 课界面上的课名用“电解质的强弱”（课次条上写“强弱电解质”），内容不变。
- 第 2 课加热后 pH 计显示“- - -”，面板只写“变小”，不给数值（见待核实事项）。
- 第 5 课用烧杯不用锥形瓶：电位滴定要插电极、放搅拌子。
- 拓展课的两个小实验做成同一页上先后两个任务，没有用分段选择。
