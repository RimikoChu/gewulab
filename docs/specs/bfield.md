## 总览

- **一句话**：学生在一座粒子加速器实验大厅里，从吊在蹄形磁体里的导体棒开始，看电流在磁场中受安培力；再看电子射线管、洛伦兹力演示仪里的电子束怎样被磁场弯成圆；然后用电磁铁、速度选择器、质谱仪、回旋加速器，把“qvB 提供向心力”用到选速度、分同位素、把质子加速到几 MeV。
- **教材位置**：物理，高中选择性必修第二册（人教版 2019），第一章“安培力与洛伦兹力”：磁场对通电导线的作用力；磁场对运动电荷的作用力；带电粒子在匀强磁场中的运动；质谱仪与回旋加速器。节号见“待核实事项”。
- **主线**：同一个 qvB。安培力是导线里大量运动电荷所受洛伦兹力的宏观表现；洛伦兹力总与速度垂直，所以只拐弯、不做功；在匀强磁场里拐成圆，r = mv/(qB)，T = 2πm/(qB)；周期与速度无关，回旋加速器才能用固定频率的交变电压一直加速。
- **场景**：一座加速器实验大厅（高大的钢结构厂房，环氧地坪上画着黄色安全线，北面是一道混凝土屏蔽墙，墙上开着一个口子，能看到后面储存环隧道里的一段同步辐射环：蓝色二极磁铁、红色四极磁铁、不锈钢束流管）。大厅里沿屏蔽墙一字排开各课的装置；头顶一台行车、一排灯。选它的理由：议题建议的“粒子加速器实验室”；回旋加速器、质谱仪、速度选择器都是加速器实验室里真有的设备，课本上的示意图在这里是一台台能看见内部的机器。
- **方向约定**：场景里 +x 往东（课次从西往东排），+y 向上，+z 朝镜头（朝南）。画面里“垂直纸面”的磁场用 × 和 · 表示（× 向里、· 向外）；水平面里的轨迹，磁场竖直，用立体的场线表示。
- **颜色约定（全间统一）**：磁场（场线、×、·）淡紫蓝 `#8fa9ff`；电场线琥珀色 `#ffc65c`；洛伦兹力、安培力品红 `#ff4fa0`；电场力橙色 `#ffa12e`；速度白色 `#eef4ff`；正电荷橙红 `#ff6b4a`，负电荷蓝色 `#46a6ff`；电流是沿导线流动的黄色亮点。电子束在稀薄气体里发出的辉光画成蓝绿色。
- **取值约定**：常量用 CODATA 2018：e = 1.602176634×10⁻¹⁹ C，mₑ = 9.109×10⁻³¹ kg，mₚ = 1.673×10⁻²⁷ kg，m_α = 6.645×10⁻²⁷ kg，u = 1.661×10⁻²⁷ kg；g 取 9.8 N/kg。界面上的数保留三位有效数字左右。
- **画面的尺度**：1 个单位 = 1 m，器材按真实尺寸画；粒子的运动都极快（纳秒级），画面里放慢了，界面上注明“画面放慢”。第 7 课的螺旋按真实圈数画（每过缝一次加 qU，半圈的半径由动能算出）。为了看清内部，第 4–7 课电磁铁的上磁极、上线圈、上轭画成透视的（只留淡淡的轮廓），第 7 课 D 形盒的盒盖前半去掉、后半透视；第 2 课条形磁体从管子前下方斜着靠近，免得挡住荧光屏。
- **洛伦兹力演示仪的磁场**：亥姆霍兹线圈中心 B = (4/5)^(3/2)·μ0·N·I/R，取 N = 130 匝、R = 0.15 m，面板上由 B 反算线圈电流（B₀ = 0.60 mT 对应约 0.77 A）。
- **简化**：磁体附近的磁场当作匀强磁场，有边界（场外为零）；不计重力（第 1 课导体棒除外）、不计相对论效应、不计粒子间作用；质谱仪的离子质量取质量数 × u。
- **和同类产品的区别**：每一处都是能看见内部的真实设备（亥姆霍兹线圈的漆包线绕组、玻璃泡里的电子枪、D 形盒剖开、电磁铁的铁芯和线圈）；看不见的场画出来（× · 和立体场线、电场线），粒子是发光的点拖着尾巴，力和速度的箭头随粒子一起走；轨迹的半径、周期由计算核心算出，和面板读数一致。

## 第 1 课 安培力

| 项目 | 内容 |
|---|---|
| 知识点 | 通电导线在磁场中受安培力；方向由左手定则判断；F = BIL（I ⊥ B） |
| 一句概念 | 磁场对电流有力的作用，F = BIL |
| 核心动作 | 闭合开关；电流反向；对调磁极；把电流调到 3 A |
| 看到的现象 | 吊在蹄形磁体两极之间的铜棒摆出去；旁边一只左手：磁感线穿过掌心，四指顺着电流，大拇指指向安培力 |
| 读数 | 电流 I、安培力 F、偏角 θ |
| 对应小测 | 第 1 题（左手定则，易错：用右手） |

任务：闭合开关，看导体棒往哪边摆 → 让电流反向，再看 → 对调磁极，再看 → 把电流调到 3 A，读出安培力。

数据：B = 0.20 T（两极之间，按匀强算），导体棒在磁场里的长度 L = 0.10 m，质量 10 g。

| 电流 | 安培力 | 偏角（约） |
|---|---|---|
| 1 A | 0.020 N | 11.5° |
| 2 A | 0.040 N | 22.2° |
| 3 A | 0.060 N | 31.5° |

主操作区：闭合开关 / 电流反向 / 对调磁极；分段选择：电流 1 A、2 A、3 A。

## 第 2 课 洛伦兹力

| 项目 | 内容 |
|---|---|
| 知识点 | 运动电荷在磁场中受洛伦兹力；方向用左手定则，负电荷四指指向运动的反方向；F = qvB；洛伦兹力始终垂直于速度，不做功 |
| 一句概念 | 洛伦兹力只改变速度方向，不做功 |
| 核心动作 | 接通高压；用磁体的 N 极、S 极从前面靠近；显示力和速度 |
| 看到的现象 | 电子射线管荧光屏上一条蓝绿色的亮线，N 极靠近向下弯，S 极靠近向上弯；电子上画着速度（白）和洛伦兹力（品红）箭头，二者始终垂直，速度大小不变 |
| 读数 | v（由 U 算出）、B、F = evB、半径 |
| 对应小测 | 第 2、3 题 |

数据：阳极电压 2000 V → v = 2.65×10⁷ m/s；磁体靠近时管内磁场按约 2.0 mT 的匀强磁场算（示意）→ F = 8.5×10⁻¹⁵ N，r ≈ 7.5 cm。

主操作区：接通高压 / 磁体靠近（拿开）/ 显示力和速度；分段选择：磁体朝前的一端 N、S。

## 第 3 课 圆周运动的半径

| 项目 | 内容 |
|---|---|
| 知识点 | v ⊥ B 时洛伦兹力提供向心力，qvB = mv²/r，r = mv/(qB) |
| 一句概念 | 半径 r = mv/(qB) |
| 核心动作 | 接通电子枪；给线圈通电（B₀）；磁场加倍；速度加倍 |
| 看到的现象 | 玻璃泡里电子束先是一条直线，线圈通电后弯成一个蓝绿色的圆；磁场加倍，圆缩成一半；速度加倍，圆又变回原来大小 |
| 读数 | B、U、v、r、T |
| 对应小测 | 第 4 题 |

数据：B₀ = 0.60 mT，U₀ = 75 V（v = 5.14×10⁶ m/s）。

| 条件 | r | T |
|---|---|---|
| B₀、U₀ | 4.87 cm | 59.5 ns |
| 2B₀、U₀ | 2.43 cm | 29.8 ns |
| 2B₀、4U₀（v 加倍） | 4.87 cm | 29.8 ns |

主操作区：接通电子枪 / 速度加倍；分段选择：线圈电流 关、B₀、2B₀。

## 第 4 课 周期与速度无关

| 项目 | 内容 |
|---|---|
| 知识点 | T = 2πr/v = 2πm/(qB)，与 v、r 无关 |
| 一句概念 | 周期 T = 2πm/(qB)，与速度无关 |
| 核心动作 | 发射一个质子；同时发射三个速度不同的质子；磁场加倍；换成 α 粒子 |
| 看到的现象 | 三个质子画出三个大小不同的圆，却同时回到出发点；磁场加倍，转一圈的时间减半；α 粒子比荷是质子的一半，周期变成两倍 |
| 读数 | B、v、r、T |
| 对应小测 | 第 5 题 |

数据：B = 0.50 T，v₀ = 2.0×10⁶ m/s：质子 r = 4.18、8.35、12.5 cm，T = 131 ns；B = 1.0 T：T = 65.6 ns；α 粒子在 1.0 T：T = 130 ns。

主操作区：发射一个 / 同时发射三个 / 磁场加倍；分段选择：质子、α 粒子。

## 第 5 课 速度选择器

| 项目 | 内容 |
|---|---|
| 知识点 | 电场力与洛伦兹力方向相反；qE = qvB 时直线通过，v = E/B；与电性、质量、电荷量无关 |
| 一句概念 | 只有 v = E/B 的粒子能直线通过 |
| 核心动作 | 只加电场；再加磁场；换快的质子；换电子 |
| 看到的现象 | 只加电场，质子弯向下板；再加磁场，速度正好的质子直线穿过狭缝；快的往上偏、慢的往下偏；电子两个力都反过来，也直线通过 |
| 读数 | E、B、v = E/B、qE、qvB |
| 对应小测 | 第 6 题 |

数据：两板电压 200 V、间距 2.0 cm → E = 1.0×10⁴ V/m；B = 0.10 T → v = 1.0×10⁵ m/s。慢、快质子的速度是它的 0.5 倍、2 倍。

主操作区：加电场 / 加磁场；分段选择：慢质子、质子、快质子、电子。

## 第 6 课 质谱仪

| 项目 | 内容 |
|---|---|
| 知识点 | qU = ½mv²，r = (1/B)√(2mU/q)；比荷不同的离子打在底片不同位置；q/m = 8U/(B²x²) |
| 一句概念 | 比荷不同，半径不同，同位素就分开了 |
| 核心动作 | 打开离子源；测谱线；电压加倍再测 |
| 看到的现象 | 氖离子束进入磁场后分成两束半圆，打在底片上两条亮线；质量大的氖 22 在外侧 |
| 读数 | 谱线到狭缝的距离 x、算出的比荷 |
| 对应小测 | 第 7 题 |

数据：U = 1000 V，B = 0.20 T：氖 20 x = 20.4 cm，氖 22 x = 21.4 cm；比荷 4.82×10⁶ C/kg、4.38×10⁶ C/kg。U = 2000 V 时 x 变为 √2 倍，算出的比荷不变。

主操作区：打开离子源 / 测量谱线 / 电压加倍。

## 第 7 课 回旋加速器

| 项目 | 内容 |
|---|---|
| 知识点 | 两个 D 形盒、缝隙里的交变电压；回旋周期与速度无关，所以交变电压频率固定 f = qB/(2πm)；最大动能 Ek = q²B²R²/(2m)，与加速电压无关 |
| 一句概念 | 最大动能由 D 形盒半径和磁场决定 |
| 核心动作 | 开始加速；看示波器；电压加倍；换大 D 形盒 |
| 看到的现象 | 质子从中心出发，每过一次缝隙被推一下，半圆一圈比一圈大，螺旋着走到边缘引出；示波器上质子每次过缝都正好赶上电压反向；电压加倍，圈数减半，引出时的能量不变；换大 D 形盒，能量变大 |
| 读数 | f、圈数、最大动能 |
| 对应小测 | 第 8、9 题 |

数据：B = 1.0 T，U = 100 kV，f = 15.2 MHz，回旋周期 65.6 ns；R = 0.30 m：Ek = 4.31 MeV，22 圈；U 加倍到 200 kV：11 圈，Ek 不变；R = 0.50 m：Ek = 12.0 MeV（100 kV 时 60 圈，200 kV 时 30 圈）。课上的顺序是先用 0.30 m 的 D 形盒，最后换 0.50 m。

主操作区：开始加速 / 看示波器 / 电压加倍；分段选择：D 形盒半径 0.30 m、0.50 m。

## 和规格卡原文的出入

- 霍尔效应没有做，拓展课只做磁流体发电机和极光两个小实验。
- 第 6 课只有三条任务（打开离子源、测谱线、电压加倍再测），算比荷和测谱线合在一步里。
- 第 5 课的分段选择里也有“慢质子”，任务没有要求，留给学生自己试。
