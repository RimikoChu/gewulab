状态：已按此卡做完九个课次，待审。讲解的解说词已写，录音还没有生成（生成后要逐课核对句数）。

## 总览

- 一句话：从一片菠菜叶一路放大到类囊体薄膜，弄懂叶绿体的结构、四种色素和它们吸收的光、光反应和暗反应各在哪里做了什么、两个阶段怎样联系、条件骤变时 C₃ 和 C₅ 怎样变，以及光照强度、CO₂ 浓度、温度怎样影响光合速率。
- 教材位置：人教版（2019）高中生物学 必修 1《分子与细胞》第 5 章 细胞的能量供应和利用，第 4 节 光合作用与能量转化（一 捕获光能的色素和结构；二 光合作用的原理和应用）。章节号见“待核实事项”。
- 主线：光能怎样一步步变成糖类里的化学能：色素吸收光能 → ATP、NADPH → 糖类。
- 场景：一间植物生理实验室，和从实验台上那盆菠菜的叶子一路放大进去看到的东西。

- 分子的形状和颜色全实验室统一：H₂O 红球带两个白球；O₂ 两个红球；CO₂ 灰球两侧红球；H⁺ 白色小球；e⁻ 黄色发亮的小点；ATP 金黄（三个磷酸小球）、ADP 暗黄（两个）、Pi 橙色小球；NADPH 紫色（带一个白色的氢）、NADP⁺ 暗紫；C₃ 三个橙球、C₅ 五个蓝球、去合成糖类的碳粉色（六个攒成一个六边形的葡萄糖）。光用黄色光束。
- 和同类产品的区别：结构、实验和过程在同一个连续的世界里；光反应发生在一块有厚度的膜上，水在腔一侧分解、NADPH 和 ATP 在基质一侧生成，位置关系一眼看得见；条件骤变时圈上 C₃、C₅ 的个数和面板上的横条一起变。

## 共用的计算核心

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `granaCount / thylakoidCount` | | 模型里的基粒数 14、类囊体数 106 | 模型的摆放表 `GRANA` |
| `bandsTopDown / widestBand / groupShare` | | 色素带从上到下的顺序；最宽的；叶绿素、类胡萝卜素各占多少 | 教材：溶解度高的扩散快；叶绿素约占 3/4 |
| `bandAt(key, t)` | 色素、层析进度 | 色素带走了多远 | 示意的先后 |

| `absorb(sample, nm) / zones / mainlyAbsorbs` | 叶绿素或类胡萝卜素、波长 | 吸收多少（示意曲线）；蓝紫、绿、红三区的平均；主要吸收哪些 | 教材结论；曲线形状见待核实事项 |
| `photolysis(n)` | 分解的水分子数 | O₂、H⁺、e⁻ 的个数，最多生成的 NADPH | 2H₂O → O₂ + 4H⁺ + 4e⁻；NADP⁺ + H⁺ + 2e⁻ → NADPH |
| `fixCO2(n) / reduceC3 / calvin(turns)` | | 碳原子守恒：CO₂ + C₅ → 2C₃；2C₃ → 1 个去合成糖类的碳 + C₅；6 圈一个葡萄糖 | 卡尔文循环的碳数 |
| `stepPools / after / shift / rates` | C₃、C₅、ATP 和 NADPH 的相对量，光照、CO₂ 有没有 | 往后一小段时间各是多少；骤变后的变化方向 | 简化的动力学模型：固定 ∝ C₅，还原 ∝ C₃ × (ATP、NADPH) |

| `compensation / saturation / bestTemp` | | 补偿点、饱和点、最适温度 | 由上面的曲线求出 |
| `colorUse / netColor / co2Boost` | | 同样强度下绿光、红蓝光的净光合速率；CO₂ 加倍前后的速率 | 拓展课 |

## 第 1 课 叶绿体的结构

| 项目 | 内容 |
|---|---|
| 知识点 | 叶绿体有外膜和内膜；内部有许多基粒，每个基粒由类囊体堆叠而成；基粒之间是基质；色素在类囊体薄膜上，酶在类囊体薄膜上和基质里 |
| 一句概念 | 叶绿体是进行光合作用的场所 |
| 核心动作 | 放大到叶肉细胞 → 放大到叶绿体 → 剖开 |
| 看到的现象 | 镜头从盆栽飞进细胞，再飞到一个叶绿体；剖面从前往后推，露出双层膜的截面和里面一摞摞的基粒 |
| 读数 | 模型里基粒 14 个、类囊体 106 个（标“这个模型里”） |
| 对应小测 | 第 1 题 |

任务：放大到叶肉细胞；放大到叶绿体；剖开，找到基粒和基质。按钮：放大到叶肉细胞、放大到叶绿体、剖开叶绿体。

## 第 2 课 绿叶中色素的提取和分离

| 项目 | 内容 |
|---|---|
| 知识点 | 无水乙醇提取色素；二氧化硅使研磨充分，碳酸钙防止色素被破坏；色素在层析液中溶解度不同而分离；四条色素带的顺序和颜色 |
| 一句概念 | 四种色素在层析液中溶解度不同 |
| 核心动作 | 研磨并过滤 → 画滤液细线 → 插入层析液 |
| 看到的现象 | 戴手套的手握着杵研磨；研钵抬到漏斗上倒出，试管里收到深绿色滤液；毛细吸管在滤纸条上画线；滤纸条立进烧杯，盖上培养皿，色素带一条条分开 |
| 读数 | 从上到下：胡萝卜素（橙黄色）、叶黄素（黄色）、叶绿素 a（蓝绿色，最宽）、叶绿素 b（黄绿色）；叶绿素约占 3/4，类胡萝卜素约占 1/4 |
| 对应小测 | 第 2、3 题 |

任务：研磨、过滤得到滤液；画滤液细线；层析分出四条色素带。按钮：研磨并过滤、画滤液细线、插入层析液。

数据：菠菜叶 5 g；滤液细线画在离底端约 1 cm 处（教材的做法）。色素带的位置（rf 0.94、0.72、0.44、0.27）和宽窄是示意，不显示数值。

## 第 3 课 色素吸收什么光

| 项目 | 内容 |
|---|---|
| 知识点 | 白光经三棱镜分成光谱；叶绿素 a、b 主要吸收蓝紫光和红光，胡萝卜素和叶黄素主要吸收蓝紫光；绿光吸收最少 |
| 一句概念 | 叶绿素主要吸收红光和蓝紫光 |
| 核心动作 | 把叶绿素溶液放进光路；移出来和完整的光带对比；换成类胡萝卜素溶液再放 |
| 看到的现象 | 黄白色的光束穿过三棱镜，散成一扇彩色的光照在光屏上；溶液推进光路后，被吸收的那几段暗下去 |
| 读数 | 面板上的吸收曲线（示意），蓝紫光区、绿光区、红光区各吸收约百分之几 |
| 对应小测 | 第 4 题 |

任务：放叶绿素溶液；移出来对比；换类胡萝卜素溶液。按钮：放进光路／移出光路（一个按钮）。分段选择：叶绿素／类胡萝卜素。光源默认开着，进来就看得见白光分成的光带；暗室里有一盏暗红的安全灯给器材勾轮廓。

## 第 4 课 光反应

| 项目 | 内容 |
|---|---|
| 知识点 | 光反应在类囊体的薄膜上进行：水分解为氧和 H⁺，O₂ 放出；H⁺ 与 NADP⁺ 结合形成 NADPH；ADP 与 Pi 形成 ATP；光能 → ATP、NADPH 中的化学能 |
| 一句概念 | 光能变成 ATP 和 NADPH 中的化学能 |
| 核心动作 | 照光 → 跟着电子走 → 跟着 H⁺ 走 |
| 看到的现象 | 黄色光束照在两个光系统上，色素发亮；腔一侧水分子进来、O₂ 出去、H⁺ 留在腔里；电子沿膜跳到光系统Ⅰ，NADP⁺ 变成 NADPH；H⁺ 穿过 ATP 合酶，转子转动，ADP + Pi 变成 ATP |
| 读数 | 已分解的水、放出的 O₂、H⁺ 的个数；这些电子最多生成几个 NADPH |
| 对应小测 | 第 5、6 题 |

任务：照光看水在哪里分解；跟着电子走到膜的另一侧；跟着 H⁺ 穿过 ATP 合酶。按钮：照光、跟着电子走、跟着 H⁺ 走。

超出教材正文的内容（光系统Ⅱ、光系统Ⅰ的名称，H⁺ 穿过 ATP 合酶推动 ATP 合成）在“看原理”里标“了解”。两个光系统之间传递电子的物质没有画。ATP 不显示个数（和 H⁺ 的比例不在教材里）。

## 第 5 课 暗反应

| 项目 | 内容 |
|---|---|
| 知识点 | 暗反应在叶绿体基质中进行：CO₂ 与 C₅ 结合成两个 C₃（固定）；C₃ 接受 ATP、NADPH 的能量并被 NADPH 还原，一部分转化为糖类，另一部分又形成 C₅ |
| 一句概念 | CO₂ 经 C₃ 变成糖类，C₅ 循环使用 |
| 核心动作 | 固定 CO₂ → 还原 C₃ → 转 6 圈 |
| 看到的现象 | CO₂ 从上面进来，在酶那里和蓝色的 C₅ 合成橙色的 C₃；ATP、NADPH 从左边过来，C₃ 往下走，粉色的碳从下面出去，其余变回 C₅ 从右边回到上面 |
| 读数 | 碳原子数：1 + 5 = 2 × 3；6 = 1 + 5；固定 6 个 CO₂ 攒出 1 个葡萄糖 |
| 对应小测 | 第 7 题 |

任务：让一个 CO₂ 和 C₅ 结合；送来 ATP 和 NADPH 把 C₃ 还原；转 6 圈攒出一个葡萄糖。按钮：固定 CO₂、还原 C₃、转 6 圈。

简化：C₃ 变成糖类和再生 C₅ 各合成一步；一个小球代表一个碳原子。每个 CO₂ 用几个 ATP、NADPH 不显示。

## 第 6 课 两个阶段的联系

| 项目 | 内容 |
|---|---|
| 知识点 | 光反应为暗反应提供 ATP 和 NADPH，暗反应为光反应提供 ADP、Pi、NADP⁺；突然停光：C₃ 增多、C₅ 减少；突然停 CO₂：C₃ 减少、C₅ 增多 |
| 一句概念 | 光反应和暗反应紧密联系、缺一不可 |
| 核心动作 | 光照、CO₂ 都正常 → 突然停光 →（恢复）→ 突然停 CO₂ |
| 看到的现象 | 类囊体和基质之间两条带箭头的路：ATP、NADPH 过去，ADP、Pi、NADP⁺ 回来；停光时光束熄灭、去基质的分子越来越少，圈上的 C₃ 变多、C₅ 变少；停 CO₂ 时相反 |
| 读数 | 面板上 C₃、C₅、ATP 和 NADPH 的横条（竖线是原来的量）和“增多／减少”；CO₂ 的固定、C₃ 的还原两个过程的快慢 |
| 对应小测 | 第 8 题 |

任务：正常运转看配合；突然停光；恢复后突然停 CO₂。按钮：光照、CO₂ 都正常；突然停光；突然停 CO₂。

模型：稳定时 C₃ : C₅ = 2 : 1（6 和 3），ATP、NADPH 记作一个 0–1 的量（稳定时 0.5）。固定速率 = 0.5 × C₅（有 CO₂ 时），还原速率 = C₃ × e，光反应供给 = 1.2 × (1 − e)（有光时），还原每单位消耗 0.2。C₅ + C₃/2 守恒。变化放慢播放。

## 第 7 课 影响光合速率的因素

| 项目 | 内容 |
|---|---|
| 知识点 | 净光合速率 = 总光合速率 − 呼吸速率；光照强度曲线上的光补偿点、光饱和点；CO₂ 浓度曲线；温度通过酶的活性影响光合速率 |
| 一句概念 | 光照、CO₂ 浓度、温度都影响光合速率 |
| 核心动作 | 选一个条件 → 开始测量 → 标出关键点，三个条件各一次 |
| 看到的现象 | 补光灯一点点变亮（光束变明显），光合仪两块屏上的数在变，面板上的曲线一点点画出来 |
| 读数 | 净光合速率（相对值）；光补偿点约 4、光饱和点约 47；CO₂ 补偿点约 44、饱和点约 584；最适温度约 25 ℃（24.5） |
| 对应小测 | 第 9 题 |

任务：测光照强度的曲线并标点；测 CO₂ 浓度的；测温度的。按钮：开始测量、标出关键点。分段选择：光照强度／CO₂ 浓度／温度。

模型：最大总光合速率 12、呼吸速率 2（25 ℃）；光照 0–100、CO₂ 0–1200（标准 400）、温度 5–45 ℃，都是相对值或模型值。黑暗中净光合速率 −2。

## 讲解

解说词在 `src/labs/chloroplast/narration.ts`。要讲清楚的地方：第 2 课四条色素带的顺序、颜色和“最宽的是叶绿素 a”；第 4 课三件事各在膜的哪一侧；第 6 课用“来源和去路”分析骤变。符号的念法：C₃ 念 C3，NADP⁺ 念“NADP 正离子”，H⁺ 念“氢离子”，CO₂ 念“二氧化碳”。

## 和规格卡原文的出入

- 第 3 课原来有“打开光源”一步，改成光源默认开着（默认画面就有光带），任务换成“放进去、移出来对比、换一种再放”。
- 第 5 课的机位里只露出半个 ATP 合酶，这一课把它收起来不画。
- 第 2 课的滤纸条、垫板和层析烧杯从一开始就摆在研钵旁边。
