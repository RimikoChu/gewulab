# 空气和氧气实验室 · 规格卡 v0.1

状态：待审（第 ② 步，只含本文件）。对应议题 #15，目录名 `air`。

## 总览

- **一句话**：学生亲手量出空气里五分之一是氧气，看清氧气是什么、能让什么烧起来，再走进一座空分厂，弄明白工业上怎样把氧气从空气里"分"出来。
- **教材位置**：人教版化学 九年级上册（2024 年版）第二单元《空气和氧气》，课题 1《我们周围的空气》、课题 2《氧气》、课题 3《制取氧气》，实验活动 1《氧气的实验室制取与性质》，跨学科实践活动 1《微型空气质量"检测站"的组装与使用》。
  - 旧版（2012 年版）这一单元叫《我们周围的空气》，课题 1 叫《空气》。本卡按 2024 新版写；学校仍用旧版的话，第 1 课的名称跟着换，内容不变。见"待核实事项"第 1 条。
- **主线**：一座空气分离厂。空气从厂门口进来，先在质检站被量清楚成分，再一路走到冷箱和精馏塔，被分成氮气和氧气。学生从"空气里有什么"开始，到"工厂里怎么把氧气拿出来"结束。实验室里的实验都在厂里的化验室和制氧车间完成。
- **场景**：整个实验室是**一座连续的空分厂**，所有的课都在这一个场景里，各占一处。换课时画布不重建，镜头在厂区里飞到另一处。

- **取值约定**（全实验室统一）
  - 空气的成分按**体积分数**：氮气 78%、氧气 21%、稀有气体 0.94%、二氧化碳 0.03%、其他气体和杂质 0.03%（教材表格的近似值）。
  - 气体密度（0 ℃、101 kPa）：氧气 1.429 g/L、空气 1.293 g/L、氦气 0.179 g/L。
  - 沸点（常压）：液氮 −196 ℃、液氧 −183 ℃。
  - 集气瓶 250 mL；钟罩截面积 200 cm²、高 500 mm、容积 10.0 L。
  - 相对原子质量：C 12、O 16、S 32、K 39、Mn 55（教材附录Ⅱ）。
- **和已有实验室的区别**：压强、浮力把"一个公式"做成一间实验室；这一间把**工业制法**做成场景本身——课本上"分离液态空气"通常只有一句话，这里学生能在剖开的精馏塔里拖温度，看氮先出来、氧后出来。化验室里的三个实验（测成分、看性质、制氧气）都挂在同一条生产线上，不是三段互不相干的动画。

## 共用的计算核心

全部写在 `physics.ts`，纯函数。界面和三维场景只取数，自己不算。

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `riseMM(frac)` | 被消耗的氧气体积分数 | 钟罩内水面上升的高度（mm） | V = S·h；钟罩容积 10.0 L、截面积 200 cm² |
| `bottleMass(rho, V)` | 气体密度（g/L）、瓶容积（L） | 瓶内气体质量（g） | m = ρV |
| `burnAt(frac)` | 瓶内氧气体积分数 | 燃烧表现分档（"空气"／"纯氧"） | 教材对同一物质在空气和氧气中现象的描述 |
| `isCombination(reactants, products)` | 反应物、生成物的种数 | 是不是化合反应 | 化合反应的定义（多变一） |
| `collect(V)` | 收集到的气体体积（L） | 水槽液面下降的体积（mL） | 排水集气法 |
| `catalystMass(m0)` | 反应前加入的二氧化锰质量（g） | 反应后回收的质量（g） | 催化剂"本身的质量不变" |
| `distill(T)` | 塔内温度（℃） | 当前馏出的组分和已馏出的体积分数 | 液氮 −196 ℃、液氧 −183 ℃ |

## 第 1 课 空气里有什么

把一只钟罩扣在水面上，看水面替我们"量"出氧气占了多少。

| 项目 | 内容 |
|---|---|
| 知识点 | 空气由多种物质组成，按体积算氮气约占 78%、氧气约占 21%；用燃烧法可以测出氧气的含量 |
| 一句概念 | 空气里五分之一是氧气 |
| 核心动作 | 把红磷放进燃烧匙、点燃、伸进钟罩；等火焰熄灭、钟罩冷却；读水面上升的高度 |
| 看到的现象 | 红磷燃烧冒白烟；冷却后钟罩里的水面上升，正好到钟罩高度的五分之一处；换木炭再做一次，水面几乎不动 |
| 读数 | 钟罩内空气体积 10.0 L、被消耗的氧气 2.1 L、水面上升 105 mm（占总高 500 mm 的 21%） |
| 器材 | 玻璃钟罩（截面积 200 cm²、高 500 mm）、水槽、燃烧匙、红磷、木炭 |
| 真实锚点 | 空分厂的分析仪读出的空气成分，和课本上的 78%、21% 对得上 |
| 对应小测 | 水面上升不到五分之一，可能是哪些原因 |

任务清单（先上手 → 换条件 → 定量目标 → 反例辨析）

- [ ] 把红磷放进燃烧匙，点燃后伸进钟罩
- [ ] 等熄灭、冷却，量出水面比原来高了多少
- [ ] 换木炭再做一次：水面几乎不动，说出为什么

视觉映射

| 知识点 | 必须看见的东西 | 由哪个量驱动 | 镜头与视图 |
|---|---|---|---|
| 氧气约占 1/5 | 钟罩里水面停在五分之一高度处，旁边一条刻度 | `riseMM` | 钟罩近景，略微俯视，水面清楚可读 |
| 白烟是固体小颗粒 | 燃烧时升起白烟，熄灭后慢慢沉降 | 燃烧进度 | 同上 |
| 木炭不行 | 木炭燃烧后水面停在原处 | `burnAt` 与生成物 | 同机位，方便对比 |

主操作区的按钮（最多三个，都是一步到位的）

- 点燃红磷
- 冷却，读水面
- 换木炭

直接操作（拖什么、点什么）

- 拖燃烧匙升降，决定伸进钟罩的深度
- 点钟罩切换"红磷／木炭"，点一次换一样

| 条件 | 读数 | 来历 |
|---|---|---|
| 钟罩容积 | 10.0 L | 器材自定：截面积 200 cm² × 高 500 mm |
| 氧气体积 | 2.1 L | 10.0 L × 21%（教材的近似值） |

| 木炭一次 | 上升约 0 mm | 木炭燃烧生成二氧化碳气体，占了被消耗氧气的位置 |

## 第 2 课 一瓶氧气

氧气看不见，但能称出它比空气重一点，也能用一根带火星的木条认出来。

| 项目 | 内容 |
|---|---|
| 知识点 | 氧气是无色、无味的气体，密度比空气略大，不易溶于水；氧气能支持燃烧，带火星的木条复燃可以检验氧气 |
| 一句概念 | 一样大的一瓶，氧气比空气重一点 |
| 核心动作 | 把一瓶氧气和一瓶空气先后放上天平；把带火星的木条分别伸进两瓶；到冷箱边看一瓶液氧 |
| 看到的现象 | 天平上氧气那瓶读数略大；木条在氧气里复燃、在空气里没有变化；液氧是淡蓝色的液体 |
| 读数 | 250 mL 氧气 0.357 g、同体积空气 0.323 g，相差 0.034 g |
| 器材 | 250 mL 集气瓶两只、分析天平（分度值 0.001 g）、带火星的木条、液氧杜瓦瓶 |
| 真实锚点 | 医院和焊接用的氧气瓶；鱼塘增氧 |
| 对应小测 | 为什么可以用向上排空气法收集氧气，也可以用排水法 |

- [ ] 把带火星的木条伸进氧气瓶，看它复燃

视觉映射

| 知识点 | 必须看见的东西 | 由哪个量驱动 | 镜头与视图 |
|---|---|---|---|
| 密度比空气略大 | 天平指针偏向氧气一侧，数字差 0.034 g | `bottleMass` | 桌面平视，天平在画面中央 |
| 氧气支持燃烧 | 木条在氧气里"啪"地复燃，在空气里没有变化 | 瓶内气体种类 | 同机位，两瓶并排 |

## 第 3 课 氧气里的燃烧

同一样东西，在空气里和在氧气里烧起来是两副样子。

| 项目 | 内容 |
|---|---|
| 知识点 | 氧气能支持燃烧（助燃性），本身不能燃烧；木炭、硫、铁丝在氧气中燃烧的现象；这些反应都是氧化反应 |
| 一句概念 | 氧气自己不烧，但能让别的东西烧得更旺 |
| 核心动作 | 从样品架上取木炭、硫、铁丝，送进氧气瓶；再把同样三样送进空气瓶，对比 |
| 看到的现象 | 木炭在氧气里发白光、放热；硫在氧气里是明亮的蓝紫色火焰，在空气里是淡蓝色；铁丝在氧气里火星四射、生成黑色固体，在空气里烧不起来 |
| 读数 | 瓶内氧气体积分数（21% 或 100%）、燃烧表现的档位 |
| 器材 | 通风橱、250 mL 集气瓶（氧气／空气）、燃烧匙、坩埚钳、铁丝（绕成螺旋、末端系一根火柴）、硫、木炭 |
| 真实锚点 | 气焊和气割用氧气；铁丝在纯氧里才烧得起来 |
| 对应小测 | 硫在空气中和在氧气中火焰的颜色 |

任务清单

- [ ] 换铁丝（绕成螺旋、末端系火柴），记下现象
- [ ] 同样两样在空气里再做一次，比一比

| 知识点 | 必须看见的东西 | 由哪个量驱动 | 镜头与视图 |
|---|---|---|---|
| 纯氧里烧得更剧烈 | 木炭的白光、铁丝的火星 | `burnAt` | 通风橱侧视，瓶口正对镜头 |

| 硫的火焰颜色不同 | 淡蓝（空气）与蓝紫（氧气） | 瓶内氧气体积分数 | 同机位对比 |

主操作区的按钮

- 送进氧气瓶
- 送进空气瓶
- 记录现象

## 第 4 课 多变一

把前面烧过的几个反应摆到一起，看它们有什么共同点。

| 项目 | 内容 |
|---|---|
| 知识点 | 化合反应：由两种或两种以上物质生成另一种物质的反应；氧化反应：物质与氧气发生的反应；剧烈氧化与缓慢氧化 |
| 一句概念 | 几种物质变成一种，就叫化合 |
| 核心动作 | 点反应墙上的反应牌，看牌面；把属于化合的牌放进"化合"槽；把不属于的放回去 |
| 看到的现象 | 三块牌放进"化合"槽后亮起；石蜡燃烧那块被推回来，牌面提示生成物有两种 |
| 读数 | 反应物的种数、生成物的种数 |
| 器材 | 化验室墙上的一面反应墙，木牌若干，两个槽 |
| 真实锚点 | 铁生锈、食物变质都是氧化反应，只是慢得看不见 |
| 对应小测 | 下面哪个反应是化合反应 |

## 第 5 课 实验室里制氧气

在制氧车间的长实验台上，把氧气从药品里"赶"出来，用排水法收一瓶。

| 项目 | 内容 |
|---|---|
| 知识点 | 实验室可以用加热高锰酸钾、分解过氧化氢的方法制取氧气；排水法收集；试管口略向下倾斜、先撤导管再熄灭酒精灯 |
| 一句概念 | 把氧气从药品里赶出来，再用排水法接住 |
| 核心动作 | 选药品、装药、固定试管、点燃酒精灯、排水法收集一瓶、验满 |
| 看到的现象 | 导管口连续冒气泡，水槽里的水被压进量筒，集气瓶里的水一点点退下去；瓶口有大气泡向外冒时说明满了 |
| 读数 | 收集到的氧气 250 mL、水槽液面下降 250 mL |
| 器材 | 铁架台、大试管、单孔塞、导管、水槽、250 mL 集气瓶、玻璃片、酒精灯、高锰酸钾、过氧化氢、二氧化锰 |
| 真实锚点 | 实验室制氧和医院制氧机不是一回事（后者用分子筛，只是把空气分开） |
| 对应小测 | 收集完毕，为什么先撤导管再熄灭酒精灯 |

任务清单

- [ ] 装好高锰酸钾，试管口略向下，点燃酒精灯
- [ ] 用排水法收满一瓶 250 mL 的氧气
- [ ] 换成过氧化氢加二氧化锰，不加热也收一瓶

## 第 6 课 二氧化锰为什么用不完

它让反应快起来，反应完却一点没少。

| 项目 | 内容 |
|---|---|
| 知识点 | 催化剂：在化学反应里能改变其他物质的化学反应速率，而本身的质量和化学性质在反应前后都没有发生变化；分解反应 |
| 一句概念 | 它帮忙，但不被消耗 |
| 核心动作 | 三次对比：过氧化氢不加二氧化锰、加 2.0 g、反应结束后滤出烘干再称 |
| 看到的现象 | 不加时气泡很少；加了以后气泡猛增；反应后回收的黑色粉末还是 2.0 g |
| 读数 | 加入的二氧化锰 2.000 g、回收的 2.000 g、气泡速率档位 |
| 器材 | 对比台：三支试管、过氧化氢、二氧化锰、托盘天平、滤纸、烘箱 |
| 真实锚点 | 汽车尾气净化器、加酶洗衣粉 |
| 对应小测 | 催化剂的说法里哪一句是错的（"一定加快"） |

任务清单

- [ ] 不加二氧化锰，看过氧化氢自己分解多慢
- [ ] 加 2.0 g 二氧化锰，再试一次
- [ ] 反应后滤出、烘干、称量，看还是不是 2.0 g

视觉映射

| 知识点 | 必须看见的东西 | 由哪个量驱动 | 镜头与视图 |
|---|---|---|---|
| 速率改变 | 三支试管气泡的疏密差别 | 反应速率档位 | 三支试管并排，近景 |
| 质量不变 | 天平上黑色粉末回到 2.000 g | `catalystMass` | 台面平视，天平数字清楚 |
| 黑色粉末没变 | 前后都是黑色固体 | 化学性质不变 | 近景 |

主操作区的按钮

- 不加二氧化锰
- 加 2.0 g
- 回收称量

直接操作

- 点试管换一支看
- 拖药匙往试管里加粉末

数据

| 条件 | 读数 | 来历 |
|---|---|---|
| 加入的二氧化锰 | 2.000 g | 器材自定 |
| 回收的二氧化锰 | 2.000 g | 催化剂质量不变 |
| 不加时 | 气泡很少，收集一瓶要很久 | 教材现象描述 |

## 第 7 课 工厂里怎么制氧

课本上一句话的"分离液态空气"，在这一课是一座可以拖温度的塔。

| 项目 | 内容 |
|---|---|
| 知识点 | 工业上利用液氮和液氧的沸点不同，分离液态空气制氧气；这个过程没有生成新物质，是物理变化 |
| 一句概念 | 不用化学，靠"谁先沸腾" |
| 核心动作 | 拖温度滑块：先降到 −196 ℃ 以下让空气液化，再慢慢升温，看氮先馏出、氧后馏出 |
| 看到的现象 | 塔内液体分层，上段清亮（液氮）、下段淡蓝（液氧）；温度升到 −196 ℃ 时塔顶开始出气，储罐液位上升；升到 −183 ℃ 时氧气才出来 |
| 读数 | 塔内温度、已馏出的氮 78%、已馏出的氧 21% |
| 器材 | 剖开的精馏塔、冷箱、液氮罐、液氧储罐、流量计 |
| 真实锚点 | 空分厂（本场景本身就是）；医院的液氧储罐 |
| 对应小测 | 分离液态空气是物理变化还是化学变化 |

任务清单

- [ ] 把温度降到 −196 ℃ 以下，看空气全部变成液体
- [ ] 升到 −196 ℃，看氮先馏出，占 78%
- [ ] 升到 −183 ℃，看氧馏出，占 21%

视觉映射

| 知识点 | 必须看见的东西 | 由哪个量驱动 | 镜头与视图 |
|---|---|---|---|
| 沸点不同才能分开 | 两个温度刻度在塔身上，氮在上、氧在下 | `distill` | 塔身剖面平视（不看塔顶往下） |
| 氮先出来 | 塔顶的出口冒气，液位下降 | 已馏出体积 | 同上 |
| 氧后出来 | 塔底的淡蓝色液体减少，储罐液位上升 | 同上 | 同上 |

主操作区的按钮

- 降到 −196 ℃
- 升到 −183 ℃
- 记录

直接操作

- 拖温度滑块
- 点塔身两段看各自是什么

数据

| 条件 | 读数 | 来历 |
|---|---|---|
| 液氮沸点 | −196 ℃ | 公认值（常压） |
| 液氧沸点 | −183 ℃ | 公认值（常压） |
| 馏出的氮 | 78% | 空气成分的体积分数 |
| 馏出的氧 | 21% | 同上 |
| 一瓶液氧 | 250 mL，0.357 g（气化后） | 1.429 g/L × 0.25 L |

## 随堂检测

九道选择题。每课一道易错题，另加两道综合题。答错可以一键回到对应那一课。

| 题 | 题目要点 | 对应课 | 考查的易错点 |
|---|---|---|---|
| 1 | 空气里含量最多的气体是什么，占多少 | 1 | 78% 是体积分数，不是质量分数 |
| 2 | 一瓶氧气和一瓶空气，同体积谁重，为什么用向上排空气法 | 2 | 密度略大，所以瓶口向上 |
| 3 | 硫在氧气中燃烧的火焰颜色 | 3 | 空气中淡蓝色、氧气中蓝紫色 |
| 4 | 下面哪个反应是化合反应 | 4 | 石蜡燃烧生成两种物质 |
| 5 | 排水法收集完毕，先撤导管还是先熄灯 | 5 | 先撤导管，防止水倒流 |
| 6 | 关于催化剂，哪句话是错的 | 6 | "一定加快"错，是"改变" |
| 7 | 分离液态空气制氧气是什么变化 | 7 | 没有新物质生成，是物理变化 |
| 8 | 综合：钟罩里水面上升 105 mm，说明氧气约占多少 | 1、2 | 体积分数的换算 |
| 9 | 综合：三瓶无色气体（空气、氧气、二氧化碳）怎样一次鉴别 | 2、3 | 带火星木条与澄清石灰水 |
