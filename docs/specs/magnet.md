## 总览

- **一句话**：学生在山坡上一座风电场的运维站实训室里，用条形磁体、蹄形磁体、小磁针、铁屑、螺线管、电磁铁、导轨和导体棒、电动机模型、灵敏电流计，一步步弄清磁体和磁场、电流的磁场、磁场对电流的作用、电磁感应；最后出门上山，把一台风力发电机的机舱剖开，看叶片怎样带着齿轮箱和发电机转起来，发出交流电。
- **教材位置**：物理，初中九年级全一册，人教版第二十章“电与磁”（磁现象 磁场；电生磁；电磁铁 电磁继电器；电动机；磁生电）。章节号和节名见“待核实事项”。
- **主线**：风电场把风的机械能变成电能。前六课在运维站实训室的长实验台上做（磁体 → 磁场 → 电生磁 → 电磁铁 → 电动机 → 电磁感应），第 7 课先在台上摇一台交流发电机模型，再飞到窗外山坡上那台风机，剖开机舱看真正的发电机。
- **场景**：华北山地风电场的一角。山脚一座单层的运维站（白墙、灰色金属屋面），朝镜头一面剖开，里面是实训室：靠北墙一条长实验台，台上方是一排高窗，窗外是山坡上的风机。山坡上一行四台风机在转（塔筒高 80 m，叶片长约 50 m），运维站东边是升压站（围墙、主变压器、构架、出线），一列输电铁塔沿山谷往远处走。选它的理由：议题建议风力发电场；发电机是这一章的落点，学生在课上弄懂的每一样（磁场、电生磁、电磁感应）都在窗外那台风机里。
- **方向约定**：场景里 −z 是北（实验台在北墙，窗外的山在北边），+x 是东。小磁针静止时 N 极指 −z。
- **取值约定**：实验台上的电源是两节干电池串联（3 V）或学生电源；电流读数保留一位小数，单位 A。铁屑、小磁针的方向由计算核心里的磁极模型算出（示意）。我国交流电的频率 50 Hz，周期 0.02 s。
- **画面的尺度**：1 m 画成 10 个单位；台上的器材按厘米写。为了看清，第 2 课的铁屑画得比真实的粗一些，第 6 课导体棒的运动放慢；界面上写“示意”的数都是模型算的。
- **和同类产品的区别**：磁感线是发光的细线，由磁极模型逐点算出来，方向箭头沿线走；铁屑是几千根细铁丝，撒下时朝向是乱的，轻敲玻璃板后一根根转到磁场方向，并在两极聚成一簇簇；小磁针是真实的支架式小磁针，会摆过头再停稳。风机按真实比例，机舱剖开能看到主轴、主轴承、齿轮箱、制动器、联轴器、发电机。

## 共用的计算核心（physics.ts）

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `poles` | 磁体种类（条形、蹄形、螺线管、地球） | 一组“磁荷”（位置、正负） | 磁极模型：N 极当作正磁荷、S 极当作负磁荷，场强按距离平方反比叠加（示意） |
| `field` | 一组磁荷、平面上一点 | 这一点磁场的方向和大小 | 同上 |
| `traceLine` | 一组磁荷、起点 | 一条磁感线上的点 | 从 N 极附近出发，沿磁场方向一步步走，到 S 极附近停 |
| `fieldLines` | 磁体种类 | 一组磁感线 | 在 N 极周围均匀取起点 |
| `filings` | 磁体种类、根数 | 每根铁屑的位置和朝向 | 场强大的地方多撒，朝向取那一点的磁场方向，几根连成一串 |
| `needleAngle` | 磁体种类、位置、地磁场 | 小磁针 N 极的朝向 | 磁体的场加地磁场（水平分量指北） |
| `wireDeflect` | 电流方向 | 小磁针偏向东还是西 | 通电直导线的磁场（安培定则），导线在小磁针正上方、南北方向 |
| `solenoidN` | 电流方向 | 螺线管哪一端是 N 极 | 安培定则 |
| `pins` | 匝数、电流、有无铁芯 | 吸起的大头针数 | 示意模型：有铁芯 n = N·I/5，没有铁芯 n = N·I/50（N 匝数，I 以 A 计），取整 |
| `forceX` | 电流方向、磁场方向 | 导体棒往哪边滚 | F 的方向 = I × B（左手定则，初中不讲名字） |
| `inducedDir` | 运动方向、磁场方向 | 感应电流方向（或没有） | 切割磁感线才有；方向 ∝ v × B |
| `commutations` | 线圈转过的圈数 | 换向器改变电流方向的次数 | 每半圈一次 |
| `acFreq` / `period` / `flips` | 转速、磁极对数 | 频率、周期、每秒改变方向的次数 | f = p·n/60；T = 1/f；每个周期方向改变两次 |
| `genRpm` | 叶轮转速、齿轮箱增速比 | 发电机转速 | n发 = n叶 × 增速比 |

## 第 1 课 磁现象

| 项目 | 内容 |
|---|---|
| 知识点 | 磁体能吸引铁、钴、镍等物质；磁体两端磁性最强，叫磁极；可以自由转动的磁体静止时 N 极指北；同名磁极相互排斥，异名磁极相互吸引 |
| 一句概念 | 同名磁极相斥，异名磁极相吸 |
| 核心动作 | 磁体靠近铁钉、铜片、铝片；放进回形针盒再提起；用细线吊起；拿另一块磁体的 N 极、S 极靠近吊着的磁体的 N 极 |
| 看到的现象 | 铁钉被吸过来，铜片、铝片不动；回形针挂在两端，中间几乎没有；吊着的磁体来回摆几下停在南北方向；N 靠 N 被推开，S 靠 N 被吸过来 |
| 读数 | 吊着的磁体静止时 N 极所指方向：北（0°） |
| 对应小测 | 1（易错：铜、铝不能被磁化，不被吸引） |

任务清单
- [ ] 拿磁体分别靠近铁钉、铜片、铝片
- [ ] 把磁体放进回形针盒，再提起来
- [ ] 用细线把磁体吊起来，等它停稳
- [ ] 用另一块磁体的 N 极、S 极分别靠近吊着的磁体的 N 极

主操作区：“靠近”（第 1、4 步，靠近什么由分段选择定）、“放进回形针盒 / 提起来”、“吊起来”。分段选择：第 1 步选材料（铁钉、铜片、铝片），第 4 步选手里那块磁体朝前的一端（N、S）。

## 第 2 课 磁场和磁感线

| 项目 | 内容 |
|---|---|
| 知识点 | 磁体周围存在磁场；放在某一点的小磁针静止时 N 极所指的方向就是那一点的磁场方向；磁感线从 N 极出来回到 S 极；地球周围存在地磁场，地磁 N 极在地理南极附近 |
| 一句概念 | 磁感线从 N 极出来，回到 S 极 |
| 核心动作 | 在盖着磁体的玻璃板上撒铁屑、轻敲；在磁体周围放八枚小磁针；画出磁感线；换蹄形磁体再做；换成地球仪，看地磁场 |
| 看到的现象 | 铁屑从乱糟糟变成一条条弧线，两极最密；小磁针的 N 极顺着弧线指；发光的磁感线带箭头从 N 极绕到 S 极；地球仪旁的小磁针指向地理北极，那里是地磁的 S 极 |
| 读数 | 八枚小磁针的 N 极朝向（示意，由磁极模型算出） |
| 对应小测 | 2（易错：磁感线是假想的线，不是真实存在的；磁感线不相交） |

任务清单
- [ ] 撒上铁屑，轻敲玻璃板
- [ ] 在磁体周围放上小磁针
- [ ] 画出磁感线
- [ ] 换成蹄形磁体，再撒铁屑、画磁感线
- [ ] 换成地球仪，看地磁场

主操作区：“撒铁屑，轻敲玻璃板”“放小磁针”“画磁感线”。分段选择：条形磁体、蹄形磁体、地球仪。

## 第 3 课 电生磁

| 项目 | 内容 |
|---|---|
| 知识点 | 奥斯特实验：通电导线周围存在磁场，磁场方向跟电流方向有关；通电螺线管外部的磁场和条形磁体的一样；安培定则：右手握螺线管，四指指向电流方向，大拇指所指那端是 N 极 |
| 一句概念 | 电流的周围存在磁场 |
| 核心动作 | 闭合开关，看导线下的小磁针；改变电流方向再闭合；换成螺线管闭合开关；改变电流方向，用安培定则判断 |
| 读数 | 电流表 1.5 A；小磁针偏向东或西；螺线管哪端是 N 极 |
| 对应小测 | 3（易错：小磁针偏转方向跟电流方向有关；安培定则用右手） |

任务清单
- [ ] 闭合开关，看导线下面的小磁针
- [ ] 改变电流方向，再闭合开关
- [ ] 换成螺线管，闭合开关
- [ ] 改变螺线管里的电流方向，用安培定则判断 N 极

主操作区：“闭合开关 / 断开开关”“改变电流方向”“换成螺线管”。

数据：电池盒 3 V，导线和保护电阻共 2 Ω，I = 3 V ÷ 2 Ω = 1.5 A（导线和保护电阻的阻值是示意）。

## 第 4 课 电磁铁

| 项目 | 内容 |
|---|---|
| 知识点 | 电磁铁通电有磁性、断电没有磁性；电流越大、线圈匝数越多，磁性越强；插入铁芯磁性大大增强 |
| 一句概念 | 电流越大、匝数越多，电磁铁磁性越强 |
| 核心动作 | 闭合、断开开关；把电流从 0.5 A 调到 1.0 A；改接 100 匝；抽出铁芯；每次数吸起的大头针 |
| 读数 | 电流 0.5 A / 1.0 A；吸起的大头针（示意）：50 匝 0.5 A 5 枚，50 匝 1.0 A 10 枚，100 匝 1.0 A 20 枚，抽出铁芯 2 枚 |
| 对应小测 | 4（易错：控制变量，比较匝数时电流要相同） |

任务清单
- [ ] 闭合开关吸大头针，再断开开关
- [ ] 把电流调到 1.0 A
- [ ] 改接 100 匝的线圈
- [ ] 抽出铁芯

主操作区：“闭合开关 / 断开开关”“调到 1.0 A”“抽出铁芯”。分段选择：50 匝、100 匝。

## 第 5 课 电动机

| 项目 | 内容 |
|---|---|
| 知识点 | 通电导线在磁场中受到力的作用；力的方向跟电流方向、磁场方向有关；电动机是利用通电线圈在磁场中受力转动的原理制成的；换向器每半圈改变一次线圈中的电流方向，线圈能持续转动；电能转化为机械能 |
| 一句概念 | 通电导线在磁场中受到力的作用 |
| 核心动作 | 闭合开关看导体棒滚动；改变电流方向；对调磁极；接通电动机模型 |
| 读数 | 导体棒滚动方向；电动机模型转过的圈数、换向器换向的次数（每圈 2 次） |
| 对应小测 | 5（易错：同时改变电流方向和磁场方向，受力方向不变） |

任务清单
- [ ] 闭合开关，看导轨上的导体棒
- [ ] 改变电流方向，再闭合开关
- [ ] 对调磁极，再闭合开关
- [ ] 接通电动机模型，看它转三圈

主操作区：“闭合开关 / 断开开关”“改变电流方向”“换成电动机模型”。分段选择：磁体 N 极在上、S 极在上。

## 第 6 课 电磁感应

| 项目 | 内容 |
|---|---|
| 知识点 | 闭合电路的一部分导体在磁场中做切割磁感线运动时，导体中就产生电流（感应电流）；感应电流的方向跟导体运动方向和磁场方向有关；机械能转化为电能 |
| 一句概念 | 切割磁感线，就产生感应电流 |
| 核心动作 | 让导体棒上下运动、向左运动、向右运动；对调磁极再向左运动 |
| 读数 | 灵敏电流计指针：不偏、向左偏、向右偏 |
| 对应小测 | 6（易错：导体顺着磁感线运动不产生电流） |

任务清单

## 讲解

解说词在 `src/labs/magnet/narration.ts`。要讲清楚的地方：第 2 课“小磁针 N 极所指就是磁场方向”；第 3 课导线要南北方向放；第 4 课每次只改一个条件；第 6 课“上下运动”是顺着磁感线，不切割；第 7 课“每秒改变 100 次”的来历。

## 画面上的约定

- 磁体：条形磁体红色一半是 N 极、蓝色一半是 S 极，顶面刻 N、S；蹄形磁体红色漆，两脚端头是本色钢，刻 N、S。
- 磁感线一律用青色发光细线，箭头从 N 指向 S；电流方向用黄色的流动亮点；导体受力用红色箭头。
- 手是带袖子的劳保手套（运维站的深蓝工装袖子）：第 1 课拿磁体，第 3、4、5 课拨开关时出现，第 7 课摇手柄。第 6 课的铜棒装在一根黑色绝缘手柄上，没有画手（画手会挡住两极之间）。
- 放慢的地方：风机机舱里的高速轴画成叶轮转速的 6 倍（实际约 100 倍）；扬声器纸盆的振动放慢到每秒 1.5 次；电动机模型每秒约 0.8 圈。界面上写明了“放慢”的只有扬声器和风机原理里的说明。

## 和规格卡原文的出入

- 建议课次 4 里的“电磁起重机、电磁继电器”：电磁起重机写进第 4 课的原理，继电器放到拓展课，随堂检测仍考它（第 4 课的原理里也讲了继电器）。
