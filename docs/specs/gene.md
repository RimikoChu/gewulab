状态：九个课次（1–7、拓展、随堂检测）全部做完（2026-11-26），待验收。关联议题 #33。

## 总览

- **一句话**：学生在一座豌豆试验园里，先认出豌豆的几对相对性状，到园边的小实验室用显微镜看染色体，一级一级放大到 DNA 和基因，看染色体怎样经生殖细胞传给后代；再回到温室亲手做一次孟德尔的杂交（去雄、套袋、授粉），种出子一代、子二代，数一数高茎和矮茎，用基因解释 3∶1；最后看人的性别怎样决定，量一量两个品种的花生，分清可遗传的变异和不可遗传的变异。
- **教材位置**：生物，初中八年级下册。人教版第七单元“生物圈中生命的延续和发展”第二章“生物的遗传和变异”，五节依次是：基因控制生物的性状、基因在亲子代间的传递、基因的显性和隐性、人的性别遗传、生物的变异。版本和节名见“待核实事项”。
- **主线**：一对豌豆性状（茎的高矮）从亲代传到子一代、子二代。第 1 课认出它，第 2、3 课看它的基因在哪、怎样传下去，第 4、5 课做杂交实验、用基因解释，第 6 课换成人的性别这对“性状”，第 7 课讲变异。
- **场景**：一座豌豆试验园（孟德尔式的试验田、玻璃温室、园边一间砖砌的小实验室、温室门口一张工作台）。**大场景的布局**见下表。
- **取值约定**：画面里 1 个单位约等于 10 cm。豌豆体细胞 14 条染色体（7 对），人的体细胞 46 条（23 对）。孟德尔的数据用他论文里的原数。各课的抽样（子二代一畦的株数、摸棋子、量花生）都由固定种子的随机数生成，每次一样。
- **和同类产品的区别**：同类产品多是一张遗传图解加一个“生成后代”按钮。这里杂交的每一步（去雄、套袋、授粉）都要学生自己做，子一代、子二代是在田里一畦一畦长出来的，要自己数；基因组成是数完以后才用来解释的，不是先给。

## 共用的计算核心

| 函数 / 表 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `TRAITS` | — | 三对相对性状：茎的高度（高茎 / 矮茎）、种子的形状（圆粒 / 皱粒）、花的颜色（紫花 / 白花），每对的显性一方 | 孟德尔论文里的七对性状中的三对 |
| `isRelative(a, b)` | 两个性状表现 | 同一性状的不同表现才是相对性状 | 教材定义 |
| `HEIGHT` | 高茎 / 矮茎 | 约 2 m / 约 0.4 m（画面里的株高） | 孟德尔论文：高茎 6–7 英尺，矮茎 0.75–1.5 英尺 |
| `LEVELS` | — | 细胞 → 细胞核 → 染色体 → DNA → 基因，每级一句说明 | 教材 |
| `CHROMOSOMES` | 物种 | 豌豆 14 条（7 对），人 46 条（23 对） | 公认数据 |
| `gamete(n)`、`zygote(a, b)` | 条数 | 生殖细胞 n ÷ 2；受精卵 a + b | 教材 |
| `cross(p1, p2)` | 两个亲本的基因组成 | 四种组合、每种的性状 | 孟德尔遗传规律 |
| `phenotype(g)` | 基因组成 | 含 D 为高茎，dd 为矮茎 | 同上 |
| `f2Bed(n, seed)` | 株数、随机种子 | 子二代一畦每株的基因组成（Dd × Dd 随机组合） | 用固定种子的随机数 |
| `MENDEL` | 性状 | 子二代的原始数据：茎 787 高 ∶ 277 矮；种子 5474 圆 ∶ 1850 皱；花 705 紫 ∶ 224 白 | 孟德尔 1866 年论文 |
| `ratio(a, b)` | 两个数 | a ÷ b，保留两位 | — |
| `KARYOTYPE` | 男 / 女 | 22 对常染色体 + XY / XX | 教材 |
| `draws(n, seed)` | 次数、随机种子 | 每次摸到的精子（X 或 Y）和卵细胞（X），结果男 / 女 | 教材模拟实验：精子袋黑白棋子各 10 枚，卵细胞袋白棋子 20 枚，摸后放回 |
| `peanuts(kind, n, seed)` | 品种、粒数 | 每粒果实的长度（cm，一位小数） | 示意：大花生平均约 3.2 cm，小花生约 2.2 cm |
| `mean(xs)` | 一组数 | 平均值，一位小数 | — |
| `VARIATION` | 例子 | 可遗传 / 不可遗传，原因 | 教材 |
| `podSeeds(n, seed)` | 粒数 | 子一代豆荚里每粒是圆粒还是皱粒 | 随机，概率 3∶1 |
| `testCross(g)` | DD / Dd | 和 dd 杂交的后代 | 孟德尔遗传规律 |

## 第 1 课 性状和相对性状

两块亲代畦并排：一畦高茎、一畦矮茎。换着看三对性状。

| 项目 | 内容 |
|---|---|
| 知识点 | 生物的形态结构特征、生理特性、行为方式都叫性状；同种生物同一性状的不同表现形式叫相对性状 |
| 一句概念 | 同一性状的不同表现，叫相对性状 |
| 核心动作 | 选一对性状，按“比一比”：茎的高矮立起一根标尺；种子的形状打开两只豆荚；花的颜色推近两朵花 |
| 看到的现象 | 高茎约 2 m，矮茎约 0.4 m；圆粒饱满光滑，皱粒表面皱缩；紫花和白花 |
| 读数 | 株高（约 2 m、约 0.4 m）；找到的相对性状对数（3） |
| 真实锚点 | 孟德尔用的就是豌豆的这几对性状 |
| 对应小测 | 第 1 题（哪一组是相对性状） |

任务清单

- [ ] 比一比高茎和矮茎的株高
- [ ] 换成“种子的形状”，打开豆荚比一比
- [ ] 换成“花的颜色”，比一比两朵花
- [ ] 判断：高茎和圆粒是不是一对相对性状

主操作区：比一比；判断（第 4 条任务时出现“不是”的判断）。分段选择：茎的高度 / 种子的形状 / 花的颜色。

数据：株高约 2 m、约 0.4 m（`HEIGHT`）。

## 第 2 课 染色体、DNA 和基因

显微镜下是豌豆根尖的细胞（压片、染色），有一个细胞正在分裂，染色体清楚。旁边的模型座上一级一级放大。

| 项目 | 内容 |
|---|---|
| 知识点 | 细胞核里有染色体；染色体主要由 DNA 和蛋白质组成；DNA 是主要的遗传物质，双螺旋；基因是有遗传效应的 DNA 片段 |
| 一句概念 | 基因是有遗传效应的 DNA 片段 |
| 核心动作 | 看显微镜；按“放大一级”四次；在细胞核那一级数染色体 |
| 看到的现象 | 视野里一片方形的根尖细胞，一个细胞里有深色的染色体；模型依次是剖开的细胞、细胞核和 14 条染色体、一条染色体（两条姐妹染色单体、着丝粒）、松开的 DNA 双螺旋、DNA 上亮起的一段（基因） |
| 读数 | 染色体 14 条（7 对） |
| 对应小测 | 第 2 题（基因、DNA、染色体的关系） |

任务清单

- [ ] 用显微镜看豌豆根尖细胞
- [ ] 放大到细胞核，数一数染色体
- [ ] 放大到一条染色体，再到 DNA
- [ ] 在 DNA 上找到一个基因

数据：豌豆体细胞 14 条染色体（`CHROMOSOMES.pea`）。

画面上的约定：模型是放大很多倍的示意，DNA 的粗细、螺距、一个基因的长度都不按比例；染色体上的条纹只是为了分得清。

## 第 3 课 基因经生殖细胞传递

黑台面上三个透明的细胞模型：左边父本（矮茎，提供花粉）的一个体细胞，右边母本（高茎）的一个体细胞，各有 7 对染色体。父方的染色体用蓝色，母方的用橙色。

| 项目 | 内容 |
|---|---|
| 知识点 | 体细胞中染色体成对存在；形成生殖细胞时每对分开，生殖细胞中染色体减少一半；受精卵中又成对，每对一条来自父方、一条来自母方；基因随染色体传递 |
| 一句概念 | 生殖细胞是基因在亲子代间传递的桥梁 |
| 核心动作 | 形成生殖细胞；受精；看一对染色体上的基因 |
| 读数 | 体细胞 14 条 → 生殖细胞 7 条 → 受精卵 14 条 |
| 对应小测 | 第 3 题 |

任务清单

- [ ] 让两个体细胞各形成生殖细胞，数一数条数
- [ ] 让精子和卵细胞结合，数一数受精卵（每对一条蓝、一条橙）
- [ ] 看第 1 对染色体上控制茎高矮的一对基因

主操作区：形成生殖细胞、受精、看基因。

数据：14、7、14（`gamete`、`zygote`）；基因：母本 DD 给 D，父本 dd 给 d，受精卵 Dd。

画面上的约定：豌豆的精子在花粉里、卵细胞在胚珠里，这里只画细胞和染色体，不画花粉管。染色体画成没有复制的单条。

## 第 4 课 孟德尔的杂交实验

温室前台上一盆高茎、一盆矮茎。推近高茎上一朵还没开的花（放大了画）。

| 项目 | 内容 |
|---|---|
| 知识点 | 豌豆是自花传粉、而且是闭花受粉的植物；人工杂交要在花未成熟时去雄、套袋，花成熟后授以另一株的花粉，再套袋 |
| 一句概念 | 子一代全是高茎 |
| 核心动作 | 去雄；套袋；授粉；种下收到的种子 |
| 看到的现象 | 镊子拨开龙骨瓣取走雄蕊；纸袋罩住花；毛笔从矮茎的花上蘸花粉点到柱头上；豆荚长出来；种进子一代畦，全部长成高茎 |
| 读数 | 子一代：高茎 24 株，矮茎 0 株 |
| 真实锚点 | 孟德尔做过高茎和矮茎的正交、反交，子一代都是高茎 |
| 对应小测 | 第 4 题（为什么要去雄、套袋） |

任务清单

- [ ] 花还没开，先去掉雄蕊
- [ ] 给去了雄的花套上纸袋
- [ ] 用矮茎的花粉授粉
- [ ] 种下这朵花结的种子，看子一代

主操作区：下一步（去雄 → 套袋 → 授粉，按钮上的字随步骤变）、种下种子。

数据：子一代畦 24 株（示意的株数），全部高茎（`cross('DD', 'dd')`）。

## 第 5 课 显性和隐性

子一代畦后面就是子二代畦。

| 项目 | 内容 |
|---|---|
| 知识点 | 子一代只表现一方的性状（显性性状），另一方（隐性性状）在子二代又出现；控制相对性状的基因有显性和隐性之分；DD、Dd 表现显性，dd 表现隐性 |
| 一句概念 | 隐性性状在子二代又出现了 |
| 核心动作 | 让子一代自花传粉、种下子二代；数一数；和孟德尔的数比；用基因解释 |
| 读数 | 这一畦 96 株里高茎、矮茎各多少（`f2Bed`）；孟德尔 787 ∶ 277 = 2.84 ∶ 1 |
| 对应小测 | 第 5、6 题 |

任务清单

- [ ] 让子一代自己传粉，种下收到的种子
- [ ] 数一数子二代里的高茎和矮茎
- [ ] 和孟德尔数的比一比
- [ ] 用 D 和 d 解释为什么约 3∶1

主操作区：种下子二代、数一数、用基因解释。

## 第 6 课 人的性别遗传

| 项目 | 内容 |
|---|---|
| 知识点 | 人的体细胞有 23 对染色体，其中 22 对男女一样，1 对决定性别，叫性染色体；男 XY，女 XX；男性产生含 X 和含 Y 两种精子，女性只产生含 X 的卵细胞；两种精子和卵细胞结合的机会相等，生男生女机会均等 |
| 一句概念 | 生男生女的机会均等 |
| 核心动作 | 切换男 / 女，看排好序的染色体，找出性染色体；模拟摸棋子，每次 10 次，摸满 50 次 |
| 读数 | 46 条、23 对；摸 50 次里男孩、女孩各几次 |
| 对应小测 | 第 7 题 |

任务清单

- [ ] 看男性的染色体，找出性染色体
- [ ] 换成女性，比一比哪一对不一样
- [ ] 模拟精子和卵细胞随机结合，摸 10 次
- [ ] 一共摸满 50 次，看男孩和女孩的比例

数据：`KARYOTYPE`；`draws(50, seed)`。

## 第 7 课 生物的变异

| 项目 | 内容 |
|---|---|
| 知识点 | 亲子间和子代个体间的差异叫变异；遗传物质发生改变引起的是可遗传的变异，只由环境引起、遗传物质没变的是不可遗传的变异 |
| 一句概念 | 遗传物质改变的变异才能遗传 |
| 核心动作 | 选品种；量 20 粒（卡尺一粒粒量，读数进记录表和小图）；判断两个例子是哪种变异 |
| 读数 | 每粒长度；两品种的平均长度 |
| 对应小测 | 第 8 题 |

任务清单

- [ ] 量大花生，随机取 20 粒
- [ ] 换成小花生，也量 20 粒
- [ ] 比一比两个品种的平均长度
- [ ] 判断：大花生种在贫瘠的土里结的果实小，这种变异能不能遗传

数据：`peanuts`（示意）。

## 讲解

自动演示的解说词在 `src/labs/gene/narration.ts`。要特别讲清楚的：第 3 课“每对一条来自父方、一条来自母方”要在受精后讲；第 5 课先数后解释，不要先报 3∶1；第 6 课说明“摸后放回”。

## 和规格卡原文的出入

- 第 7 课原想种在两种土里看变异，改成教材上的“花生果实大小的变异”探究，判断放在最后一条任务。
- 第 3 课原写四条任务，“受精”和“数受精卵、看每对从哪来”合成一条，共三条。
- 第 5 课主操作区：种下子二代、数一数（数完变成“和孟德尔比”）、用基因解释。
- 拓展课的测交只用一个按钮，先甲后乙（每课最多一组分段选择，分段选择用来切换两个实验）。

## 画面上的约定

- 画面里 1 个单位约等于 10 cm。第 1 课样品台上的两枝花、第 4 课推近看的那朵花、拓展课的豆荚是放大了画的，结论卡里写明。
- 子一代畦 24 株、子二代畦 96 株、测交后代 8 株，都是示意的株数；子二代每株的基因组成按 Dd × Dd 随机生成（固定种子，每次一样：高茎 73、矮茎 23）。
- 第 6 课的模拟用固定种子：摸 50 次男孩 25 次、女孩 25 次。
- 拓展课 4 个豆荚共 28 粒（7、6、8、7），圆粒 21、皱粒 7，同样是固定种子的随机结果。
- 第 2 课、第 3 课、第 6 课的染色体、DNA 都是模型：染色体画成盘绕的染色质丝，长短只表示相对大小；人的 23 对的相对长度是示意。
