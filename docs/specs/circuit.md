状态：九个课次（1–7、拓展、随堂检测）按这张卡做完（2026-11-23），待验收。首页清单 `src/labs.ts` 的卡片和封面线稿还没加。关联议题 #11。

## 总览

- **一句话**：学生在一套正在做水电改造的毛坯房里，用电池盒、小灯泡、开关和导线在工作台上亲手连电路：先认通路、断路、短路，再比串联和并联（拆一只灯看另一只）；然后学会用电流表、电压表（选量程、分正负接线柱、读数），自己测出串联、并联电路里电流和电压的规律；最后用电阻示教板和滑动变阻器弄清电阻跟什么有关、变阻器怎样改变电流。拓展课看这套房子里真的电路：楼梯灯的双控开关、并联的插座。
- **教材位置**：物理，初中九年级全一册。人教版第十五章“电流和电路”（电流和电路；串联和并联；电流的测量；串、并联电路中电流的规律）、第十六章“电压 电阻”（电压；串、并联电路中电压的规律；电阻；变阻器）。章节号和节名见“待核实事项”。
- **主线**：同一只电池盒（两节干电池，3 V）和两只规格不同的小灯泡 L₁、L₂，从第 1 课用到第 7 课。
- **场景**：一套正在装修的复式住宅，水电改造阶段：水泥地坪、抹灰墙上开着槽、槽里埋着红蓝两色的线管和接线底盒，顶上吊着一只临时灯泡；靠窗一张马凳搭的长工作台，屋子中间一张折叠工作台，右边是上二楼的混凝土楼梯，墙角有配电箱、人字梯、电线盘、乳胶漆桶。选它的理由：议题建议的就是装修中的房子；水电改造时电线、开关、插座都露在外面，学生能直接看到课上连的电路和家里墙里的电路是一回事；拓展课的双控开关和插座就在同一套房子里，不用另搭场景。
- **取值约定**：一节干电池 1.5 V，电池盒里两节串联 3.0 V；电池的内阻、导线的电阻不计；电流表、电压表当作理想电表（电流表不分压，电压表不分流）。小灯泡当作阻值不变的用电器：L₁ 10 Ω、L₂ 15 Ω（简化，见“画面上的约定”）。电流用 A，保留两位小数；电压用 V，保留一位小数；电阻用 Ω。电流表量程 0–0.6 A（分度值 0.02 A）和 0–3 A（0.1 A）；电压表量程 0–3 V（0.1 V）和 0–15 V（0.5 V）。家庭电路电压 220 V。
- **和同类产品的区别**：电路是真的一根根导线连起来的：导线从接线柱上拧出来、弯着落到台面、再拐进下一个接线柱；电流沿导线流成一串亮点，从电源正极出发，经过用电器回到负极，并联时在分支处分成两股、到汇合处又合成一股。电表是课堂上那种表：斜面表盘上两排刻度、三个接线柱，指针会摆过头再停稳，接反时打到左边的限位，超过量程时打到右边的限位；读数要自己看对哪一排刻度。

## 第 1 课 电路的组成

| 项目 | 内容 |
|---|---|
| 知识点 | 电路由电源、用电器、开关、导线组成；通路、断路、短路；电流从电源正极经用电器流向负极 |
| 一句概念 | 电流要有一条闭合的路才流得动 |
| 核心动作 | 闭合开关；断开开关；接上一根短路导线再拿掉 |
| 看到的现象 | 通路：灯亮，导线上的亮点从正极出发绕一圈回到负极；断路：亮点停了，灯灭；短路：亮点在短路导线上飞快地跑，灯不亮，电池发红变热 |
| 读数 | 面板：电路状态（通路 / 断路 / 短路）、灯泡亮不亮、电源电压 3.0 V |
| 对应小测 | 第 1 题（短路的危害） |

任务清单

- [ ] 闭合开关，让灯泡亮起来（通路）
- [ ] 断开开关，看灯泡和电流（断路）
- [ ] 闭合开关，再用一根导线把电池盒的两个接线柱直接连起来（短路）
- [ ] 赶快拿掉这根导线

按钮：闭合开关 / 断开开关、接上短路导线 / 拿掉导线。电流方向的亮点一直显示。短路导线接上约 1.5 秒后（电池开始发红）才能拿掉，让学生看清。

## 第 2 课 串联和并联

| 项目 | 内容 |
|---|---|
| 一句概念 | 串联一条路，并联几条路 |
| 核心动作 | 选串联或并联；闭合开关；拧下 L₁ |
| 看到的现象 | 串联：两灯都亮但较暗，拧下 L₁，L₂ 也灭；并联：两灯都较亮，拧下 L₁，L₂ 照常亮；电流亮点在并联的分支处分成两股 |
| 读数 | 面板：电流的路径有几条、L₁ 和 L₂ 亮不亮、电路图 |
| 对应小测 | 第 2 题 |

任务清单

- [ ] 串联：闭合开关，看两只灯
- [ ] 拧下 L₁，看 L₂
- [ ] 换成并联，闭合开关
- [ ] 再拧下 L₁，看 L₂

按钮：闭合开关、拧下 L₁ / 装回 L₁。分段选择：连接方式（串联 / 并联）。换连接方式时先断开开关、装回灯泡，导线重新连好。

## 第 3 课 电流和电流表

| 项目 | 内容 |
|---|---|
| 一句概念 | 电流表要串联，电流从“+”进、从“−”出 |
| 核心动作 | 选接线柱（大量程试触 / 小量程 / 接反）；闭合开关；读数 |
| 看到的现象 | 用 0–3 A：指针只偏一点（0.3 A），读不准；改用 0–0.6 A：指针偏到一半，读 0.30 A；接反：指针向左打到头 |
| 读数 | 电流表 0.30 A；面板放大的表盘，标出该读的那一排刻度 |
| 对应小测 | 第 3、4 题 |

任务清单

- [ ] 用“−”和“3”两个接线柱（0–3 A），闭合开关试触
- [ ] 指针偏得太小：改用“−”和“0.6”（0–0.6 A），读出电流
- [ ] 把正负接线柱接反，闭合开关看指针

按钮：闭合开关 / 断开开关、记下读数。分段选择：电流表的接法（−、3 / −、0.6 / 正负接反）。

## 第 4 课 串、并联电路中电流的规律

| 项目 | 内容 |
|---|---|
| 一句概念 | 串联处处相等，并联干路等于支路之和 |
| 核心动作 | 选电流表接在 A、B、C 哪一处；记录；换成并联再测 |
| 读数 | 串联 I_A = I_B = I_C = 0.12 A；并联 I_A（L₁ 支路）0.30 A、I_B（L₂ 支路）0.20 A、I_C（干路）0.50 A |
| 对应小测 | 第 5 题 |

任务清单

- [ ] 串联：电流表接在 A 处，记一次
- [ ] 再接到 B、C 两处，各记一次
- [ ] 换成并联：在 L₁、L₂ 两条支路上（A、B）各记一次
- [ ] 在干路上（C）记一次

按钮：记录数据、换成并联电路。分段选择：电流表接在（A / B / C）。换位置时先断开开关，电流表挪过去、导线接好再闭合。

## 第 5 课 电压和电压表

| 项目 | 内容 |
|---|---|
| 一句概念 | 电压表要并联在被测的两点之间 |
| 核心动作 | 选电池节数；接上电压表；三节时换 15 V 量程 |
| 读数 | 一节 1.5 V、两节 3.0 V（0–3 V 量程）；三节用 0–3 V 指针打到头，换 0–15 V 读 4.5 V |
| 对应小测 | 第 6 题 |

任务清单

- [ ] 把电压表并联在一节干电池两端（0–3 V），读数
- [ ] 换成两节串联，读数
- [ ] 换成三节：指针超过了满刻度，换用 0–15 V，读数

按钮：接上电压表 / 拿开、换用 0–15 V / 0–3 V 量程。分段选择：电池（一节 / 两节 / 三节）。

|---|---|

| 读数 | 串联 U₁ 1.2 V、U₂ 1.8 V、U 3.0 V；并联都是 3.0 V |
| 对应小测 | 第 7 题 |

任务清单

- [ ] 串联：电压表接在 L₁ 两端，记一次
- [ ] 再接在 L₂ 两端、电源两端，各记一次
- [ ] 换成并联：L₁、L₂、电源两端各记一次

按钮：记录数据、换成并联电路。分段选择：电压表接在（L₁ 两端 / L₂ 两端 / 电源两端）。

## 第 7 课 电阻和滑动变阻器

| 项目 | 内容 |
|---|---|
| 一句概念 | 导体越长、越细，电阻越大 |
| 器材 | 电阻示教板：a 镍铬合金 0.5 m 细、b 镍铬合金 0.25 m 细、c 镍铬合金 0.5 m 粗（横截面积是细的 2 倍）、d 锰铜合金 0.5 m 细；滑动变阻器“20 Ω 2 A”；灯泡 L₁；电流表 0–0.6 A |
| 读数 | a 0.15 A、b 0.20 A、c 0.20 A、d 0.21 A；滑动变阻器：滑片在阻值最大处 0.10 A，移到另一端 0.30 A |
| 对应小测 | 第 8、9 题 |

金属丝的阻值：细丝横截面积取 0.055 mm²，a = 1.1 × 0.5 ÷ 0.055 = 10 Ω，b = 5 Ω，c = 5 Ω，d = 0.44 × 0.5 ÷ 0.055 = 4 Ω。电流 I = 3 V ÷ (10 Ω + R丝)。界面上只出电流和“长、短、粗、细、材料”，不出横截面积的数。

任务清单

- [ ] 把 a 接进电路，记下电流
- [ ] 换成 b（长度减半），记下电流
- [ ] 换成 c（横截面积加倍），记下电流
- [ ] 换成 d（换一种材料），记下电流
- [ ] 换成滑动变阻器，把滑片从阻值最大的一端移到另一端

按钮：记录数据、滑片移到另一端。分段选择：接入电路的是（a / b / c / d / 滑动变阻器）。滑片可以直接拖。

## 画面上的约定

- 1 m 画成 10 个单位（1 cm 是 0.1 个单位），房子和桌上的器材是同一个比例：两节电池的电池盒长 15.6 cm，灯座底板 7 cm，电表 12.8 cm 宽，滑动变阻器约 28 cm 长，电阻示教板 62 cm，工作台面高 80 cm；客厅挑空两层，层高 6 m，二楼走廊和楼梯平台高 3 m。
- 示教板上的金属丝画粗了：细的画成直径 1.7 mm，粗的 2.6 mm，否则在画面上看不见。
- 人手：拧灯泡、扳开关、挪电流表时，出现一只带工装袖子的线手套，动作一完就收走。
- 小灯泡当作阻值不变的用电器（L₁ 10 Ω、L₂ 15 Ω）。真实的灯丝电阻随温度升高而变大，这里不计。灯泡的亮度按实际功率和 0.9 W 的比来画，只是看得出“较亮、较暗、不亮”，不是测出来的。
- 导线上的亮点表示电流的方向（从正极经用电器回到负极），跑得快慢大致和电流大小一致。它不是电子：电子的移动方向和电流方向相反，原理里写明。
- 短路时电池不计内阻电流就是无穷大，这里不出数字，只画“电流很大、电池发热”，三秒后提示拿掉导线。
- 换连接方式、换电表位置时，开关先自动断开，导线重新连好后再闭合。真实实验里也要求断开开关再接线。
- 双控开关、插座这些家庭电路只画示意，墙里的线管和接线盒不对应某一份施工图。
- 第 1 课短路时界面只说“电池发热”，不出温度和电流的数。
