# 地震实验室 · 规格卡 v1.0（重做）

状态：九个课次（1–7、拓展、随堂检测）按现行规范重做完，待验收。关联议题 #42。

## 总览

- **一句话**：学生在龙门山的沙盘上让断层错动、标出震源和震中，比较一次地震的震级和各地的烈度，在河谷小镇看纵波横波先后到达，给几座城市发地震预警，用三个台站画圆找震中，再剖开地球看地震波怎样揭示地球内部，最后摇一摇不同高度的楼，弄懂“地震是怎么发生、怎么传播、怎么防”。
- **教材位置**：高中地理必修第一册。地震、震级和烈度、防震减灾在“自然灾害”一章；地震波、莫霍界面、古登堡界面在“地球的圈层结构”一节。版本、章节号见“待核实事项”。
- **主线**：2008 年 5 月 12 日的汶川地震（8.0 级，震中映秀，震源深度 14 km）。前四课都是这一次地震；第 5 课换成一次假想的小地震；第 6 课在整个地球的尺度上看地震波。
- **场景**：三处，在同一个世界里，换课时镜头飞过去。
- **取值约定**：地壳里纵波 6.0 km/s、横波 3.5 km/s；能量 lg E = 4.8 + 1.5 M（J）；预警系统处理 8 s；楼的固有周期 ≈ 层数 × 0.1 s；阻尼比 5%（装阻尼器后 20%，示意）；地球模型参照 PREM 取整；纵波影区按课本取 104°–143°。
- **和同类产品的区别**：常见的是看一段动画或一张示意图。这里每课学生都亲手触发一件事（让断层错动、发预警、画圆、摇楼），并读出一个数（震中距、烈度、能量倍数、时间差、提前几秒、震中位置、界面深度、晃动倍数）。

## 共用的计算核心（`physics.ts`）

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `tP`、`tS`、`lagSP` | 震中距 d、震源深度 h | 纵波、横波走时，横波晚到几秒 | 直线传播，震源距 √(d² + h²)，6.0 / 3.5 km/s |
| `groundRadius` | 波速、时间、深度 | 波前在地面上的半径 | 球面波和地面的交线 |
| `energy`、`energyRatio` | 震级 | 能量（J）、能量倍数 | lg E = 4.8 + 1.5 M |
| `depthType` | 深度 | 浅源 < 70 km ≤ 中源 ≤ 300 km < 深源 | 课本分类 |
| `rupture`、`intensity`、`cityIntensity` | 震级、位置 | 烈度（度） | 破裂带长度 lg L = 0.59 M − 2.44；I = 10.2 + 1.5 M − 7.95 lg(R + 10)，示意 |
| `alertTime`、`leadTime`、`blindRadius` | 城市 | 警报时刻、提前时间、盲区半径 | 警报 = 最近台站的纵波到时 + 8 s；提前 = 城市横波到时 − 警报 |
| `stationLag`、`radiusFromLag`、`locate`、`circleCross` | 台站 | 时间差、圆的半径、交点 | D = 时间差 × 8.4 km/s，震中距 = √(D² − h²)；最小二乘找交点 |
| `vel`、`traceRay`、`rayFan`、`receives` | 半径、射线角 | 波速、射线、能否收到 | 简化 PREM；射线参数守恒；影区 104°–143° |
| `natPeriod`、`response`、`buildingTR`、`worst` | 层数、地震波周期、阻尼 | 楼顶晃动是地面的几倍、相位 | 单自由度振子的传递率 |
| `seismogram` | 距离 | 合成的两分量记录 | 示意的波形，到时按上面的走时 |

沙盘上城镇的位置由各地经纬度换算（以映秀为原点向东、向北的千米数），城市之间的距离是约数。

## 第 1 课 地震发生

| 项目 | 内容 |
|---|---|
| 知识点 | 震源、震中、震源深度、震中距；按震源深度分浅源、中源、深源 |
| 一句概念 | 震源在地下，震中在它正上方的地面 |
| 核心动作 | 剖开地面 → 断层错动 → 标出震中 → 量震中距 |
| 看到的现象 | 映秀以南的一条地块滑开，露出剖面：岩层、向西北倾斜的断层；断层上盘沿断层往上错动，地下 14 km 处亮起震源，波前一圈圈扩开；一条竖线从震源升到地面；地面上一条线从映秀连到成都 |
| 读数 | 震源深度 14 km（浅源地震）；成都的震中距约 70 km |
| 真实锚点 | 汶川地震：8.0 级，震中映秀，震源深度 14 km |
| 对应小测 | 第 1 题（震中是震源正上方的地面） |

任务：剖开地面；让断层错动；标出震中；量出成都的震中距。按钮三个：剖开地面 / 断层错动（同一个位置先后出现）、标出震中、量震中距。

## 第 2 课 震级和烈度

| 项目 | 内容 |
|---|---|
| 知识点 | 震级表示释放能量的多少，一次地震只有一个；烈度表示地面受影响和破坏的程度，各地不同，离震中越远一般越低；震级每大 1 级，能量约大 32 倍 |
| 一句概念 | 震级只有一个，烈度处处不同 |
| 核心动作 | 发生 8.0 级地震；看城镇的烈度；换 7.0 级再来一次 |
| 看到的现象 | 沙盘上按烈度上色，沿龙门山拉长的一圈圈色带；各城镇挂上烈度 |
| 读数 | 8.0 级：映秀 11 度，成都 7 度，北川 11 度（示意）；7.0 级：映秀 10 度、成都 6 度；能量 8.0 级约 6.3×10¹⁶ J，是 7.0 级的约 32 倍 |
| 真实锚点 | 汶川地震最高烈度 11 度，在映秀和北川一带 |
| 对应小测 | 第 2 题（震级和烈度的个数） |

任务：发生 8.0 级地震；读映秀和成都的烈度；换成 7.0 级再发生一次。按钮：发生地震；分段选择：8.0 级 / 7.0 级。

## 第 3 课 纵波和横波

| 项目 | 内容 |
|---|---|
| 知识点 | 纵波快、横波慢；纵波上下颠、横波左右晃；纵波能在固体、液体、气体中传播，横波只能在固体中传播 |
| 一句概念 | 纵波快，先颠；横波慢，后晃 |
| 核心动作 | 发生地震看房子；看水库里的船；换成离震中 100 km |
| 看到的现象 | 剖面上蓝色的纵波波前先升上来，地面的点上下动，房子上下颠；橙色的横波后到，点左右动，房子左右晃；横波到水库底就没了，船只上下颠；面板上的地震记录先出现小而快的纵波，再出现大的横波 |
| 读数 | 离震中 60 km：纵波约 10.3 s、横波约 17.6 s 到，晚 7.3 s；30 km 晚 3.9 s；100 km 晚 12.0 s（震源深 14 km） |
| 真实锚点 | 地壳里纵波约 6 km/s、横波约 3.5 km/s |
| 对应小测 | 第 3、4 题 |

任务：发生地震，看房子先颠还是先晃；看水库里的船；换到离震中 100 km，读横波晚到几秒。按钮：发生地震、看水库 / 看房子；分段选择：离震中 30 / 60 / 100 km。画面放慢（快放的时钟写明）。

## 第 4 课 地震预警

| 项目 | 内容 |
|---|---|
| 知识点 | 电磁波比地震波快得多；纵波比横波快；台站测到纵波就发警报，抢在破坏性的横波之前；离震中太近来不及（盲区） |
| 一句概念 | 纵波先到报信，横波后到破坏 |
| 核心动作 | 发生地震看警报；在都江堰、成都、绵阳之间切换读数 |
| 看到的现象 | 地面上蓝圈（纵波）、橙圈（横波）扩开；最近的台站闪亮，处理 8 s 后警报发出，各城市同时亮起；盲区是一圈红色 |
| 读数 | 警报在地震后约 10.5 s 发出；都江堰来不及（横波早到约 4.8 s，在盲区里）；汶川县城约 3.8 s；成都约 10.0 s；绵阳约 24.5 s；盲区半径约 34 km |
| 真实锚点 | 汶川地震时还没有地震预警系统；这一课是“如果今天再发生一次”的示意 |
| 对应小测 | 第 5、6 题 |

任务：发生地震，看警报怎么发出；读成都能提前几秒；读绵阳；看都江堰为什么收不到。按钮：发生地震；分段选择：都江堰 / 成都 / 绵阳。时钟快放 2 倍。

## 第 5 课 找到震中

| 项目 | 内容 |
|---|---|
| 知识点 | 横波比纵波晚到的时间越长，离震源越远；一个台站只知道距离，三个台站画圆交于一点 |
| 一句概念 | 三个台站画三个圆，交点就是震中 |
| 核心动作 | 依次读 A、B、C 三台的时间差、画圆；标出震中 |
| 看到的现象 | 沙盘正上方俯视；每画一个圆，圆从台站往外长到算出的半径；两个圆交出两点，第三个圆把一点挑出来 |
| 读数 | A 台 3.2 s → 震中距约 25 km；B 台 5.3 s → 约 43 km；C 台 6.5 s → 约 54 km（假想地震，震源深 10 km） |
| 对应小测 | 第 7 题（两个台站定不了） |

任务：画 A 台的圆；画 B 台的圆；画 C 台的圆；标出震中。按钮：画下一个圆、标出震中。

## 第 6 课 看穿地球

| 项目 | 内容 |
|---|---|
| 知识点 | 地震波速度在莫霍面明显加快、在古登堡面纵波突然变慢横波消失；地壳、地幔、外核（液态）、内核；影区 |
| 一句概念 | 横波到古登堡面消失，外核是液态 |
| 核心动作 | 发生地震看射线；分段选择看莫霍面、古登堡面；标出影区 |
| 看到的现象 | 切掉四分之一的地球，两个切面上是各圈层；蓝色纵波射线弯着穿过地幔，进外核折一下再出来；橙色横波射线碰到外核就停；地面上 104°–143° 是一段没有射线到达的灰带 |
| 读数 | 古登堡面约 2900 km；内外核分界约 5150 km；莫霍面以下纵波从约 6.5 加快到约 8.0 km/s；古登堡面纵波从约 13.7 降到约 8.0 km/s，横波从约 7.3 降到 0 |
| 对应小测 | 第 8 题 |

任务：发生地震，看两种波穿过地球；看莫霍面；看古登堡面；标出影区。按钮：发生地震、标出影区；分段选择：莫霍面 / 古登堡面。

## 第 7 课 房屋抗震

| 项目 | 内容 |
|---|---|
| 知识点 | 楼越高，自己来回晃一次的时间（固有周期）越长；地震波的周期和它接近就会共振；阻尼器、隔震等抗震措施 |
| 一句概念 | 楼和地震波合拍，就会共振 |
| 核心动作 | 选地震波的周期，开始摇；给 20 层楼装阻尼器 |
| 看到的现象 | 三栋楼一起晃，合拍的那栋楼顶甩得最远；装了阻尼器的楼晃得小多了 |
| 读数 | 楼顶晃动是地面的几倍：0.3 s 波 → 3 层约 10 倍；1 s → 10 层约 10 倍；2 s → 20 层约 10 倍，装阻尼器后约 2.7 倍 |
| 对应小测 | 第 9 题 |

任务：用 1 s 的地震波摇，找出晃得最凶的楼；换成 2 s；给 20 层楼装阻尼器。按钮：开始摇 / 停下、装阻尼器；分段选择：0.3 s / 1 s / 2 s。

## 讲解

`src/labs/quake/narration.ts`。要讲清楚的地方：第 1 课震源和震中一个在地下、一个在地面；第 3 课提醒看船只上下动；第 4 课都江堰为什么来不及；第 7 课“不是越高越危险，是合拍才危险”。

## 和规格卡原文的出入

- 议题建议第 2 课讲地基对烈度的影响。软土放大晃动只在第 2 课原理里说明，没有单独做任务（一课只允许一组分段选择，已用于震级）。
- 旧版第 6 课有“软土地基”“隔震支座”两个开关；新版只保留阻尼器，隔震写进原理。
- 简化地球模型里有一两条穿过内核的纵波射线会落进影区，这几条不画（`rayFan` 里过滤）。
- 第 3 课的“民房”、地震台小房子、水库都在河谷小镇里；小镇离震中多远由分段选择设定（30 / 60 / 100 km），小镇本身是示意的地方，不对应汶川地震里的某个镇。
- 第 5 课面板上列的是“到震源的距离”（约 27、44、55 km），沙盘上画圆用的是扣掉震源深度后的震中距（约 25、43、54 km）。
- 拓展课“预警响了”的倒计时按 10 s（`SCHOOL_LEAD`，示意），时钟快放 2 倍。
