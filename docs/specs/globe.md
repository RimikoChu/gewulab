# 地球和经纬网实验室 · 规格卡 v0.1

状态：九个课次（1–7、拓展、随堂检测）做完（2026-11-26），待验收。关联议题 #35。

## 总览

- **一句话**：学生在一艘远洋科考船上，看远处的船从海平线上露出来，转一只大地球仪，读卫星定位屏，在海图上判方向，弄懂地球的形状、经线纬线、经纬度定位和半球的划分。
- **教材位置**：地理，初中。人教版七年级上册《地球和地图》里讲“地球和地球仪”的一节（地球的形状和大小、地球仪、纬线和纬度、经线和经度、经纬网）。准确的章节号见“待核实事项”。
- **主线**：一艘远洋科考船。船上的“地球仪大厅”里有一只直径 1.27 米的大地球仪，驾驶台上有卫星定位屏和海图桌，夜里在罗经甲板上用六分仪量北极星。
- **取值约定**：地球平均半径 6371 km；赤道周长约 4 万 km（2π × 6371 ≈ 40 030 km）；长度一律按地球是正球体算，显示为“万 km”，保留两位小数；地球仪的地轴和地面的夹角 66.5°；经度 0°–180°（东经 E、西经 W），纬度 0°–90°（北纬 N、南纬 S）；东西半球的分界是 20°W 和 160°E 组成的经线圈，20°W 以东、160°E 以西是东半球。
- **和同类产品的区别**：同类产品多是一只会转的数字地球。这里每课都要学生自己动手：让船开近、选纬线经线、在海图上点出船的位置、把地球劈成两半，读一个数、得出一句结论。地球仪按真地球仪做：黄铜子午圈带刻度、木支架、地轴倾斜、球面上印着经纬网和度数。

## 共用的计算核心

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `parallelLength(纬度)` | 纬度 | 这条纬线的长度（km）= 2πR × cos 纬度 | 正球体的几何关系 |
| `meridianLength()` | — | 一条经线的长度（km）= πR | 经线是半个大圆 |
| `globeScale()` | 地球仪直径 | 比例尺分母 = 地球直径 ÷ 地球仪直径 | 12 742 km ÷ 1.2742 m = 1 000 万 |
| `latText` / `lonText` | 纬度、经度 | “北纬 30°”“东经 120°”“0°”“180°”，以及简写“30°N”“120°E” | 教材写法 |
| `hemiNS` / `hemiEW` | 纬度 / 经度、分法 | 北半球 / 南半球；东半球 / 西半球 | 教材的分法 |
| `direction(甲, 乙)` | 两点经纬度 | 乙在甲的哪个方向（八个方向） | 经度差定东西，纬度差定南北；经度差取不超过 180° 的那一边 |
| `hiddenHeight(距离)` | 货轮离观察者的距离 | 被海面挡住的高度（m，示意） | (d − √(2Rh))² ÷ 2R，R 用示意的海面半径 |
| `polarisAltitude(纬度)` | 纬度 | 北极星的高度角 ≈ 当地纬度 | 北天极的高度等于纬度 |
| `arcLength(纬度差或经度差, 所在纬度)` | 度数 | 沿经线、沿纬线走过的距离（km） | 每度 = πR ÷ 180 ≈ 111.2 km；沿纬线再乘 cos 纬度 |

## 每一课

### 第 1 课 地球是个球体

| 项目 | 内容 |
|---|---|
| 一句概念 | 海面是弯的，地球是个球体 |
| 核心动作 | 让货轮分三段开近，每段记下露出海面的比例；把海面换成平的再看 |
| 看到的现象 | 货轮在远处只露出生活楼和集装箱，船身下半截藏着，开近才整条露出；海面是平的时，远处的船整条都看得见，只是小 |
| 任务 | ① 货轮在 570 m，记一次 ② 开近到 470 m，记一次 ③ 开到 330 m，记一次 ④ 把海面换成平的，看远处的船 |
| 结论 | 船先露桅杆后露船身，说明海面是弯的；地球是个球体 |

示意：海面画成半径 2000 m 的球面，弯曲被放大了很多倍（真实地球要几十千米外才看得出），界面标“示意”。

### 第 2 课 地球仪

| 项目 | 内容 |
|---|---|
| 一句概念 | 地球仪是缩小的地球模型 |
| 任务 | ① 让地球仪自西向东转一圈 ② 量地球仪的直径，算出比例 ③ 量地轴的倾角 |
| 读数 | 直径 1.27 m，比例 1 : 1000 万；地轴和地面夹角 66.5°；地球平均半径 6371 km、赤道周长约 4 万 km |
| 结论 | 地球仪把地球缩小了约一千万倍；地轴穿过南北两极，斜着和地面成 66.5° |

### 第 3 课 纬线和纬度

| 项目 | 内容 |
|---|---|
| 一句概念 | 纬线是圆圈，越往两极越短 |
| 任务 | ① 选赤道，记下长度 ② 选 30°N ③ 选 60°N ④ 选 30°S ⑤ 选 90°N |
| 读数 | 4.00、3.47、2.00、3.47 万 km；90°N 是一个点 |
| 结论 | 纬线是圆圈，指示东西方向；赤道最长，向两极变短，到极点成了一个点。赤道以北是北纬，以南是南纬 |

### 第 4 课 经线和经度

| 项目 | 内容 |
|---|---|
| 一句概念 | 经线是半圆，长度都相等 |
| 任务 | ① 找到本初子午线（0°） ② 选 120°E ③ 选 60°W ④ 选 180° 经线 |
| 读数 | 都是 2.00 万 km |
| 结论 | 经线连接南北两极，指示南北方向，长度都相等。0° 以东是东经，以西是西经，到 180° 会合 |

### 第 5 课 用经纬网定位

| 项目 | 内容 |
|---|---|
| 一句概念 | 有了经度和纬度，就能确定位置 |
| 任务 | ① 第一站，选出船的位置 ② 第二站 ③ 第三站 |
| 读数 | 卫星定位屏：10°N 170°E、10°S 170°W、10°N 170°W；海图上四个点 A（10°N 170°E）B（10°N 170°W）C（10°S 170°E）D（10°S 170°W） |
| 结论 | 先看纬度定南北，再看经度定东西。过了 180° 经线，东经变西经 |

### 第 6 课 半球的划分

| 项目 | 内容 |
|---|---|
| 一句概念 | 赤道分南北，20°W 和 160°E 分东西 |
| 任务 | ① 用赤道分南北半球 ② 试试用 0° 和 180° 经线分 ③ 换成 20°W 和 160°E 分东西半球 |
| 读数 | 四座城市落在哪个半球（见数据表） |
| 结论 | 赤道以北是北半球；20°W 和 160°E 组成的经线圈把地球分成东西半球，这样不会把欧洲、非洲劈开 |

### 第 7 课 经纬网上的方向

| 项目 | 内容 |
|---|---|
| 一句概念 | 经线指南北，纬线指东西 |
| 任务 | ① 从出发点到甲，判断方向 ② 到乙 ③ 到丙 |
| 读数 | 正北、正东、东北 |
| 结论 | 沿着经线走是南北方向，沿着纬线走是东西方向；经度、纬度都不同时，两个方向合起来 |
