# 圆锥曲线实验室 · 规格卡 v0.1

状态：九个课次（1–7、拓展、随堂检测）做完（2026-11-27），待验收。关联议题 #81。

## 总览

- **一句话**：学生在一座射电观测站里，从切圆锥的模型、两钉一绳的大画板、坐标屏，一路看到抛物面天线和天象厅，弄懂椭圆、双曲线、抛物线各是怎么定义的、标准方程里的 a、b、c、p、e 各管什么，以及它们的光学性质用在哪里。
- **教材位置**：数学，高中。人教 A 版选择性必修第一册第三章“圆锥曲线的方程”：椭圆、双曲线、抛物线。准确的节号、章引言和阅读材料的标题见“待核实事项”。
- **主线**：“焦点”。每一课的图上都有焦点：两颗钉子、屏上的 F₁ 和 F₂、天线的馈源、轨道盘上的太阳。颜色全间统一：曲线金黄，焦点橙红，两条焦半径一青一粉，准线紫，渐近线淡蓝，光线和电波亮黄。
- **场景**：高原上的一座射电观测站。远处有两座发电厂的冷却塔和一圈山。
- **取值约定**：长度单位：画板上是 dm，坐标屏上是“单位”，天线和回音壁是 m，轨道用天文单位 AU。读数最多保留两位小数（轨道的近日点、远日点保留三位），去掉末尾的 0。角度用度。
- **为了看得清做的简化**：切圆锥用的是一片“光幕”，能直接穿过模型；轨道盘上三条轨道的长半轴画成一样长，只比形状；天线口朝天不转动，电波只画截面里的六条；回音壁的声音只画八路，画在墙顶稍高的平面上。
- **和同类产品的区别**：同类产品多是坐标纸上拖滑块。这里每条曲线都长在一件真东西上：截口是光幕照出来的，椭圆是绳子画出来的，抛物线是天线的截面，轨道上的焦点是太阳。

## 共用的计算核心（`src/labs/conic/physics.ts`）

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `sectionType(β, α)`、`sectionEcc(β, α)` | 平面和轴的夹角 β、母线和轴的夹角 α | 截口的种类；离心率 cos β / cos α | 平面截圆锥 |
| `sectionCurve(β, y0, z0)` | 平面的方向和位置 | 截口在平面自己坐标里的折线（x² = k²y² − z²） | 圆锥方程和平面联立 |
| `ellipseB(a, c)`、`ecc(a, c)`、`ellipsePoint`、`focalRadii`、`ellipseValue` | a、c、点 | b = √(a² − c²)、e = c/a、椭圆上的点、到两焦点的距离、x²/a² + y²/b² 的值 | 椭圆的定义和标准方程 |
| `hyperC(a, b)`、`hyperPoint`、`asymSlope` | a、b | c = √(a² + b²)、双曲线上的点、渐近线斜率 b/a | 双曲线的标准方程 |
| `paraY`、`paraFocus`、`paraFocalDist`、`paraDirDist` | p、x | x² = 2py 上的点、焦点 (0, p/2)、到焦点和到准线 y = −p/2 的距离 | 抛物线的定义 |
| `reflect(d, n)`、`dishRay(p, x0, tilt)`、`dishPath` | 入射方向、法线；电波的落点和偏角 | 反射方向；反射线和轴的交点；波前到焦点的路程 | 反射定律 |
| `perihelion`、`aphelion`、`flatness`、`eccAnomaly`、`orbitAt` | a、e、走了一圈的几分之几 | a(1 − e)、a(1 + e)、b/a、开普勒方程的解、位置和到太阳的距离 | 椭圆的几何性质；开普勒方程 |
| `ellipseBounce`、`hyperBounce` | 曲线上的点 | 反射点、反射方向、路程 | 反射定律 |
| `towerR(y)`、`towerLine(φ, ±1, y)` | 离地高度 | 塔的半径 a√(1 + (y − 80)²/b²)；塔面上直线的点 | 单叶双曲面是直纹面 |

## 第 1 课 用平面切圆锥

两个对顶的亚克力圆锥，母线和轴的夹角 α = 30°，每一半高 1.2 m。外面套一个方框形的光幕架，框里是一片光。光幕沿自己的法线方向推进去，圆锥上被照亮的一圈就是截口，随着光幕推进连续变化。

| 项目 | 内容 |
|---|---|
| 知识点 | 用不过顶点的平面截圆锥，平面和轴的夹角 β 不同，截口是圆、椭圆、抛物线、双曲线 |
| 一句概念 | 平面的方向不同，截口不同 |
| 核心动作 | 选方向（分段选择），按“切下去” |
| 读数 | α = 30°；β = 90°、60°、30°、0°；截口的名称 |
| 对应小测 | 第 1 题 |

任务：① 光幕垂直于轴，切下去（圆）；② 斜一点 β = 60°（椭圆）；③ 平行于一条母线 β = 30°（抛物线）；④ 平行于轴 β = 0°（双曲线，两支）。

按钮：切下去。分段选择：光幕的方向（垂直于轴 / 斜一点 / 平行于母线 / 平行于轴）。

| 条件 | 读数 | 来历 |
|---|---|---|
| β = 90° | 圆；过顶点上方 0.66 m，半径 0.381 m | `sectionCurve` |
| α < β < 90° | 椭圆（e = cos 60° / cos 30° = 0.577，界面不显示） | `sectionEcc` |
| β = α | 抛物线（e = 1） | 同上 |
| β < α | 双曲线（e = 1.155） | 同上 |

## 第 2 课 两钉一绳画椭圆

大画板（每格 1 dm）上两颗钉子，一根 10 dm 的细绳两头拴在钉子上。戴手套的手拿粉笔铅笔绷紧绳子走一圈，线一点点画出来；板上一直显示两段绳长和它们的和。

| 项目 | 内容 |
|---|---|
| 知识点 | 椭圆的定义：到两定点的距离之和等于常数（大于两定点的距离）；焦点、焦距 |
| 一句概念 | 到两定点的距离之和是常数 |
| 核心动作 | 选钉距，按“画一圈” |
| 读数 | 两段绳长（随笔尖变）和它们的和 10 dm；2a = 10、2c、b |
| 对应小测 | 第 2 题 |

任务：① 钉距 6 dm 画一圈（b = 4，椭圆）；② 钉距 8 dm（b = 3，更扁）；③ 两钉重合（b = 5，圆）。

按钮：画一圈。分段选择：两钉的距离（6 dm / 8 dm / 0）。

## 第 3 课 椭圆的方程和离心率

坐标屏上的椭圆 x²/25 + y²/b² = 1，a = 5 不变，c 取 3、4、1.4。

| 项目 | 内容 |
|---|---|
| 知识点 | 标准方程；顶点、长轴、短轴；a² = b² + c²；离心率 e = c/a |
| 一句概念 | e = c / a 越大，椭圆越扁 |
| 核心动作 | 标出 a、b、c；验一个点；换 c |
| 读数 | a、b、c、e；点 (3, 3.2) 代入得 9/25 + 10.24/16 = 1 |
| 对应小测 | 第 3、4 题 |

任务：① c = 3 时标出 a、b、c（直角三角形，25 = 16 + 9）；② 验点 (3, 3.2)；③ c = 4（b = 3，e = 0.8）；④ c = 1.4（b = 4.8，e = 0.28）。

按钮：标出 a、b、c；验一个点。分段选择：c 的值。

## 第 4 课 双曲线

第二块坐标屏上的双曲线 x²/9 − y²/16 = 1（a = 3，b = 4，c = 5，e = 1.67）；换成 a = 4、b = 3（c = 5，e = 1.25）。

| 项目 | 内容 |
|---|---|
| 知识点 | 定义：到两定点的距离之差的绝对值是常数；标准方程；c² = a² + b²；渐近线 y = ±(b/a)x；离心率 |
| 一句概念 | 到两定点的距离之差的绝对值是常数 |
| 核心动作 | 让点 P 沿右支、左支各走一遍；画渐近线；换一条 |
| 读数 | |PF₁| − |PF₂|：右支上 6，左支上 −6；渐近线 y = ±4/3 x、±3/4 x；a、b、c、e |
| 对应小测 | 第 5、6 题 |

任务：① 走一遍；② 画渐近线（先画 2a × 2b 的矩形，对角线延长）；③ 换成 a = 4、b = 3。

按钮：走一遍；画渐近线。分段选择：双曲线（a = 3，b = 4 / a = 4，b = 3）。

## 第 5 课 抛物线：焦点和准线

天线朝镜头剖开一半，截面上立一块半透明的坐标平面，原点在反射面的顶点，1 单位 = 1 m。截面是 x² = 16y（p = 8 m，口径 12 m，口沿高 2.25 m），馈源在焦点 (0, 4)，准线 y = −4 画在顶点下方。

| 项目 | 内容 |
|---|---|
| 知识点 | 定义：到定点和到定直线的距离相等；标准方程 x² = 2py，焦点 (0, p/2)，准线 y = −p/2 |
| 一句概念 | 到焦点和到准线的距离相等 |
| 核心动作 | 按三次“量下一个点”；把 p 换成 4 |
| 读数 | (0, 0)：4 m、4 m；(4, 1)：5 m、5 m；(6, 2.25)：6.25 m、6.25 m；p = 4 时 x² = 8y，焦点 (0, 2) |
| 对应小测 | 第 7 题 |

任务：① 量顶点；② 量 x = 4；③ 量口沿 x = 6；④ 把 p 换成 4 比一比。

按钮：量下一个点。分段选择：p 的值（p = 8 天线 / p = 4 对比）。课本常用开口向右的 y² = 2px，这里因为天线口朝天，用的是 x² = 2py；原理和随堂检测里两种都出现。

## 第 6 课 天线为什么是抛物面

还是剖开的天线，换一个机位。截面里画六条电波（落点 x = ±2、±3.5、±5），沿路程匀速前进。

| 项目 | 内容 |
|---|---|
| 知识点 | 抛物线的光学性质：平行于轴的光线反射后过焦点；从焦点发出的光线反射后平行于轴 |
| 一句概念 | 平行于轴的光线，反射后过焦点 |
| 核心动作 | 三个按钮各按一次 |
| 读数 | 从 y = 9 的波前到焦点的路程，每条都是 13 m（= 9 + p/2）；偏 8° 时各条反射线和轴的交点不在一处 |
| 对应小测 | 第 8 题 |

任务：① 平行于轴射下来；② 偏 8° 射进来；③ 从焦点往反射面发射。

按钮：平行电波；斜着进来；从焦点发射。

## 第 7 课 行星的椭圆轨道

天象厅打开一半，里面斜放一块深色的轨道盘。盘上的轨道把长半轴都画成 3.3 m；天体按开普勒方程走（近日点快、远日点慢）。

| 项目 | 内容 |
|---|---|
| 知识点 | 行星轨道是椭圆，太阳在一个焦点上；近日点 a − c、远日点 a + c；离心率决定扁圆 |
| 一句概念 | 太阳在椭圆轨道的一个焦点上 |
| 核心动作 | 选天体，按“转一圈” |
| 读数 | 到太阳的距离（随位置变）；a、e、近日点、远日点 |
| 对应小测 | 第 9 题 |

| 天体 | a / AU | e | 近日点 / AU | 远日点 / AU |
|---|---|---|---|---|
| 地球 | 1 | 0.017 | 0.983 | 1.017 |
| 火星 | 1.524 | 0.093 | 1.382 | 1.666 |
| 哈雷彗星 | 17.8 | 0.967 | 0.587 | 35.013 |

任务：地球、火星、哈雷彗星各转一圈。按钮：转一圈。分段选择：天体。

## 讲解

解说词在 `src/labs/conic/narration.ts`。要特别讲清的地方：第 1 课每切完一种，在转向下一种之前说出截口的名称；第 2 课强调“两段绳长的和就是绳长”；第 4 课右支差是 6、左支差是 −6，所以定义里要取绝对值；第 6 课三种情况都要说出“所以馈源装在焦点上”“所以天线要对准天体”这两句因果。第 1、2、5、7 课重复出现的按钮提示用通用说法。

## 和规格卡原文的出入

- 议题里建议“平行电波汇聚到馈源、展厅里的圆锥模型、天象厅穹顶上的轨道”。做的时候圆锥模型、画板和坐标屏放在展厅楼前的露天广场上（背后的深色幕墙当背景），没有做展厅室内；轨道画在天象厅里斜放的轨道盘上，没有直接投在穹顶曲面上（曲面上的椭圆会变形）。
- 椭圆和双曲线的光学性质放在拓展课，抛物线的光学性质单独成第 6 课。
