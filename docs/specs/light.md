# 光的波动性和光电效应实验室 · 规格卡 v1.0

状态：待审。关联议题 #68。

## 总览

- 一句话：让学生亲手做出双缝干涉、薄膜干涉、衍射、偏振和光电效应，弄懂条纹间距 Δx = Lλ/d、截止频率和遏止电压，知道光既有波动性又有粒子性。
- 教材位置：高中物理 · 选择性必修第一册“光”（光的干涉、实验：用双缝干涉测量光的波长、光的衍射、光的偏振）；选择性必修第三册“原子结构和波粒二象性”（光电效应）。版本和章节号见“待核实事项”。
- 主线：一束光。前五课拿它做干涉、衍射、偏振，说明光是波（而且是横波）；后两课拿它照光电管，说明光的能量是一份一份的。拓展课用“一个一个光子攒出干涉条纹”把两头接起来。
- 场景：一间光学暗室。全反射在初中折射一间里已经提过，这里不做。
- **大场景的布局**：靠遮光帘一排五张光学平台（台面高 0.9，光轴高 1.7，相邻两张中心相距 15），从左到右：
  1. 激光双缝台（x = −30）：导轨上依次是激光器、双缝、光屏。第 1、2 课、拓展“一个一个光子”、随堂检测。
  2. 双缝干涉仪台（x = −15）：光源、滤光片、单缝、双缝、遮光筒、测量头。第 3 课。
  3. 薄膜台（x = 0）：灯、装在环形架里的铁丝圈和肥皂膜、一碟肥皂水。第 4 课；拓展“增透膜”换成一只相机镜头。
  4. 衍射和偏振台（x = 15）：导轨上是激光器、可调单缝、光屏，或者白炽灯、两片偏振片、光屏。第 5 课；拓展“泊松亮斑”。
  5. 光电效应台（x = 30）：光源、光电管、微安表、电压表、直流电源。第 6、7 课。
  整间暗室只有正在上课的那一张台子头顶的射灯亮着，换课时镜头沿着这排台子飞过去。
- 取值约定：h = 6.63×10⁻³⁴ J·s，c = 3.00×10⁸ m/s，e = 1.60×10⁻¹⁹ C。波长用 nm，条纹间距用 mm，屏距用 m，频率写成 ×10¹⁴ Hz（两位小数），能量用 eV（两位小数），电流用 μA。
- 激光波长：红 650 nm、绿 532 nm、蓝 450 nm、紫 405 nm（常见半导体激光器的标称波长）。
- 为看得清做的简化：
  - 屏上的条纹放大了画（2.0 宽的屏代表 40 mm），屏下沿的毫米刻度一起放大，读数自洽。
  - 导轨上 1 m 画成 2.6 个单位，器材的粗细没有按这个比例缩。
  - 肥皂膜的厚度按上薄下厚的简化曲线算，界面上标“约”。
  - 可调单缝的缝画宽了才看得见它在变。
  - 光电管画得比实物大；管里的小亮点是示意的光电子，个数和快慢不按比例。
  - 光电流的大小是设定值（弱光 12 μA），只保证“光强加倍、电流加倍”这个比例；反向电压下电流按 (1 − U/Uc)² 减小，只是示意曲线，界面上不给公式。
- 台上的陪衬：激光双缝台和衍射台上有激光电源盒、一盒备用狭缝片。空格键等于按“记录”。
- 和同类产品的区别：条纹不是贴图，是按公式逐点算出来的，换任何一个量条纹都跟着连续变；每课都要读数、记数据。

## 共用的计算核心

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `fringeGap(L, nm, d)` | 屏距 m、波长 nm、缝距 mm | 条纹间距 mm | Δx = Lλ/d |
| `doubleSlitI(x, …)` | 屏上位置 mm | 相对亮度 | cos²(πx/Δx) 乘单缝衍射的光带；挡住一条缝时只剩光带 |
| `singleSlitI`、`centralWidth(L, nm, a)` | 缝宽 mm | 相对亮度、中央亮纹宽 mm | (sin u/u)²；2Lλ/a |
| `headReading(f, n)`、`wavelengthFrom(x1, xn, n)` | 滤光片、第几条 | 手轮读数 mm、波长 nm | λ = dΔx/L，Δx = (xn − x1)/(n − 1) |
| `filmStep(nm)`、`filmReflect(t, nm)`、`filmFringes(age, nm)` | 膜厚 nm | 膜厚差、反射亮度、亮纹条数 | 相邻亮纹膜厚差 λ/(2n)；有半波损失，膜极薄处为暗 |
| `analyzer(deg)` | 两片透振方向夹角 | 相对亮度 | cos²θ（马吕斯定律；课上只用 0° 和 90°） |
| `freq14(nm)`、`photonEV(nm)` | 波长 | 频率、光子能量 eV | ν = c/λ，ε = hν |
| `emits`、`ekMax`、`stopU` | 波长 | 能否发生、最大初动能 eV、遏止电压 V | Ek = hν − W₀，eUc = Ek，W₀ = hνc |
| `photoCurrent(nm, level, reverse)` | 波长、光强倍数、反向电压 | 光电流 μA | 设定值，见总览 |
| `planckFrom(…)` | 两种光的波长和遏止电压 | h | h = eΔUc/Δν |
| `reflectance(coated)`、`arThickness()` | 是否镀膜 | 反射率、膜厚 nm | 垂直入射的菲涅耳公式；λ/(4n) |
| `photonHits(n, …)` | 光子个数 | 落点 | 按干涉亮度分布随机取（固定种子） |

## 第 1 课 两束光叠出条纹

| 项目 | 内容 |
|---|---|
| 知识点 | 光的双缝干涉；路程差是波长整数倍处为亮纹，半波长奇数倍处为暗纹 |
| 一句概念 | 两束相干光叠加，出现明暗相间的条纹 |
| 核心动作 | 挡住一条缝、再打开；量间距 |
| 看到的现象 | 两条缝都透光时屏上是等间距的明暗条纹；挡住一条只剩一片光带 |
| 读数 | 5 个间距 19.5 mm，Δx = 3.9 mm |
| 真实锚点 | 1801 年托马斯·杨的双缝实验 |
| 对应小测 | 第 1 题 |

任务：① 记下双缝时屏上的图样；② 挡住一条缝再记；③ 重新打开，量出相邻亮纹的间距。
按钮：挡住一条缝 / 打开两条缝；量间距；记录。
数据：红光 650 nm、d = 0.20 mm、L = 1.20 m → Δx = 3.9 mm（公式）。双缝每条缝宽取 0.04 mm（决定光带宽度，界面上不显示）。

## 第 2 课 间距由什么决定

| 项目 | 内容 |
|---|---|
| 知识点 | Δx = Lλ/d |
| 一句概念 | Δx = Lλ/d：屏远、波长长、缝近，条纹就宽 |
| 核心动作 | 每次只改一个量，记一次 |
| 读数 | 见下表 |
| 对应小测 | 第 2、3 题 |

| 光 | d / mm | L / m | Δx / mm |
|---|---|---|---|
| 红 650 nm | 0.20 | 1.20 | 3.90 |
| 红 | 0.10 | 1.20 | 7.80 |
| 红 | 0.20 | 0.60 | 1.95 |
| 绿 532 nm | 0.20 | 1.20 | 3.19 |
| 蓝 450 nm | 0.20 | 1.20 | 2.70 |

按钮：换成另一种缝距的双缝；把光屏移到另一个位置；记录。分段选择：激光的颜色。光屏在导轨上匀速滑动，条纹随屏距连续变化。

## 第 3 课 用条纹量出波长

| 项目 | 内容 |
|---|---|
| 知识点 | 实验：用双缝干涉测量光的波长；λ = dΔx/L |
| 一句概念 | 量出条纹间距，就能算出光的波长 |
| 器材 | 光源、滤光片、单缝、双缝、遮光筒、测量头（目镜、分划板、手轮） |
| 核心动作 | 让分划板刻线先后对准第 1 条和第 6 条亮纹，记两次读数 |
| 读数 | d = 0.20 mm，L = 0.700 m。红色滤光片：x₁ = 2.320 mm，x₆ = 13.870 mm，Δx = 2.310 mm，λ = 660 nm。绿色滤光片：x₁ = 2.530 mm，x₆ = 11.980 mm，Δx = 1.890 mm，λ = 540 nm |
| 对应小测 | 第 4 题（隔着 5 个间距，不是 6 个） |

读数面板上画出目镜里的圆视场，条纹随手轮平移，亮纹上标着是第几条。x₁ 是设定的起点，两种滤光片的透过波长（660 nm、540 nm）是设定值。
按钮：对准第 1 条亮纹；对准第 6 条亮纹；记录读数。分段选择：滤光片。

## 第 4 课 肥皂膜上的条纹

| 项目 | 内容 |
|---|---|
| 知识点 | 薄膜干涉：膜前后两个表面的反射光叠加 |
| 一句概念 | 薄膜前后两个表面的反射光发生干涉 |
| 核心动作 | 等肥皂水往下流；把铁丝圈转 90°；换白光 |
| 看到的现象 | 黄光下是水平的明暗条纹；膜流薄后顶上发黑、下面变密；转铁丝圈条纹仍水平；白光下是彩色条纹 |
| 读数 | 钠黄光 589 nm，肥皂水折射率 1.33，相邻亮纹膜厚差 λ/(2n) ≈ 221 nm；亮纹条数 7 → 11（按简化的膜厚曲线） |
| 真实锚点 | 肥皂泡、油膜的彩色 |
| 对应小测 | 第 5 题 |

铁丝圈装在一只带角度刻线的环形架里，可以整体转动（代替手拿着转）。膜厚曲线：刚拉出来 300–1800 nm 线性；流了一阵 0–2400 nm、上端更薄（示意）。
按钮：等肥皂水往下流 / 重新拉一张膜；把铁丝圈转 90° / 转回去；记录。分段选择：钠灯、白光灯。

## 第 5 课 光的衍射和偏振

| 项目 | 内容 |
|---|---|
| 知识点 | 单缝衍射；偏振；光是横波 |
| 一句概念 | 衍射说明光是波，偏振说明光是横波 |
| 核心动作 | 把缝从 0.40 mm 调到 0.10 mm；把第二片偏振片转 90° |
| 读数 | 红光 650 nm、L = 1.20 m：缝宽 0.40 mm 中央亮纹宽 3.9 mm，0.10 mm 时 15.6 mm。偏振：夹角 0° 亮度 100%，90° 时 0% |
| 对应小测 | 第 6、7 题 |

按钮：把缝调窄 / 调宽；把第二片转 90° / 转回去；记录。分段选择：单缝、偏振片（换台上的器材）。

## 第 6 课 光打出了电子

| 项目 | 内容 |
|---|---|
| 知识点 | 光电效应；截止频率；饱和光电流和光强的关系 |
| 一句概念 | 频率够高才有光电子，光越强电流越大 |
| 器材 | 光源（可换颜色、调光强）、光电管（阴极钾）、微安表、电压表、直流电源 |
| 读数 | 红光 4.62×10¹⁴ Hz：弱光 0 μA，强光 0 μA。绿光 5.64×10¹⁴ Hz：弱光 12 μA，强光 24 μA。钾的截止频率 5.44×10¹⁴ Hz。正向电压 1.0 V |
| 对应小测 | 第 8 题 |

按钮：把光调强 / 调弱；记录。分段选择：红、绿、蓝、紫光。

## 第 7 课 遏止电压和光子

| 项目 | 内容 |
|---|---|
| 知识点 | 遏止电压；爱因斯坦光电效应方程 Ek = hν − W₀；光子；波粒二象性 |
| 一句概念 | Ek = hν − W₀：最大初动能只由频率决定 |
| 核心动作 | 加反向电压到电流刚好为零；电压不动把光调强；换紫光、绿光再测 |
| 读数 | W₀ = hνc = 2.25 eV。蓝光 6.67×10¹⁴ Hz：hν = 2.76 eV，Uc = 0.51 V（光强加倍不变）。紫光 7.41×10¹⁴ Hz：Uc = 0.82 V。绿光：Uc = 0.08 V。由斜率 h = 6.63×10⁻³⁴ J·s |
| 对应小测 | 第 9 题 |

面板上有 Uc–ν 图线：记一个点画一个点，有两个点以后画出直线并标出截止频率。
按钮：加反向电压 / 把电压调回零；把光调强 / 调弱；记录。分段选择：绿、蓝、紫光。

## 讲解

解说词在 `src/labs/light/narration.ts`。要特别讲清楚的：第 1 课“挡住一条缝条纹就没了”；第 3 课“第 1 条到第 6 条隔着 5 个间距”；第 6 课“红光再强也是零”；第 7 课“电压不动把光调强，电流还是零”。读法：×10¹⁴ Hz 念成“乘十的十四次方赫兹”，Uc 念“遏止电压”，hν 念“h 纽”改说成“光子的能量”。

## 和规格卡原文的出入

- 没有。（规格卡和代码同一轮写成。）
- 没有做拖动：全部操作都是按钮和分段选择，条纹、光屏、手轮、偏振片的变化是连续动画。
