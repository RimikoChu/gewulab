## 总览

- **一句话**：学生在一座城市滨水公园里，从花坛、音乐喷泉、篮球场、江心高喷、拱桥一路看下来，弄懂二次函数是什么、抛物线的开口和顶点由什么决定、怎样配方、和一元二次方程有什么关系，最后用它求最大面积、最大利润。
- **教材位置**：数学，初中。人教版九年级上册第二十二章“二次函数”：二次函数的图像和性质、二次函数与一元二次方程、实际问题与二次函数。准确的节号见“待核实事项”。
- **主线**：“这条抛物线就是那道水柱”。每一课的坐标系都叠在实物上：半透明的坐标平面立在水柱、球的轨迹、桥拱所在的竖直面里，1 个单位 = 1 m（第 5 课的横轴是时间）。
- **场景**：一座城市滨水公园。从西往东：花园（圆形花坛、靠墙的矩形花圃）→ 喷泉广场（圆形喷泉池、沿江的一排音乐喷泉）→ 篮球场 → 江心高喷 → 游船码头 → 河上的抛物线拱桥。换课时镜头沿着江岸飞。
- **取值约定**：长度 m，面积 m²，时间 s，钱 元。水柱、球按斜抛运动算，不计空气阻力，g 取 9.8 N/kg；第 5 课沿用教材的写法 h = v₀t − 5t²（g 取 10）。π 取计算器值，面积保留两位小数。
- **和同类产品的区别**：同类产品多是一块坐标纸上拖滑块。这里的抛物线都长在真东西上：水柱的落点就是方程的根，球的最高点就是配方得出的顶点，桥下水面的宽度是用解析式算出来的。

## 第 1 课 画一个圆形花坛

| 项目 | 内容 |
|---|---|
| 知识点 | 二次函数的概念：形如 y = ax² + bx + c（a、b、c 是常数，a ≠ 0）的函数 |
| 一句概念 | 面积 S 是半径 r 的二次函数 |
| 核心动作 | 选绳长，按“画圆”，木桩上的绳子绕一圈在草坪上画出白线；按“记录” |
| 读数 | r = 1、2、3 m 时 S ≈ 3.14、12.57、28.27 m² |
| 真实锚点 | 园林工人用木桩和绳子放线画圆 |

任务：r = 1 m 画一个并记下；r = 2 m 再画一个；r = 3 m 再画一个；按“连起来”看三个点连成的是曲线。
结论：r 翻一倍，面积变成 4 倍；S = πr² 是二次函数，它的图像不是直线。

## 第 2 课 喷泉的水柱（样板课）

| 项目 | 内容 |
|---|---|
| 知识点 | y = ax² 的图像是抛物线；顶点在原点、对称轴是 y 轴；a > 0 开口向上，a < 0 开口向下；|a| 越大开口越小 |
| 一句概念 | a 决定开口的方向和大小 |
| 核心动作 | 分段选择 a = −½、−1、−2，水柱连续地变形；最后选 a = 1，只有图像，和 a = −1 的水柱上下对称 |
| 读数 | 原点在水柱最高点，最高点离水面 3 m；a = −½、−1、−2 时水柱在水面上落点 x = ±2.45、±1.73、±1.22 m |

任务：看 a = −1 的水柱，按“描点”；换 a = −½；换 a = −2；换 a = 1。
结论：a < 0 开口向下，a > 0 开口向上；|a| 越大，抛物线越窄。

## 第 3 课 把水柱挪一挪

| 项目 | 内容 |
|---|---|
| 知识点 | y = a(x − h)² + k 由 y = ax² 平移得到；顶点 (h, k)，对称轴 x = h |
| 一句概念 | h、k 定位置，a 定形状 |
| 核心动作 | 按“向上移 1”“向右移 2”，喷头小车沿轨道移动、水压升高；再把 a 从 −1 换成 −2 |
| 读数 | y = −x² → y = −x² + 1，顶点 (0, 1) → y = −(x − 2)² + 1，顶点 (2, 1)，对称轴 x = 2 → a = −2 时顶点不变 |

## 第 4 课 投篮的轨迹

| 项目 | 内容 |
|---|---|
| 知识点 | 一般式 y = ax² + bx + c 配方成顶点式；顶点 (−b/2a, (4ac − b²)/4a) |
| 一句概念 | 配方，就能读出顶点 |
| 核心动作 | 按“投篮”，球沿轨迹进篮；按“配方下一步”三次 |
| 读数 | y = −0.2x² + x + 2.25 = −0.2(x² − 5x) + 2.25 = −0.2(x − 2.5)² + 1.25 + 2.25 = −0.2(x − 2.5)² + 3.5；出手高度 2.25 m，最高点离出手处水平 2.5 m、高 3.5 m；x = 4 m 时 y = 3.05 m，正是篮圈高 |
| 真实锚点 | 标准篮圈上沿离地 3.05 m |

## 第 5 课 水滴能升多高

| 项目 | 内容 |
|---|---|
| 知识点 | 二次函数 y = ax² + bx + c 的图像与直线 y = m 的交点 ⇔ 方程 ax² + bx + c = m 的根；Δ > 0 两个、Δ = 0 一个、Δ < 0 没有 |
| 一句概念 | 交点的个数看判别式 |
| 核心动作 | 分段选择高度 15、20、25 m，按“解方程”；最后选 0 m 求落回水面的时间 |
| 读数 | h = 20t − 5t²：15 m → t = 1 s、3 s；20 m → t = 2 s；25 m → 无解（Δ = −100）；0 m → t = 0 s、4 s |
| 真实锚点 | 江心高喷：水从喷口以 20 m/s 竖直喷出（示意，不计空气阻力） |

这一课的抛物线不是水柱的形状，是一滴水的高度随时间的变化：横轴是时间。界面上说清楚。

## 第 6 课 桥下的水面

| 项目 | 内容 |
|---|---|
| 知识点 | 建立坐标系、待定系数求解析式、由函数值反求自变量 |
| 一句概念 | 先建坐标系求解析式，再代入求宽度 |
| 核心动作 | 按“求解析式”；分段选择水位：常水位、下降 1 m、上涨 1 m（江水慢慢升降）；按“让游船过桥” |
| 读数 | 常水位拱顶离水面 4 m、水面宽 12 m → y = −(1/9)x²；下降 1 m 水面宽 2√45 ≈ 13.42 m；上涨 1 m 水面宽 2√27 ≈ 10.39 m；游船宽 6 m、露出水面 2.5 m：常水位时船边上方净空 3 m，能过；上涨 1 m 时只有 2 m，过不去 |

## 第 7 课 围一个最大的花圃

| 项目 | 内容 |
|---|---|
| 知识点 | 实际问题中的最大值：配方或顶点公式 |
| 一句概念 | 顶点就是最大值 |
| 核心动作 | 分段选择垂直于墙的边 x = 3、5、7 m（栅栏沿地面移动）；按“配方求最大” |
| 读数 | 栅栏总长 20 m、一面靠墙：S = x(20 − 2x) = −2x² + 20x；x = 3、5、7 时 S = 42、50、42 m²；配方 S = −2(x − 5)² + 50，x = 5 m 时最大 50 m² |

## 随堂检测

九道题，每课至少一道：概念判断（a ≠ 0）、开口方向与 |a|、平移后的顶点、配方求顶点、判别式与交点个数、拱桥水面宽、面积最大值、综合（由图像判断 a、c 的符号）、易错（y = (x − 2)² 向右还是向左）。

## 讲解

- 第 2 课要讲清：原点在水柱最高点，所以水柱是 y = ax²。
- 第 5 课要讲清：横轴是时间，不是水平距离。
- 配方的每一步念成“提出负零点二”“加上再减去六点二五”。
