状态：九个课次（1–7、拓展、随堂检测）做完（2026-11-26），待验收。关联议题 #44。

## 总览

- **一句话**：学生跟着一辆车走一趟高速公路，看里程表、油量表、加油机上的数怎样一起变，弄懂变量和函数；把表格、解析式、图像对上；再在大屏上改 k 和 b，看直线怎样转、怎样移；最后用两组读数求解析式，用两条直线的交点选运费方案。
- **教材位置**：数学，初中。人教版八年级下册“一次函数”一章：变量与函数、函数的图象、正比例函数、一次函数、一次函数与方程和不等式、选择方案。章、节的编号见“待核实事项”。
- **主线**：一趟高速公路上的行程：车在开，时间、里程、油量、费用跟着变。
- **场景**：一段双向四车道的高速公路。路边有里程碑；路的一侧是服务区（加油站、停车场、一块大电子屏）；往回是收费站和出口。讲图像的几课，坐标平面立在公路中央分隔带的上空，横轴就是这段路的里程，车开到哪，点就描在它头顶上。换课时镜头沿着公路飞。
- **取值约定**：车速 100 km/h；小轿车满箱 50 L，每百千米耗油 8 L；92 号汽油 7.50 元/L；货车满箱 300 L，每百千米耗油 30 L；两种运费方案甲 y = 5x + 200、乙 y = 7x（元）；出租车起步价 10 元含 3 km，之后每千米 2 元。这些是为了算起来方便取的接近真实量级的数，不对应某一辆车、某一家公司或某个城市。
- **画面里的比例**：公路上的里程按示意缩短（坐标平面上 100 km 只占十来米），车按真实大小画。界面上“图中路程按比例缩短”写在读数面板上。
- **和同类产品的区别**：同类产品多是在白纸上画直线、拖滑块。这里每个点都是车开出来的读数：车走一段，表格加一行，图像上加一个点；k、b 只用几个一步到位的按钮切换，直线连续地转过去、移过去。

## 共用的计算核心（`src/labs/linear/physics.ts`）

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `drive(t)` | 行驶时间 t（h） | 里程 s = 100t（km），油量 50 − 0.08s（L），速度 100 | 取值约定 |
| `cost(x)` | 加油量 x（L） | 金额 y = 7.5x（元） | 单价 7.50 元/L |
| `fuelLeft(x)` | 里程 x（km） | 油量 y = 50 − 0.08x（L） | 满箱 50 L、百千米 8 L |
| `prop(k, x)` | k、x | y = kx | 正比例函数 |
| `lin(k, b, x)` | k、b、x | y = kx + b | 一次函数 |
| `trend(k)` | k | 上升 / 下降 / 水平 | k > 0 时 y 随 x 增大而增大 |
| `solve2(p, q)` | 两个点 | k = (y₂ − y₁) ÷ (x₂ − x₁)，b = y₁ − kx₁ | 待定系数法 |
| `truckFuel(x)` | 里程（km） | 300 − 0.3x（L） | 取值约定 |
| `planA(x)`、`planB(x)` | 运距（km） | 5x + 200、7x（元） | 取值约定 |
| `meet(k1, b1, k2, b2)` | 两条直线 | 交点 | 解方程 k₁x + b₁ = k₂x + b₂ |
| `taxi(x)` | 路程（km） | x ≤ 3 时 10 元；x > 3 时 2x + 4 元 | 取值约定 |
| `toF(c)` | 摄氏度 | 1.8c + 32 | 公认的换算式 |
| `clip(k, b, xr, yr)` | 直线和画框 | 直线在画框里的两个端点 | 画图用 |

## 第 1 课 谁在变

一辆小轿车在高速公路上以 100 km/h 匀速行驶。镜头在车里，看得见仪表盘（速度表、油量表、中间的里程和行驶时间）和前方的路，里程碑一块块迎面过来。

| 项目 | 内容 |
|---|---|
| 知识点 | 在一个变化过程中，数值发生变化的量叫变量，数值始终不变的量叫常量 |
| 一句概念 | 会变的是变量，不变的是常量 |
| 核心动作 | 开 1 小时；再开 2 小时；从四个量里指出不变的那个 |
| 看到的现象 | 速度表指针一直指着 100；里程表、时钟在走，油量表的指针往下落 |
| 读数 | 1 h：100 km，剩 42 L；3 h：300 km，剩 26 L；速度始终 100 km/h |
| 对应小测 | 第 1 题 |

任务

- [ ] 开 1 小时，读出里程和油量
- [ ] 再开 2 小时，又读一次
- [ ] 指出这四个量里哪个没有变

主操作区：开 1 小时（第二次起是“再开 2 小时”）。分段选择：没变的量是（时间 / 里程 / 油量 / 速度）。

## 第 2 课 一个对一个

服务区加油站。小轿车停在加油机旁，油枪插在加油口。加油机的屏上三行：金额、升数、单价。

| 项目 | 内容 |
|---|---|
| 知识点 | 两个变量 x、y，x 每取一个值，y 都有唯一确定的值和它对应，y 就是 x 的函数，x 是自变量 |
| 一句概念 | 一个 x 只对应一个 y，y 就是 x 的函数 |
| 核心动作 | 加 10 升，读金额；再加两次 |
| 读数 | 10 L → 75.00 元；20 L → 150.00 元；30 L → 225.00 元；单价 7.50 元/L 不变 |
| 对应小测 | 第 2 题 |

任务

- [ ] 加 10 升，读出金额
- [ ] 加到 20 升，再读
- [ ] 加到 30 升，写出金额和升数的关系

主操作区：加 10 升。数字是连续跳上去的。

## 第 3 课 列表、描点、连线（样板课）

公路 A 段。坐标平面立在中央分隔带上空：横轴是里程 x（km），0 到 500；纵轴是油箱里剩的油 y（L），0 到 50。小轿车满箱从 0 km 出发。

| 项目 | 内容 |
|---|---|
| 知识点 | 函数的图像；画图像的三步：列表、描点、连线；表格、解析式、图像三种表示法 |
| 一句概念 | 列表、描点、连线，就画出了函数的图像 |
| 核心动作 | 每按一次车开 100 km，表格加一行，车头顶上描一个点；连线；从图上读 250 km 的油量 |
| 读数 | 0、100、200、300、400、500 km → 50、42、34、26、18、10 L；250 km → 30 L；解析式 y = 50 − 0.08x |
| 对应小测 | 第 3 题 |

任务

- [ ] 开出 100 km，表格记一行、图上描一个点
- [ ] 开到 500 km，描出全部六个点
- [ ] 把点连起来
- [ ] 从图像上读出开到 250 km 时还剩多少油

主操作区：开 100 千米、连线、读图。

## 第 4 课 过原点的直线

服务区停车场边的大电子屏上，一个画着网格的坐标系（−5 到 5）。

| 项目 | 内容 |
|---|---|
| 知识点 | 正比例函数 y = kx（k ≠ 0）；图像是经过原点的直线；k > 0 时经过一、三象限，y 随 x 增大而增大；k < 0 时经过二、四象限，y 随 x 增大而减小；|k| 越大越陡 |
| 一句概念 | y = kx 的图像是一条过原点的直线 |
| 核心动作 | 选 k，按“画图像”：先描 (0, 0) 和 (1, k)，再连成直线 |
| 读数 | k = 1：过 (1, 1)；k = 2：过 (1, 2)；k = −1：过 (1, −1) |
| 对应小测 | 第 4 题 |

任务

- [ ] k = 1，画出图像
- [ ] 换成 k = 2，再画一条
- [ ] 换成 k = −1，再画一条

分段选择：k = 1 / 2 / −1。主操作区：画图像。

## 第 5 课 k 和 b

收费站广场边的电子屏。屏上一条直线 y = kx + b，起始是 y = 2x。

| 项目 | 内容 |
|---|---|
| 知识点 | 一次函数 y = kx + b 的图像是直线；b 是直线与 y 轴交点的纵坐标；k 相同、b 不同的直线互相平行；k 决定增减和倾斜程度 |
| 一句概念 | b 定直线和 y 轴的交点，k 定它的方向 |
| 核心动作 | 换 b 看直线上下平移；换 k 看直线绕 y 轴上那一点转 |
| 读数 | y = 2x + 2 与 y 轴交于 (0, 2)；y = 2x − 3 交于 (0, −3)；y = −x − 3 仍交于 (0, −3)，变成下降 |
| 对应小测 | 第 5、6 题 |

任务

- [ ] 把 b 换成 2，看直线怎么动
- [ ] 把 b 换成 −3，再看
- [ ] 把 k 换成 −1，看直线怎么动

主操作区：k = 2、k = −1 两个按钮。分段选择：b = 0 / 2 / −3。

## 第 6 课 两组读数定直线

公路 B 段。一辆货车，坐标平面横轴 0 到 1000 km，纵轴 0 到 300 L。800 km 处有一座加油站。

| 项目 | 内容 |
|---|---|
| 知识点 | 待定系数法：一次函数有 k、b 两个待定系数，知道两组对应值就能求出来；用解析式预测 |
| 一句概念 | 两个点定一条直线 |
| 核心动作 | 货车开到 100 km、300 km 的里程碑各记一次油量；求解析式；算到 800 km 还剩多少 |
| 读数 | (100, 270)、(300, 210)；k = −0.3，b = 300；y = −0.3x + 300；800 km 剩 60 L |
| 对应小测 | 第 7 题 |

任务

- [ ] 开到 100 km 的里程碑，记下油量
- [ ] 开到 300 km 的里程碑，再记一次
- [ ] 用这两组数求出解析式
- [ ] 算出开到 800 km 的加油站还剩多少油

主操作区：开到下一块里程碑、求解析式、算 800 千米。

## 第 7 课 选哪种运费

公路 C 段。一车货要运走，两家公司报价：甲每千米 5 元另收装卸费 200 元，乙每千米 7 元不收装卸费。坐标平面横轴 0 到 250 km，纵轴 0 到 1800 元。

| 项目 | 内容 |
|---|---|
| 知识点 | 用一次函数比较方案；两条直线的交点；交点的横坐标是方程 5x + 200 = 7x 的解；哪条线在下面哪个方案便宜 |
| 一句概念 | 交点左右，便宜的方案换了 |
| 核心动作 | 画出两条直线；运距选 60、200、100 km，货车开到那里，读出两个报价 |
| 读数 | 60 km：甲 500 元，乙 420 元；200 km：甲 1200 元，乙 1400 元；100 km：都是 700 元 |
| 对应小测 | 第 8、9 题 |

任务

- [ ] 画出两种方案的图像
- [ ] 运 60 km，比一比哪家便宜
- [ ] 运 200 km，再比一比
- [ ] 找到两家一样贵的运距

主操作区：画出两条直线。分段选择：运距 60 / 100 / 200 km。

## 拓展课 生活里的一次函数

| 专题 | 一句话 | 学生的核心动作 | 位置 |
|---|---|---|---|
| 出租车计价 | 起步价内不变，超过 3 km 后每千米加 2 元，图像是一段水平线接一段斜线 | 按“打表出发”，车开 8 km，图像跟着画 | 出口路边 |

## 讲解

自动演示的解说词在 `src/labs/linear/narration.ts`。要讲清楚的地方：第 3 课每描一个点都要说“横坐标是里程，纵坐标是油量”；第 5 课 b 换了以后直线是“平移”不是“转”；第 7 课比价时说“哪条线在下面，哪家便宜”。数字读法：y = 2x + 2 读作“y 等于 2x 加 2”，−0.3 读作“负零点三”。
