# 板块运动实验室 · 规格卡 v0.1

状态：九个课次（1–7、拓展、随堂检测）做完，待验收。关联议题 #38。

## 总览

- **一句话**：学生把大西洋两岸拼回去、开钻探船到洋中脊取岩芯、让大陆张裂、让印度撞上亚洲、让大洋板块俯冲，再回到地球上找火山地震带，弄懂“大陆在漂移，板块在运动，火山地震在板块交界处”。
- **教材位置**：地理，初中七年级上册“陆地和海洋”一章里讲海陆变迁的一节（大陆漂移、板块构造学说、六大板块、板块的碰撞和张裂、火山地震带）。准确的版本、章节号待对着现行教材核实（见“待核实事项”）。
- **主线**：一条真实走向的“地球切片”——从太平洋出发，经安第斯山、南美洲、大西洋中脊、非洲、东非大裂谷、印度洋、印度，到喜马拉雅山和青藏高原。四种板块边界正好依次出现在这一条线上：海沟（太平洋板块|美洲板块）、洋中脊（美洲板块|非洲板块）、裂谷（非洲板块|印度洋板块）、碰撞带（印度洋板块|亚欧板块）。
- **场景**：这条切片朝镜头剖开，看得见海水、沉积物、洋壳、大陆地壳、岩石圈地幔、软流层和岩浆；切片后面是一直延伸到天边的地面和海面。正上方很高的太空里是一颗地球（NASA 实拍影像），讲全球分布的课在那里。换课时镜头沿切片飞，或者从切片飞上太空。
- **取值约定**：洋中脊每侧每年推开 1.5 cm；俯冲板块按 30° 往下插；张裂两侧每年分开约 1 cm；大西洋约 1.3 亿年前开始张开。都是约数，见“待核实事项”。
- **和同类产品的区别**：同类产品多是看一张板块地图或一段动画。这里每课都要学生自己让板块动起来，并读出一个数（宽度、岩石年龄、震源深度、山的高度、离交界的距离）。

### 为什么改了议题建议的场景

议题建议“海底到高原的一条大剖面”。保留了这个想法，但把它对到了地球上一条真实的走向（太平洋—南美—大西洋—非洲—印度洋—印度—青藏高原），这样四种边界、六大板块里的五块都在同一条线上，换课只是沿线飞。全球分布（大陆漂移、六大板块、火山地震带）在剖面上看不出来，所以另加一颗太空里的地球。

## 共用的计算核心

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `distKm`、`distToLine` | 两点或一点和一条折线的经纬度 | 沿大圆的距离（km） | 球面几何，地球半径 6371 km |
| `driftSA` | 南美洲上一点、合拢的进度 k | 转动后的经纬度 | 绕欧拉极（北纬 44°、西经 30.6°）转 57° × k，布拉德等人 1965 年的拼合（待核实） |
| `atlanticGap` | k | 纳塔尔到它拼合时贴着的那处非洲海岸的距离（km） | 上面两条 |
| `rockAge` | 离中脊的距离 | 岩石年龄（百万年）= 距离 ÷ 每侧的扩张速度 | 匀速扩张 |
| `riftWidth` | 张裂的时间 | 宽度 = 速度 × 时间 | 匀速张裂，示意 |
| `peakAt` | 碰撞进度 c | 最高峰的高度；c = 1 时为珠峰高度 | 示意的升高过程，终点是实测值 |
| `quakeDepth` | 离海沟的距离 | 震源深度 = 8 km + 距离 × tan 30° | 俯冲板块的几何，示意 |
| `nearestBoundary` | 一点的经纬度 | 离最近的板块交界多远、在哪条火山地震带上 | `plates.ts` 里的简化边界线 |
| `rateCmYr`、`kmAfter` | 距离和时间 | 速度（cm/年），或按速度走多远 | 单位换算 |

`plates.ts` 里是六大板块的边界线（照常见的六大板块示意图手写的简化折线，误差约一两百千米）、东非大裂谷、28 座著名火山和 24 次著名大地震的经纬度。板块的填色是程序在一张经纬度图上从每块板块里的一点往外填出来的。

## 第 1 课 大陆漂移的猜想

| 项目 | 内容 |
|---|---|
| 知识点 | 大陆漂移假说；证据：轮廓吻合、化石相同、岩层相接 |
| 一句概念 | 大陆原来连在一起，后来漂移分开 |
| 核心动作 | 合拢两岸；证据换成“化石”“岩层”；漂回今天 |
| 看到的现象 | 南美洲一点点转向非洲，东北角的凸出嵌进几内亚湾；两岸的中龙化石牌、古老岩层色块拼合后挨在一起 |
| 读数 | 大西洋的宽度（纳塔尔到对岸）约 4800 km → 0；“约 1.3 亿年前” |
| 真实锚点 | 大西洋两岸轮廓；中龙化石只在南美洲南部和非洲南部发现 |
| 对应小测 | 第 1 题（今天的气候不是证据） |

任务：合拢 → 看化石 → 看岩层 → 漂回今天。按钮：合拢两岸、漂回今天；分段选择：轮廓 / 化石 / 岩层。

## 第 2 课 海底扩张

| 项目 | 内容 |
|---|---|
| 知识点 | 洋中脊处岩浆上涌生成新洋底，向两侧推开；岩石年龄的规律 |
| 一句概念 | 洋中脊处不断长出新的洋底 |

## 第 5 课 大陆和大陆相撞

| 项目 | 内容 |
|---|---|
| 一句概念 | 大陆相撞，挤出高大的山脉 |

| 对应小测 | 第 6、7 题 |

## 和规格卡原文的出入

- 场景从“海底到高原的一条剖面”改成一条真实走向的地球切片加太空里的地球，理由见总览。
- 第 3 课“剖开看”原来是大西洋到东非一大段，太宽太扁、两端被面板挡住，收窄成大西洋中脊两侧一段。
- 第 4 课裂谷阶段谷底加了湖，火山改成谷边一座孤立的锥（不再沿谷延伸成山脊）。
- 拓展课只做了两个实验（日本、板块的速度），没做印尼。印尼放在第 7 课的地中海—喜马拉雅带里提到。
