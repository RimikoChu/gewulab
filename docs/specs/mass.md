# 质量守恒定律实验室 · 规格卡 v0.1

状态：九个课次（1–7、拓展、随堂检测）做完，每课自动演示带讲解能走到结论条，待验收。关联议题 #18。

## 总览

- **一句话**：学生在一座纯碱化工厂里，先在厂里的化验室用托盘天平称三个反应前后的质量（密闭的红磷燃烧、铁钉和硫酸铜溶液、敞口和密闭的碳酸钠与盐酸、镁条燃烧），弄清“参加反应的各物质的质量总和等于生成的各物质的质量总和”；再用分子模型看水的电解和氢气燃烧，明白原子种类、数目、质量都不变；然后到反应车间、中控室和石灰窑，读化学方程式、配平化学方程式、用化学方程式算原料和产品。
- **教材位置**：化学，初中。人教版九年级上册“化学反应的定量关系”单元（旧版单元名“化学方程式”）：质量守恒定律、化学方程式（书写与配平）、根据化学方程式进行简单计算。准确的单元号、课题名见“待核实事项”，界面上不写课题号。
- **主线**：天平和原子。前三课用天平称出“质量不变”，第 4 课用原子说明为什么不变，第 5、6 课把“不变”写成化学方程式，第 7 课用方程式里的质量比算生产。
- **场景**：纯碱化工厂（议题建议“化工厂的称量和反应车间”）。理由：纯碱厂的石灰窑煅烧石灰石，正好是“根据化学方程式计算”的教材例题（CaCO₃ 高温分解）；厂里的化验室天天用天平；碳酸钠就是第 3 课的药品。
- **取值约定**：场景里 1 m 画成 6 个单位（`M = 6`），化验台台面高 85 cm。相对原子质量：H 1，C 12，O 16，Na 23，Mg 24，P 31，S 32，Cl 35.5，Ca 40，Fe 56，Cu 64。实验室里的质量用 g，保留一位小数（托盘天平的分度值 0.2 g，但参加反应的物质的质量保留两位）；工厂里的质量用 t，保留一位小数。
- **和同类产品的区别**：托盘天平照实物建（铸件底座、刀口、横梁、指针分度盘、标尺游码、平衡螺母、砝码盒和镊子），横梁按左右两盘的质量差真实地偏转、摆动、停住；砝码由镊子一只只夹到右盘。分子模型的原子按常见的配色（H 白、O 红、C 黑、P 橙），拆开、重组有过程，原子个数随时可数。配平时系数加一，台上就真的多一个分子模型。

## 共用的计算核心

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `AR`、`mr` | 化学式 | 相对分子质量 | 相对原子质量表 |
| `massParts` | 一个方程式 | 各物质的“系数 × 相对分子质量” | 化学方程式的质量比 |
| `scaled` | 一个方程式、某物质的质量 | 其余各物质按比例的质量 | 同上 |
| `tilt` | 左盘、右盘的质量（g） | 横梁偏转（−1 到 1） | 示意：差 0.5 g 以上偏到头 |
| `weigh` | 一个质量（g） | 要放的砝码和游码示数 | 砝码 100、50、20、20、10、5 g，游码 0–5 g |
| `atomCount` | 方程式和系数 | 两边每种原子的个数 | 数原子 |
| `balanceSteps` | 要配的方程式 | 配平的每一步（系数和说明） | 最小公倍数法、观察法 |
| `solveSteps` | 已知产品质量 | 解题格式的每一行、算出的原料质量 | 比例式 |
| `kilnBalance` | 投入碳酸钙的质量 | 生石灰、二氧化碳的质量 | CaCO₃ 高温分解，100 : 56 : 44 |

## 第 1 课 红磷燃烧前后（样板课）

| 项目 | 内容 |
|---|---|
| 知识点 | 在密闭容器里，红磷燃烧前后总质量不变；气球的作用：缓冲气压，防止塞子被冲开 |
| 一句概念 | 密闭容器里，反应前后总质量不变 |
| 核心动作 | 把锥形瓶放上左盘，夹砝码、拨游码到平衡，记下质量；取下锥形瓶，玻璃管在酒精灯上烧红后塞紧，红磷燃烧；冷却后放回天平 |
| 看到的现象 | 红磷燃烧发出黄白色火焰、产生大量白烟；气球先胀大，冷却后变瘪；放回天平后指针仍指在分度盘正中 |
| 读数 | 反应前 118.6 g，反应后 118.6 g（装置的质量是设定值，示意）；参加反应：红磷 0.31 g + 氧气 0.40 g = 五氧化二磷 0.71 g |
| 对应小测 | 第 1 题 |

任务：称出反应前的总质量 → 点燃红磷 → 冷却后再称一次。

主操作区：称量（放上左盘，镊子夹砝码，拨游码）、点燃红磷、冷却后放回天平。没有分段选择。

## 第 2 课 铁和硫酸铜溶液

| 项目 | 内容 |
|---|---|
| 知识点 | Fe + CuSO₄ = Cu + FeSO₄；铁钉表面覆盖一层红色的铜，溶液由蓝色逐渐变成浅绿色；反应前后总质量不变 |
| 一句概念 | 没有气体进出，称出来的质量也不变 |
| 核心动作 | 把锥形瓶和铁钉一起放在天平上称量；把铁钉放进溶液、塞好塞子；溶液变色后再称 |
| 读数 | 反应前后都是 146.4 g（示意）；参加反应：铁 0.56 g + 硫酸铜 1.60 g = 铜 0.64 g + 硫酸亚铁 1.52 g |
| 对应小测 | 第 2 题 |

任务：称出锥形瓶和铁钉的总质量 → 把铁钉放进硫酸铜溶液 → 等溶液变色，再看天平。锥形瓶画成 150 mL 的（比第 1 课的小一号），左盘上还要放称量纸和铁钉。

## 第 3 课 天平不平衡了？

| 项目 | 内容 |
|---|---|
| 知识点 | Na₂CO₃ + 2HCl = 2NaCl + H₂O + CO₂↑，敞口烧杯里二氧化碳逸出，称得质量变小；2Mg + O₂ =点燃= 2MgO，生成物里多了参加反应的氧气，称得质量变大；所有化学反应都遵守质量守恒定律，验证时有气体参加或生成的反应要在密闭容器里做 |
| 一句概念 | 有气体进出，要在密闭容器里称 |
| 核心动作 | 敞口烧杯：称量，把小试管里的盐酸倒进烧杯，放回天平；镁条：和陶土网一起称，点燃，产物和陶土网再称；改用带气球的锥形瓶，再做一次碳酸钠和盐酸 |
| 看到的现象 | 烧杯里冒出大量气泡，放回天平后右盘下沉；镁条燃烧发出耀眼的白光、生成白色粉末，左盘下沉；密闭时气球胀大，天平平衡 |
| 读数 | 碳酸钠 1.06 g 完全反应逸出 0.44 g 二氧化碳：72.6 g → 72.2 g（示意，按 72.16 g 偏转）；镁条 0.24 g 燃烧得到 0.40 g 氧化镁：28.4 g → 28.6 g（示意，按 28.56 g 偏转；实际做时一部分白烟跑掉，可能反而变轻）；密闭锥形瓶 96.2 g → 96.2 g |
| 对应小测 | 第 3、4 题 |

任务：在敞口烧杯里让碳酸钠和盐酸反应，再称 → 镁条燃烧前后各称一次 → 改用密闭的锥形瓶，再做一次。分段选择：敞口烧杯 / 镁条 / 密闭锥形瓶。主操作区：称量、反应（倒入盐酸 / 点燃镁条）、再称一次。

## 第 4 课 原子的重新组合

| 项目 | 内容 |
|---|---|
| 知识点 | 2H₂O =通电= 2H₂↑ + O₂↑：正极得氧气、负极得氢气，体积比约 1 : 2；化学反应的实质是分子分成原子、原子重新组合成新分子；原子的种类、数目、质量都不变，所以总质量不变 |
| 一句概念 | 原子重新组合，种类、数目、质量都不变 |
| 核心动作 | 接通电源，看两极的气体；把两个水分子拆成原子；原子重新组合；换成氢气燃烧，再拆、再组 |
| 读数 | 氢原子 4 → 4，氧原子 2 → 2；36 份质量的水 → 4 份氢气 + 32 份氧气 |
| 对应小测 | 第 5 题 |

任务：接通电源电解水 → 把水分子拆成原子 → 让原子重新组合 → 换成氢气燃烧，再看一次。分段选择：水通电分解 / 氢气燃烧。

## 第 5 课 化学方程式的意义

| 项目 | 内容 |
|---|---|
| 知识点 | C + O₂ =点燃= CO₂：质的方面（碳和氧气在点燃的条件下生成二氧化碳）；量的方面（每 12 份质量的碳和 32 份质量的氧气完全反应生成 44 份质量的二氧化碳）；粒子（1 个碳原子和 1 个氧分子生成 1 个二氧化碳分子） |
| 一句概念 | 一个方程式，读出物质、条件、质量比、个数比 |
| 核心动作 | 读物质和条件（燃烧炉点火）；读质量比（两条进料管按 12 : 32 计量进炉，出料计 44）；读粒子个数比（炉口上方出现分子模型）；换成 2H₂ + O₂ =点燃= 2H₂O 读质量比 |
| 读数 | 12 kg 碳 + 32 kg 氧气 → 44 kg 二氧化碳；4 kg 氢气 + 32 kg 氧气 → 36 kg 水（示意的投料量） |
| 对应小测 | 第 6 题 |

任务：读出反应物、生成物和条件 → 读出各物质的质量比 → 读出粒子个数比 → 换成氢气燃烧，读质量比。

## 第 6 课 配平化学方程式

| 项目 | 内容 |
|---|---|
| 知识点 | 书写化学方程式要以客观事实为基础，遵守质量守恒定律；配平时只能改化学式前面的系数，不能改化学式；最小公倍数法、观察法；配平后短线改等号，注明条件和气体、沉淀符号 |
| 一句概念 | 只改系数，让两边每种原子一样多 |
| 核心动作 | 磷燃烧：找出氧原子，按最小公倍数 10 一步步配系数；炼铁（Fe₂O₃ + CO）：用观察法配；每次配完数一数原子；写上等号和条件 |
| 读数 | 4P + 5O₂ =点燃= 2P₂O₅；Fe₂O₃ + 3CO =高温= 2Fe + 3CO₂；两边原子个数 |
| 对应小测 | 第 7 题 |

任务：磷燃烧：用最小公倍数法配平 → 数一数原子，写上等号和条件 → 炼铁：用观察法配平 → 数一数原子，写上等号和条件。主操作区：配一个系数、数原子、写等号和条件（没数原子不能写等号）。分段选择：磷燃烧 / 炼铁。提示语就是下一步要配的那个系数的理由。

## 第 7 课 根据化学方程式计算

| 项目 | 内容 |
|---|---|
| 知识点 | 解题格式：设未知量；写出化学方程式；写出相关物质的相对质量和已知量、未知量；列比例式；求解；简明地写出答案 |
| 一句概念 | 按方程式里的质量比算原料和产品 |
| 核心动作 | 一步步写出解题过程：要制取 5.6 t 氧化钙，需要多少碳酸钙；按算出的 10 t 投料（卡车过地磅、倒进窑），煅烧后称出生石灰 |
| 读数 | CaCO₃ =高温= CaO + CO₂↑，100 : 56；x = 10 t；出料 5.6 t（按纯碳酸钙算，示意） |
| 真实锚点 | 纯碱厂用石灰窑煅烧石灰石，得到生石灰和二氧化碳 |
| 对应小测 | 第 8 题 |

任务：设未知量，写出化学方程式 → 写出相关量，列比例式 → 求解，写出答案 → 按算出的量投料，核对产品。

## 随堂检测

| 题 | 要点 | 对应课 | 易错点 |
|---|---|---|---|
| 1 | 红磷燃烧实验中气球的作用 | 1 | 缓冲气压、防止塞子冲开，不是“收集白烟” |
| 2 | 质量守恒定律的“参加反应” | 2 | 没参加反应的物质不算 |
| 3 | 敞口烧杯里碳酸钠和盐酸反应后变轻 | 3 | 不是不守恒，是二氧化碳跑掉了 |
| 4 | 镁条燃烧后质量变大 | 3 | 生成物里多了氧气的质量 |
| 5 | 化学反应前后一定不变的是 | 4 | 分子的种类、数目可能变；原子不变 |
| 6 | C + O₂ = CO₂ 的读法 | 5 | 不能读成“碳加氧气等于二氧化碳” |
| 7 | 配平时能改的是什么 | 6 | 只改系数，不改化学式 |
| 8 | 计算的格式与比例 | 7 | 相对质量要乘系数；已知量带单位 |
| 9 | 综合：密闭容器里各物质质量变化的表格 | 1、3 | 增加的是生成物，减少的是反应物 |

## 画面上的约定

- 天平的偏转是示意：差 0.5 g 以上偏到头；反应前后读数取一位小数，偏转按两位小数的质量差算。
- 分子模型的大小、键长按比例画大，原子配色：H 白、O 红、C 黑、P 橙、Fe 褐、Ca 绿灰。界面写“示意”。
- 燃烧炉的投料量、石灰窑的产量是为了算得清楚取的整数，按纯物质算。
- 反应、冷却、煅烧的过程都加快了。

## 和规格卡原文的出入

- 第 4 课不放在中控室，放在化验室第 4 格：水电解器是化验台上的器材；分子模型摆在旁边的黑色展台上。镜头和前三课不同（对着展台，低机位）。
- 第 3 课三件事用一组分段选择切换（敞口烧杯 / 镁条 / 密闭锥形瓶），主操作区仍是三个按钮。
- 拓展课选了钢丝棉燃烧和石灰窑的物料衡算两个小实验；没有做拉瓦锡的实验（史料数据拿不准，见待核实）。
- 第 2 课最后一步是“再看天平”：锥形瓶一直在左盘上，放铁钉也在盘上做，砝码不动，反应完再看指针。
- 第 4 课：氢气燃烧这一步，用水电解器负极管里收集的氢气，打开活塞点燃（淡蓝色火焰），再看分子模型。
- 第 5 课：燃烧炉的投料量按质量比每份取 1 kg（12 kg、32 kg → 44 kg）；分子模型摆在燃烧炉右上方。三种读法各一个按钮，没有先后限制，提示语按任务顺序引导。
- 第 7 课：卡车过汽车衡称出 10.0 t 后开走（示意送到上料斜桥），料车沿斜桥上窑顶，出灰称量斗称出 5.6 t。
- 场景：石灰窑区放在中控室以东（x 约 180–350）；碳化塔只作远景，高度压低成约 17 m（示意），免得挡住窑区。
