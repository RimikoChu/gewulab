# 水循环实验室 · 规格卡 v0.1

状态：九个课次（1–7、拓展、随堂检测）全部做完（2026-11-18），待验收。关联议题 #40。

## 总览

- **一句话**：学生跟着一滴水，从海洋出发走遍一个流域，弄懂水循环有哪些环节、三种循环怎么分、水量为什么是平衡的，以及修水库、铺水泥地这些事改变了哪一环。
- **教材位置**：地理，高中。必修第一册“地球上的水”一章里的“水循环”一节。准确的版本和节号见“待核实事项”。
- **主线**：同一个流域里的一滴水：它在哪、往哪去、人把它的路改成了什么样。
- **场景**：一个从海洋到雪山的流域，做成一块切开的地块：左边是海，中间是平原和城市，右边是山地、森林和雪峰，一条河从雪山流到海；靠近镜头的一面是剖面，能看到地下的含水层。换课时镜头在流域里飞。
- **取值约定**：水体的比例、全球水量平衡、更新周期用通行的全球水文数据（希克洛曼诺夫的估算）；径流系数、水库调节、洪峰是简化模型，只用来比较大小。
- **和同类产品的区别**：同类产品多是一张会动的水循环示意图。这里每个环节要学生自己打开、自己记数，人类活动的影响是改了条件比出来的。

## 共用的计算核心

| 函数 | 输入 | 输出 | 依据 |
|---|---|---|---|
| 水体的比例 | 哪种水体 | 占全球水量的百分比、占淡水的百分比 | 全球水文数据 |
| 一种循环包含哪些环节 | 循环的类型 | 环节的列表；能不能更新陆地水 | 教材 |
| 径流和下渗 | 降雨量、地面类型 | 地表径流 = 降雨量 × 径流系数；其余算下渗（短时间内不计蒸发） | 简化模型。径流系数取：林地 0.2、草地 0.3、裸地 0.5、硬化地面 0.9 |
| 水库调节后的流量 | 各月天然流量 | 调节后 = 年平均 + 0.4 ×（天然 − 年平均） | 简化模型：水库削掉六成的丰枯差 |
| 一场暴雨的洪水过程 | 城市的状况 | 各时刻的流量；洪峰大小和出现的时间 | 简化模型：洪峰和径流系数成正比；地面越硬，汇流越快，洪峰来得越早 |
| 水量平衡 | — | 海洋：蒸发 − 降水；陆地：降水 − 蒸发；两者相等，等于入海径流 | 全球水文数据 |

## 拓展课

| 专题 | 一句话 | 学生的核心动作 |
|---|---|---|
| 哪种水换得最快 | 不同水体更新一遍要的时间差得很远：河水十几天，深层地下水上千年 | 按“排一排”，看六种水体按更新周期排队 |
| 把水调到缺水的地方 | 跨流域调水改变的是地表径流的空间分布 | 按“开闸”，看一条引水渠把水送到另一个流域 |
| 砍掉山上的森林 | 林地变裸地，下渗减少，地表径流增加，河水暴涨暴落 | 按“砍掉森林”再下同样的雨，比较径流 |

## 随堂检测

九道题：水体比例、最多的淡水、环节的名称、海陆间循环的意义、内流区的循环类型、植被对下渗的影响、水库影响哪个环节、城市硬化的后果、水量平衡。
