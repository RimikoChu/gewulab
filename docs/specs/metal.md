状态：九个课次（1–7、拓展、随堂检测）做完（2026-11-24），每课自动演示带讲解能走到结论条，待验收。关联议题 #21。

## 总览

- **一句话**：学生在一座钢铁厂里，先在厂里的化验室用试管、烧杯、酒精灯把几种金属和氧气、酸、盐溶液逐一试一遍，排出金属活动性顺序；再看实验室里一氧化碳怎样把氧化铁还原成铁，然后到高炉出铁场看真正的炼铁；最后回到化验室弄清铁为什么会生锈、怎样防锈。拓展课到轧钢车间看钢坯轧成钢板。
- **教材位置**：化学，初中。人教版九年级下册“金属和金属材料”单元：金属材料（金属的物理性质、合金）、金属的化学性质（与氧气、与稀盐酸稀硫酸、与盐溶液的反应，金属活动性顺序，置换反应）、金属资源的利用和保护（铁的冶炼、铁的锈蚀和防护）。准确的单元号、课题名见“待核实事项”。
- **主线**：铁。第 1 课认识金属（铁钉、铜丝、铝箔），第 2–5 课比较几种金属“活泼”的程度，排出铁在活动性顺序里的位置；第 6 课把铁从铁矿石里炼出来；第 7 课让铁钉生锈又把它保护起来；拓展课把铁变成钢、轧成钢板。
- **场景**：一座钢铁厂（议题建议，保留）。理由：钢铁厂本来就有化验室（化验原料和成品），台上是试管、烧杯、酒精灯；高炉出铁场能直接看到铁水和炉渣从出铁口、出渣口流出来，炉顶有皮带把铁矿石、焦炭、石灰石送上去，热风炉把热风鼓进炉缸；轧钢车间里红热的钢坯被轧机一道道压薄，正好接上“生铁和钢”。
- **取值约定**：场景里 1 m 画成 6 个单位（`M = 6`），化验台台面高 85 cm。相对原子质量：H 1、C 12、O 16、Mg 24、Al 27、S 32、Cl 35.5、Fe 56、Cu 64、Zn 65、Ag 108（教材附录的取值）。质量用 g（工业上用 t），保留两位小数；工业计算的结果保留一位小数。
- **和同类产品的区别**：四支试管里的冒泡快慢、铁丝上析出铜的厚度、溶液颜色的深浅都随时间连续变化；活动性顺序表是学生用前几课的结果自己排出来的，排好以后立刻拿来判断三个新反应；第 6 课先在化验台上做一氧化碳还原氧化铁（先通气后加热、红棕色变黑、石灰水变浑浊、尾气点燃），再飞到同一座厂里的高炉，看到原料、热风、铁水、炉渣各从哪里进出；锈蚀实验的三支试管按天数推进，生锈的位置在水面附近。

## 第 1 课 金属的物理性质

化验台第 1 格。四件小事：铜丝接进电路，小灯泡亮；加热铜棒的一端，另一端粘着的蜡粒一颗颗掉下来；小锤敲铝块，铝块被敲扁不碎；黄铜片和铜片互相刻画，铜片上留下划痕。

| 项目 | 内容 |
|---|---|
| 知识点 | 金属有光泽，有良好的导电性、导热性和延展性；合金的硬度一般比组成它的纯金属大 |
| 一句概念 | 金属能导电导热、能延展；合金更硬 |
| 核心动作 | 一个主按钮，按顺序做四件事：接通电路、点燃酒精灯、锤打铝块、互相刻画 |
| 看到的现象 | 灯泡亮；蜡粒从靠近火焰的一头开始依次掉落；铝块变扁变宽；铜片上有一道划痕，黄铜片上几乎没有 |
| 读数 | 面板上教材数据表里的导电性：银 100、铜 99、金 74、铝 61、铁 17；硬度：铁 4–5、铜 2.5–3、铝 2–2.9 |
| 真实锚点 | 电线用铜和铝做，炊具用铁和铝做，导线外面包绝缘皮 |
| 对应小测 | 第 1 题：黄铜片和铜片互相刻画（合金更硬） |

## 第 2 课 金属和氧气

化验台第 2 格的通风橱里。用坩埚钳夹着金属，在酒精灯上加热。

| 项目 | 内容 |
|---|---|
| 知识点 | 镁、铝在常温下就能和氧气反应；铜在加热时能和氧气反应；金即使在高温时也不和氧气反应。铝表面生成一层致密的氧化铝薄膜，阻止里面的铝进一步氧化 |
| 一句概念 | 越活泼的金属，越容易和氧气反应 |
| 核心动作 | 分段选择换金属（镁条、铝箔、铜丝、金丝），按“夹住加热” |
| 看到的现象 | 镁条剧烈燃烧，发出耀眼的白光，生成白色固体；铝箔里的铝熔化了却不滴落，被外面的氧化膜兜住；铜丝表面变黑；金丝烧红了，冷下来还是金黄色 |
| 读数 | 0.24 g 镁条完全燃烧生成 0.40 g 氧化镁 |
| 真实锚点 | “真金不怕火炼”；铝制品耐腐蚀 |
| 对应小测 | 第 2 题：铝比铁活泼，为什么铝制品更耐腐蚀 |

## 第 3 课 金属和酸

化验台第 3 格。试管架上四支试管各盛约 3 mL 稀盐酸，依次放进镁条、锌粒、铁片、铜片。

| 项目 | 内容 |
|---|---|
| 知识点 | 镁、锌、铁能和稀盐酸反应放出氢气，镁最剧烈，锌次之，铁较慢，铁和盐酸反应后溶液变浅绿色；铜不反应。氢气能燃烧，产生淡蓝色火焰 |
| 一句概念 | 能和酸反应放出氢气的金属更活泼 |
| 核心动作 | 放入金属；等一会儿看冒泡；收集锌那支试管的气体点燃 |
| 看到的现象 | 镁那支气泡翻滚、镁条很快变小；锌那支持续冒泡；铁那支冒得很慢，溶液渐渐变浅绿；铜那支没有气泡。点燃收集到的气体，发出轻微的爆鸣声，有淡蓝色火焰 |
| 读数 | 6.5 g 锌和足量稀盐酸反应生成 0.2 g 氢气；等质量（1 g）的镁、锌、铁生成的氢气：0.08 g、0.03 g、0.04 g |
| 真实锚点 | 实验室用锌和稀硫酸制氢气 |
| 对应小测 | 第 3 题：冒泡快慢说明活动性，等质量金属生成氢气的多少不说明活动性 |

## 第 4 课 金属和盐溶液

化验台第 4 格。三支试管：硫酸铜溶液（蓝色）、硝酸银溶液（无色）、硫酸铝溶液（无色）。分段选择换一组，按“放入金属丝”，放置一会儿。

| 项目 | 内容 |
|---|---|
| 知识点 | 铁能把铜从硫酸铜溶液里置换出来，铜能把银从硝酸银溶液里置换出来，铜不能置换出硫酸铝溶液里的铝。活动性：铁 > 铜 > 银，铝 > 铜 |
| 一句概念 | 强的金属能把弱的从它的盐溶液里换出来 |
| 核心动作 | 选一组，放入金属丝，看现象 |
| 看到的现象 | 铁丝表面覆盖一层红色的铜，溶液由蓝色渐渐变成浅绿色；铜丝表面长出银白色的银，溶液渐渐变成蓝色；铜丝放进硫酸铝溶液，没有变化 |
| 读数 | 56 g 铁置换出 64 g 铜（固体质量增加）；64 g 铜置换出 216 g 银 |
| 真实锚点 | 古代“曾青得铁则化为铜”（湿法炼铜） |
| 对应小测 | 第 4 题：铁和硫酸铜反应后溶液的颜色 |

## 第 6 课 铁的冶炼

前半在化验台第 6 格：硬质玻璃管里放 1.60 g 氧化铁粉末，一端接一氧化碳，另一端接盛澄清石灰水的试管，石灰水后面的导管口放一盏点着的酒精灯处理尾气。后半飞到高炉出铁场。

| 项目 | 内容 |
|---|---|
| 知识点 | Fe₂O₃ + 3CO =高温 2Fe + 3CO₂；先通一氧化碳再加热（排净空气，防止爆炸），实验结束先停止加热，继续通一氧化碳到玻璃管冷却（防止铁又被氧化）；尾气要点燃或收集；高炉的原料是铁矿石、焦炭、石灰石和空气，从炉顶加入原料，从下部鼓入热空气，产物生铁从出铁口放出，炉渣从出渣口放出 |
| 一句概念 | 一氧化碳把铁从氧化铁里还原出来 |
| 核心动作 | 通一氧化碳 → 点燃酒精喷灯加热 → 停止加热、继续通气到冷却 → 去高炉 → 出铁 |
| 看到的现象 | 红棕色粉末逐渐变黑，石灰水变浑浊，导管口的尾气燃烧（蓝色火焰）；高炉出铁口打开，铁水沿铁沟流出发出亮光，在撇渣器处炉渣浮在上面被分到渣沟，铁水流进下面的铁水罐车 |
| 读数 | 玻璃管里固体 1.60 g → 1.12 g；1000 t 含氧化铁 80% 的赤铁矿，理论上能炼出含铁 96% 的生铁 583.3 t |
| 真实锚点 | 高炉炼铁 |
| 对应小测 | 第 7 题：先通一氧化碳再加热的原因 |

任务清单
- [ ] 先通入一氧化碳
- [ ] 加热，看粉末和石灰水
- [ ] 停止加热，继续通气到冷却
- [ ] 到高炉打开出铁口

数据

| 条件 | 读数 | 来历 |
|---|---|---|
| 1.60 g Fe₂O₃ | 1.12 g Fe | 160 → 112 |
| 1000 t 矿石、80%、生铁含铁 96% | 583.3 t | 1000×80%×112/160÷96% |

画面上的约定：高炉按一座中型高炉的大致比例搭（炉缸直径约 8 m，炉体约 28 m 高），热风炉三座，都不是某一座真高炉。出铁的过程加快。

## 第 7 课 铁的锈蚀和防护

化验台第 7 格，试管架上三支试管各放一根光亮的铁钉：A 一半浸在水里（接触水和空气）；B 浸没在煮沸过的蒸馏水里，水面上一层植物油（只接触水）；C 管里放干燥剂（氯化钙），塞紧橡胶塞（只接触干燥的空气）。

| 项目 | 内容 |
|---|---|
| 知识点 | 铁生锈是铁和氧气、水等发生反应；防锈的原理是隔绝氧气和水：刷漆、涂油、镀一层耐腐蚀的金属、制成不锈钢；铁锈疏松，不能阻止里面的铁继续生锈 |
| 一句概念 | 铁同时接触水和氧气才会生锈 |
| 核心动作 | 放置一周 → 看哪支生锈 → 选一种防护办法给新铁钉做防护 → 再按 A 的条件放置一周 |
| 看到的现象 | A 的铁钉在水面附近生出红褐色的锈；B、C 仍然光亮；做过防护的铁钉放一周不生锈 |
| 读数 | 天数 0 → 7 |
| 真实锚点 | 自行车：车架刷漆、链条涂油、车把镀铬 |
| 对应小测 | 第 8 题：铁生锈的条件 |

任务清单
- [ ] 三支试管放置一周
- [ ] 取出铁钉，找出生锈的那一支
- [ ] 给新铁钉刷漆、涂油或镀锌
- [ ] 放进 D 里再放置一周

- 议题建议的七课没有调整。拓展课只做了轧钢线一件事（加生铁和钢的比较），金属回收没做。
