# 内容结构

站点按"学科 → 实验室 → 课 → 小测"四层组织。实验室是基本单位，对应课本的一个单元。

## 层级

| 层级 | 例子 | 规则 |
|---|---|---|
| 学科 | 物理、化学、生物、地理、数学 | 首页按学科分栏 |
| 实验室 | 浮力、地震 | 对应课本一个单元；有自己的封面、说明、知识点 |
| 课 | 阿基米德原理、沉还是浮 | 一个实验室一般七课基础课，每课一个知识点；另有一节拓展课和一节随堂检测，共九个课次 |
| 小测 | 每个实验室的最后一节 | 每课至少对应一道题，另加一两道迁移题 |
| 拓展课 | 太空里浮力消失了、冰山的九成在水下 | 课本之外的真实场景，用的还是这一章的规律；每个实验室一节，里面可以有两三个专题，标"拓展"，小测不考 |

每个实验室还有两个属性：

- **学段**：初中 / 高中
- **教材位置**：版本、册、章（先按人教版写，其他版本以后补）

## 基础课和拓展课

- **基础课**：严格对应教材，实验和数据与课本一致，老师可以照着上课。这是每个实验室的主体，必须先做完。
- **拓展课**：把同样的规律放到课本之外的大场景里，负责"酷"和"好奇心"。可以选讲。
- 先基础后拓展：基础课全部通过验收后，再做拓展课。
